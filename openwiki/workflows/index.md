# Files

- [Weekly Changelog Publication](changelog-publication.md) - Human-reviewed weekly proposal workflow for LangSmith Cloud and Fleet changelogs. It collects merged changes, uses structured model output with conservative rollout and public-content gates, and opens a review PR rather than publishing automatically.
- [Runnable Code Samples and Snippet Generation](code-sample-lifecycle.md) - Explains how runnable documentation sources are executed, extracted, rendered as committed MDX, optionally linked to public LangSmith traces, and operated through CI.
- [Maintain the LangSmith Egress IP Inventory](egress-ip-inventory.md) - Maintain the canonical public egress-address inventory, its deterministic version, and the generated allowlist tables for LangSmith SaaS and LangSmith Deployment. Use this workflow to make safe inventory changes, validate generated content, and confirm publication of the machine-readable artifact.
- [Integration Listing Automation](integration-listing-automation.md) - How integration metadata becomes hosted guides, external listings, generated download tables, and the Python provider overview. Covers ownership boundaries, scheduled regeneration, URL safety validation, and the checks required for safe changes.
- [LangSmith Agent and Observability Documentation Changes](langsmith-agent-documentation.md) - Maintain the LangSmith Agent Registry, agent trace routing, OpenTelemetry endpoint guidance, runnable language samples, and Managed Deep Agents local-development documentation from their current authored sources.
- [LangSmith OpenAPI Refresh](langsmith-openapi-refresh.md) - Documents the reviewed daily refresh that converts the LangSmith platform OpenAPI source into the committed Mintlify input for the LangSmith REST reference. Covers processor policy, constrained ingestion, PR lifecycle, validation limits, and the separate Agent Server and Control Plane inputs.
- [Local Documentation Development](local-development.md) - Set up the repository toolchain, turn authored source changes into a local Mintlify preview, and choose proportionate local and CI validation. Understand watcher limits, generated-output boundaries, credentialed sample checks, and worktree setup.
- [Documentation Release Watch](release-watch.md) - Managed Deep Agent workflow that researches eligible product releases and prepares evidence-backed, one-feature documentation handoffs. It covers release selection, guarded Linear and draft-PR delivery, recovery, and label-gated GitHub-to-Linear lifecycle synchronization.
- [Maintaining Versioned Content](versioned-content.md) - Safely change shared and language-owned documentation by coordinating source ownership, conditional rendering, generated routes, docs.json navigation, redirects, and link validation.
