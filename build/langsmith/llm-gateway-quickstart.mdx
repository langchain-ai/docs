The LLM Gateway lets you call models across configured providers through one standard endpoint with one LangSmith API key.

<Note>
**Beta:** The LLM Gateway is in [beta](/langsmith/release-stages).
</Note>

## Prerequisites

Before you start, confirm that:

- Your [Organization admin](/langsmith/rbac#organization-admin) has enabled the LLM Gateway. For bring-your-own-key models, the admin must also add the provider API key to workspace secrets. See [Admin setup](/langsmith/llm-gateway-admin-setup).
- You have a workspace-scoped [LangSmith API key](/langsmith/create-account-api-key) attached to a role with `gateway:invoke` and `workspaces:read` [permissions](/langsmith/organization-workspace-operations). Ask your organization admin if you are unsure.

## Make a call

<Tabs>

<Tab title="Chat completions">

OpenAI-compatible Chat Completions endpoint (`/v1/chat/completions`). Use this with the OpenAI SDK or any OpenAI-compatible client.

<CodeGroup>

```bash cURL
export LANGSMITH_API_KEY="lsv2_..."

curl https://gateway.smith.langchain.com/v1/chat/completions \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"anthropic/claude-opus-5","messages":[{"role":"user","content":"Explain what an LLM gateway does in one sentence."}]}'
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.smith.langchain.com/v1",
    api_key=os.environ["LANGSMITH_API_KEY"],
)
response = client.chat.completions.create(
    model="anthropic/claude-opus-5",
    messages=[{"role": "user", "content": "Explain what an LLM gateway does in one sentence."}],
)
print(response.choices[0].message.content)
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.smith.langchain.com/v1",
  apiKey: process.env.LANGSMITH_API_KEY,
});
const response = await client.chat.completions.create({
  model: "anthropic/claude-opus-5",
  messages: [{ role: "user", content: "Explain what an LLM gateway does in one sentence." }],
});
console.log(response.choices[0].message.content);
```

</CodeGroup>

</Tab>

<Tab title="Messages">

Anthropic Messages API format (`/v1/messages`). Point the Anthropic SDK at the gateway root — no `/v1` suffix, the SDK appends its own path.

<CodeGroup>

```bash cURL
export LANGSMITH_API_KEY="lsv2_..."

curl https://gateway.smith.langchain.com/v1/messages \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Anthropic-Version: 2023-06-01" \
    -H "Content-Type: application/json" \
    -d '{"model":"anthropic/claude-opus-5","max_tokens":1024,"messages":[{"role":"user","content":"Explain what an LLM gateway does in one sentence."}]}'
```

```python Python
import os
import anthropic

client = anthropic.Anthropic(
    base_url="https://gateway.smith.langchain.com",
    api_key=os.environ["LANGSMITH_API_KEY"],
)
message = client.messages.create(
    model="anthropic/claude-opus-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain what an LLM gateway does in one sentence."}],
)
print(message.content[0].text)
```

```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://gateway.smith.langchain.com",
  apiKey: process.env.LANGSMITH_API_KEY,
});
const message = await client.messages.create({
  model: "anthropic/claude-opus-5",
  max_tokens: 1024,
  messages: [{ role: "user", content: "Explain what an LLM gateway does in one sentence." }],
});
console.log(message.content[0].text);
```

</CodeGroup>

<Tab title="Deep Agents">

Set `LANGSMITH_GATEWAY=true` to route all Deep Agents calls through the gateway automatically.

<CodeGroup>

```python Python
# pip install "deepagents>=0.1.0"
# export LANGSMITH_API_KEY="lsv2_..."
# export LANGSMITH_GATEWAY="true"
from deepagents import create_deep_agent

agent = create_deep_agent(model="anthropic:claude-opus-5")
result = agent.invoke({"messages": [{"role": "user", "content": "Explain what an LLM gateway does in one sentence."}]})
print(result["messages"][-1].content)
```

```typescript TypeScript
// npm install deepagents
// export LANGSMITH_API_KEY="lsv2_..."
// export LANGSMITH_GATEWAY="true"
import { createDeepAgent } from "deepagents";

const agent = createDeepAgent({ model: "anthropic:claude-opus-5" });
const result = await agent.invoke({
  messages: [{ role: "user", content: "Explain what an LLM gateway does in one sentence." }],
});
console.log(result.messages[result.messages.length - 1].content);
```

</CodeGroup>

<Tip>
`LANGSMITH_GATEWAY` is a global setting — it routes all agent calls through the gateway. To route a specific agent instance through the gateway instead, use the `langsmith:` model prefix without setting `LANGSMITH_GATEWAY`:

```python
agent = create_deep_agent(model="langsmith:anthropic/claude-opus-5")
```
</Tip>

## View your trace

Open the [LangSmith UI](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=langsmith-llm-gateway-quickstart) and go to the tracing project named `gateway` or `gateway-<short_api_key>-<api_key_id>` in your workspace. You should see a trace for the call you just made.

## Set a spend policy (optional)

Go to **LLM Gateway** in LangSmith to create a spend policy. For example, set a daily $10 cap on your API key. When the cap is reached, the gateway returns a `402` with the message: `"Request blocked by gateway policies: R&D Spend Cap"`.

See [Spend policies](/langsmith/llm-gateway-spend-policies) for the full guide.

## Using LangChain SDKs

Set `LANGSMITH_GATEWAY` to send all supported LangChain and Deep Agents **chat model** calls through the gateway — no `base_url` or `api_key` wiring needed per client.

```bash
export LANGSMITH_API_KEY="lsv2_..."
export LANGSMITH_GATEWAY="true"                                   # US gateway (default)
# export LANGSMITH_GATEWAY="https://eu.gateway.smith.langchain.com"  # EU
# export LANGSMITH_GATEWAY="https://<data_plane_host>/gateway"       # BYOC
```

<Warning>
When setting `LANGSMITH_GATEWAY` to a URL, use only the base URL with no path suffix. The SDK appends the provider-specific path automatically — a trailing `/v1` causes a doubled path and request failures.
</Warning>

<Note>
Only **chat models** are affected. Non-chat integrations such as `OpenAIEmbeddings` continue to use their normal provider endpoints.
</Note>

<Note>
To use a different API key for gateway calls, set `LANGSMITH_GATEWAY_API_KEY` (workspace-scoped key with `gateway:invoke` permission). By default, `LANGSMITH_API_KEY` is used.
</Note>

| Provider | Python | TypeScript |
|---|---|---|
| [Anthropic](/oss/python/integrations/chat/anthropic) | `langchain-anthropic >= 1.5.1` | [`@langchain/anthropic >= 1.5.4`](/oss/javascript/integrations/chat/anthropic) |
| [Baseten](/oss/python/integrations/chat/baseten) | `langchain-baseten >= 0.2.3` | — |
| [Fireworks](/oss/python/integrations/chat/fireworks) | `langchain-fireworks >= 1.5.1` | [`@langchain/fireworks >= 0.2.7`](/oss/javascript/integrations/chat/fireworks) |
| [Google Gemini](/oss/python/integrations/chat/google_generative_ai) | `langchain-google-genai >= 4.3.2` | — |
| [OpenAI](/oss/python/integrations/chat/openai) | `langchain-openai >= 1.4.1` | [`@langchain/openai >= 1.5.7`](/oss/javascript/integrations/chat/openai) |

### Override precedence

`LANGSMITH_GATEWAY` is the lowest-priority routing signal — anything more specific overrides it:

| Setting | Overrides gateway? |
|---|---|
| Per-client `base_url=` / `configuration.baseURL` | Yes — always |
| Provider env var (`OPENAI_API_BASE` / `OPENAI_BASE_URL`) | Yes |
| `LANGSMITH_GATEWAY` | — (this is the gateway setting) |

For the API key: `LANGSMITH_GATEWAY_API_KEY` takes precedence over `OPENAI_API_KEY` when the gateway URL is in use. If neither is set, no key is sent.

<Note>
TypeScript key resolution differs from Python in some edge cases. If you observe unexpected routing, verify against `@langchain/openai` directly.
</Note>

## Gateway URLs

### Regional instances

| Instance | Base URL |
|---|---|
| US (default) | `https://gateway.smith.langchain.com` |
| EU | `https://eu.gateway.smith.langchain.com` |
| BYOC / self-hosted | `https://<data_plane_host>/gateway` |

### Unified endpoint vs direct provider routes

Using `https://gateway.smith.langchain.com` as the example base URL:

| Style | Full URL | Notes |
|---|---|---|
| Unified `/v1` (recommended) | `https://gateway.smith.langchain.com/v1/chat/completions` | Accepts Chat Completions, Messages, and Responses formats; **translates between formats** as needed. [API formats reference](/langsmith/llm-gateway-api-formats). |
| Unified `/v1` | `https://gateway.smith.langchain.com/v1/messages` | Anthropic Messages format via the unified endpoint. |
| Unified `/v1` | `https://gateway.smith.langchain.com/v1/responses` | OpenAI Responses format via the unified endpoint. |
| Direct provider route | `https://gateway.smith.langchain.com` | No `/v1` suffix — the SDK appends its own path. **No format translation.** [Direct model access reference](/langsmith/llm-gateway-direct-model-access). |
