This guide prepares an Azure subscription for a LangSmith BYOC data plane. Complete Azure setup with the LangChain team. For AWS, use [BYOC onboarding](/langsmith/byoc-onboarding-aws).

## Prerequisites

- **Enterprise plan**: BYOC requires the [Enterprise plan](https://www.langchain.com/pricing).
- **Azure subscription**: Choose the subscription for the data plane.
- **Azure administrator**: Involve an administrator who can configure access in your Microsoft Entra tenant and subscription.
- **Region**: Confirm the region and capacity requirements with the LangChain team.

To prepare the data plane:

<Steps>
  <Step title="Enable BYOC on your organization">
    Create an organization at [azure.smith.langchain.com](https://azure.smith.langchain.com), or use an existing organization.

    Send your organization ID to the LangChain team to enable BYOC.
  </Step>
  <Step title="Prepare Azure access">
    Use the [Azure BYOC Terraform module]() to prepare:

    - A dedicated resource group for the data plane.
    - An Azure Key Vault with Azure RBAC for access control.
    - Access permissions for the LangSmith service principal in your Microsoft Entra tenant.

    Keep the resource group ID and the Microsoft Entra tenant ID for the next step.
  </Step>
  <Step title="Supply the data plane configuration">
    Give the LangChain team these values:

    - **Name**: The data plane name.
    - **Region**: The Azure region for the data plane.
    - **Microsoft Entra tenant ID**: The tenant that contains the subscription.
    - **Resource group ID**: The full Azure resource ID of the prepared group, which includes the subscription ID.
    - **VNet address range**: The private CIDR range for the virtual network that LangChain creates.
    - **Load balancer access**: Choose private or public ingress. The default is private.

    LangChain verifies Azure access and capacity before it provisions the data plane.
  </Step>
  <Step title="Connect to the data plane">
    Confirm the data plane API URL with the LangChain team.

    For private ingress, provide a network path from your users and applications to the data plane. Your browser must reach the API URL to use its workspaces.
  </Step>
</Steps>

## Create workspaces

After the data plane becomes active and reachable, select it when you create a workspace. See [Organizations, data planes, and workspaces](/langsmith/byoc-usage#organizations-data-planes-and-workspaces).
