The LLM Gateway **Usage** tab shows how much LLM cost a [workspace](/langsmith/administration-overview#workspaces) has accrued through the gateway. Use it to compare spend over time and identify the users, API keys, models, providers, and request header values that account for that spend.

Viewing the **Usage** tab requires the `runs:read-stats` and `projects:read` [permissions](/langsmith/rbac) in the workspace, and a Plus or Enterprise [plan](/langsmith/pricing-plans).

## Open the Usage tab

To view the total cost of requests routed through the gateway for a workspace:

1. In the [LangSmith UI](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=langsmith-llm-gateway-monitoring), select the workspace from the workspace selector at the top left.
1. Select **LLM Gateway** in the left navigation.
1. Select **Usage**.

## Set the time range and granularity

Use the controls to define the period covered by every summary, chart, and table on the page:

- **Time range**: Select a preset range from one day to one year, or choose custom dates. Dates and time buckets use UTC.
- **Aggregation granularity**: Group spend into hourly, daily, or weekly buckets. The available options depend on the length of the selected time range.
- **Previous or next period**: Shift backward or forward by one period of the same length to compare adjacent time ranges.

## Break down and filter spend

Select **Breakdown by** to group spend across one of the following dimensions:

- **User**: Attributes spend to the user associated with the personal access token that invoked the gateway. Requests made with a workspace or organization-scoped service key appear as **Unaffiliated with any user**.
- **API key**: Attributes spend to the LangSmith API key that invoked the gateway.
- **Model**: Attributes spend to the model used for the request.
- **Model Provider**: Attributes spend to the provider that served the request, such as OpenAI or Anthropic.
- **Custom Dimension**: Attributes spend to the value of a request header that you name. See [Group spend by custom header](#group-spend-by-custom-header).

After you select a dimension, use the adjacent filter to show only the entities you select. To remove the filter, select the **All** option at the bottom of the list.

## Interpret the spend summary

The cards above the chart summarize usage for the selected workspace, time range, dimension, and filters:

- **Total Spend**: The sum of gateway spend over the selected time range.
- **Hourly, Daily, or Weekly Avg**: Total spend divided by the number of time buckets in the selected range.
- **Hourly, Daily, or Weekly Avg / dimension**: Average spend per selected entity for each time bucket. When you have not applied an entity filter, this metric uses the top 10 entities by spend.
- **Total Tokens**: The number of tokens in requests routed through the gateway over the selected time range.

## Analyze the chart and table

The stacked bar chart shows how each entity contributed to spend in every time bucket. Hover over a bar to view the bucket total and the contribution from each visible entity. When no filter is applied, the chart displays the six highest-spend entities as individual series and combines the remaining entities into **Other**.

The table summarizes the same selection with one row per visible entity. Use it to compare:

- **Hourly, Daily, or Weekly Avg**: The entity's total spend divided by the number of time buckets.
- **Spend Share**: The percentage of spend attributed to the entity.
- **Total Spend**: The entity's total spend over the selected time range.

To drill down, select a row to open a detailed view of that entity. Select a dimension from **Group by** to break its spend down further, for example an API key's spend by user. The detailed view has its own filter, time range, and granularity controls, which do not change the controls on the main view.

<Tip>
In the detailed view for a user, an API key, or a custom header value, click **View traces** to open the **Traces** tab filtered to that entity's requests over the detailed view's time range. For what each trace records, see [View LLM Gateway traces](/langsmith/llm-gateway-traces).
</Tip>

## Group spend by custom header

The **Custom Dimension** breakdown groups spend by the value of an `X-Gateway-*` request header that your application sends, such as `X-Gateway-Customer-Id`. Use it to compare spend across end customers, teams, or services. For how to send these headers, see [Header-based policies](/langsmith/llm-gateway-header-policies).

Select **Custom Dimension** from **Breakdown by**, then enter the header name. The `X-Gateway-` prefix is optional. Requests without the header appear under **No value**. **Custom Dimension** is also available from **Group by** in an API key's detailed view.
