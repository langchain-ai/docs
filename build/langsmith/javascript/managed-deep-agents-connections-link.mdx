[Link](https://link.com) is Stripe's consumer wallet. Run
[Link CLI](https://docs.stripe.com/agentic-commerce/link-cli) in a Managed Deep Agents
[sandbox](/langsmith/javascript/managed-deep-agents-sandboxes) to check payment methods and request payment approval.
A [connection](/langsmith/javascript/managed-deep-agents-connections) stores each user's session.
The example's helpers manage sign-in, session renewal, and permitted wallet operations.
The [sandbox auth proxy](/langsmith/sandbox-auth-proxy) supplies authorization headers for those operations.
