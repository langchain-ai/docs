[Claude Cowork](https://claude.com/docs/cowork/guide/plugins) runs the same plugins as Claude Code, so the [LangSmith tracing plugin for Claude Code](/langsmith/trace-claude-code) also traces Cowork tasks. Each task turn becomes a trace with its model calls, tool calls, skill calls, and subagent runs, grouped into a thread per task.

## Prerequisites

Before setting up tracing, ensure you have:

- Access to Claude Cowork in the Claude desktop app.
- A [LangSmith CLI sign-in](/langsmith/trace-claude-code#sign-in-with-the-langsmith-cli) or a [LangSmith API key](/langsmith/create-account-api-key).

## Add the plugin

Cowork installs plugins from your claude.ai account. Add the LangSmith repository as a marketplace, then install the tracing plugin from it:

1. Go to **Customize** > **Plugins** on claude.ai.
2. Add the `langchain-ai/langsmith-claude-code-plugins` repository as a marketplace.
3. Install the `langsmith-tracing` plugin from that marketplace.

The plugin loads into the next Cowork task you start.

## Turn on tracing

Cowork reads the same settings file as Claude Code. To turn on tracing, add the following to `~/.claude/langsmith.json`:

```json
{ "enabled": true, "project": "claude-cowork" }
```

If you use an API key instead of the CLI sign-in, add it to the same file as `api_key`. For all other settings, see [Trace Claude Code applications](/langsmith/trace-claude-code).

## View traces in LangSmith

Start a Cowork task, then open the project you configured. Each turn appears as a trace, and the turns from one task share a `thread_id` in the **Threads** tab.

Skill calls record which skill ran, so you can filter traces by skill and count how often each one is used.

- Tracing has been tested in desktop Cowork tasks only. Cloud Cowork sessions are not yet tested.
