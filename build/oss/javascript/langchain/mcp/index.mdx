[Model Context Protocol (MCP)](https://modelcontextprotocol.io) is an open protocol that standardizes how applications provide tools and context to language models. LangChain agents call tools defined on MCP servers through @[`MCPAdapter`], which discovers a server's tools and adapts them into LangChain tools you can pass straight to [`create_agent`](https://reference.langchain.com/javascript/langchain/index/createAgent).

<Note>
This guide assumes you're using `@langchain/mcp-adapters>=2`. If you're using an older version of `@langchain/mcp-adapters`, you can either read the pre-v1 docs or read the [migration guide](/oss/javascript/migrate/langchain-mcp-adapters).
</Note>


## Install



LangChain's mcp utilities are exported in the `@langchain/mcp-adapters` package.

<CodeGroup>
```bash npm
npm install @langchain/mcp-adapters
```

```bash pnpm
pnpm add @langchain/mcp-adapters
```

```bash yarn
yarn add @langchain/mcp-adapters
```

```bash bun
bun add @langchain/mcp-adapters
```
</CodeGroup>

## Transports



@[`MCPAdapter`] accepts a map of named server definitions. It selects the transport from each definition, so one adapter can connect to local stdio servers and remote HTTP servers at the same time:

<McpTransportsJs />

Each server definition can use one of these transports:

- **stdio**: Provide `command` and `args`. The adapter starts the command as a child process and communicates over standard input and output.
- **Streamable HTTP**: Provide `url`. This is the default transport for URL-based servers, so `transport: "http"` is optional.
- **SSE**: Provide `url` and set `transport: "sse"`. Use this transport only for legacy servers that expose an SSE endpoint.

Transport selection and protocol negotiation are separate. The optional `mode` setting controls which MCP protocol era the client accepts:

- **`"auto"`** (default): Try the current protocol and fall back when the server only supports the legacy protocol.
- **`"modern"`**: Require the current protocol and fail instead of connecting to a legacy server.
- **`"legacy"`**: Use the legacy client interface without protocol auto-negotiation.

<Note>
For new remote servers, omit both `transport` and `mode`. The adapter uses Streamable HTTP with automatic protocol negotiation. Specify these settings only when connecting to a server with known legacy requirements.
</Note>
