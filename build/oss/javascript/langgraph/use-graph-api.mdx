This section shows how to build with LangGraph's Graph API. Start with the [Graph API overview](/oss/javascript/langgraph/graph-api) for concepts, then use these guides for concrete patterns.

## Setup



Install `langgraph`:

```bash
npm install @langchain/langgraph
```


<Tip>
**Set up LangSmith for better debugging**

Sign up for [LangSmith](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-langgraph-use-graph-api) to quickly spot issues and improve the performance of your LangGraph projects. LangSmith lets you use trace data to debug, test, and monitor your LLM apps built with LangGraph—read more about how to get started in the [docs](/langsmith/observability).
</Tip>

## Guides

- [Define and update state](/oss/javascript/langgraph/graph-api-state): Schemas, reducers, messages, private state, and input/output schemas.
- [Build sequences, branches, and loops](/oss/javascript/langgraph/graph-api-control-flow): Linear steps, parallel branches, conditional routing, and cycles.
- [Use Send and Command](/oss/javascript/langgraph/graph-api-send-command): Map-reduce fan-out with `Send`, and combined state updates plus routing with `Command`.
- [Configure nodes](/oss/javascript/langgraph/graph-api-nodes): Runtime configuration, retries, timeouts, error handling, defaults, and caching.
- [Visualize your graph](/oss/javascript/langgraph/graph-api-visualize): Mermaid and PNG diagrams for debugging and documentation.
