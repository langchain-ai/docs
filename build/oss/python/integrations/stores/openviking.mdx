`OpenVikingStore` is a LangGraph [`BaseStore`](https://reference.langchain.com/python/langgraph.store/base/BaseStore) backed by OpenViking. Use it for [long-term memory](/oss/python/langgraph/stores) across threads in an OpenViking HTTP deployment.

## Overview

OpenViking is a context database for AI agents. The `langchain-openviking` package includes an `OpenVikingStore` class for storing LangGraph values as durable OpenViking content records and indexing them for query-based `search` calls.

<Note>
The examples on this page require `langchain-openviking>=0.2.0`.
</Note>

## Setup

To use `OpenVikingStore`, you need an OpenViking HTTP deployment and an API key.

### Installation

Use Python 3.10 or later. Install the integration with the `langgraph` extra:

```bash
pip install -qU "langchain-openviking[langgraph]>=0.2.0"
```

### Credentials

Set your OpenViking URL and API key:

```python
from getpass import getpass

OPENVIKING_URL = getpass("OpenViking URL: ")
OPENVIKING_API_KEY = getpass("OpenViking API key: ")
```

## Instantiation

Instantiate `OpenVikingStore` with your OpenViking HTTP connection settings:

```python
from langchain_openviking import OpenVikingStore

store = OpenVikingStore(
    url=OPENVIKING_URL,
    api_key=OPENVIKING_API_KEY,
    auth_mode="api_key",
)
```

`root_uri` defaults to `viking://~/memories/langgraph_store`. Use an OpenViking server that supports the `viking://~` home alias, which resolves to the authenticated user's space. To target a specific user, pass an explicit `viking://user/<uid>/...` URI as `root_uri`.

## Usage

Use `put` to write a JSON-serializable mapping under a namespace and key:

```python
store.put(
    ("users", "ada"),
    "preferences",
    {"color": "azure"},
)
```

Use `get` to retrieve the stored item:

```python
item = store.get(("users", "ada"), "preferences")
print(item.value)
```

Use `search` with a namespace prefix. Pass `query` for semantic search:

```python
results = store.search(("users",), query="azure", limit=3)
```

To skip semantic indexing for a value, pass `index=False` or `index=[]` to `put`. The value remains available through `get`:

```python
store.put(
    ("users", "ada"),
    "preferences",
    {"color": "azure"},
    index=[],
)
```

Use `delete` to remove a key:

```python
store.delete(("users", "ada"), "preferences")
```

When you finish using the store, close its connection:

```python
store.close()
```

In async code, use `await store.aclose()`. The store also supports `with` and `async with` for automatic cleanup. If you supply a client through `client=`, close that client yourself.
