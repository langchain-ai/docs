This page compares Deep Agents with other agent harnesses on two terminal-based coding benchmarks and one professional-work benchmark. Each frontier model, Claude Opus 5.5 (med) and GPT-6.1 Sol (med), runs in its provider's native harness, in Deep Agents, and in [Pi](https://github.com/badlogic/pi-mono), another provider-agnostic harness. The open-weight Kimi K3.1 Pro (med) has no native harness, so it runs in each of them.

Deep Agents is competitive with leading harnesses on frontier models, often at a lower cost for a comparable score. With both frontier models, Deep Agents scores within about three points of the model's native harness on every benchmark, and it costs less per task than Claude Code on all three. Deep Agents is provider-agnostic and general purpose: the same harness runs every model, on coding and non-coding work, with no custom system prompt and no benchmark-specific tuning.

## Methodology

- **Harness configuration**: Deep Agents runs `create_deep_agent` with its defaults, a local shell [backend](/oss/python/deepagents/backends) rooted at the task's working directory, and a web search tool. It sets no custom system prompt. On APEX-Agents, every harness also gets the benchmark's MCP tools for documents, files, calendar, chat, and code execution.
- **Benchmarks**: Terminal-Bench 4.0 (CPU-only dataset) and Terminal-Bench Science 0.1 for coding, and 48 tasks of APEX-Agents 1.1 (16 each in investment banking, law, and management consulting) for professional work. All run through [Harbor](https://github.com/harbor-framework/harbor) from the [Deep Agents eval workflow](https://github.com/langchain-ai/deepagents/actions/workflows/harbor.yml). Every run uses medium reasoning effort and three trials per task.
- **Score**: The fraction of a task's trials that pass, averaged across tasks. Trials that error before the verifier runs are dropped. On APEX-Agents, a GLM 5.3 judge grades each answer against the task's rubric, and a trial passes only if it meets every criterion.
- **Cost**: Estimated from each model call's token usage at the provider's list prices (Fireworks for Kimi K3.1 Pro). Each task's cost is the mean over its trials, and the plots show the median task.
- **Task sets**: A task is kept only if every harness for that model has a scored trial on it. On Terminal-Bench 4.0 that leaves 57 tasks for Opus 5.5, 60 for Sol, and 56 for Kimi K3.1 Pro. On Terminal-Bench Science, every pair uses the same 59 tasks. On APEX-Agents, 38 tasks for Opus 5.5 and 39 for Sol.
- **Error bars**: One standard error, with the task set held fixed. Score differences under about five points are within run-to-run noise.
