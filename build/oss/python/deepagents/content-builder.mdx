## Overview

This guide shows how to build a content writing agent with [Deep Agents](/oss/python/deepagents). The agent loads brand voice and skills, delegates research to a subagent, drafts blog or social content, and generates companion images.

The agent you build will:

1. Load voice and workflow rules from brand instructions and skill folders
1. Delegate web research to a specialized subagent with `web_search`
1. Draft blog or social content following the loaded skill
1. Generate cover or social images with Gemini and save files under the project directory

For the full runnable SDK project, see the [content-builder-agent](https://github.com/langchain-ai/deepagents/tree/main/examples/content-builder-agent) example.

### Key concepts

This tutorial covers:

- Brand instructions ([instructions](/langsmith/python/managed-deep-agents-instructions) on Managed Deep Agents, or [memory](/oss/python/deepagents/memory) files on the SDK) for always-on voice and research rules
- [Skills](/oss/python/deepagents/skills) for blog and social playbooks
- [Subagents](/oss/python/deepagents/subagents) for research before writing
- [Filesystem backends](/oss/python/deepagents/backends) on the SDK path for file read and write
- Custom [tools](/oss/python/langchain/tools) for search and image generation

## Prerequisites

API keys:

- Anthropic (Claude) or another chat model provider
- Google (Gemini) for image generation with `gemini-2.5-flash-image`
- [Tavily](https://www.tavily.com/) for web search (free tier)
- [LangSmith](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-deepagents-content-builder) for tracing (optional on the SDK path; required for Managed Deep Agents)

Python 3.11 or later.




## Choose your path

Start with [Managed Deep Agents](/langsmith/python/managed-deep-agents-overview) to run production agents without having to manage infrastructure. Alternatively, for maximum flexibility while using the same Deep Agents harness, use the Deep Agents SDK and host agents yourself, or run a custom [LangSmith Deployment](/langsmith/deployment).

<Steps>


### Run the agent

<Warning>
The filesystem backend can read, write, and delete files under `root_dir`. Run only in a dedicated directory and review generated content before publishing.
</Warning>

From the project directory you can invoke the agent without passing an argument or by passing the prompt as an argument:

<CodeGroup>
```bash Default wrap

```

```bash With prompt wrap

```
</CodeGroup>




With `LANGSMITH_API_KEY` set, you can inspect runs in [LangSmith](/langsmith/observability).

### Output



On success, generated artifacts are written under a system temporary directory (on macOS and Linux, typically under `/tmp/`), not next to your project files.


```text
blogs/
└── prompt-engineering/
    ├── post.md
    └── hero.png
research/
└── prompt-engineering.md
```

Paths follow the skill instructions in `SKILL.md`.
