In the [LangSmith UI](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=snippets-langsmith-set-workspace-secrets), add your model provider's API key as a workspace secret:

1. Open <Icon icon="settings" /> **Settings**. If your organization has workspaces, select **Workspace** at the top of the sidebar and pick the workspace that needs the secret. Under **Configuration**, select **Secrets**.
1. Click **+ Secret**. Under **Provider**, select your model provider, enter your API key, and click **Save**.

If you use self-hosted LangSmith, your provider is not listed, or you cannot add secrets, see [Workspace secrets](/langsmith/workspace-secrets).
