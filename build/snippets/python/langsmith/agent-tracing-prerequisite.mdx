<Note>
In an [agent-based workspace](/langsmith/agents), [create an agent](/langsmith/create-an-agent) once before sending traces. Use [agent addressing](/langsmith/log-traces-to-agent) to select its identifier and environment. If an integration only accepts project names, use the environment's [existing tracing project](/langsmith/create-an-agent#use-an-environment-project) as a compatibility option. Configuring a destination does not register an agent.
</Note>
