{feature} uses its own Fernet encryption key to encrypt secrets such as credentials and tokens. A separate key per feature allows independent rotation and limits exposure if a key is compromised. Generate a key with Python:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Store the key in a predefined Kubernetes secret under <code>{secretKey}</code> rather than setting it directly in your config file. See [Use an existing secret](/langsmith/self-host-using-an-existing-secret#parameters). To set the key inline instead, use <code>{valuesKey}.encryptionKey</code>.
