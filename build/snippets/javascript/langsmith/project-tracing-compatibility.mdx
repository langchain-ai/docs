<Note>
The configuration below uses project names. In an agent-based workspace, [create an agent](/langsmith/create-an-agent) first, then use its [existing environment project name](/langsmith/create-an-agent#use-an-environment-project). Replace example project names and overrides, including `default`, with that name. This is a compatibility flow; for SDKs and exporters that support agent addressing, use the [agent identifier and environment](/langsmith/log-traces-to-agent).
</Note>
