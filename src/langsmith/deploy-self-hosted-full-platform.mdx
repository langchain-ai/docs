In addition to the base [LangSmith](/langsmith/self-hosted) platform, you can enable the following features on LangSmith Self-hosted. Each feature has its own setup page.

| Feature | What it adds | Setup guide |
|---------|--------------|-------------|
| [LangSmith Deployment](/langsmith/deployment) | A [control plane](/langsmith/control-plane) and [data plane](/langsmith/data-plane) to deploy, scale, and manage agents and applications through the LangSmith UI. For a lightweight alternative, use [standalone servers](/langsmith/deploy-standalone-server). | [Enable LangSmith Deployment](/langsmith/self-host-deployment) |
| [Fleet](/langsmith/fleet) | Creates, deploys, and manages agents in LangSmith with no code. | [Self-host Fleet](/langsmith/fleet/self-hosted) |
| [Insights](/langsmith/insights) | Analyzes your traces to detect usage patterns, common agent behaviors, and failure modes. Shares a deployment with Engine. | [Enable Insights](/langsmith/self-host-insights) |
| [Chat](/langsmith/chat) | Answers natural language questions about your traces, threads, and prompts from inside your workspace. | [Enable Chat](/langsmith/self-host-chat) |
| [Sandboxes](/langsmith/sandboxes) | Lets users run code, expose temporary services, and create memory snapshots from LangSmith. | [Enable Sandboxes](/langsmith/self-host-sandboxes) |
| [Engine](/langsmith/engine-overview) | Finds recurring issues in a tracing project, diagnoses them against your source code, and proposes fixes. Requires Sandboxes. | [Engine on Self-hosted](/langsmith/engine-self-hosted) |

<Info>
These features require an [Enterprise](https://langchain.com/pricing) plan. [Get a demo](https://www.langchain.com/contact-sales) to learn more.
</Info>

## Prerequisites

Complete these steps before you enable LangSmith Deployment, Fleet, Insights, or Chat. Sandboxes and Engine list their own prerequisites on their setup pages.

<Steps>
  <Step title="Install the base LangSmith platform">
    Follow the [Kubernetes installation guide](/langsmith/kubernetes) to install the base LangSmith platform before continuing.
  </Step>
  <Step title="Install KEDA">
    Run the following commands to install `KEDA` on your cluster:

    ```bash
    helm repo add kedacore https://kedacore.github.io/charts
    helm upgrade --install keda kedacore/keda --namespace keda --create-namespace
    ```

    <Info>
    KEDA automatically scales the deployment system based on queue size.
    </Info>
  </Step>
  <Step title="Configure an ingress">
    Configure an ingress, gateway, or Istio for your LangSmith instance. All agents will be deployed as Kubernetes services behind this ingress. See [Set up an ingress](/langsmith/self-host-ingress). You must provide a `hostname` in your [`langsmith_config.yaml`](/langsmith/kubernetes#configure-your-helm-charts).
  </Step>
  <Step title="Verify cluster capacity">
    Ensure your cluster has available capacity for multiple deployments. A cluster autoscaler is recommended.
  </Step>
  <Step title="Verify storage">
    Ensure a valid dynamic PV provisioner or PVs are available on your cluster.

    ```bash
    kubectl get storageclass
    ```

    At least one StorageClass should have a `PROVISIONER` value (not `kubernetes.io/no-provisioner`) and be marked `(default)`, or you must configure one before proceeding.
  </Step>
  <Step title="Verify egress">
    Ensure egress to `https://beacon.langchain.com` is available. See the [egress documentation](/langsmith/self-host-egress).
  </Step>
</Steps>
