The LangSmith [prompt playground](/langsmith/prompt-engineering-concepts#prompt-playground) supports a wide range of model providers. You can select a provider, configure your preferred settings, and save these configurations to reuse across multiple prompts.

Use this page for a list of the available providers and

For details on creating and managing model configurations, refer to the [Configure prompt settings](/langsmith/managing-model-configurations) page.

## Model providers

The following model providers are available directly through their APIs:

### <Icon icon="openai" /> OpenAI

Access models from OpenAI, including GPT-4 and GPT-3.5 series models.

### <img src="/images/providers/anthropic.svg" alt="" className="inline-block h-5 w-auto align-middle" /> Anthropic

Access Claude models from Anthropic, including Claude 3 and Claude 2 series models.

### <img src="/images/providers/google-gemini-icon.svg" alt="" className="inline-block h-5 w-auto align-middle" /> Google Gemini

Access Gemini models directly from Google.

### <img src="/images/providers/mistral-icon.svg" alt="" className="inline-block h-5 w-auto align-middle" /> Mistral AI

Access Mistral models, including Mistral Large and Mistral Small.

### Fireworks

Access models through the Fireworks AI platform.

### Groq

Access models through Groq's high-performance inference platform.

### <img src="/images/providers/deepseek-icon.svg" alt="" className="inline-block h-5 w-auto align-middle" /> DeepSeek

Access DeepSeek models for various language understanding and generation tasks.

### XAI

Access models from XAI (formerly known as Grok).

## Cloud providers

You can also connect to models through major cloud platforms:

### <img src="/images/providers/microsoft-icon.svg" alt="" className="inline-block h-5 w-auto align-middle" /> Azure OpenAI

Access OpenAI models deployed through Microsoft Azure. Requires Azure OpenAI Service configuration.

### Google Vertex AI

Access Google's models and other supported models through the Vertex AI platform. Requires Google Cloud configuration.

### <img src="/images/providers/bedrock-icon.png" alt="" className="inline-block h-5 w-auto align-middle" /> Amazon Bedrock

Access foundation models from various providers through Amazon Bedrock. Requires AWS configuration.

## Other

### OpenAI Compatible Endpoint

Connect to any model provider that implements the OpenAI-compatible API format. This allows you to use custom or third-party model endpoints that follow OpenAI's API specification.

For details on setting up custom endpoints, see [Custom OpenAI-compliant model](/langsmith/custom-openai-compliant-model) and [Custom endpoint](/langsmith/custom-endpoint).
