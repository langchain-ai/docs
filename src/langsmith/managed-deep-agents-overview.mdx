Managed Deep Agents (MDA) is the simplest way to build and deploy production agents. You focus on what your agent does. MDA runs it.

You write the agent's intelligence: its instructions, the tools it can call, the skills it follows, and the model that drives it. MDA provides everything underneath: the open source [Deep Agents](/oss/deepagents/overview) harness that runs the agent loop, and a managed runtime that hosts and operates the agent. There are no servers to run and no infrastructure to wire together.

<ManagedDeepAgentsPrivateBetaNote />

## Define your agent

An MDA agent is just a folder. Each part of the agent is a file, and MDA discovers it by name. To add a capability, add a file:

:::python
```text research-assistant/
research-assistant/
├── agent.py          # Model and configuration
├── instructions.md   # System prompt
├── skills/           # Playbooks loaded when relevant
└── tools/            # Functions the agent can call
```
:::

:::js
```text research-assistant/
research-assistant/
├── agent.ts          # Model and configuration
├── instructions.md   # System prompt
├── skills/           # Playbooks loaded when relevant
└── tools/            # Functions the agent can call
```
:::

Only two files are required. The agent definition picks a model:

:::python
```python agent.py
from managed_deepagents import define_deep_agent

agent = define_deep_agent(
    name="research-assistant",
    model="openai:gpt-5.5",
)
```
:::

:::js
```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

export const agent = defineDeepAgent({
  name: "research-assistant",
  model: "openai:gpt-5.5",
});
```
:::

The instructions describe how the agent behaves, in plain Markdown:

```markdown instructions.md
# Research assistant

You are a careful research assistant. Search for sources, keep notes, and return
concise answers with citations.
```

Run it locally, then deploy it to LangSmith:

```bash
mda dev .
mda deploy .
```

MDA syncs your instructions and skills to Context Hub, so you can edit them in the UI and apply changes without redeploying.

## Let MDA run it

MDA runs the agent on managed infrastructure, so you do not operate servers or manage state. Every deployment includes:

- **The Deep Agents harness**: The agent loop that plans, calls tools, manages a filesystem, and delegates to subagents. See [Deep Agents](/oss/deepagents/overview).
- **A managed runtime**: LangSmith Agent Server hosts and operates the agent, and keeps sessions running across restarts.

## Add capabilities

Each part of the agent maps to a file or directory. Add the ones your agent needs:

:::python
| Capability | Path | Description |
| --- | --- | --- |
| [Model and configuration](/langsmith/managed-deep-agents-agent-definition) | `agent.py` | Selects the model and core options. Required. |
| [Instructions](/langsmith/managed-deep-agents-instructions) | `instructions.md` | The system prompt that defines how the agent behaves. Required. |
| [Skills](/langsmith/managed-deep-agents-skills) | `skills/` | Task-specific playbooks the agent loads when they are relevant. |
| [Tools](/langsmith/managed-deep-agents-tools) | `tools/` | Functions the agent calls to run your application logic or reach external services. |
| [Middleware](/langsmith/managed-deep-agents-middleware) | `middleware/` | Custom logic that runs around model and tool calls. |
| [Sandbox](/langsmith/managed-deep-agents-sandboxes) | `sandbox/` | An isolated filesystem and shell for running agent-written code. |
| [Memory](/langsmith/managed-deep-agents-memory) | `memory.py` | Preferences and knowledge that persist across threads. |
| [Identity](/langsmith/managed-deep-agents-identity) | `identity.py` | Per-caller private threads, memory, and credentials for multi-user deployments. |
| [Channels](/langsmith/managed-deep-agents-channels) | `channels/` | Connections to messaging services, such as Slack, that start runs and receive responses. |
| [Schedules](/langsmith/managed-deep-agents-schedules) | `schedules/` | Managed cron schedules that run the agent on a recurring basis. |
| [Evals](/langsmith/managed-deep-agents-evals) | `evals/` | Harbor-style tasks that test the agent. |
:::
