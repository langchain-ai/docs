Normally when a Managed Deep Agent interacts with users, its memory is scoped that thread or session. We usually refer to that as conversational memory or threads.

When we talk about Memory, we really mean long term memory. Memory is optional durable knowledge that a Managed Deep Agent can retain **across** threads and sessions.
By default, Managed Deep Agents do **not** have memory, but you can easily turn it on.
When turned on, that memory exists for the agent as a whole, across all users.

</Note>

## Enable memory

Add a root `memory.py` or `memory.ts` file that exports memory with the `"agent"` scope:

<CodeGroup>

```python memory.py
from managed_deepagents import define_memory

memory = define_memory(scope="agent")
```

```ts memory.ts
import { defineMemory } from "managed-deepagents";

export const memory = defineMemory({ scope: "agent" });
```

</CodeGroup>

Remove the memory declaration to turn memory off.

## How the agent uses memory

Hot memory is loaded into the agent's context automatically. Cold memory is loaded only when the agent reads it:

| Path | Use |
| --- | --- |
| `/memories/agent/AGENTS.md` | Hot memory for compact, frequently relevant knowledge. |
| Other files under `/memories/agent/` | Cold memory for detailed knowledge needed only in specific situations. |

The agent reads and updates memory with `read_file`, `edit_file`, and `write_file`.

<Warning>
Memory is shared by every caller of the deployment. Store only knowledge that every caller may read and influence; never store personal data, customer-private data, credentials, or other secrets.
</Warning>

## How the agent decides what to remember

The agent decides what to remember based on prompting.
If you want the agent to remember certain things, tell it to do so in its system prompt.

## Distinguish instructions from memory

`instructions.md` defines how the agent should behave. Memory stores knowledge the agent learns and uses across threads. Use instructions to tell the agent what kinds of shared knowledge are worth remembering.

`instructions.md` is always read-only. The agent will never update it.
