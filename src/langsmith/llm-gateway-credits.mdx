LangChain-hosted models run through the LLM Gateway without a provider account or key. Authenticate with only your [LangSmith API key](/langsmith/create-account-api-key). No [provider secret](/langsmith/llm-gateway-admin-setup#1-add-provider-secrets) is required.

Hosted generative models use Gateway Credits. Hosted decision models use the native System One API and can be free or consume Gateway Credits, depending on the model. The gateway routes each request based on its endpoint and model ID. A model ID that starts with a configured bring-your-own-key provider, such as `anthropic/claude-opus-5`, uses that provider's secret instead.

<Card title="Base URL" icon="link">
Point any supported client at the standard gateway API:

```text
https://gateway.smith.langchain.com/v1
```

Authenticate with your LangSmith API key as a bearer token.

For regional base URLs, see [Regional gateways](/langsmith/llm-gateway-how-it-works#use-a-regional-gateway).
</Card>

## Available models

Select a hosted model by ID in the request body. Model IDs are case-insensitive. Feature flags, plan tier, region, and [model access policies](/langsmith/llm-gateway-model-access-policies) determine which models are available to your workspace.

| Model ID | Type | Billing | Supported endpoint |
| --- | --- | --- | --- |
| `moonshotai/kimi-k2.6` | Generative model by Moonshot AI, powered by Fireworks Inference. | Gateway Credits | Chat Completions, Messages, and Responses |
| `moonshotai/kimi-k3` | Generative model by Moonshot AI, powered by Fireworks Inference. | Gateway Credits | Chat Completions, Messages, and Responses |
| `jev-latest` | TypeSafe decision model for typed Noul, Choice, and Score questions. | Gateway Credits | System One |
| `semif-qwen3.5-4b` | Open SemIf decision model based on Qwen3.5-4B. | Free through September 28, 2026 | System One |

<Note>
SemIf is not available on the AWS US gateway. It is an independent open-source project and is not affiliated with TypeSafe or Jev.
</Note>

List every model available to your workspace, including configured bring-your-own-key providers and hosted models, with the standard model-list endpoint:

```bash
curl https://gateway.smith.langchain.com/v1/models \
    -H "Authorization: Bearer $LANGSMITH_API_KEY"
```

Use a returned model ID exactly as shown in the `model` field of a prompt request.

## Prerequisites

All hosted models require a workspace-scoped [LangSmith API key](/langsmith/create-account-api-key) attached to a role with `gateway:invoke` and `workspaces:read` [permissions](/langsmith/organization-workspace-operations). See [Admin setup](/langsmith/llm-gateway-admin-setup) if you are unsure.

Credit-funded models also require a paid plan other than Enterprise ([Developer, Plus, Startup, or Premier](/langsmith/pricing-plans)). Free SemIf access does not require Gateway Credits.

## Call a generative model

Point an OpenAI-compatible client at `https://gateway.smith.langchain.com/v1`, authenticate with your LangSmith API key, and set `model` to a hosted generative model ID.

<CodeGroup>

```bash cURL
curl https://gateway.smith.langchain.com/v1/chat/completions \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"moonshotai/kimi-k3","messages":[{"role":"user","content":"ping"}]}'
```

```python OpenAI SDK
import os

from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.smith.langchain.com/v1",
    api_key=os.environ["LANGSMITH_API_KEY"],
)
response = client.chat.completions.create(
    model="moonshotai/kimi-k3",
    messages=[{"role": "user", "content": "ping"}],
)
print(response.choices[0].message.content)
```

```python LangChain
import os

from langchain.chat_models import init_chat_model

model = init_chat_model(
    model="moonshotai/kimi-k3",
    model_provider="openai",
    base_url="https://gateway.smith.langchain.com/v1",
    api_key=os.environ["LANGSMITH_API_KEY"],
)
print(model.invoke("ping").content)
```

</CodeGroup>

## Call a decision model

Decision models return typed judgments instead of generated text. Send a `state` to evaluate and one or more questions to `POST /v1/systemone`. Each question uses one of three primitives:

- **Noul**: Answers a yes-or-no question. The `noul` value is the probability of `true` from 0 to 1.
- **Choice**: Selects one option and returns the selected `choice`, a probability for each option, and `confidence`.
- **Score**: Evaluates an ordered scale and returns the probability-weighted `score`, its `legend`, a probability for each level, and `confidence`.

Use SemIf without Gateway Credits:

```bash
curl https://gateway.smith.langchain.com/v1/systemone \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "semif-qwen3.5-4b",
      "state": "The export button crashes the settings page in Safari.",
      "questions": {
        "needs_attention": {
          "type": "noul",
          "instructions": "Does this issue need engineering attention?"
        },
        "team": {
          "type": "choice",
          "instructions": "Which team should handle this issue?",
          "criteria": {
            "frontend": "Browser UI and interaction issues",
            "backend": "API and data-processing issues"
          }
        },
        "severity": {
          "type": "score",
          "instructions": "How severe is this issue?",
          "criteria": [
            "Cosmetic; no impact to functionality",
            "A feature is broken, but a workaround exists",
            "Blocking issue with no workaround"
          ]
        }
      }
    }'
```

The response contains one entry in `answers` for each question. SemIf reports `null` for `usage.input_tokens` and `usage.output_tokens` because token usage is unknown. Its Choice and Score `confidence` values measure concentration in the returned probability distribution, not calibrated correctness. Validate thresholds against your workload before automating consequential actions.

Jev accepts the same request shape. Set `model` to `jev-latest`; Jev calls consume Gateway Credits.

## Supported endpoints

| Method and path | Behavior |
| --- | --- |
| `POST /v1/chat/completions` | Calls supported hosted generative models with OpenAI Chat Completions, including streaming. |
| `POST /v1/messages` | Calls supported hosted generative models with Anthropic Messages, including streaming. |
| `POST /v1/responses` | Calls supported hosted generative models with OpenAI Responses. |
| `POST /v1/systemone` | Calls supported hosted decision models with native System One requests and responses. |
| `GET /v1/models` | Lists models available to the workspace and their supported endpoints. |

For generative request examples and translation behavior, see [API formats](/langsmith/llm-gateway-api-formats).

## Pricing

Gateway Credits are available on all paid plans besides Enterprise. See [the pricing page](https://www.langchain.com/pricing) for plan details and current rates. Gateway Credits are denominated in **LangChain Credit Units (LCUs)**; each credit-funded call consumes LCUs based on usage. SemIf calls do not consume Gateway Credits during the free promotional period.

Standard gateway [spend policies](/langsmith/llm-gateway-spend-policies), rate limits, data policies, and model access policies still apply to free hosted-model traffic. Spend policies also govern Gateway Credit usage. You can control Gateway Credit consumption with the same tools you use for bring-your-own-key providers. For example, cap a specific API key at $200/month across every provider, or set a workspace-wide daily limit that includes credit-funded hosted-model calls.

## Tracing

Like all gateway traffic, hosted-model calls are traced to LangSmith. For where traces land and how to control access to them, see [Traces, Engine, and access control](/langsmith/llm-gateway-access).
