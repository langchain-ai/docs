Watch mode lets a [Slack-connected agent](/langsmith/managed-deep-agents-channels-slack) read channel messages without waiting for a mention. The agent decides from context whether to reply or stay silent.

## Configure the Slack channel

Start with a project that has a [Slack channel](/langsmith/managed-deep-agents-channels-slack#add-a-slack-channel) and update its declaration:

:::python
```python channels/slack.py
from managed_deepagents import channels

channel = channels.slack(
    trigger_mode="all",
    reactions=False,
    status=False,
)
```
:::

:::js
```ts channels/slack.ts
import { channels } from "managed-deepagents";

export const channel = channels.slack({
  triggerMode: "all",
  reactions: false,
  status: false,
});
```
:::

Every message in channels the bot belongs to starts a run, and each run incurs usage. Turning off reactions and working status keeps the agent quiet when it chooses not to reply.

## Write the instructions

Add to `instructions.md`:

```markdown instructions.md
# Slack watch agent

Answer direct questions and mentions. For other messages, reply only when you
can add something useful. Otherwise, respond with exactly [quiet].
```

An exact `[quiet]` response posts nothing.

[Deploy the agent](/langsmith/managed-deep-agents-deploy) and invite it to a channel. Send a message that needs no reply and a message that mentions the agent, then confirm only the mention gets a reply.

## Add check-ins

To let the agent follow up later, add a [custom tool](/langsmith/managed-deep-agents-tools) that schedules a one-time [check-in](/langsmith/managed-deep-agents-schedules#create-schedules-at-runtime) in the current thread.

:::js
With `managed-deepagents` 0.10.4, use npm: pnpm can resolve incompatible LangChain versions. Install the tool's dependencies:

```bash
npm install langchain zod
```
:::

:::python
```python tools/watch.py
from datetime import datetime, timedelta, timezone

from langchain.tools import tool
from managed_deepagents import ManagedDeepAgentRuntime


@tool
async def schedule_check_in(
    prompt: str, minutes: int, runtime: ManagedDeepAgentRuntime
) -> str:
    """Schedule one check-in in the current conversation, 2 to 1440 minutes from now."""
    origin = runtime.thread.origin
    if origin is None or origin.channel.provider != "slack":
        return "A Slack conversation is required to schedule a check-in."
    if not 2 <= minutes <= 1440:
        return "Choose a delay between 2 and 1440 minutes."
    item = await runtime.schedules.create(
        owner={"type": "agent"},
        at=datetime.now(timezone.utc) + timedelta(minutes=minutes),
        new_thread=False,
        prompt=prompt,
    )
    return f"Scheduled check-in {item['id']}."
```
:::

:::js
```ts tools/watch.ts
import { tool } from "langchain";
import type { ManagedDeepAgentRuntime } from "managed-deepagents";
import { z } from "zod";

export const scheduleCheckIn = tool(
  async ({ prompt, minutes }, runtime) => {
    const managedRuntime = runtime as typeof runtime &
      Pick<ManagedDeepAgentRuntime, "thread" | "schedules">;
    const origin = managedRuntime.thread?.origin;
    if (!origin || origin.channel.provider !== "slack") {
      return "A Slack conversation is required to schedule a check-in.";
    }
    if (minutes < 2 || minutes > 1440) {
      return "Choose a delay between 2 and 1440 minutes.";
    }
    const item = await managedRuntime.schedules!.create({
      owner: { type: "agent" },
      at: new Date(Date.now() + minutes * 60_000),
      newThread: false,
      prompt,
    });
    return `Scheduled check-in ${item.id}.`;
  },
  {
    name: "schedule_check_in",
    description: "Schedule one check-in in the current conversation, 2 to 1440 minutes from now.",
    schema: z.object({
      prompt: z.string(),
      minutes: z.number().int(),
    }),
  },
);
```
:::

Register the tool:

:::python
```python agent.py
from managed_deepagents import define_deep_agent

from tools.watch import schedule_check_in

agent = define_deep_agent(
    name="watch-agent",
    model="openai:gpt-6.1-sol",
    tools=[schedule_check_in],
)
```
:::

:::js
```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

import { scheduleCheckIn } from "./tools/watch";

export const agent = defineDeepAgent({
  name: "watch-agent",
  model: "openai:gpt-6.1-sol",
  tools: [scheduleCheckIn],
});
```
:::

Add to `instructions.md`:

```markdown instructions.md
When work is ongoing and a later check could help, call schedule_check_in.
When a check-in runs, reply only if there is something new; otherwise respond
with exactly [quiet].
```

For example, if someone says a fix is rolling out, the agent can schedule a check-in for 15 minutes later. Check-ins run as the agent and see only messages already delivered to its thread.

## Extend the pattern

:::python
- Filter messages before a run starts by returning `None` from an `on_event` `"message"` handler on `channels.slack(...)` to cut usage in busy channels.
:::

:::js
- Filter messages before a run starts by returning `null` from an `onEvent` `"message"` handler on `channels.slack(...)` to cut usage in busy channels.
:::
- Add a Slack history [tool](/langsmith/managed-deep-agents-tools) so check-ins can read the latest replies in the thread.
- Track a thread across multiple check-ins by letting each check-in schedule the next, with tools to [list and delete](/langsmith/managed-deep-agents-schedules#manage-schedules) pending checks when done.
