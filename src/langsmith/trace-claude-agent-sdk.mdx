The [Claude Agent SDK](https://platform.claude.com/docs/en/agent-sdk/overview) is Anthropic's SDK for building managed agentic applications with Claude. LangSmith provides native integration with the Claude Agent SDK to automatically trace your agent executions, tool calls, and interactions with Claude models — giving you full visibility into every step of your agent's reasoning.

## Installation

Install the LangSmith integration for Claude Agent SDK:

<InstallClaudeAgentSdk/>

## Setup

Set your [API keys](/langsmith/create-account-api-key):

<SetupClaudeAgentSdk/>

You can find your LangSmith API key and project name in the [LangSmith UI](https://smith.langchain.com) under **Settings**.

For an Anthropic API key, refer to the [Claude console](https://claude.ai/login).

## What gets traced

LangSmith captures the full execution lifecycle of your Claude Managed Agent:

| Span type | Description |
|-----------|-------------|
| Agent query | The top-level agent run, including the prompt and final response |
| Tool call | Each tool invocation, with inputs and outputs |
| Model interaction | Individual Claude model API calls with token counts |
| MCP server operation | Calls to Model Context Protocol servers |

## View your traces

After running your agent, open your [LangSmith project](https://smith.langchain.com) to see the full trace tree. Each trace shows the agent's reasoning steps, tool usage, and model interactions side by side.
