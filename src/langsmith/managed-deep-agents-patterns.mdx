## Patterns

- [Schedules](/langsmith/managed-deep-agents-tutorial): Add memory and a daily schedule to the quickstart agent.
- [Personal agent](/langsmith/managed-deep-agents-personal-agent): Text an agent that uses a browser to get things done.
- [Watch mode](/langsmith/managed-deep-agents-watch-mode): Let a Slack agent decide when to reply.
- [Goals](/langsmith/managed-deep-agents-goal-oriented): Track team commitments and post a daily review.
- [Dreaming](/langsmith/managed-deep-agents-dreaming): Learn from a person's traces each night.
- [Swarm](/langsmith/managed-deep-agents-swarm): Investigate an incident with parallel subagents.
