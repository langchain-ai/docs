An agent comes into existence in one of four ways, and the route decides three things about it: how its identifier is set, how many [environments](/langsmith/agent-environments) it starts with, and whether it can hold a [deployment](/langsmith/deployment).

Choose the route by where the agent runs. An agent you build inside LangSmith is created as you build it, while an agent that runs on your own machines is created the first time it reports in.

<AgentBetaNote />

## Compare the four routes

| Route | Identifier | Environments at creation | Deployments section |
| --- | --- | --- | --- |
| [Build tab](/langsmith/build-an-agent) | Generated for you | Production alone | No |
| **Create a new agent** dialog | You set it | All four | No |
| [Tracing](/langsmith/log-traces-to-agent) to an identifier that does not exist | The value you send | All four | No |
| [Deploying a project](/langsmith/deploy-to-agent-environment) | Taken from the deployment | All four | Yes |

The **Deployments** section appears on an agent created by a deployment and on no other. An agent built in the Build tab cannot hold a deployment at all, because it runs on a Studio runtime.

For why the first row differs on environments, see [Agent environments](/langsmith/agent-environments#the-four-environments).

## Start from the New Agent panel

Three controls open the **New Agent** panel: **+ Agent** above the agent list, and **+ Create new agent** and **Trace existing agent** on a creation card at the end of the list, also titled **New Agent**. The first two open the panel on its grid of options, while **Trace existing agent** opens it on the Observability option.

The panel offers four routes, and only the first creates an agent when you follow it:

- **Builder**, "Build with AI inside LangSmith". Leaves the panel for the **Build** tab, where the agent is created when you submit the form. See [Build an agent in the UI](/langsmith/build-an-agent).
- **Managed Deep Agent**, "Build locally and deploy". Opens a guided setup flow. The agent is created when you deploy. See [Managed Deep Agents](/langsmith/managed-deep-agents-overview). This route requires a paid plan.
- **Open Source**, "Build an agent with our open source frameworks". Opens a guided setup flow. The agent is created when the first trace arrives. See [LangChain](/oss/langchain/overview).
- **Observability**, "Trace an existing agent". Opens a guided setup flow. The agent is created when the first trace arrives. See the [tracing quickstart](/langsmith/observability-quickstart), or [LangSmith skills](/langsmith/skills) for the prompt-driven setup the panel offers first.

An **All options** button returns a guided flow to the grid.

## Name an agent traced from outside LangSmith

To create the agent before any trace arrives, use the agent switcher's **+ New agent** action. It opens a **Create a new agent** dialog, which takes an **Agent name** and, in its own field, an **Agent ID**. The dialog notes that the ID is used in URLs and API calls and cannot be changed later.

That action requires permission to create projects, and it appears on the tracing project pages, not on the agent views.

Creating the agent first is optional. [Tracing to an identifier that does not exist](/langsmith/log-traces-to-agent#addressing-an-agent-that-does-not-exist) creates the agent under the value you sent, so the dialog is for naming an agent ahead of its first run.

## Identifier rules

An identifier is 1 to 63 characters, using lowercase letters, digits, and hyphens. It must start with a letter and end with a letter or digit, so `support-agent` and `billing-v2` are valid. Anything else is rejected.

The rules apply wherever you supply the value, both in the **Agent ID** field and in the identifier you trace to. An agent built in the Build tab is the exception, because LangSmith generates that identifier rather than taking one from you.

An identifier cannot be changed after the agent is created. The display name can. For which value is which, see [Identifiers and display names](/langsmith/agents#identifiers-and-display-names).
