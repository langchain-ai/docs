LangSmith Cloud is a fully managed deployment option for LangSmith agents. LangChain hosts and operates the control plane, data plane, Agent Server runtime, and supporting databases on AWS and GCP. Push code to a connected GitHub repository or invoke the `langgraph deploy` CLI, and the platform handles build, provisioning, scaling, and ongoing operations.

## Prerequisites

Cloud deployments require a [Plus plan or above](https://www.langchain.com/pricing). Before creating your first agent deployment, verify that your application runs locally with `langgraph dev`. See [Local development and testing](/langsmith/local-dev-testing).
