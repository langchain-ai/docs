The LLM Gateway lets you call models across configured providers through one standard endpoint with one LangSmith API key.

<Note>
**Beta:** The LLM Gateway is in [beta](/langsmith/release-stages).
</Note>

## Prerequisites

Before you start, confirm that:

- Your [Organization admin](/langsmith/rbac#organization-admin) has enabled the LLM Gateway. For bring-your-own-key models, the admin must also add the provider API key to workspace secrets. See [Admin setup](/langsmith/llm-gateway-admin-setup).
- You have a workspace-scoped [LangSmith API key](/langsmith/create-account-api-key) attached to a role with `gateway:invoke` and `workspaces:read` [permissions](/langsmith/organization-workspace-operations). Ask your organization admin if you are unsure.

## Make a call

<Tabs>

<Tab title="Chat completions">

OpenAI-compatible Chat Completions endpoint (`/v1/chat/completions`). Use this with the OpenAI SDK or any OpenAI-compatible client.

<CodeGroup>

```bash cURL
export LANGSMITH_API_KEY="lsv2_..."

curl https://gateway.smith.langchain.com/v1/chat/completions \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"anthropic/claude-opus-5","messages":[{"role":"user","content":"Explain what an LLM gateway does in one sentence."}]}'
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.smith.langchain.com/v1",
    api_key=os.environ["LANGSMITH_API_KEY"],
)
response = client.chat.completions.create(
    model="anthropic/claude-opus-5",
    messages=[{"role": "user", "content": "Explain what an LLM gateway does in one sentence."}],
)
print(response.choices[0].message.content)
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.smith.langchain.com/v1",
  apiKey: process.env.LANGSMITH_API_KEY,
});
const response = await client.chat.completions.create({
  model: "anthropic/claude-opus-5",
  messages: [{ role: "user", content: "Explain what an LLM gateway does in one sentence." }],
});
console.log(response.choices[0].message.content);
```

</CodeGroup>

<Tab title="Messages">

Anthropic Messages API format (`/v1/messages`). Point the Anthropic SDK at the gateway root — no `/v1` suffix, the SDK appends its own path.

<CodeGroup>

```bash cURL
export LANGSMITH_API_KEY="lsv2_..."

curl https://gateway.smith.langchain.com/v1/messages \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Anthropic-Version: 2023-06-01" \
    -H "Content-Type: application/json" \
    -d '{"model":"anthropic/claude-opus-5","max_tokens":1024,"messages":[{"role":"user","content":"Explain what an LLM gateway does in one sentence."}]}'
```

```python Python
import os
import anthropic

client = anthropic.Anthropic(
    base_url="https://gateway.smith.langchain.com",
    api_key=os.environ["LANGSMITH_API_KEY"],
)
message = client.messages.create(
    model="anthropic/claude-opus-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain what an LLM gateway does in one sentence."}],
)
print(message.content[0].text)
```

```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://gateway.smith.langchain.com",
  apiKey: process.env.LANGSMITH_API_KEY,
});
const message = await client.messages.create({
  model: "anthropic/claude-opus-5",
  max_tokens: 1024,
  messages: [{ role: "user", content: "Explain what an LLM gateway does in one sentence." }],
});
console.log(message.content[0].text);
```

<Tab title="Deep Agents">

Set `LANGSMITH_GATEWAY=true` to route all Deep Agents calls through the gateway automatically.

<CodeGroup>

```python Python
# pip install "deepagents>=0.1.0"
# export LANGSMITH_API_KEY="lsv2_..."
# export LANGSMITH_GATEWAY="true"
from deepagents import create_deep_agent

agent = create_deep_agent(model="anthropic:claude-opus-5")
result = agent.invoke({"messages": [{"role": "user", "content": "Explain what an LLM gateway does in one sentence."}]})
print(result["messages"][-1].content)
```

```typescript TypeScript
// npm install deepagents
// export LANGSMITH_API_KEY="lsv2_..."
// export LANGSMITH_GATEWAY="true"
import { createDeepAgent } from "deepagents";

const agent = createDeepAgent({ model: "anthropic:claude-opus-5" });
const result = await agent.invoke({
  messages: [{ role: "user", content: "Explain what an LLM gateway does in one sentence." }],
});
console.log(result.messages[result.messages.length - 1].content);
```

</CodeGroup>

<Tip>
`LANGSMITH_GATEWAY` is a global setting — it routes all agent calls through the gateway. To route a specific agent instance through the gateway instead, use the `langsmith:` model prefix without setting `LANGSMITH_GATEWAY`:

```python
agent = create_deep_agent(model="langsmith:anthropic/claude-opus-5")
```
</Tip>

## View your trace

Open the [LangSmith UI](https://smith.langchain.com) and go to the tracing project named `gateway` or `gateway-<short_api_key>-<api_key_id>` in your workspace. You should see a trace for the call you just made.

## Set a spend policy (optional)

Go to **LLM Gateway** in LangSmith to create a spend policy. For example, set a daily $10 cap on your API key. When the cap is reached, the gateway returns a `402` with the message: `"Request blocked by gateway policies: R&D Spend Cap"`.

See [Spend policies](/langsmith/llm-gateway-spend-policies) for the full guide.

## Automatic routing (LangChain and Deep Agents)

Set `LANGSMITH_GATEWAY` to route all supported LangChain and Deep Agents **chat models** through the gateway — no `base_url` or `api_key` wiring needed per client.

```bash
export LANGSMITH_API_KEY="lsv2_..."
export LANGSMITH_GATEWAY="true"                                   # US gateway (default)
# export LANGSMITH_GATEWAY="https://eu.gateway.smith.langchain.com"  # EU
# export LANGSMITH_GATEWAY="https://<data_plane_host>/gateway"       # BYOC
```

<Warning>
When setting `LANGSMITH_GATEWAY` to a URL, use only the base URL with no path suffix. The SDK appends the provider-specific path automatically — a trailing `/v1` causes a doubled path and request failures.
</Warning>

<Note>
Only **chat models** are routed. Non-chat integrations such as `OpenAIEmbeddings` are unaffected. To use a separate API key for gateway calls, set `LANGSMITH_GATEWAY_API_KEY` (workspace-scoped, requires `gateway:invoke`).
</Note>

### URL and key resolution precedence

When `LANGSMITH_GATEWAY` is set, the SDK resolves the final base URL and API key using these rules in order (first match wins). Examples use the OpenAI integration; other providers use their own `*_API_BASE` / `*_BASE_URL` and `*_API_KEY` env vars.

**Base URL:**

1. Per-client `base_url=` kwarg (Python) / `configuration.baseURL` (TypeScript) — always wins.
2. Provider env var (`OPENAI_API_BASE` in Python, `OPENAI_BASE_URL` in TypeScript) — overrides the gateway.
3. `LANGSMITH_GATEWAY` — routes to the gateway; the SDK appends the provider path (e.g. `/openai/v1`).
4. Provider default (e.g. `api.openai.com`).

**API key** (evaluated after the URL is resolved):

1. If routed to the gateway and `LANGSMITH_GATEWAY_API_KEY` is set — use the gateway key.
2. If routed to the gateway and the provider key (`OPENAI_API_KEY`) is set — use the provider key.
3. Otherwise — use whichever key matches the resolved URL.

<Note>
TypeScript key resolution differs from Python in some edge cases (rows 8–11 of the full table). If you observe unexpected routing in TypeScript, verify against `@langchain/openai` directly.
</Note>

## Regional URLs and endpoint styles

The base URL depends on your LangSmith instance:

| Instance | Base URL |
|---|---|
| US (default) | `https://gateway.smith.langchain.com` |
| EU | `https://eu.gateway.smith.langchain.com` |
| BYOC / self-hosted | `https://<data_plane_host>/gateway` |

The gateway exposes two endpoint styles:

- **Unified `/v1`** (recommended) — a single endpoint that accepts Chat Completions, Responses, and Messages format requests and translates between API formats as needed. Append `/v1` to the base URL. Full reference: [API formats](/langsmith/llm-gateway-api-formats).
- **Direct provider routes** — pass requests straight through to the selected provider without format translation. Use the base URL with no suffix — the SDK appends its own path. Full reference: [Direct model access](/langsmith/llm-gateway-direct-model-access).
