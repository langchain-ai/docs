## Configure the agent

Start with the research assistant from the [quickstart](/langsmith/managed-deep-agents-quickstart), which already has web search. Enable shared [memory](/langsmith/managed-deep-agents-memory):

:::python
```python memory.py
from managed_deepagents import MemoryLayer, define_memory

memory = define_memory(agent=MemoryLayer())
```
:::

:::js
```ts memory.ts
import { defineMemory, memoryLayer } from "managed-deepagents";

export const memory = defineMemory({ agent: memoryLayer() });
```
:::

Replace `instructions.md`:

```markdown instructions.md
# Digest agent

You are a research assistant. When someone asks you to follow or stop
following a topic, update /memories/agent/topics.md and confirm the change.

When asked for a digest, read that file, search for news from the last day on
each topic, and write a short digest with one or two cited items per topic.
```

## Add a schedule

Add a [schedule](/langsmith/managed-deep-agents-schedules) that runs every weekday at 8:00 AM Pacific:

:::python
```python schedules/daily_digest.py
from managed_deepagents import define_schedule

schedule = define_schedule(
    cron="0 8 * * 1-5",
    timezone="America/Los_Angeles",
    prompt="Write today's digest.",
)
```
:::

:::js
```ts schedules/daily-digest.ts
import { defineSchedule } from "managed-deepagents";

export const schedule = defineSchedule({
  cron: "0 8 * * 1-5",
  timezone: "America/Los_Angeles",
  prompt: "Write today's digest.",
});
```
:::

## Try it

Run the agent with `mda dev` and tell it to follow a topic, such as "Follow LangChain releases." Start a new thread and ask for today's digest. The agent reads your saved topics from memory even though the new thread has no history.

[Deploy the agent](/langsmith/managed-deep-agents-deploy) to run the schedule automatically. Each scheduled run starts a new thread on the deployment.
