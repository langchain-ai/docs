Threads preserve the conversation and execution state for a Managed Deep Agent.

<Note>
    Managed Deep Agents is in private preview. [Join the waitlist](https://www.langchain.com/langsmith-managed-deep-agents-waitlist) to request access. For an end-to-end workflow with request examples, see [Deploy Managed Deep Agents](/langsmith/deploy-managed-deep-agent).
</Note>

## Authentication

Requests require a LangSmith API key for a workspace with Managed Deep Agents private preview access. Pass the key with each request:

```txt
X-Api-Key: <LANGSMITH_API_KEY>
```

## Base route

Thread endpoints use `/v1/deepagents/threads`.

## Endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/v1/deepagents/threads` | Create a thread for a Managed Deep Agent. |

Additional thread endpoints will be documented after public OpenAPI-generated reference pages are available for these routes.

## Create a thread

Create a thread before running an agent. The request body can include:

| Field | Purpose |
| --- | --- |
| `agent` | Managed Deep Agent ID. |
| `options` | Runtime options for the thread. |

The `options` object can include `test_run` and `skip_memory_write_protection`. For a complete request example, see [Create a thread](/langsmith/deploy-managed-deep-agent#create-a-thread).
