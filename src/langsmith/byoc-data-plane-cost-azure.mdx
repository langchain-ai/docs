<Warning>
These are estimates, not a quote. Azure changes its prices without notice. Your bill depends on region, usage, and any discount agreement with Azure. The estimates use pay-as-you-go prices in `eastus` and 730 hours per month.
</Warning>

This is a rough monthly cost for a LangSmith data plane in your Azure subscription. Use it to budget for the resources described in [BYOC architecture on Azure](/langsmith/byoc-architecture-azure).

<Note>
This estimate excludes sandboxes, including sandbox hosts, their storage, and their private endpoint. Application and SmithDB node counts are budgeting assumptions, not fixed deployment sizes or scaling limits. Node auto-provisioning selects nodes based on workload requirements and available capacity.
</Note>

Azure data planes run SmithDB, without ClickHouse or ZooKeeper. SmithDB uses separate pools for local NVMe cache and compute workloads.

| Area | Rough monthly estimate | Notes |
| --- | --- | --- |
| PostgreSQL, LangSmith | ~\$270 | `GP_Standard_D2ds_v4`, PostgreSQL 16, 32 GiB starting storage, with zone-redundant standby where supported. |
| PostgreSQL, SmithDB metastore | ~\$290 | `GP_Standard_D2ds_v4`, PostgreSQL 18, 128 GiB starting storage, with zone-redundant standby where supported. |
| Azure Managed Redis | ~\$95 | `Balanced_B3` with high availability. |
| AKS control plane | ~\$73 | One AKS cluster on the Standard tier. |
| System node pool | ~\$221 | 3 `Standard_D2s_v6` on-demand nodes. Disks appear separately below. |
| Application nodes | \$560–\$1,680 | Example budget for 2 to 6 `Standard_D8s_v5` nodes. Excludes SmithDB and sandbox nodes. |
| SmithDB nodes | \$1,740–\$2,460 | Example budget for 2 to 3 `Standard_D16ds_v6` local NVMe nodes and 1 `Standard_D8s_v5` compute node. Actual node selection and count depend on pod replicas, resource requests, and scheduling. |
| Managed disks | \$50–\$120 | Allowance for system and application OS disks and the SmithDB compute node OS disk. Local NVMe storage is included in the SmithDB VM price. |
| Networking | \$120–\$170 | Low-volume allowance for a StandardV2 NAT gateway, public IP, ingress load balancer, 7 private endpoints, and data processing. Traffic and data transfer can increase this cost. |
| Blob storage, Key Vault, DNS | \$5–\$30 | Low-volume allowance for trace and SmithDB storage, secrets, and DNS. Grows with stored data, transactions, and retention. |

Estimated monthly total: **\$3,424–\$5,409**, or about **\$3.4k–\$5.4k**.

The node estimates use approximately \$0.101 per hour for `Standard_D2s_v6`, \$0.384 for `Standard_D8s_v5`, and \$0.997 for `Standard_D16ds_v6`. Check [Azure pricing](https://azure.microsoft.com/pricing/calculator/) for your region and agreement. The allowances are not spending caps, and the example node counts do not guarantee capacity for a particular workload.

For scaling behavior, see [Scaling and operations](/langsmith/byoc-architecture-azure#scaling-and-operations).
