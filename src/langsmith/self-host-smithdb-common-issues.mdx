This page lists what to check first when you monitor SmithDB. For what each metric measures and how to use it, see [Essential SmithDB metrics](/langsmith/self-host-smithdb-metrics).

## Is SmithDB healthy?

Start with these eight metrics. The section of each metric in [Essential SmithDB metrics](/langsmith/self-host-smithdb-metrics) tells you what a problem looks like. If none of them shows a problem, SmithDB is healthy. If one does, the other metrics on that page help you find the cause.

- [`langsmith_ingestion_e2e_latency_seconds`](/langsmith/self-host-smithdb-metrics#langsmith_ingestion_e2e_latency_seconds)
- [`langsmith_asynq_ingestion_queue_retry`](/langsmith/self-host-smithdb-metrics#langsmith_asynq_ingestion_queue_retry)
- [`ingest_batch_latency`](/langsmith/self-host-smithdb-metrics#ingest_batch_latency)
- [`ingest_pending_segment_entry_count`](/langsmith/self-host-smithdb-metrics#ingest_pending_segment_entry_count)
- [`server_requests_duration` on query pods](/langsmith/self-host-smithdb-metrics#server_requests_duration-on-query-pods)
- [`compaction_jobs_scheduled`, `compaction_jobs_executed`](/langsmith/self-host-smithdb-metrics#compaction_jobs_scheduled-compaction_jobs_executed)
- [`compaction_job_completion`](/langsmith/self-host-smithdb-metrics#compaction_job_completion)
- [`compaction_queue_job_count`](/langsmith/self-host-smithdb-metrics#compaction_queue_job_count)
