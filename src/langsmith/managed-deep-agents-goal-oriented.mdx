Some goals take hours or days: a pull request gets merged, CI on `main` turns green, a release ships. A goal-oriented agent sets its own schedule to check progress, moves the goal forward when it can, and stops checking once the goal is met.

## Add the schedule tools

Give the agent two [tools](/langsmith/managed-deep-agents-tools) that wrap [runtime schedules](/langsmith/managed-deep-agents-schedules#create-schedules-at-runtime). `check_progress` starts a recurring check in the current thread, and `stop_checking` deletes it:

:::js
With `managed-deepagents` 0.10.4, use npm: pnpm can resolve incompatible LangChain versions. Install the tools' dependencies:

```bash
npm install langchain zod
```
:::

:::python
```python tools/goals.py
from langchain.tools import tool
from managed_deepagents import ManagedDeepAgentRuntime

OWNER = {"type": "agent"}


@tool
async def check_progress(goal: str, cron: str, runtime: ManagedDeepAgentRuntime) -> str:
    """Check progress on a goal in this thread on a cron schedule, until you stop it."""
    item = await runtime.schedules.create(
        owner=OWNER,
        cron=cron,
        new_thread=False,
        prompt=f"Check progress on this goal: {goal}",
    )
    return f"Checking progress with schedule {item['id']}."


@tool
async def stop_checking(schedule_id: str, runtime: ManagedDeepAgentRuntime) -> str:
    """Stop checking progress on a goal that is met or abandoned."""
    await runtime.schedules.delete(schedule_id, owner=OWNER)
    return f"Stopped schedule {schedule_id}."
```
:::

:::js
```ts tools/goals.ts
import { tool } from "langchain";
import type { ManagedDeepAgentRuntime } from "managed-deepagents";
import { z } from "zod";

const owner = { type: "agent" } as const;

export const checkProgress = tool(
  async ({ goal, cron }, runtime) => {
    const { schedules } = runtime as typeof runtime & Pick<ManagedDeepAgentRuntime, "schedules">;
    const item = await schedules!.create({
      owner,
      cron,
      newThread: false,
      prompt: `Check progress on this goal: ${goal}`,
    });
    return `Checking progress with schedule ${item.id}.`;
  },
  {
    name: "check_progress",
    description: "Check progress on a goal in this thread on a cron schedule, until you stop it.",
    schema: z.object({ goal: z.string(), cron: z.string() }),
  },
);

export const stopChecking = tool(
  async ({ scheduleId }, runtime) => {
    const { schedules } = runtime as typeof runtime & Pick<ManagedDeepAgentRuntime, "schedules">;
    await schedules!.delete(scheduleId, { owner });
    return `Stopped schedule ${scheduleId}.`;
  },
  {
    name: "stop_checking",
    description: "Stop checking progress on a goal that is met or abandoned.",
    schema: z.object({ scheduleId: z.string() }),
  },
);
```
:::

Register the tools:

:::python
```python agent.py
from managed_deepagents import define_deep_agent

from tools.goals import check_progress, stop_checking

agent = define_deep_agent(name="goal-agent", tools=[check_progress, stop_checking])
```
:::

:::js
```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

import { checkProgress, stopChecking } from "./tools/goals";

export const agent = defineDeepAgent({ name: "goal-agent", tools: [checkProgress, stopChecking] });
```
:::

## Write the instructions

The instructions are what turn the tools into a loop. Add to `instructions.md`:

```markdown instructions.md
## Goals

When someone gives you a goal, decide how to tell when it is met and how often
to check, then call check_progress with the goal and a cron expression. Then
stop and wait for the next check instead of working on the goal right away.

Each time you check progress, look at the current state with your tools.
Never assume. If you can move the goal forward, do it. Otherwise, say who
needs to act. When the goal is met or cannot be met, report it and call
stop_checking.
```

Each check runs in the same thread, so it sees the goal, earlier progress, and the schedule ID that `check_progress` returned, which `stop_checking` needs. If the goal came from Slack, each check replies in that Slack thread.

## Try it

The quickstart agent has web search, so it can watch for public events. [Deploy the agent](/langsmith/managed-deep-agents-deploy) and send: "Goal: tell me when LangChain publishes its next release." The agent schedules a check, searches each time it runs, and stops checking once the release appears.

## Extend the pattern

- Add a GitHub [MCP server](/langsmith/managed-deep-agents-mcp-connectors) so the agent can work toward goals like "PR #123 is merged" and nudge reviewers along the way.
- Save each goal to [memory](/langsmith/managed-deep-agents-memory) so the agent can list and report on every open goal.
- Set a minimum interval in `check_progress` to keep costs predictable: each check is a model run.
