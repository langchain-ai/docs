A goal is a completion condition, such as "every open issue labeled `docs` has a reply". Instead of stopping when it thinks it is done, the agent keeps working until a separate judge model confirms the condition holds.

## Add the goal middleware

This [middleware](/langsmith/managed-deep-agents-middleware) runs after each turn. If the request starts with `Goal:`, a judge model checks whether the goal is met. If it is not, the judge's reason goes back to the agent as a new message, and the agent keeps working:

:::python
```python middleware/goal.py
from langchain.agents.middleware import after_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage
from pydantic import BaseModel


class Verdict(BaseModel):
    met: bool
    reason: str


@after_agent(can_jump_to=["model"])
async def keep_working(state, runtime):
    messages = state["messages"]
    start = max(i for i, m in enumerate(messages) if m.type == "human" and m.name != "judge")
    goal = messages[start].text
    nudges = sum(m.name == "judge" for m in messages[start:])
    if not goal.startswith("Goal:") or nudges >= 10:
        return None
    judge = init_chat_model("openai:gpt-6.1-sol").with_structured_output(Verdict)
    verdict = await judge.ainvoke([*messages, HumanMessage(f"Is this met? {goal}")])
    if verdict.met:
        return None
    return {"messages": [HumanMessage(verdict.reason, name="judge")], "jump_to": "model"}
```
:::

:::js
```ts middleware/goal.ts
import { createMiddleware, HumanMessage, initChatModel } from "langchain";
import { z } from "zod";

const Verdict = z.object({ met: z.boolean(), reason: z.string() });

export const keepWorking = createMiddleware({
  name: "KeepWorking",
  afterAgent: {
    canJumpTo: ["model"],
    hook: async (state) => {
      const messages = state.messages;
      const start = messages.map((m) => HumanMessage.isInstance(m) && m.name !== "judge").lastIndexOf(true);
      const goal = messages[start].text;
      const nudges = messages.slice(start).filter((m) => m.name === "judge").length;
      if (!goal.startsWith("Goal:") || nudges >= 10) return;
      const judge = (await initChatModel("openai:gpt-6.1-sol")).withStructuredOutput(Verdict);
      const verdict = await judge.invoke([...messages, new HumanMessage(`Is this met? ${goal}`)]);
      if (verdict.met) return;
      return { messages: [new HumanMessage({ content: verdict.reason, name: "judge" })], jumpTo: "model" };
    },
  },
});
```
:::

Pass it to the agent definition:

:::python
```python agent.py
from managed_deepagents import define_deep_agent

from middleware.goal import keep_working

agent = define_deep_agent(name="goal-agent", middleware=[keep_working])
```
:::

:::js
```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

import { keepWorking } from "./middleware/goal";

export const agent = defineDeepAgent({ name: "goal-agent", middleware: [keepWorking] });
```
:::

The agent stops after 10 nudges from the judge, even if the goal is never met.

## Write a good goal

The judge does not run tools. It reads only what the agent has shown in the conversation, so write a goal the agent's own output can prove: one measurable end state, and how to check it. For example, "Goal: `pytest` exits 0 and no test files are modified."

## Try it

Run the agent with `mda dev` and send: "Goal: find five sources on agent evaluation, each from a different publisher." Open the trace to see the judge's messages between turns.

## Extend the pattern

- Use a smaller, faster model for the judge.
- Replace the judge with a deterministic check, such as running tests in the agent's [sandbox](/langsmith/managed-deep-agents-sandboxes).
- Keep long goals going across hours with a [runtime schedule](/langsmith/managed-deep-agents-schedules#create-schedules-at-runtime) that resumes the thread.
