A goal-oriented agent works toward an ongoing outcome rather than a single task. In this example, people tell the agent about team commitments in Slack, and a weekday review posts what needs attention.

## Configure the agent

Start with a project from the [quickstart](/langsmith/managed-deep-agents-quickstart) that has a [Slack channel](/langsmith/managed-deep-agents-channels-slack#add-a-slack-channel). Enable shared [memory](/langsmith/managed-deep-agents-memory):

:::python
```python memory.py
from managed_deepagents import MemoryLayer, define_memory

memory = define_memory(agent=MemoryLayer())
```
:::

:::js
```ts memory.ts
import { defineMemory, memoryLayer } from "managed-deepagents";

export const memory = defineMemory({ agent: memoryLayer() });
```
:::

Replace `instructions.md`:

```markdown instructions.md
# Coordination agent

Help the team keep its commitments on track. When someone tells you about a
commitment, update, or blocker, record it in /memories/agent/commitments.md
with its owner and due date, then confirm what changed.

On a scheduled review, read that file and post only what needs attention:
blockers, missing owners, and commitments due soon. If nothing needs
attention, respond with exactly [quiet].
```

Memory is shared across the deployment, so record only information that everyone in the channel may see.

## Add a scheduled review

Add a [schedule](/langsmith/managed-deep-agents-schedules) that reviews commitments each weekday and posts to a Slack channel. To find the channel ID, open the channel in Slack, click its name, and copy the **Channel ID** at the bottom of the **About** tab. Then invite the agent with `/invite @<agent-name>`.

:::python
```python schedules/coordination_review.py
from managed_deepagents import define_schedule

schedule = define_schedule(
    cron="0 9 * * 1-5",
    timezone="America/Los_Angeles",
    prompt="Review team commitments and post what needs attention today.",
    deliver_to={
        "channel": "slack",
        "to": {"type": "provider_conversation", "conversation_id": "C0123456789"},
    },
)
```
:::

:::js
```ts schedules/coordination-review.ts
import { defineSchedule } from "managed-deepagents";

export const schedule = defineSchedule({
  cron: "0 9 * * 1-5",
  timezone: "America/Los_Angeles",
  prompt: "Review team commitments and post what needs attention today.",
  deliverTo: {
    channel: "slack",
    to: { type: "provider_conversation", conversationId: "C0123456789" },
  },
});
```
:::

An exact `[quiet]` answer posts nothing.

## Try it

[Deploy the agent](/langsmith/managed-deep-agents-deploy). In Slack, mention the agent with a commitment, such as "Maya is shipping the billing fix by Friday." Then ask it to review commitments, or wait for the scheduled review.

To stop reviews, remove the schedule file and redeploy.
