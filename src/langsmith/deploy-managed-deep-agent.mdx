Managed Deep Agents is an API-first hosted runtime for creating, running, and operating deep agents in LangSmith. It gives Deep Agents a durable home with managed execution, threads, streaming, human-in-the-loop support, files, sandboxes, and LangSmith tracing.

<Note>
    Managed Deep Agents is in private preview. [Join the waitlist](https://www.langchain.com/langsmith-managed-deep-agents-waitlist) to request access.
</Note>

Deep Agents give developers an open-source harness for building agents that can plan, use tools, delegate to subagents, write files, and work over long horizons. Managed Deep Agents packages the operational layer around that harness, so you can focus on the agent's behavior instead of running custom runtime infrastructure.

For route-level details, see the [Managed Deep Agents API reference](/langsmith/managed-deep-agents-api).

## When to use Managed Deep Agents

Use Managed Deep Agents when you want to:

- Create and manage deep agents programmatically.
- Run long-running agents without standing up a custom agent server.
- Stream runs and preserve durable thread state.
- Use managed files, tools, and sandbox-backed execution.
- Inspect traces and agent behavior in LangSmith.

<Tip>
    You can also deploy Deep Agents with a standard [LangSmith Deployment](/langsmith/deployment-quickstart). Use that path when you need custom application code, custom routes, advanced authentication, full Agent Server APIs, stronger isolation controls, or maximum scalability.
</Tip>

## What Managed Deep Agents provides

### Managed runtime

Managed Deep Agents provides hosted runtime primitives for deep agents. You can create managed agents, update their configuration, create threads, and stream runs from your own application or platform workflow.

The private preview API is available under `/v1/deepagents`. It includes managed agent resources, thread operations, and streaming runs.

### Agent context and files

Managed Deep Agents keeps the familiar Deep Agents project shape:

| File or directory | Purpose |
| --- | --- |
| `AGENTS.md` | Defines the agent instructions. |
| `skills/` | Contains skills the agent can use. |
| `subagents/` | Contains subagent definitions for delegated work. |
| `tools.json` | Configures tools for the managed agent. |

Managed Deep Agents stores and versions the files that define the agent. Context Hub gives the agent a managed place to retain and update the context it needs to work over time.

### Tools and sandboxes

Configure tools with `tools.json`. Use sandbox-backed execution for workflows that need code, shell commands, and file I/O.

Managed Deep Agents keeps tool and sandbox setup in the managed runtime, so you do not need to rebuild that operational layer for every agent.

### Sleep-time compute

You can optionally enable sleep-time compute through the Managed Deep Agents API. Sleep-time compute enables LangSmith Engine for your agent, letting it review conversations, learn from real usage, and update Context Hub files between runs.

This turns agent creation from a static step into a feedback loop: the agent can improve from the work it actually does.

### LangSmith visibility

Runs are traced in LangSmith, so teams can debug behavior, inspect tool calls, and understand how an agent is improving over time.

## How it works

<Steps>
    <Step title="Create or update a managed agent">
        Use the Managed Deep Agents API to create an agent and provide the files that define it, including instructions, skills, subagents, and tool configuration.
    </Step>
    <Step title="Create a thread">
        Create a thread for the work you want the agent to perform. Threads preserve the conversation and execution state needed for long-running work.
    </Step>
    <Step title="Stream a run">
        Stream a run from your application using the thread run streaming endpoint. This lets your application display progress while the agent works.
    </Step>
    <Step title="Inspect the result in LangSmith">
        Use LangSmith traces to inspect messages, tool calls, files, and runtime behavior as the agent runs and improves.
    </Step>
</Steps>

For the supported private preview endpoint groups, see the [Managed Deep Agents API reference](/langsmith/managed-deep-agents-api).

## What this unlocks

Managed Deep Agents is designed for teams building agents that need durable execution, tools, sandboxes, tracing, and a managed path to production.

Common patterns include:

- Support and triage agents that work across long-running threads.
- Research agents that keep track of sources, notes, and deliverables.
- Coding agents that need a filesystem, shell commands, and resumable execution.
- Data analysis agents that can run code and preserve artifacts.
- Internal operations agents that improve their own context from repeated use.

## Built on open-source Deep Agents

Deep Agents remains open source. Managed Deep Agents is the hosted path for teams that want the Deep Agents harness plus LangSmith-managed runtime infrastructure.

You can keep the agent definition in your repository, then use the Managed Deep Agents API to create and operate managed agents in LangSmith.

## Private preview scope

Managed Deep Agents does not mirror every LangSmith Deployment endpoint in private preview. Non-LangGraph Platform (non-LGP) endpoint groups such as integrations, auth, triggers, skills, and sandboxes are not mirrored yet.

Request and response examples will be added after API testing is complete and public OpenAPI-generated reference pages are available.
