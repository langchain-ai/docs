The Managed Deep Agents API is a private preview API for creating, updating, and invoking Managed Deep Agents. For normal deploy workflows, use the beta `deepagents-cli` experience described in [Managed Deep Agents](/langsmith/deploy-managed-deep-agent). Use the REST API when you need a custom client, automation that cannot shell out to the CLI, or direct control over request payloads.

<Note>
    Managed Deep Agents is in private preview. [Join the waitlist](https://www.langchain.com/langsmith-managed-deep-agents-waitlist) to request access. For usage guidance, see [Managed Deep Agents](/langsmith/deploy-managed-deep-agent).
</Note>

For an end-to-end CLI workflow, see [Managed Deep Agents](/langsmith/deploy-managed-deep-agent). For run examples, see [Run Managed Deep Agents](/langsmith/managed-deep-agents-invoke).

Browse the Managed Deep Agents API reference pages in the sidebar. The generated reference includes:

- Agents: Create, list, get, update, and delete Managed Deep Agents.
- Threads: Create, search, count, and inspect durable thread state.
- Runs: Start and stream runs on Managed Deep Agent threads.
- MCP servers: Register MCP servers and store credentials referenced by agent tools.
- Auth sessions: Complete the OAuth flow for MCP servers in the `/v1/deepagents` namespace.

Managed Deep Agents are not LangSmith Deployments. Creating a Managed Deep Agent creates a Managed Deep Agent resource, a separate LangSmith tracing project, and a Context Hub agent repo for the managed file tree.

## Authentication

Requests require a LangSmith API key for a workspace with Managed Deep Agents private preview access. Pass the key with each request:

```txt
X-Api-Key: <LANGSMITH_API_KEY>
```

## Base route

The private preview API uses `/v1/deepagents`.

Routes are versioned at `/v1/`, but the surface is in private preview and may change in backwards-incompatible ways before general availability. See [API stability](/langsmith/deploy-managed-deep-agent#api-stability) for breaking-change communication.

## Resource groups

| Resource group | Purpose |
| --- | --- |
| Agents | Create and manage Managed Deep Agent resources. |
| Threads | Create and manage durable thread state for Managed Deep Agents. |
| Runs | Start and stream Managed Deep Agent runs on threads. |
| MCP servers | Register MCP servers and store credentials referenced by agent tools. |
| Auth sessions | Start and poll user OAuth sessions for OAuth MCP servers. |

## Private preview scope

Managed Deep Agents is available on LangSmith Cloud in the US region only during private preview. Self-hosted and Hybrid deployments are not supported, and EU and other regions are planned after general availability.

The API also does not mirror every LangSmith Deployment endpoint in private preview. Endpoint groups such as integrations, triggers, skills, sandboxes, auth providers, and auth tokens are not mirrored yet.

For operational notes about supported models, thread retention, rate limits, agent limits, and support channels during preview, see [Limits and notes](/langsmith/deploy-managed-deep-agent#limits-and-notes) in the deploy guide.
