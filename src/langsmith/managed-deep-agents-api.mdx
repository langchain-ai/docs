The Managed Deep Agents API is a private preview API for creating, updating, and invoking Managed Deep Agents.

<Note>
    Managed Deep Agents is in private preview. [Join the waitlist](https://www.langchain.com/langsmith-managed-deep-agents-waitlist) to request access. For usage guidance, see [Deploy Managed Deep Agents](/langsmith/deploy-managed-deep-agent).
</Note>

This page is a manually authored reference overview for the private preview. Public OpenAPI-generated reference pages are not available yet for these routes. For an end-to-end workflow with request examples, see [Deploy Managed Deep Agents](/langsmith/deploy-managed-deep-agent).

Browse the Managed Deep Agents API resource pages in the sidebar, or use the links below:

- [Agents](/langsmith/managed-deep-agents-api-agents): Create, list, get, update, and delete Managed Deep Agents.
- [Threads](/langsmith/managed-deep-agents-api-threads): Create threads that preserve conversation and execution state.
- [Runs](/langsmith/managed-deep-agents-api-runs): Stream runs on Managed Deep Agent threads.

## Authentication

Requests require a LangSmith API key for a workspace with Managed Deep Agents private preview access. Pass the key with each request:

```txt
X-Api-Key: <LANGSMITH_API_KEY>
```

## Base route

The private preview API uses `/v1/deepagents`.

## Resource groups

| Resource group | Purpose |
| --- | --- |
| [Agents](/langsmith/managed-deep-agents-api-agents) | Create and manage Managed Deep Agent resources. |
| [Threads](/langsmith/managed-deep-agents-api-threads) | Create and manage durable thread state for Managed Deep Agents. |
| [Runs](/langsmith/managed-deep-agents-api-runs) | Stream Managed Deep Agent runs on threads. |

## Private preview scope

Managed Deep Agents does not mirror every LangSmith Deployment endpoint in private preview. Non-LangGraph Platform (non-LGP) endpoint groups such as integrations, auth, triggers, skills, and sandboxes are not mirrored yet.

Request and response schemas will be added after public OpenAPI-generated reference pages are available for these routes.
