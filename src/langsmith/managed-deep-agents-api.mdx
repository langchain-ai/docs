The Managed Deep Agents API is a private preview API for creating, updating, and invoking Managed Deep Agents.

<Note>
    Managed Deep Agents is in private preview. [Join the waitlist](https://www.langchain.com/langsmith-managed-deep-agents-waitlist) to request access.
</Note>

This page is a manually authored overview for the private preview. Public OpenAPI-generated reference pages are not available yet for these routes.

## Authentication

Requests require a LangSmith API key for a workspace with Managed Deep Agents private preview access. Pass the key with each request:

```txt
X-Api-Key: <LANGSMITH_API_KEY>
```

## Endpoint groups

The private preview API uses `/v1/deepagents/agents` for managed agent resources and `/v1/deepagents/threads` for thread and run operations.

| Endpoint group | Purpose |
| --- | --- |
| `GET /v1/deepagents/agents` | List Managed Deep Agents available to the workspace. |
| `POST /v1/deepagents/agents` | Create a Managed Deep Agent. |
| `GET /v1/deepagents/agents/{agent_id}` | Get a Managed Deep Agent. |
| `PATCH /v1/deepagents/agents/{agent_id}` | Update a Managed Deep Agent. |
| `DELETE /v1/deepagents/agents/{agent_id}` | Delete a Managed Deep Agent. |
| `/v1/deepagents/threads/*` | Create and manage threads for Managed Deep Agents. |
| `/v1/deepagents/threads/{thread_id}/runs/stream` | Stream a run for a thread. |

## CLI relationship

The deprecated `deepagents deploy` command calls the Managed Deep Agents API. Existing CLI-created agents use the same managed agent model as agents managed through the API. For new deployments, use the API directly.

## Limitations

Managed Deep Agents does not mirror every LangSmith Deployment endpoint in private preview. Non-LangGraph Platform (non-LGP) endpoint groups such as integrations, auth, triggers, skills, and sandboxes are not mirrored yet.

The private preview API overview intentionally does not document request or response schemas until those routes are available from a public OpenAPI source.
