Agent Skills are reusable, on-demand capabilities that bundle instructions for a coding agent. The [`langchain-skills`](https://github.com/langchain-ai/langchain-skills) plugin includes skills for working with LangSmith: adding tracing, building datasets and evaluators, running experiments, and monitoring agents in production. The same plugin also covers building agents with LangChain, LangGraph, and Deep Agents. To work with LangSmith data directly from the terminal, use the [LangSmith CLI](/langsmith/langsmith-cli).

The set of skills changes between releases. For the current list, browse the [`skills` directory](https://github.com/langchain-ai/langchain-skills/tree/main/skills) or list the skills in your agent.

<Note>
The LangSmith skills moved to `langchain-skills` from the deprecated `langsmith-skills` repository, which no longer receives updates. To switch, see [Migrate from `langsmith-skills`](#migrate-from-langsmith-skills).
</Note>

## Install the plugin

The plugin bundles the skills with MCP connections to the LangChain documentation and API reference. Installing the plugin is the recommended path.

<CodeGroup>
```text Claude Code
/plugin marketplace add langchain-ai/langchain-skills
/plugin install langchain-skills@langchain-skills
```

```bash Codex
codex plugin marketplace add langchain-ai/langchain-skills
codex plugin add langchain-skills@langchain-skills
```

```bash Deep Agents Code
dcode plugin marketplace add langchain-ai/langchain-skills
dcode plugin install langchain-skills@langchain-skills
```
</CodeGroup>

Run the Claude Code commands inside a Claude Code session. With Claude Code v2.1.292 or later, you can install from your shell in one command instead:

```bash
claude plugin install langchain-skills --marketplace langchain-ai/langchain-skills
```

## Turn on auto-update

The skills change often. Turn on auto-update so your agent loads the current guidance instead of an outdated copy:

- **Claude Code**: Claude Code leaves auto-update off for third-party marketplaces. Run `/plugin`, go to **Marketplaces**, select `langchain-skills`, and choose **Enable auto-update**. To update immediately, run `/plugin marketplace update langchain-skills`.
- **Deep Agents Code**: The plugin opts in to background updates. After an update, run `/reload` or start a new session.
- **Codex**: Local Git marketplace installs have no documented auto-update setting. Run `codex plugin marketplace upgrade langchain-skills` to update.

After an update, start a new agent session to load the updated skills. For scripted setups and managed workspaces, see [Updates](https://github.com/langchain-ai/langchain-skills#updates) in the repository README.

## Install skills only

To install the skills without the plugin, use `npx skills`. This path does not register the documentation MCP servers.

<CodeGroup>
```bash Local (current project)
npx skills add langchain-ai/langchain-skills --skill '*' --yes
```

```bash Global (all projects)
npx skills add langchain-ai/langchain-skills --skill '*' --yes --global
```

```bash Link to a specific agent (for example, Claude Code)
npx skills add langchain-ai/langchain-skills --agent claude-code --skill '*' --yes --global
```
</CodeGroup>

<Tip>
`npx skills` does not update automatically. To update, run `npx skills update`, then start a new agent session.
</Tip>

For other agents and for installing from a cloned checkout, see [Installation](https://github.com/langchain-ai/langchain-skills#installation) in the repository README.

## Connect to LangSmith

Installing the plugin or the skills does not require a LangSmith API key. To let your coding agent query or manage a LangSmith workspace, install the [LangSmith CLI](/langsmith/langsmith-cli#install) on the same machine and authenticate:

```bash
langsmith auth login
```

Choose the intended workspace during authentication. For self-hosted instances and profiles, see [Authenticate](/langsmith/langsmith-cli#authenticate).

To trace or evaluate an application you build, configure the LangSmith SDK with a [LangSmith API key](/langsmith/create-account-api-key). Set the key as the `LANGSMITH_API_KEY` environment variable and keep it out of source control.

## Migrate from `langsmith-skills`

Remove the `langsmith-skills` skills before you install `langchain-skills`, so your agent does not load two overlapping sets of guidance:

- **Claude Code plugin**: Run `claude plugin marketplace remove langsmith-skills`, which also uninstalls the plugin.
- **`npx skills`**: Run the following command once, then run it again without `--global` in each project where you installed skills:

  ```bash
  npx skills remove langsmith-trace langsmith-dataset langsmith-evaluator \
    langsmith-custom-apps langsmith-experiment-diagnosis \
    langsmith-graph-evaluator langsmith-online-eval-engineering --global --yes
  ```

- **`install.sh` or copied folders**: Delete the `langsmith-*` folders from each skills directory you installed into, such as `~/.claude/skills/`, `.claude/skills/`, `~/.agents/skills/`, or `.agents/skills/`.

For the exact commands for each install method, see [Migrate from the standalone skills](https://github.com/langchain-ai/langchain-skills#migrate-from-the-standalone-skills) in the repository README. Then [install the plugin](#install-the-plugin) and [turn on auto-update](#turn-on-auto-update).
