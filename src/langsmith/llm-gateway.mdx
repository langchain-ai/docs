The LLM Gateway is a proxy between your application and the model providers your workspace has configured. Your application authenticates with a [LangSmith API key](/langsmith/create-account-api-key). The gateway routes each request to the provider named in its model ID, traces the call, and applies your organization's governance policies.

Without the gateway, provider keys are copied onto every application and deployment that calls a model. Spend and data controls depend on each provider account. With the gateway, provider keys stay in LangSmith, every call appears as a [LangSmith trace](/langsmith/llm-gateway-traces), and [spend limits](/langsmith/llm-gateway-spend-policies), [rate limits](/langsmith/llm-gateway-rate-limit-policies), and [data policies](/langsmith/llm-gateway-data-policy) apply to every call in their scope.

## Choose a request format

The gateway accepts OpenAI Chat Completions, Anthropic Messages, and OpenAI Responses requests. The request format and the provider are independent: a Chat Completions request can call an Anthropic model, and the gateway translates the request and response when the provider uses a different native format. Keep the format your application already uses, and switch providers by changing the model ID. For endpoints, model ID syntax, and translation behavior, see [API formats](/langsmith/llm-gateway-api-formats).

LangChain chat models and Deep Agents reach the gateway through the `LANGSMITH_GATEWAY` environment variable, which uses [direct model access](/langsmith/llm-gateway-direct-model-access) in each provider's native format, so no translation applies.

## Choose how credentials are managed

The gateway calls each provider with a credential that LangSmith holds: your own provider key, stored as a workspace secret, or [Gateway Credits](/langsmith/llm-gateway-credits), which LangChain bills to your LangSmith account. For every credential source and who bills it, see [Provider authentication](/langsmith/llm-gateway-provider-authentication#choose-a-credential-source).
