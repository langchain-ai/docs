</Note>

A model access policy defines an allowlist of providers and models that may be used through the [LLM Gateway](/langsmith/llm-gateway). Any request that targets a provider or model not on the list is blocked. If no model access policy matches a request, there is no restriction and all configured providers and models are available.

## Policy configuration

A model access policy specifies a `providers` array. Each entry names a direct gateway provider and specifies one of two access modes:

- `all` — every model the provider can serve is allowed.
- `selected` — only the listed models are allowed. At least one model is required.

## Scopes and overrides

A model access policy is scoped to exactly one subject tier:

| Tier | Scope |
| --- | --- |
| `organization_id` | Applies to the entire organization. An empty matcher list is treated as org-wide. |
| `workspace_id` | Applies to one workspace. |
| `user_id` | Applies to one user. |
| `api_key_id` | Applies to a single API key. |

### Policy overrides

When a request matches model access policies at multiple tiers, only the narrowest tier applies:

```
api_key_id > user_id > workspace_id > organization_id
```

The narrower policy is a **complete replacement**, not an intersection. If an org-wide policy allows OpenAI and Anthropic, and a workspace-level policy allows only OpenAI, then requests in that workspace may only use OpenAI — the Anthropic access granted at the org level does not carry through.

This lets administrators set a broad baseline at the org level and carve out stricter access for specific workspaces, users, or API keys without modifying the broader policy. If multiple policies match at the same tier, all of them apply and a model is usable only if every same-tier policy allows it.

## No policy defined

Model access is opt-in. If no model access policy matches a request, there is no restriction: all configured providers and models remain available. There is no implicit default-deny — restrictions exist only where a policy has been explicitly created.
