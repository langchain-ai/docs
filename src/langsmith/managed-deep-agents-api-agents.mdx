Agents are the managed resources that define a Deep Agent's runtime configuration, instructions, and tool access.

<Note>
    Managed Deep Agents is in private preview. [Join the waitlist](https://www.langchain.com/langsmith-managed-deep-agents-waitlist) to request access. For an end-to-end workflow with request examples, see [Deploy Managed Deep Agents](/langsmith/deploy-managed-deep-agent).
</Note>

## Authentication

Requests require a LangSmith API key for a workspace with Managed Deep Agents private preview access. Pass the key with each request:

```txt
X-Api-Key: <LANGSMITH_API_KEY>
```

## Base route

Agent endpoints use `/v1/deepagents/agents`.

## Endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/v1/deepagents/agents` | List Managed Deep Agents available to the workspace. |
| `POST` | `/v1/deepagents/agents` | Create a Managed Deep Agent. |
| `GET` | `/v1/deepagents/agents/{agent_id}` | Get a Managed Deep Agent. |
| `PATCH` | `/v1/deepagents/agents/{agent_id}` | Update a Managed Deep Agent. |
| `DELETE` | `/v1/deepagents/agents/{agent_id}` | Delete a Managed Deep Agent. |

## Create or update an agent

Create and update requests can include the following fields:

| Field | Purpose |
| --- | --- |
| `name` | Human-readable agent name. |
| `description` | Short description of the agent. |
| `graph_id` | Graph identifier for the managed Deep Agent runtime. |
| `visibility` | Visibility scope for the agent. |
| `tenant_access_level` | Workspace access level for the agent. |
| `runtime` | Runtime configuration, including model and tool server settings. |
| `instructions` | Agent instructions. |
| `tools` | Tool configuration, including MCP tools and interrupt settings. |

The `tools` field uses the same shape as `tools.json` in the [deployment guide](/langsmith/deploy-managed-deep-agent#define-the-agent).
