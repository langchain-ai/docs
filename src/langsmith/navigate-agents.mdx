## Switch between agents

The agent switcher sits at the left of the top bar, after the workspace switcher and the panel collapse toggle. It reads either **All agents** or the name of the agent you are in. In a section other than the Overview, a breadcrumb follows it and names that section.

The address behind it is `/o/<workspaceId>/a/<agentIdentifier>/...`. The workspace slot takes a UUID, and the agent slot takes the agent's [identifier](/langsmith/agent-registry#identifiers-and-display-names). A hyphen in the agent slot means all agents, so `/a/-` is the **All agents** view and `/a/<agentIdentifier>` is a single agent. Either state can be set from the address bar, which is how to link directly to one of the two views.

## All agents and single-agent views

The switcher moves between two views:

- **All agents**: The agent list, with one card for each agent in the workspace. In an empty workspace it shows a get-started screen instead, which offers ways to build or connect a first agent. For the options, see the [new agent menu](/langsmith/create-an-agent#start-from-the-new-agent-menu).
- **A single agent**: That agent's Overview.

The left navigation lists the same items in both views, though its first row reads **All agents** on the agent list and **Overview** inside an agent. Two things differ:

- **Badge counts**: Hidden on the agent list, except on Deployments. When you select an agent, the counts appear and cover only that agent.
- **Section availability**: Some sections ask you to pick an agent first. See [Sections that require an agent](#sections-that-require-an-agent).

## Sections that require an agent

Most sections work with **All agents** selected, including the agent list, which lists every agent in the workspace, and Deployments, which lists every deployment in the workspace. Engine, Studio, Tracing, and Monitoring need you to select an agent. If you open these sections with **All agents** selected, what you see depends on whether your workspace has any agents yet.

If your workspace has agents, the section shows a searchable list of agents to pick from, headed **Pick an agent to view**. The top bar stays in place, so you can also pick from the switcher. Tracing shows **Connect an agent** below the list to users with the `projects:create` permission. The list includes every agent in the workspace.

Studio opens on its own page, headed **Agent Studio**, with three choices:

- **Build a new agent**: Starts [building an agent in Studio](/langsmith/build-an-agent).
- **Connect a local server**: Runs and debugs an agent from your machine.
- **Select existing agent**: Shows the agent list, with **Connect agent server** below it.

With no agents in the workspace, the agent list in Engine, Studio, Tracing, and Monitoring is empty, reading **No agents available**. Deployments shows its own page, which offers ways to create a first deployment when the workspace has none.

After you pick an agent, LangSmith keeps it selected as you move between these sections. To see the agent list for **All agents**, hover over the selected agent's name in the switcher and select the **X** that appears beside it.

## Open Settings

Settings opens in its own layout: the agent switcher is gone, the navigation splits into Organizations and Workspace sections, and a **Back to LangSmith** link returns to the agent views.

## Read the agent Overview

When you select an agent, LangSmith opens its Overview. The page summarizes what the agent did over the last 7 days and links to the places where you work on it.

The header shows the agent's display name, followed by these items:

- **ID**: Copies the agent's identifier, which is also the value the address bar carries. Use it when you need the value for tracing. [Agent addressing](/langsmith/log-traces-to-agent) takes the identifier, not the display name. For which value is which, see [Identifiers and display names](/langsmith/agent-registry#identifiers-and-display-names).
- **Source**: A badge that says how the agent runs. It reads **External** for an agent traced from outside LangSmith, and **LangSmith Deployment** or **Managed Deep Agent** for an agent deployed through LangSmith. An agent [built in Studio](/langsmith/build-an-agent) has no badge.
- **Owner**: The owner's name or email.
- **Agent settings**: The gear button opens a menu to rename the agent, change its owner or avatar, and delete it. An external agent also lists **API keys**, and an agent built in Studio lists **Edit configuration**. The items you see depend on your permissions.

Below the name, three links lead out of the Overview:

- **Tracing**: Opens the agent's traces. The time beside it is how long ago the most recent run started, across all environments. Hover over it to see the latest run in each environment.
- **Engine**: Opens [Engine](/langsmith/engine) for this agent.
- **Deployment**: Opens the deployments page. For an agent deployed through LangSmith, it also shows how many revisions are active, and hovering lists each environment's revision ID. The link is unavailable for agents built in Studio.

The rest of the page shows the following, in order. The charts and tables combine all of the agent's environments over a fixed window of the last 7 days, counted from midnight UTC six days ago.

- **Engine summary**: Appears once Engine has written an [agent overview document](/langsmith/engine-setup#give-context-on-your-agent) for one of the agent's environments. It shows the summary with a **Read more** link.
- **Activity**: Three daily charts of root traces. **Trace count** splits traces into succeeded and failed, **Trace latency** shows P50 and P99, and **Cost** shows the total for the window.
- **Models** and **Tools**: Side-by-side tables that count model calls by model name and tool calls by tool name, with each one's share of the total. The top five appear first, and the rest are grouped under **Other**.
- **Online Evaluators**: With no [online evaluators](/langsmith/evaluators) on the agent, the section reads **No online evaluators** and offers templates to add, such as **User Satisfaction**. Once evaluators run, it charts up to three feedback keys, with the average score or the category counts over time.

The **Engine** panel sits beside these sections on a wide screen and after them on a narrow one. It lists up to six open issues with their severity, category, title, and number of affected traces. With none, it reads **No open issues**. The panel does not show whether Engine is turned on for this agent. To check, select **Go to Engine**. For the setup steps, see [Turn on Engine for a tracing project](/langsmith/engine-setup#turn-on-engine-for-a-tracing-project). The panel is hidden when Engine is not enabled for your organization or you do not have permission to view issues.
