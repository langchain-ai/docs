[Chat](/langsmith/chat) is built into your LangSmith workspace and answers natural language questions about your traces, threads, and prompts. On self-hosted LangSmith, Chat is an optional feature that runs alongside the base platform. Chat was formerly named Polly, so its Helm values block and secret key still use `polly`. For the other optional features, see [Enable additional LangSmith features](/langsmith/deploy-self-hosted-full-platform).

<Note>
As of Helm chart `0.16.0`, `polly.enabled` defaults to `true`. Provide the Chat encryption key before you upgrade, or set `polly.enabled` to `false`.
</Note>

Before starting, complete the [prerequisites](/langsmith/deploy-self-hosted-full-platform#prerequisites) for additional features.

## Components

Enabling Chat provisions the following components in your cluster:

- `api-server`: The main API server that handles Chat requests.
- `queue`: Background task processing queue.
- `postgres`: Dedicated PostgreSQL instance for Chat data. Can be replaced with an external PostgreSQL instance.
- `redis`: Dedicated Redis instance for caching and pub/sub. Can be replaced with an external Redis instance.

## Enable Chat

<SelfHostAgentBootstrapMigration />

<Steps>
  <Step title="Add the configuration to your langsmith_config.yaml">
    <Tabs>
      <Tab title="Using Kubernetes secrets (recommended)">
        Reference your existing secret by name. The chart reads `polly_encryption_key` from it automatically.

        ```yaml
        config:
          existingSecretName: "<your-secret-name>"

        polly:
          enabled: true
        ```
      </Tab>
      <Tab title="Using inline values">
        Set the encryption key directly in your config file. Avoid committing this file to version control.

        ```yaml
        polly:
          enabled: true
          encryptionKey: "<chat-encryption-key>"
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step title="(Optional) Use external databases">
    Chat deploys its own PostgreSQL and Redis instances by default. To use external instances instead, configure `polly.postgres.external` and `polly.redis.external`:

    ```yaml
    polly:
      enabled: true
      postgres:
        external:
          enabled: true
          connectionUrl: "<chat-postgres-connection-url>"
      redis:
        external:
          enabled: true
          connectionUrl: "<chat-redis-connection-url>"
    ```
  </Step>
  <Step title="Apply the changes">
    <SelfHostApplyHelmChanges feature="Chat" />
  </Step>
</Steps>

## Disable Chat

To disable Chat, set `polly.enabled` to `false` in your [`langsmith_config.yaml`](/langsmith/kubernetes#configure-your-helm-charts):

```yaml
polly:
  enabled: false
```
