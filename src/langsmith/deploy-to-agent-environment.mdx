Deploying to an agent environment binds a [deployment](/langsmith/deployment) to one [agent](/langsmith/agents) and one of that agent's [environments](/langsmith/agent-environments). Two flags carry the binding, and the LangGraph CLI and the `mda` CLI both accept them.

Use it to keep a staging build and a production build of the same agent apart, so each one reports into its own environment.

<AgentBetaNote />

Run either CLI from the project folder that holds `langgraph.json`.

## Addressing flags

Both CLIs take the same two flags:

- **`--agent-id`**: The agent to deploy to. The value is the agent's identifier, not its display name. For which value is which, see [Identifiers and display names](/langsmith/agents#identifiers-and-display-names).
- **`--agent-environment`**: The environment the deployment reports into, and one of `local`, `development`, `staging`, or `production`. Use the lowercase form, which maps to the Local, Development, Staging, and Production labels in the UI.

The flags name the same pair that [agent addressing](/langsmith/log-traces-to-agent) names on the tracing side, so a deployment and the traces it produces can address one agent and one environment.

## Deploy with the LangGraph CLI

These flags require `langgraph-cli` v0.4.32 or later. To deploy:

1. Install the CLI:

   ```bash
   uv tool install --force "langgraph-cli>=0.4.32"
   ```

1. Deploy, naming the agent and the environment:

   ```bash
   langgraph deploy --agent-id my-agent --agent-environment staging --remote
   ```

`--remote` forces a remote build. Without it, the CLI builds locally whenever Docker is available. For the rest of the flags, see [`langgraph deploy`](/langsmith/cli#deploy).

## Deploy with the mda CLI

These flags require `managed-deepagents` 0.7.5.dev4, which is a prerelease build. Install that version exactly, because 0.8.0 and later do not accept the flags and a version range resolves to a build that rejects them. To deploy:

1. Install the CLI:

   ```bash
   uv tool install --force --prerelease allow "managed-deepagents==0.7.5.dev4"
   ```

1. Deploy the project in the current folder:

   ```bash
   mda deploy . --agent-id my-agent --agent-environment staging
   ```

This command installs `mda` as a global tool, which is a different binary from the project-local `mda` that [Deploy a Managed Deep Agent](/langsmith/managed-deep-agents-deploy) runs through `uv run`. For the rest of the flags, see [Deploy projects](/langsmith/managed-deep-agents-cli#deploy-projects).
