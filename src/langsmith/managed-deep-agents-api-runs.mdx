Runs invoke a Managed Deep Agent on a thread. The private preview API supports streaming run output as server-sent events.

<Note>
    Managed Deep Agents is in private preview. [Join the waitlist](https://www.langchain.com/langsmith-managed-deep-agents-waitlist) to request access. For an end-to-end workflow with request examples, see [Deploy Managed Deep Agents](/langsmith/deploy-managed-deep-agent).
</Note>

## Authentication

Requests require a LangSmith API key for a workspace with Managed Deep Agents private preview access. Pass the key with each request:

```txt
X-Api-Key: <LANGSMITH_API_KEY>
```

## Base route

Run endpoints are scoped to a thread under `/v1/deepagents/threads`.

## Endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/v1/deepagents/threads/{thread_id}/runs/stream` | Stream a run for a Managed Deep Agent thread. |

Set the `Accept` header to `text/event-stream` when streaming:

```txt
Accept: text/event-stream
```

## Stream a run

The streaming request body can include:

| Field | Purpose |
| --- | --- |
| `messages` | Input messages for the run. |
| `stream_mode` | Stream modes to return. |
| `stream_subgraphs` | Whether to stream subgraph events. |
| `user_timezone` | User timezone for runtime context. |

Supported stream modes in the deployment guide include `values`, `updates`, and `messages-tuple`. For a complete request example, see [Stream a run](/langsmith/deploy-managed-deep-agent#stream-a-run).
