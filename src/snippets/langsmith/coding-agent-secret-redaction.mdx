It catches provider API keys, JSON Web Tokens, and PEM private keys along with common patterns such as `API_KEY=<value>` or a password in a URL. Each match is replaced with `[SECRET_DETECTED]` and the full rule list is in [Redact secrets from traces](/langsmith/redact-secrets#rules-in-the-preset).

Redaction only matches known credential shapes so treat it as a safety net rather than a guarantee. Run names, tags, and attachments skip it and a redacted trace still holds your prompts and file contents. Limit who can read the tracing project.
