Before running the application, register its tracing destination:

1. In an [agent-based workspace](/langsmith/agents), open **+ Agent**, choose **Observability**, and create an agent with an **Agent name** and **Agent ID**. This requires permission to create projects. If the agent already exists, reuse it.
2. Copy the **Agent ID** and choose an environment: `local`, `development`, `staging`, or `production`.
3. Configure [agent addressing](/langsmith/log-traces-to-agent) before running the application:

    ```bash
    export LANGSMITH_AGENT_ID="<your-agent-id>"
    export LANGSMITH_AGENT_ENVIRONMENT="production"
    ```

Register the agent once, not for every trace. Remove `LANGSMITH_PROJECT`, `LANGCHAIN_PROJECT`, and `LANGCHAIN_SESSION` from this application's environment. Do not combine project settings with agent addressing. For automated registration, see [Create an agent programmatically](/langsmith/create-an-agent#create-an-agent-programmatically).

<Accordion title="Project-based workspaces and self-hosted LangSmith">
Agent addressing is available in agent-based workspaces on LangSmith Cloud. In a project-based workspace, including self-hosted LangSmith, set `LANGSMITH_PROJECT` to your tracing project name instead of setting the two agent variables.
</Accordion>
