To send traces to a specific project, use the [`LANGSMITH_PROJECT` environment variable](/langsmith/log-traces-to-project). If this is not set, LangSmith will create a default tracing project automatically on trace ingestion. In an [agent-based workspace](/langsmith/agents), the project that LangSmith creates becomes the **Production** [environment](/langsmith/agent-environments) of an agent named after it. To name the agent and the environment directly instead, see [Log traces to an agent](/langsmith/log-traces-to-agent).
