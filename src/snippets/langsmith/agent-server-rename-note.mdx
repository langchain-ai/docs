<Note>
LangSmith Deployment is now **LangSmith Agent Servers**, and each deployment is now called an Agent Server. CLI command names, environment variables, APIs, IDs, and URLs are unchanged. Billing and plan line items keep the LangSmith Deployment name.

The Python LangGraph CLI and `mda` use `--agent-server-id` and `--agent-server-type` where supported. The legacy `--deployment-id` and `--deployment-type` flags remain accepted. Older CLI versions and the JavaScript LangGraph CLI may still require the legacy spellings. Check command help for your installed version. Older self-hosted LangSmith versions may still show Deployment labels.
</Note>
