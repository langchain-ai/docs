In the [LangSmith UI](https://smith.langchain.com), add your model provider's API key as a [workspace secret](/langsmith/workspace-secrets):

1. Open <Icon icon="settings" /> **Settings**. If your organization has workspaces, select **Workspace** at the top of the sidebar and pick the workspace that needs the secret. Under **Configuration**, select **Secrets**.
1. Select **+ Secret**. Under **Provider**, select your model provider, enter your API key, and select **Save**.

For self-hosted LangSmith, providers that are not listed, and the permission that adding a secret requires, see [Add a secret](/langsmith/workspace-secrets#add-a-secret).
