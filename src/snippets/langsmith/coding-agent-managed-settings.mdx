An admin can lock tracing settings for every user with a managed file at `~/.langsmith-plugins/managed.json` in each user's home folder. The Claude Code, Cursor, and Codex plugins all read this file and its settings override the user's own config files and environment variables.

```json
{
  "api_url": "https://langsmith.example.com",
  "project": "engineering",
  "strict_auth": true
}
```

The managed file works on macOS and Linux. The plugin only trusts it when:

- Root owns the file and its folder.
- No other user can write to either.
- Neither is a symlink.

If the file exists but fails these checks then tracing stops and the user sees a message to contact their admin. Locking a setting also locks the settings tied to it so users cannot route traces around the lock. For example locking `project` also stops users from adding their own [replicas](/langsmith/trace-replicas).

Admins usually install the file on each machine with a mobile device management (MDM) tool such as Jamf or Microsoft Intune. For an example of that install and every setting you can lock see the [plugin settings guide](https://github.com/langchain-ai/langsmith-plugin-binary/blob/main/docs/settings.md).
