## Dataset experiment runs: query

Query dataset examples together with the experiment runs recorded against each example. Accepts one or more `experiment_ids` so you can view runs from multiple experiments side by side; results are returned as a cursor-paginated page.

### Main changes

<Tabs>

#### Response fields

<Tabs>
  <Tab title="Python">
    `get_experiment_results` returned experiment results with an `examples_with_runs` iterator. `datasets.experiment_runs.query` returns a paginated page object with `items` and `next_cursor`.

    | Before | After | Notes |
    |---|---|---|
    | `examples_with_runs` | `page.items` | Example rows moved into the page envelope |
    | *(handled internally)* | `page.next_cursor` | Pass as `cursor` to fetch the next page |
    | Run fields controlled by `preview=True/False` | Run fields controlled by `selects=[...]` | Omitted selects return only `id` |
    | `run.session_id` | `run.project_id` | Renamed |
    | `run.in_dataset` | `run.is_in_dataset` | Renamed |
    | Cost detail strings | Numeric cost fields | v2 returns numeric costs |
  </Tab>
  <Tab title="TypeScript">
    The legacy dataset runs endpoint was not exposed on the public TypeScript `Client`. `datasets.experimentRuns.query` returns a paginated page with item helpers and a `next_cursor` value.

    | Before | After | Notes |
    |---|---|---|
    | Legacy endpoint JSON array | `page.getPaginatedItems()` | Example rows moved into the page envelope |
    | Numeric `offset` in direct HTTP requests | `page.next_cursor` | Pass as `cursor` to fetch the next page |
    | Run fields controlled by `preview` in direct HTTP requests | Run fields controlled by `selects: [...]` | Omitted selects return only `id` |
    | `run.session_id` | `run.project_id` | Renamed |
    | `run.in_dataset` | `run.is_in_dataset` | Renamed |
    | Cost detail strings | Numeric cost fields | v2 returns numeric costs |
  </Tab>
  <Tab title="Java">
    `runs().query` returned an optional list. `experimentRuns().query` returns a page object with `items()` and `nextCursor()`.

    | Before | After | Notes |
    |---|---|---|
    | `Optional<List<ExampleWithRunsCh>>` | `ExperimentRunQueryPage` | Example rows moved into the page envelope |
    | Numeric `offset()` for the next request | `nextCursor()` | Pass as `cursor()` to fetch the next page |
    | Run fields controlled by `preview()` | Run fields controlled by `selects()` | Omitted selects return only `id` |
    | `sessionId()` | `projectId()` | Renamed |
    | `inDataset()` | `isInDataset()` | Renamed |
    | Cost detail strings | Numeric cost fields | v2 returns numeric costs |
  </Tab>
  <Tab title="Go">
    `Datasets.Runs.Query` returned a slice pointer. `Datasets.ExperimentRuns.Query` returns an `ItemsCursorPostPagination` with `Items` and `NextCursor`.

    | Before | After | Notes |
    |---|---|---|
    | `*[]ExampleWithRunsCh` | `*pagination.ItemsCursorPostPagination[DatasetExperimentRunQueryResponse]` | Example rows moved into the page envelope |
    | Numeric `Offset` for the next request | `NextCursor` | Pass as `Cursor` to fetch the next page |
    | Run fields controlled by `Preview` | Run fields controlled by `Selects` | Omitted selects return only `ID` |
    | `SessionID` | `ProjectID` | Renamed |
    | `InDataset` | `IsInDataset` | Renamed |
    | Cost detail strings | Numeric cost fields | v2 returns numeric costs |
  </Tab>
  <Tab title="cURL">
    `POST /api/v1/datasets/{dataset_id}/runs` returned a JSON array. `POST /v2/datasets/{dataset_id}/experiment-runs` returns `{ "items": [...], "next_cursor": "..." }`.

    | Before | After | Notes |
    |---|---|---|
