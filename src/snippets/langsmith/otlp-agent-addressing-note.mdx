<Note>
**Agent-based workspaces.** Which container a span lands in depends on how your workspace is organized. A project-based workspace uses the `Langsmith-Project` header to name the tracing project. An agent-based workspace addresses a span with the `langsmith.trace.agent_id` and `langsmith.trace.agent_environment` span attributes instead, and `Langsmith-Project` does not apply to a span that is already agent-addressed. Naming both an agent and a tracing project is rejected.

Agent addressing is not yet available on the OTLP path. For the addressing model, see [Log traces to an agent](/langsmith/log-traces-to-agent).
</Note>
