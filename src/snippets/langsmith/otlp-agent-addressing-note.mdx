<Note>
**Agent-based workspaces.** Agent addressing is not yet available on the OTLP path. Use the `Langsmith-Project` header to name the tracing project, whichever way your workspace is organized.

When it lands, an agent-based workspace will address a span with the `langsmith.trace.agent_id` and `langsmith.trace.agent_environment` span attributes, `Langsmith-Project` will not apply to a span that is already agent-addressed, and naming both an agent and a tracing project will be rejected. For the addressing model, see [Log traces to an agent](/langsmith/log-traces-to-agent).
</Note>
