<Note>
**Agent-based workspaces.** Agent addressing is in [beta](/langsmith/release-stages). To send OTLP traces to an agent and an environment instead of a project, replace the `Langsmith-Project` header with both of the following headers:

- **`Langsmith-Agent-Id`**: The identifier of the agent. It must be 1 to 63 lowercase letters, digits, or hyphens, start with a letter, and end with a letter or digit. LangSmith creates the agent on first use.
- **`Langsmith-Agent-Environment`**: The environment the traces belong to. One of `local`, `development`, `staging`, or `production`.

For example, set `OTEL_EXPORTER_OTLP_HEADERS="x-api-key=<your langsmith api key>,Langsmith-Agent-Id=<agent id>,Langsmith-Agent-Environment=<environment>"`.

The headers apply to every span in the request. Send both headers or neither: LangSmith rejects a request that sets one without the other, or that sets either alongside `Langsmith-Project`, with a `400` error. A workspace that does not support agent addressing rejects the request with a `403` error. Span attributes, including `gen_ai.agent.name`, do not address an agent. For the addressing model, see [Log traces to an agent](/langsmith/log-traces-to-agent).
</Note>
