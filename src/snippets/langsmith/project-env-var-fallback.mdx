If your workspace is [project-based](/langsmith/migrate-to-agent-based-workspaces#check-which-one-you-have), set `LANGSMITH_PROJECT=<your-project-name>` instead of `LANGSMITH_AGENT_ID` and `LANGSMITH_AGENT_ENVIRONMENT`. Do not set both: when the environment names an agent and a project, the SDK does not send traces that name no destination in code.
