<Note>
User group scope requires [User Groups](/langsmith/user-groups), available on the [Enterprise plan](https://www.langchain.com/pricing) and self-hosted deployments. For self-hosted prerequisites and enablement, see [Enable user groups for self-hosted deployments](/langsmith/user-groups#enable-user-groups-for-self-hosted-deployments). Selecting a user group also requires the `organization:user-groups:read` permission.
</Note>
