[Respan](https://www.respan.ai/) provides observability, tracing, evaluation, prompt management, and an OpenAI-compatible gateway for LLM applications. The `@respan/instrumentation-langchain` package exports LangChain callback spans to Respan for LangChain.js, LangGraph.js, and Langflow-style component flows.

## Installation and setup

Install the Respan SDK, the LangChain instrumentation package, and LangChain Core:

<CodeGroup>
```bash npm
npm install @respan/respan @respan/instrumentation-langchain @langchain/core
```

```bash yarn
yarn add @respan/respan @respan/instrumentation-langchain @langchain/core
```

```bash pnpm
pnpm add @respan/respan @respan/instrumentation-langchain @langchain/core
```
</CodeGroup>

Create a Respan API key in the [Respan platform](https://platform.respan.ai/platform/api/api-keys), then set it as an environment variable:

```bash
export RESPAN_API_KEY="your-respan-api-key"
```

## Tracing

Use `LangChainInstrumentor` with the Respan SDK, then attach the Respan callback config to a runnable invocation.

```typescript
import { HumanMessage } from "@langchain/core/messages";
import { FakeListChatModel } from "@langchain/core/utils/testing";
import { LangChainInstrumentor } from "@respan/instrumentation-langchain";
import { Respan } from "@respan/respan";

const langchain = new LangChainInstrumentor();
const respan = new Respan({
  apiKey: process.env.RESPAN_API_KEY,
  appName: "langchain-js-respan-example",
  instrumentations: [langchain],
});

await respan.initialize();

const model = new FakeListChatModel({
  responses: ["Hello from a traced LangChain.js run."],
});

try {
  const response = await model.invoke(
    [new HumanMessage("Say hello to Respan tracing.")],
    langchain.addCallback({
      runName: "hello_respan",
      tags: ["langchain", "respan"],
      metadata: { service: "docs-example" },
    })
  );
  console.log(response.content);
} finally {
  await respan.shutdown().catch(() => undefined);
}
```

You can also create a reusable callback handler when independent Langflow-style component runs should be grouped into the same trace:

```typescript
import {
  addRespanCallback,
  getCallbackHandler,
} from "@respan/instrumentation-langchain";

const handler = getCallbackHandler();
const config = addRespanCallback(
  {
    tags: ["langflow", "custom-component"],
    metadata: { framework: "langflow", langflow_component: "RoutingComponent" },
  },
  handler
);
```

## Gateway

LangChain can also route underlying LLM calls through the OpenAI-compatible Respan gateway. See the [Respan LangChain gateway guide](https://docs.respan.ai/docs/gateway/langchain) for setup details.
