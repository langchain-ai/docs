[You.com](https://you.com) provides real-time web search, content extraction, and research APIs built for grounding LLMs in current, accurate information.

The `@youdotcom-oss/langchain` package connects to the hosted You.com MCP server via `createYouClient()`, returning a LangChain MCP client whose `getTools()` method resolves the full tool set.

## Installation and setup

<CodeGroup>
    ```bash npm
    npm install @youdotcom-oss/langchain langchain
    ```

    ```bash yarn
    yarn add @youdotcom-oss/langchain langchain
    ```

    ```bash pnpm
    pnpm add @youdotcom-oss/langchain langchain
    ```
</CodeGroup>

[Get a You.com API key](https://you.com/platform/api-keys) and set it as an environment variable:

```bash
export YDC_API_KEY="your-api-key"
```

## Tools

The package connects to `https://api.you.com/mcp` and exposes the following tools via `client.getTools()`:

| Tool | Description |
|------|-------------|
| `you-search` | Real-time web and news search with filtering |
| `you-research` | Comprehensive, cited answers with configurable effort |
| `you-contents` | Full page content extraction from URLs |
| `you-finance` | Finance-optimized research over SEC filings, earnings, and market data |

`you-finance` is not included in the default tool set. Request it explicitly with the `tools` option.

See a [usage example](/oss/integrations/tools/youdotcom).

## Quick start

```typescript
import { createAgent, initChatModel } from "langchain";
import { createYouClient } from "@youdotcom-oss/langchain";

const client = await createYouClient();
const tools = await client.getTools();

const agent = createAgent({
  model: await initChatModel("claude-sonnet-4-6"),
  tools,
  systemPrompt: "You are a helpful research assistant. Always cite your sources.",
});

const result = await agent.invoke({
  messages: [{ role: "user", content: "What are the latest developments in AI?" }],
});

await client.close();
```
