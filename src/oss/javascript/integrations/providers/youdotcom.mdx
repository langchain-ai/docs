[You.com](https://you.com) provides real-time web search, content extraction, and research APIs built for grounding LLMs in current, accurate information.

The `@youdotcom-oss/langchain` package exposes three `DynamicStructuredTool` factories for LangChain.js agents: `youSearch`, `youResearch`, and `youContents`.

## Installation and setup

<CodeGroup>
    ```bash npm
    npm install @youdotcom-oss/langchain langchain
    ```

    ```bash yarn
    yarn add @youdotcom-oss/langchain langchain
    ```

    ```bash pnpm
    pnpm add @youdotcom-oss/langchain langchain
    ```
</CodeGroup>

[Get a You.com API key](https://you.com/platform/api-keys) and set it as an environment variable:

```typescript
process.env.YDC_API_KEY = "your-api-key";
```

## Tools

See a [usage example](/oss/integrations/tools/youdotcom).

```typescript
import { youSearch, youResearch, youContents } from "@youdotcom-oss/langchain";
```

### `youSearch`

Web and news search with advanced filtering by recency, country, language, and live-crawling for full page content.

### `youResearch`

Comprehensive, cited answers to complex questions, with configurable effort levels (`lite`, `standard`, `deep`, `exhaustive`).

### `youContents`

Full page content extraction from URLs in markdown or HTML format.
