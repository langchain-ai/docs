LangChain integrates with [Oracle Cloud Infrastructure (OCI) Generative AI](https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm) through the `@oracle/langchain-oci` package.

The package provides LangChain.js integrations for OCI Generative AI chat models and text embedding models.

## Installation

```bash npm
npm install @oracle/langchain-oci @langchain/core
```

The integration is published as the [`@oracle/langchain-oci`](https://www.npmjs.com/package/@oracle/langchain-oci) npm package and requires Node.js 18 or later.

## Authentication

The integration uses the OCI TypeScript SDK for authentication. By default, the SDK uses the OCI configuration file at `~/.oci/config` and the `DEFAULT` profile.

The integration also supports:

- Configuration-file authentication with a custom path and profile
- Instance Principal authentication
- Resource Principal authentication
- Session authentication
- A caller-provided OCI authentication provider or `GenerativeAiInferenceClient`

See the [OCI SDK authentication documentation](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/sdk_authentication_methods.htm) for details.

## Chat models

### OciGenAiGenericChat

Use `OciGenAiGenericChat` for OCI Generic chat models. It supports text chat, streaming, token-usage metadata, tool calling, tool-result turns, and LangChain structured output.

See the [OCI Generic chat integration guide](/oss/integrations/chat/oci_generative_ai).

```typescript
import { OciGenAiGenericChat } from "@oracle/langchain-oci";

const model = new OciGenAiGenericChat({
  compartmentId: process.env.OCI_COMPARTMENT_ID!,
  onDemandModelId: "meta.llama-3.3-70b-instruct",
});

const response = await model.invoke("Hello from LangChain and OCI!");
console.log(response.content);
```

You can also target a dedicated AI cluster endpoint by providing `dedicatedEndpointId` instead of `onDemandModelId`.

### OciGenAiCohereChat

Use `OciGenAiCohereChat` only with OCI's legacy Cohere V1 chat API. Current Cohere chat models that require the V2 API are not supported, and the legacy integration does not support tool-result turns.

## Embeddings

Use `OciGenAiEmbeddings` for OCI Generative AI text embeddings. The integration supports on-demand models, dedicated endpoints, batched document embedding, query embedding, truncation, input type, and output-dimension configuration where supported by the selected model.

See the [OCI embeddings integration guide](/oss/integrations/embeddings/oci_generative_ai).

```typescript
import { OciGenAiEmbeddings } from "@oracle/langchain-oci";

const embeddings = new OciGenAiEmbeddings({
  compartmentId: process.env.OCI_COMPARTMENT_ID!,
  onDemandModelId: "cohere.embed-v4.0",
});
```
