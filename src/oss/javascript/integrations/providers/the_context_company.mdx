[The Context Company](https://www.thecontextcompany.com) provides observability and customer analytics for production AI agents. The integration captures LangChain and LangGraph runs, model calls, tool executions, errors, token usage, latency, sessions, and metadata.

For complete configuration and usage options, see [The Context Company LangChain and LangGraph documentation](https://docs.thecontextcompany.com/frameworks/langchain-langgraph).

## Install the integration

```bash
npm install @contextcompany/langchain @langchain/core @langchain/langgraph @langchain/openai
```

Set your API key:

```bash
export TCC_API_KEY="your-api-key"
```

## Trace LangChain

Pass the callback handler to a model, chain, or agent invocation:

```typescript
import { TCCCallbackHandler } from "@contextcompany/langchain";
import { ChatOpenAI } from "@langchain/openai";

const model = new ChatOpenAI({ model: "gpt-5.4" });
const handler = new TCCCallbackHandler();

const response = await model.invoke(
  "What patterns are users encountering?",
  { callbacks: [handler] },
);
console.log(response.content);
```

## Trace LangGraph

The same handler traces a compiled LangGraph application:

```typescript
const result = await graph.invoke(
  {
    messages: [
      { role: "user", content: "Help me investigate this account." },
    ],
  },
  {
    callbacks: [handler],
    metadata: {
      tcc: {
        runId: crypto.randomUUID(),
        sessionId: "session-123",
        userId: "user-123",
      },
      environment: "production",
    },
  },
);
```

See the [integration guide](https://docs.thecontextcompany.com/frameworks/langchain-langgraph) for global instrumentation, sessions, organizations, agents, feedback, and additional metadata options.
