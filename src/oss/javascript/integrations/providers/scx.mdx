[SCX](https://scx.ai/) serves open-weight models — chat, multimodal (image **and video** input), embeddings, and speech-to-text — over an OpenAI-compatible API.

## Installation

```bash
npm install @scx-ai/langchain @langchain/core
```

Get an API key at [platform.scx.ai](https://platform.scx.ai) and set `SCX_API_KEY` in your environment. See the [ChatSCX](/oss/integrations/chat/scx) page for setup details.

## Audio transcription

The package also ships `SCXTranscription`, a runnable speech-to-text component backed by Whisper-Large-v3. See the [repository README](https://github.com/SouthernCrossAI/scx-langchain#audio-transcription) for usage.
