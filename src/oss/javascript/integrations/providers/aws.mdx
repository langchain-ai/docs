## Tools

### AgentCore Code Interpreter

[Amazon Bedrock AgentCore Code Interpreter](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/code-interpreter-tool.html) lets agents run Python, JavaScript, and TypeScript code in a secure, managed sandbox.

See a [usage example](/oss/integrations/tools/bedrock_agentcore_code_interpreter).

```typescript
import { CodeInterpreterToolkit } from "@langchain/aws";
```
