---
title: "You.com search tools"
description: "Integrate with the You.com search tools using LangChain JavaScript."
---

The `@youdotcom-oss/langchain` package connects to the hosted You.com MCP server and returns a LangChain MCP client. Call `client.getTools()` to resolve the tool set and pass it to any LangChain agent.

## Setup

Install the package with your preferred package manager:

<CodeGroup>
    ```bash npm
    npm install @youdotcom-oss/langchain langchain
    ```

    ```bash yarn
    yarn add @youdotcom-oss/langchain langchain
    ```

    ```bash pnpm
    pnpm add @youdotcom-oss/langchain langchain
    ```
</CodeGroup>

[Get a You.com API key](https://you.com/platform/api-keys) and set it as an environment variable:

```bash
export YDC_API_KEY="your-api-key"
```

## Create a client

`createYouClient()` connects to `https://api.you.com/mcp` and returns a `MultiServerMCPClient`. Always call `client.close()` when finished.

```typescript
import { createYouClient } from "@youdotcom-oss/langchain";

const client = await createYouClient();
const tools = await client.getTools();

// ... use tools ...

await client.close();
```

The client accepts a `YouClientConfig` object:

```typescript
type YouClientConfig = {
  apiKey?: string;           // defaults to YDC_API_KEY env var
  tools?: string | string[]; // scope which tools are returned
  profile?: string;          // select a hosted server profile
};
```

## Available tools

The default tool set returned by `client.getTools()`:

| Tool | Description |
|------|-------------|
| `you-search` | Real-time web and news search with filtering by recency, country, language, and live-crawling |
| `you-research` | Comprehensive, cited answers with configurable effort (`lite`, `standard`, `deep`, `exhaustive`) |
| `you-contents` | Full page content extraction from URLs as markdown or HTML |

`you-finance` is optional and not included by default. Request it explicitly:

```typescript
const client = await createYouClient({
  tools: ["you-search", "you-research", "you-contents", "you-finance"],
});
```

To use only a subset of tools:

```typescript
const client = await createYouClient({
  tools: ["you-search", "you-contents"],
});
```

## Use within an agent

Pass the resolved tools to any LangChain agent. The model selects the right tool based on the request:

```typescript
import { createAgent, initChatModel } from "langchain";
import { createYouClient } from "@youdotcom-oss/langchain";

const client = await createYouClient();
const tools = await client.getTools();

const agent = createAgent({
  model: await initChatModel("claude-sonnet-4-6", { temperature: 0 }),
  tools,
  systemPrompt: "You are a helpful research assistant. Always cite your sources.",
});

const result = await agent.invoke({
  messages: [{ role: "user", content: "What are the latest developments in AI?" }],
});

await client.close();
```

## Invoke a tool directly

```typescript
import { createYouClient } from "@youdotcom-oss/langchain";

const client = await createYouClient({ tools: "you-search" });
const tools = await client.getTools();
const searchTool = tools.find((t) => t.name === "you-search");

const result = await searchTool?.invoke({ query: "AI news", count: 5 });
console.log(result);

await client.close();
```
