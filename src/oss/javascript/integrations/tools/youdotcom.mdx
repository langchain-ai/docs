---
title: "You.com search tools"
description: "Integrate with the You.com search tools using LangChain JavaScript."
---

The `@youdotcom-oss/langchain` package provides three `DynamicStructuredTool` factories for web search, research, and content extraction, built for LangChain.js agents.

## Setup

Install the package with your preferred package manager:

<CodeGroup>
    ```bash npm
    npm install @youdotcom-oss/langchain langchain
    ```

    ```bash yarn
    yarn add @youdotcom-oss/langchain langchain
    ```

    ```bash pnpm
    pnpm add @youdotcom-oss/langchain langchain
    ```
</CodeGroup>

[Get a You.com API key](https://you.com/platform/api-keys) and set it as an environment variable:

```typescript
process.env.YDC_API_KEY = "your-api-key";
```

Each factory reads `YDC_API_KEY` from the environment. To pass a key explicitly, provide `apiKey`:

```typescript
import { youSearch } from "@youdotcom-oss/langchain";

const searchTool = youSearch({ apiKey: process.env.YDC_API_KEY });
```

## `youSearch`

Web and news search with up-to-date results. The tool accepts the following arguments at invocation:

- `query` (required, `string`): The search query.
- `count` (`number`): Max results to return.
- `freshness` (`string`): Filter by recency.
- `offset` (`number`): Pagination offset.
- `country` (`string`): Two-letter country code to focus results geographically.
- `safesearch` (`"off" | "moderate" | "strict"`): Content filter.
- `livecrawl` (`"web" | "news" | "all"`): Fetch full page content.
- `livecrawl_formats` (`("markdown" | "html")[]`): Format for live-crawled content.
- `language` (`string`): Language code for results.

```typescript
import { youSearch } from "@youdotcom-oss/langchain";

const searchTool = youSearch();
const result = await searchTool.invoke({ query: "latest AI developments", count: 5 });
```

## `youResearch`

Comprehensive answers with cited sources. The tool accepts:

- `input` (required, `string`): The research question.
- `research_effort` (`"lite" | "standard" | "deep" | "exhaustive"`): Controls depth and speed. Defaults to `standard`.

```typescript
import { youResearch } from "@youdotcom-oss/langchain";

const researchTool = youResearch();
const result = await researchTool.invoke({
  input: "WebAssembly vs JavaScript performance",
  research_effort: "deep",
});
```

## `youContents`

Extract full page content from URLs. The tool accepts:

- `urls` (required, `string[]`): URLs to extract content from.
- `formats` (`("markdown" | "html" | "metadata")[]`): Output formats. Defaults to `["markdown", "metadata"]`.
- `crawl_timeout` (`number`): Per-URL crawl timeout in seconds.

```typescript
import { youContents } from "@youdotcom-oss/langchain";

const contentsTool = youContents();
const result = await contentsTool.invoke({ urls: ["https://example.com/article"] });
```

## Use within an agent

Pass the tools to an agent. The model decides which one to call:

```typescript
import { createAgent, initChatModel } from "langchain";
import { youSearch, youResearch, youContents } from "@youdotcom-oss/langchain";

const model = await initChatModel("claude-sonnet-4-6", { temperature: 0 });

const agent = createAgent({
  model,
  tools: [youSearch(), youResearch(), youContents()],
  systemPrompt: "You are a helpful research assistant. Always cite your sources.",
});

const result = await agent.invoke({
  messages: [{ role: "user", content: "What are the latest developments in AI?" }],
});
```

For more details, see the [You.com LangChain package README](https://github.com/youdotcom-oss/dx-toolkit/tree/main/packages/langchain#readme).
