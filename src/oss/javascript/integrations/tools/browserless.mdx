[Browserless](https://browserless.io) is a hosted browser automation MCP server. It exposes 10 tools—search, smart scraper, map, crawl, export, performance, function, download, and a multi-turn browser agent—over a single streamable-HTTP MCP endpoint, auto-imported via [`@langchain/mcp-adapters`](https://www.npmjs.com/package/@langchain/mcp-adapters) with no partner package required. Browser sessions are pinned by `Mcp-Session-Id`, so multi-turn ReAct loops preserve browser state across calls.

## Setup

The integration uses the generic [`@langchain/mcp-adapters`](https://www.npmjs.com/package/@langchain/mcp-adapters) package, which you can install as shown below:

<CodeGroup>
```bash npm
npm install @langchain/mcp-adapters @langchain/langgraph @langchain/core
```
```bash yarn
yarn add @langchain/mcp-adapters @langchain/langgraph @langchain/core
```
```bash pnpm
pnpm add @langchain/mcp-adapters @langchain/langgraph @langchain/core
```
</CodeGroup>

### Credentials

Get a Browserless API token at [account.browserless.io](https://account.browserless.io) and set it as an environment variable:

```typescript
process.env.BROWSERLESS_TOKEN = "YOUR_API_KEY";
```

## Instantiation

Connect to the hosted MCP server and load all 10 tools:

```typescript
import { MultiServerMCPClient } from "@langchain/mcp-adapters";

const client = new MultiServerMCPClient({
  mcpServers: {
    browserless: {
      transport: "http",
      url: "https://mcp.browserless.io/mcp",
      headers: { Authorization: `Bearer ${process.env.BROWSERLESS_TOKEN}` },
    },
  },
});

const tools = await client.getTools();
console.log(tools.map((t) => t.name));
```

```text
[
  'browserless_smartscraper', 'browserless_function',
  'browserless_download',    'browserless_export',
  'browserless_skill',       'browserless_agent',
  'browserless_search',      'browserless_map',
  'browserless_crawl',       'browserless_performance'
]
```

## Invocation

### Invoke a stateless tool directly

Eight of the tools are stateless single-shot calls (`browserless_smartscraper`, `browserless_search`, `browserless_map`, `browserless_crawl`, `browserless_export`, `browserless_performance`, `browserless_function`, `browserless_download`). You can call them without an LLM:

```typescript
const smartscraper = tools.find((t) => t.name === "browserless_smartscraper");
const result = await smartscraper.invoke({
  url: "https://example.com",
  formats: ["markdown"],
});
console.log(result[0].text);
```

```text
Example Domain

Example Domain
==============

This domain is for use in documentation examples without needing permission. Avoid use in operations.

[Learn more](https://iana.org/domains/example)
```

### Multi-turn browser agent

The `browserless_agent` tool runs a multi-turn ReAct loop with browser state preserved across calls (navigate → snapshot → click → re-snapshot → extract). The `@langchain/mcp-adapters` JavaScript client reuses a single MCP session across `tool.invoke()` calls by default, so no extra setup is needed:

```typescript
const agent = tools.find((t) => t.name === "browserless_agent");

await agent.invoke({
  method: "goto",
  params: { url: "https://example.com" },
});
await agent.invoke({ method: "snapshot" });
const result = await agent.invoke({
  method: "text",
  params: { selector: "h1" },
});
console.log(result);
```

```text
{
  "text": "Example Domain",
  "time": 4
}
```

## Agents

Hand all 10 tools to a LangGraph ReAct agent. The model decides when to use the multi-turn `browserless_agent` versus a stateless tool.

```typescript
import { createReactAgent } from "@langchain/langgraph/prebuilt";
import { ChatAnthropic } from "@langchain/anthropic";

const llm = new ChatAnthropic({ model: "claude-sonnet-4-6" });

const agentExecutor = createReactAgent({ llm, tools });

const out = await agentExecutor.invoke({
  messages: [
    {
      role: "user",
      content:
        "Use browserless_search to find recent articles on WebAssembly outside the browser, then use browserless_smartscraper to read the top result and summarize the takeaways in 5 bullet points.",
    },
  ],
});
console.log(out.messages.at(-1)?.content);

await client.close();
```

For guides on how to use LangChain tools in agents, see the [LangGraph.js](https://langchain-ai.github.io/langgraphjs/how-tos/#tool-calling) docs.
