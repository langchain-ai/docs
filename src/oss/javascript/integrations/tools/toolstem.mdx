[Toolstem](https://toolstem.com) provides agent-ready financial intelligence via MCP (Model Context Protocol) servers. It exposes 8 production tools across two domains: **Finance** (stock snapshots, company metrics, peer comparisons) and **SEC EDGAR** (filings, insider trades, institutional holdings, material events, disclosure signals).

This guide covers the `langchain-toolstem` package, which wraps Toolstem's MCP servers as native LangChain.js tools with built-in [x402](https://www.x402.org/) micropayment support.

### Tool summary

**Finance tools** (via `ToolstemFinanceToolkit`):

| Tool | Description |
| :--- | :--- |
| `get_stock_snapshot` | Real-time quote, valuation, DCF signal, and analyst rating for a single ticker |
| `get_company_metrics` | Deep fundamentals: profitability, health signal, cash flow, 3-year CAGR, per-share data |
| `compare_companies` | Side-by-side comparison of 2-5 companies with relative ranking |

**SEC EDGAR tools** (via `ToolstemSECToolkit`):

| Tool | Description |
| :--- | :--- |
| `get_company_filings_summary` | Recent SEC filings (10-K, 10-Q, 8-K, etc.) with summaries |
| `get_insider_signal` | Insider buying/selling activity and net signal |
| `get_institutional_signal` | 13F institutional ownership changes and concentration |
| `get_material_events_digest` | Material events from 8-K filings (earnings, M&A, leadership changes) |
| `compare_disclosure_signals` | Cross-company comparison of disclosure patterns |

## Setup

Install the `langchain-toolstem` package:

<CodeGroup>
```bash npm
npm install langchain-toolstem @langchain/core
```
```bash yarn
yarn add langchain-toolstem @langchain/core
```
```bash pnpm
pnpm add langchain-toolstem @langchain/core
```
</CodeGroup>

### Credentials

Toolstem uses [x402](https://www.x402.org/) for per-call payments. Each tool invocation costs $0.01 USDC on Base mainnet. You need a wallet private key with a USDC balance on Base.

Set the following environment variable:

```typescript
process.env.TOOLSTEM_WALLET_PRIVATE_KEY = "YOUR_WALLET_PRIVATE_KEY"
```

No API key or account registration is required. Discovery (listing available tools) is free; only tool invocations incur a charge.

It's also helpful (but not needed) to set up [LangSmith](https://smith.langchain.com/) for best-in-class observability:

```typescript
process.env.LANGSMITH_TRACING="true"
process.env.LANGSMITH_API_KEY="your-api-key"
```

## Instantiation

Import and create a toolkit instance:

```typescript
import { ToolstemFinanceToolkit } from "langchain-toolstem";

const toolkit = new ToolstemFinanceToolkit({
  walletPrivateKey: process.env.TOOLSTEM_WALLET_PRIVATE_KEY,
});

const tools = await toolkit.getTools();
```

For SEC EDGAR tools:

```typescript
import { ToolstemSECToolkit } from "langchain-toolstem";

const secToolkit = new ToolstemSECToolkit({
  walletPrivateKey: process.env.TOOLSTEM_WALLET_PRIVATE_KEY,
});

const secTools = await secToolkit.getTools();
```

## Invocation

### Invoke directly with args

```typescript
const snapshotTool = tools.find((t) => t.name === "get_stock_snapshot");

const result = await snapshotTool.invoke({
  symbol: "AAPL",
});
```

### Invoke with ToolCall

```typescript
const modelGeneratedToolCall = {
  args: {
    symbol: "AAPL",
  },
  id: "1",
  name: "get_stock_snapshot",
  type: "tool_call",
};

await snapshotTool.invoke(modelGeneratedToolCall);
```

## Agents

Toolstem tools work with any LangChain agent that supports tool calling. Here is an example using LangGraph:

```typescript
import { ToolstemFinanceToolkit } from "langchain-toolstem";
import { ChatOpenAI } from "@langchain/openai";
import { createReactAgent } from "@langchain/langgraph/prebuilt";

const toolkit = new ToolstemFinanceToolkit({
  walletPrivateKey: process.env.TOOLSTEM_WALLET_PRIVATE_KEY,
});
const tools = await toolkit.getTools();

const llm = new ChatOpenAI({ model: "gpt-4.1" });

const agent = createReactAgent({
  llm,
  tools,
});

const result = await agent.invoke({
  messages: [{ role: "user", content: "Compare AAPL and MSFT fundamentals" }],
});
```

| Supported wallets | Any EVM wallet (Coinbase Smart Wallet, MetaMask, etc.) |

## Distribution

Toolstem MCP servers are available through two channels:

- **Self-custody via x402**: Connect directly to `https://mcp.toolstem.com/mcp/finance` or `https://mcp.toolstem.com/mcp/sec`. Pay per call with your own wallet. No intermediary.
- **Apify Actor**: Run as an Apify Actor with Pay-Per-Event billing. See [Toolstem on Apify](https://apify.com/toolstem).

The `langchain-toolstem` npm package uses the self-custody x402 path by default.
