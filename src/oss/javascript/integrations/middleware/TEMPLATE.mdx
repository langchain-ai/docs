How to use this JavaScript middleware template:

- [ ] Substitute (PROVIDER_NAME) with the name of the provider, e.g. Anthropic, OpenAI, etc. (`command + F` is your friend here)
- [ ] Substitute (MIDDLEWARE_EXPORT) with the middleware factory export name, e.g. `anthropicPromptCachingMiddleware`
- [ ] Substitute (NPM_PACKAGE) with the npm package that exports the middleware, e.g. `langchain` or `@langchain/anthropic`
- [ ] Substitute (MODEL_NAME) with a model id string supported by your provider, e.g. `claude-sonnet-4-6`
- [ ] Update links to point to the correct module and API reference
- [ ] If you use `@[...]` for API links, add the symbol to the `js` scope in `pipeline/preprocessors/link_map.py`
- [ ] Update the API key environment variable prefix if needed
- [ ] Fill in the middleware table with each middleware your package provides
- [ ] For each middleware, add a section with API reference, code example, configuration options, and a full example
