---
title: Chunking strategies for retrieval
description: Choose and evaluate document chunking strategies for retrieval applications.
---

Chunking affects retrieval recall, precision, context continuity, and cost. Treat the values below as a starting point and measure them on a representative question set rather than assuming one universal setting.

## Start with a baseline

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200,
    add_start_index=True,
)
chunks = splitter.create_documents(
    [text],
    metadatas=[{"source": "course.md", "section": "algebra"}],
)
```

Smaller chunks can improve precision but may lose context. Larger chunks preserve more context but can dilute the relevant passage. Overlap helps preserve continuity across boundaries, while increasing index size and repeated retrieval content.

## Match the splitter to document structure

For Markdown, preserve headings as metadata so retrieved evidence can be cited and filtered:

```python
from langchain_text_splitters import MarkdownHeaderTextSplitter

splitter = MarkdownHeaderTextSplitter(
    headers_to_split_on=[("#", "h1"), ("##", "h2")],
)
chunks = splitter.split_text(markdown_text)
```

Use structure-aware splitting for documents whose headings, records, or code boundaries carry meaning. Use a length-based splitter when the source has no reliable structure.

## Measure the choice

Keep the corpus, question set, and answer policy fixed while comparing chunk settings. At minimum record:

- chunk count and retained metadata;
- retrieval hit rate for expected sources;
- citation completeness for supported answers;
- abstention correctness when no evidence is present.

Do not report a chunk size as generally optimal from one corpus. Report the measured trade-off and the corpus assumptions.

## Scope note

Semantic chunking and parent-document retrieval are separate techniques with additional dependencies and were not evaluated in this local reproduction. Document them only after their current APIs and examples are verified.
