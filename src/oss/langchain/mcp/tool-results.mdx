When a LangChain tool from @[`MCPAdapter`] runs, its result is converted into LangChain-native values: content blocks the model can read, an artifact for structured output, and metadata describing the tool's provenance. This page covers how errors, structured content, multimodal output, and metadata surface.

## Errors

An MCP tool result carries an `isError` flag. When a server reports `isError=True`, the adapter converts it into a @[`ToolMessage`] with `status="error"` carrying the server's own message, so the agent can read it and correct itself:

<McpToolErrorsPy />

The distinction matters: a server-reported error reaches the model as a failed tool message, but a transport or session failure raises instead, because a model cannot act on a dropped connection. Error handling is fixed behavior; there is no flag to configure.

## Multimodal content

An MCP tool result arrives as LangChain [content blocks](/oss/langchain/messages#content-blocks), not a bare string. Image and file content convert into standardized `image` and `file` blocks alongside `text`, so a tool that returns a screenshot reaches the model as an image block:

<McpMultimodalToolContentPy />

## Structured content

When a tool returns structured content, the adapter attaches it to the @[`ToolMessage`] as an artifact rather than folding it into the model-visible text. Read it off `message.artifact`:

```python
message = await tool.ainvoke({"name": "...", "args": {...}, "id": "1", "type": "tool_call"})
if message.artifact is not None:
    structured = message.artifact["structured_content"]
```

The artifact is an `MCPToolArtifact`, whose `structured_content` field holds the tool result's `structuredContent`.

## Tool metadata

Every tool the adapter produces carries its MCP provenance under an `mcp` namespace on the LangChain tool's metadata:

- **`metadata["mcp"]["tool"]["annotations"]`**: the tool's MCP annotations, such as `destructive_hint` or `read_only_hint`.
- **`metadata["mcp"]["tool"]["_meta"]`**: the server's `_meta` payload for the tool.
- **`metadata["mcp"]["server"]`**: the identity of the server that served the tool.

Reading annotations lets you treat a tool based on what the server declares about it, rather than hardcoding tool names:

<McpToolMetadataPy />
