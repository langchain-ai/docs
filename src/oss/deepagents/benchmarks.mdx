This page compares Deep Agents with other agent harnesses on two terminal-based coding benchmarks. Each model, Claude Opus 5.5 (med) and GPT-6.1 Sol (med), runs in its provider's native harness, in Deep Agents, and in [Pi](https://github.com/badlogic/pi-mono), another provider-agnostic harness.

Deep Agents is competitive with leading harnesses on frontier models, often at a lower cost for a comparable score. On both benchmarks and with both models, Deep Agents scores within about three points of the model's native harness, and it costs less per task than Claude Code on both. Deep Agents is provider-agnostic and general purpose: the same harness runs both models, with no custom system prompt and no benchmark-specific tuning.

## Methodology

- **Harness configuration**: Deep Agents runs `create_deep_agent` with its defaults, a local shell [backend](/oss/deepagents/backends) rooted at the task's working directory, and a web search tool. It sets no custom system prompt.
- **Benchmarks**: Terminal-Bench 4.0 (CPU-only dataset) and Terminal-Bench Science 0.1, run through [Harbor](https://github.com/harbor-framework/harbor) from the [Deep Agents eval workflow](https://github.com/langchain-ai/deepagents/actions/workflows/harbor.yml). Every run uses medium reasoning effort and three trials per task.
- **Score**: The fraction of a task's trials that pass, averaged across tasks. Trials that error before the verifier runs are dropped.
- **Cost**: Estimated from each model call's token usage at the provider's list prices. Each task's cost is the mean over its trials, and the plots show the median task.
- **Task sets**: A task is kept only if every harness for that model has a scored trial on it. On Terminal-Bench 4.0 that leaves 57 tasks for Opus 5.5 and 60 for Sol. On Terminal-Bench Science, every pair uses the same 59 tasks.
- **Error bars**: One standard error, with the task set held fixed. Score differences under about five points are within run-to-run noise.
