## Overview

This guide shows how to build a multi-step web research agent with [Deep Agents](/oss/deepagents). The agent decomposes research questions into focused tasks, delegates them to specialized sub-agents, and synthesizes findings into a comprehensive report.

The agent you build will:

1. Plan research using the opt-in todo list middleware
1. Delegate focused research tasks to sub-agents with isolated context
1. Assess search results and plan next steps as you gather information
1. Synthesize findings with proper citations into a final report

The spawned sub-agents conduct web searches with Tavily, fetching full webpage content for analysis.

### Key concepts

This tutorial covers:

- [Subagents](/oss/deepagents/subagents) for parallel, context-isolated research
- Custom [tools](/oss/langchain/tools) for web search
- Multi-step planning with the opt-in [planning tool](/oss/deepagents/overview#task-planning)

## Prerequisites

API keys for:

- Anthropic (Claude) or Google (Gemini)
- [Tavily](https://www.tavily.com/) for web search (optional; free tier is sufficient)
- [LangSmith](https://smith.langchain.com) for tracing (optional if you are using the SDK; required for Managed Deep Agents)

## Choose your path

This guide shows how to build this agenet with [Managed Deep Agents](/langsmith/managed-deep-agents-overview) and the Deep Agnets SDK. Managed Deep Agents laets you deploy agents without having to manage infrastructure. The Deep Agents SDK, lets you have maximum flexibility while using the same Deep Agents harness and you can host agents yourself, or run a custom [LangSmith Deployment](/langsmith/deployment).

### Run the agent

<Steps>
<Step title="Run locally">

Install dependencies and start the agent:

:::python
```bash
uv sync
uv run mda dev
```
:::

:::js
<CodeGroup>
```bash npm
npm install
npx mda dev
```

```bash pnpm
pnpm install
pnpm exec mda dev
```

```bash bun
bun install
bunx mda dev
```
</CodeGroup>
:::

`mda dev` loads API keys from `.env`, starts a local Agent Server, and opens the agent in LangSmith Studio.

In Studio, send a research question such as:

```txt wrap
Compare the main approaches to context engineering for AI agents in 2025.
```

You should see the orchestrator plan with `write_todos`, delegate to the research sub-agent, and write a report. For more information, see [Develop locally with LangSmith Studio](/langsmith/managed-deep-agents-local-development).

</Step>

## Next steps

Now that you've built the agent, customize the workflow by editing the orchestrator instructions (Managed Deep Agents: `instructions.md`; SDK: prompt constants in your agent file). You can also tune the delegation limits to allow more parallel sub-agents or delegation rounds.

For more information on the concepts in this tutorial, see:

- [Subagents](/oss/deepagents/subagents): Configure subagents with different tools and prompts
- [Customization](/oss/deepagents/customization): Customize models, tools, system prompts, and optional [task planning](/oss/deepagents/overview#task-planning)
- [Managed Deep Agents](/langsmith/managed-deep-agents-overview): Build deep agents with managed deployment infrastructure
- [LangSmith](/langsmith/observability): Trace research runs and debug multi-step behavior
- [Deep Research Course](https://academy.langchain.com/courses/deep-research-with-langgraph): Full course on deep research with LangGraph
