If you provide a sandbox platform and want to contribute an integration for deep agents you can publish your own package.

Be aware that we feature third-party sandbox integrations only when:

- The integration is authored and maintained by the company that provides the sandbox.
- **Or** the integration is widely used, meaning the integration must have a minimum of 10,000 daily downloads on PyPI or npm to be considered for featuring.

### Publish your own package

Do not submit PRs into the [deepagents monorepo](https://github.com/langchain-ai/deepagents) — we do not accept third-party integrations there.
Instead, publish your own package following these guidelines:

:::python

- **Package naming:** Use `langchain-[partner]` (for example `langchain-daytona`)
- **Reference implementation:** See the [Daytona partner integration](https://github.com/langchain-ai/deepagents/tree/main/libs/partners/daytona) for structure and patterns
- **Test suite:** Ensure your integration passes the [standard integration test suite](https://github.com/langchain-ai/deepagents/blob/main/libs/partners/daytona/tests/integration_tests/test_integration.py)

:::

:::js

- **Package naming:** Use `langchain-[partner]` (for example `langchain-daytona`)
