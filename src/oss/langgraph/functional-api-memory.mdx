Add memory to a Functional API [entrypoint](/oss/langgraph/functional-api#entrypoint) with a [checkpointer](/oss/langgraph/persistence) and, optionally, a [store](/oss/langgraph/stores). Checkpoints persist state across invocations of the same `thread_id`. A store persists facts across thread IDs.

For concepts, see the [Functional API overview](/oss/langgraph/functional-api). For Graph API memory recipes, see [Memory](/oss/langgraph/add-memory).

## Save state on a thread

Pass a checkpointer when you create the entrypoint. Identify each run with `thread_id`.
