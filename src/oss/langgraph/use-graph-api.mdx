This section shows how to build with LangGraph's Graph API. Start with the [Graph API overview](/oss/langgraph/graph-api) for concepts, then use these guides for concrete patterns.

## Setup

:::python
Install `langgraph`:

<CodeGroup>
```bash pip
pip install -U langgraph
```

```bash uv
uv add langgraph
```
</CodeGroup>
:::

:::js
Install `langgraph`:

```bash
npm install @langchain/langgraph
```
:::

<Tip>
**Set up LangSmith for better debugging**

Sign up for [LangSmith](https://smith.langchain.com) to quickly spot issues and improve the performance of your LangGraph projects. LangSmith lets you use trace data to debug, test, and monitor your LLM apps built with LangGraph—read more about how to get started in the [docs](/langsmith/observability).
</Tip>

## Guides

- [Define and update state](/oss/langgraph/graph-api-state): Schemas, reducers, messages, private state, and input/output schemas.
- [Build sequences, branches, and loops](/oss/langgraph/graph-api-control-flow): Linear steps, parallel branches, conditional routing, and cycles.
- [Use Send and Command](/oss/langgraph/graph-api-send-command): Map-reduce fan-out with `Send`, and combined state updates plus routing with `Command`.
- [Configure nodes](/oss/langgraph/graph-api-nodes): Runtime configuration, retries, timeouts, error handling, defaults, and caching.
- [Visualize your graph](/oss/langgraph/graph-api-visualize): Mermaid and PNG diagrams for debugging and documentation.
