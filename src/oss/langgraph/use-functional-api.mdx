This guide walks through the decisions you make when building with the Functional API. For install and an end-to-end agent example, see the [LangGraph quickstart](/oss/langgraph/quickstart). For a design walkthrough, see [Thinking in the Functional API](/oss/langgraph/thinking-in-functional-api). For concepts, see the [Functional API overview](/oss/langgraph/functional-api). To choose between the Graph API and the Functional API, see [Choosing between Graph and Functional APIs](/oss/langgraph/choosing-apis).

## Build your workflow

Work through these decisions in order. Each step links to the how-to for full recipes.

<Steps>
<Step title="Compose the workflow">
Define an entrypoint, wrap units of work in tasks, and choose how steps connect.

- Start from a single entrypoint and pass inputs as one argument (often a dict).
- Use tasks for discrete work that should checkpoint and retry independently.
- Fan out with parallel tasks when steps are independent.
- Call a compiled [Graph API](/oss/langgraph/graph-api) graph or another entrypoint when you need composition.

See [Compose Functional API workflows](/oss/langgraph/functional-api-workflows).
</Step>

<Step title="Configure tasks">
Add reliability controls when steps can fail, hang, or repeat.

- Retries for transient failures
- Timeouts for slow tasks or entrypoints
- Caching for expensive repeated work
- Resume after an error without redoing completed tasks

See [Configure Functional API tasks](/oss/langgraph/functional-api-tasks).
</Step>

<Step title="Stream progress">
Stream updates, model tokens, or custom data while the workflow runs.

See [Stream with the Functional API](/oss/langgraph/functional-api-streaming).
</Step>

<Step title="Add human-in-the-loop">
Pause for approval or tool-call review with interrupts, then resume with `Command`.

See [Add human-in-the-loop with the Functional API](/oss/langgraph/functional-api-human-in-the-loop).
</Step>

<Step title="Add memory">
Keep short-term thread state with a checkpointer, and long-term data with a store.

See [Add memory with the Functional API](/oss/langgraph/functional-api-memory).
</Step>
</Steps>
