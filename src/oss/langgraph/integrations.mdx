LangGraph integrates with a growing ecosystem of tools and protocols that help you connect your agents to front ends, standardize agent definitions, and build production-ready applications.

| Integration | Description | Use case |
|-------------|-------------|----------|
| [AG-UI Protocol](#ag-ui-protocol) | Open event-based protocol for agent-frontend communication | Connect any LangGraph agent to any frontend |
| [CopilotKit](#copilotkit) | React framework with pre-built UI components | Build AI copilots in React/Next.js apps |
| [Open Agent Spec](#open-agent-spec) | Framework-agnostic agent definition language | Portable agent definitions across runtimes |

## Front-end integrations

These integrations help you connect LangGraph agents to frontend applications with streaming state updates, human-in-the-loop workflows, and interactive UIs.

### AG-UI Protocol

[AG-UI](https://github.com/ag-ui-protocol/ag-ui) (Agent-User Interaction Protocol) is an open, event-based protocol that standardizes how AI agents connect to user-facing applications. It provides a lightweight bridge between LangGraph and any front end.

To install the AG-UI LangGraph integration:

:::python
```bash
pip install ag-ui-langgraph
```
:::

:::js
```bash
npm install @ag-ui/langgraph
```
:::

### CopilotKit

[CopilotKit](https://github.com/CopilotKit/CopilotKit) is an open-source framework for building AI copilots and in-app AI agents. Their [CoAgents](https://docs.copilotkit.ai/coagents) feature provides deep integration with LangGraph, allowing you to embed agents directly into React applications.

CopilotKit is built on the AG-UI protocol, providing a higher-level abstraction with ready-to-use UI components.

## Standards and interoperability

### Open Agent Spec

[Open Agent Spec](https://github.com/oracle/agent-spec) by Oracle is a framework-agnostic declarative language for defining agentic systems. It allows you to define agents and workflows in a portable format that can be executed across different runtimes.

```bash
pip install pyagentspec
```
