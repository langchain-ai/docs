Stream from a Functional API [entrypoint](/oss/langgraph/functional-api#entrypoint) in two ways. Custom data is a side channel: you push progress with a writer, then read `custom` chunks. Values are state snapshots the runtime records, including the entrypoint return value. You do not call a writer for values.

For concepts, see the [Functional API overview](/oss/langgraph/functional-api). For messages and other typed projections, see [event streaming](/oss/langgraph/event-streaming).

## Emit custom data

The Functional API uses the same stream as the [Graph API](/oss/langgraph/graph-api). Emit with a writer, then consume `custom` chunks. For stream modes, see [Streaming](/oss/langgraph/streaming).

:::python
<LanggraphFunctionalApiStreamCustomDataPy />

1. Import @[`get_stream_writer`] from `langgraph.config`.
2. Call it inside the entrypoint to get a writer.
3. Emit custom data before and after the computation.
4. Call `stream(..., stream_mode="custom")` and iterate the chunks.

<Warning>
**Async with Python < 3.11**
In async code on Python < 3.11, @[`get_stream_writer`] does not work. Use the injectable `StreamWriter` parameter instead. See [Async with Python < 3.11](/oss/langgraph/streaming#async).

<LanggraphFunctionalApiStreamWriterInjectPy />
</Warning>
:::

:::js
<LanggraphFunctionalApiStreamCustomDataJs />

1. Take `config` as the second argument to the entrypoint.
2. Emit custom data with `config.writer` before and after the computation.
3. Call `stream(..., { streamMode: "custom" })` and iterate the chunks.
:::
