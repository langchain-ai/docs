Keiro provides embedding vectors as part of its deep search response, so you never need a separate embedding API call. The `KeiroEmbeddings` class gives you standalone access to the same endpoint when you just need vectors without full search results.

Matryoshka dimensions (384 to 1024) let you shrink vectors to trade precision for speed and storage. No other search/embedding integration offers this.

## Setup

To access the Keiro embedding model, you need a Keiro API key and the `langchain-keiro` package.

### Credentials

Get an API key at [keirolabs.cloud](https://keirolabs.cloud). The Explorer plan gives you 500 free credits, no credit card needed.

```python Set API key icon="key"
import getpass
import os

if "KEIRO_API_KEY" not in os.environ:
    os.environ["KEIRO_API_KEY"] = getpass.getpass("Enter your Keiro API key: ")
```

It is also helpful to set up [LangSmith](/langsmith/home) for best-in-class observability/tracing of your embedding calls:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

```python Initialize embeddings icon="robot"
from langchain_keiro.embeddings import KeiroEmbeddings

embeddings = KeiroEmbeddings(
    keiro_api_key=os.environ["KEIRO_API_KEY"],
    dimensions=768,  # Matryoshka: 384, 512, 768, 1024
)
```

## Embed single queries

```python Embed query icon="search"
vec = embeddings.embed_query("What is artificial intelligence?")
len(vec)  # 768
```

## Embed multiple documents

```python Embed documents icon="file-text"
vecs = embeddings.embed_documents(["AI overview", "Machine learning basics"])
len(vecs)  # 2
len(vecs[0])  # 768
```

## Async

```python
vec = await embeddings.aembed_query("What is AI?")
vecs = await embeddings.aembed_documents(["doc 1", "doc 2"])
```

## Matryoshka dimensions

You can shrink the vectors to trade precision for speed and storage:

- 384: Fast similarity search, massive indexes
- 512: Balanced
- 768 (default): General RAG
- 1024: When you need maximum precision

```python
fast_embeddings = KeiroEmbeddings(keiro_api_key=os.environ["KEIRO_API_KEY"], dimensions=384)
```
