This guide walks you through generating embeddings with [Voxell's](/oss/integrations/providers/voxell) Forge API through its LangChain integration.

[Forge](https://voxell.ai/forge) is Voxell's hosted text-embedding API. It runs the Qwen3-Embedding family across three tiers, so you can pick a quality and cost point: `turbo` (1024 dimensions, the fast default), `pro` (2560 dimensions), and `ultra` (4096 dimensions). The `ultra` tier is the Qwen3-Embedding-8B model, which scores roughly 75+ on the MTEB average task score and is currently #4 on MTEB (English), making it the top usable model (the few ranked above it are research-only). Forge returns vectors only; storage and search are yours to keep.

## 1. Set up your account

Create a free account at [dash.voxell.ai](https://dash.voxell.ai). New accounts start with 10M tokens and no credit card. Then create an API key from the dashboard and keep it somewhere safe.

## 2. Install the integration package

Install the [`langchain-voxell`](https://pypi.org/project/langchain-voxell/) package.

<CodeGroup>
```bash pip
pip install langchain-voxell
```

```bash uv
uv add langchain-voxell
```
</CodeGroup>

## 3. Embed a document and a query

First, initialize the client with your API key. You can set the `FORGE_API_KEY` environment variable or pass `api_key` directly, as we do here.

```python
from langchain_voxell import ForgeEmbeddings

# Use the ultra tier (Qwen3-Embedding-8B) for the highest quality.
client = ForgeEmbeddings(
    model="ultra",
    api_key="PASTE_YOUR_API_KEY_HERE",
    # dimensions=256,  # Optionally truncate (Matryoshka, re-normalized) for smaller vectors.
)
```

Embed a stored document with `embed_documents`. This tells Forge the text is content to be retrieved (`input_type="document"`), which keeps the vectors optimized for retrieval.

```python
document_embedding = client.embed_documents(
    texts=["GitHub charges for additional storage and data transfer beyond the included quota."]
)[0]
```

Now embed two search queries with `embed_query`, which marks them as queries (`input_type="query"`). One is clearly relevant to the document and one is not.

```python
relevant_query_embedding = client.embed_query(text="What are GitHub's billing policies?")
irrelevant_query_embedding = client.embed_query(text="How do I bake sourdough bread?")
```

Forge vectors are L2-normalized, so the dot product equals their cosine similarity. Use [`numpy`](https://numpy.org/) to rank the queries against the document.

```python
import numpy as np  # You may need to `pip install numpy`.

relevant_similarity = np.dot(relevant_query_embedding, document_embedding)
irrelevant_similarity = np.dot(irrelevant_query_embedding, document_embedding)

print(f"Similarity of relevant query to the document: {relevant_similarity * 100:.2f}")
print(f"Similarity of irrelevant query to the document: {irrelevant_similarity * 100:.2f}")
```

The relevant query scores noticeably higher than the irrelevant one, which shows the embeddings captured the meaning of the texts. From here you can store the document vectors in any vector store and rank incoming queries by cosine similarity to build semantic search or RAG retrieval.
