## A minimalist retrieval system

The main feature of the embeddings is that the cosine similarity between two embeddings captures the semantic relatedness of the corresponding original passages. This allows us to use the embeddings to do semantic retrieval / search.

 We can find a few closest embeddings in the documents embeddings based on the cosine similarity, and retrieve the corresponding document using the `KNNRetriever` class from LangChain.

<LangchainCommunityUnmaintained />

```python
from langchain_community.retrievers import KNNRetriever

retriever = KNNRetriever.from_texts(documents, embeddings)

# retrieve the most relevant documents
result = retriever.invoke(query)
top1_retrieved_doc = result[0].page_content  # return the top1 retrieved result

print(top1_retrieved_doc)
```

It formats the prompt template using the input key values provided (and also memory key values, if available), passes the formatted string to LLM and returns the LLM output.

## Contextualized chunk embeddings

Contextual models (`voyage-context-4` and `voyage-context-3`) embed each chunk with the context of the surrounding chunks from the same document, improving retrieval quality without a separate contextualization step. Call these models through the `voyageai` client's `contextualized_embed` method ([source](https://docs.voyageai.com/docs/contextualized-chunk-embeddings)):

```bash
pip install -qU voyageai
```

The `inputs` parameter is typed `Union[List[List[str]], List[str]]`, so both input formats are supported.

Pass a `List[List[str]]` to embed pre-chunked documents. Each inner list is one document, and its chunks are embedded together as a group:

```python
import voyageai

vo = voyageai.Client()  # uses the VOYAGE_API_KEY environment variable

inputs = [
    [
        "This is the SEC filing on Leafy Inc.'s Q2 2024 performance.",
        "The company's revenue increased by 15% compared to the previous quarter.",
    ],
    [
        "This is the SEC filing on Elephant Ltd.'s Q2 2024 performance.",
        "The company's revenue decreased by 2% compared to the previous quarter.",
    ],
]

result = vo.contextualized_embed(
    inputs=inputs,
    model="voyage-context-4",
    input_type="document",
)

# result.results holds one entry per document; .embeddings holds one vector per chunk
document_embeddings = [res.embeddings for res in result.results]
```

Pass a `List[str]` to embed a flat list of texts, such as queries:

```python
result = vo.contextualized_embed(
    inputs=[
        "What was the revenue growth for Leafy Inc. in Q2 2024?",
        "What changed in Elephant Ltd. between Q1 and Q2 2024?",
    ],
    model="voyage-context-4",
    input_type="query",
)

query_embeddings = [res.embeddings[0] for res in result.results]
```
