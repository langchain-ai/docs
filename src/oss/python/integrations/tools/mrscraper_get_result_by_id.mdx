---
title: "MrScraperGetResultById integration"
description: "Retrieve a single MrScraper result by ID in LangChain."
---

`MrScraperGetResultById` retrieves one scraping result by its result ID.

## Setup

```python
import os
from langchain_mrscraper import MrScraperGetResultById

# Option 1: pass API key directly
tool = MrScraperGetResultById(mrscraper_api_key="your-api-key")

# Option 2: auto-read from environment variable
os.environ["MRSCRAPER_API_KEY"] = "your-api-key"
tool = MrScraperGetResultById()
```

## Invocation

```python
from langchain_mrscraper import MrScraperGetResultById

tool = MrScraperGetResultById(mrscraper_api_key="your-api-key")

result = tool.invoke({"result_id": "result_12345"})
print(result)
```

## Parameters

| Parameter | Type | Description |
| :-- | :-- | :-- |
| `result_id` | `str` | Target result ID |
