This guide provides a quick overview for getting started with the Haunt [tool](/oss/langchain/tools). [Haunt](https://hauntapi.com?utm_source=langchain&utm_medium=integration&utm_campaign=sweep-2026-07) extracts structured data or clean text from public web pages for AI agents.

### Features

- Extract structured JSON from any public page with a plain-language prompt, no selectors.
- Honest failure: a blocked, missing, or login-walled page returns a structured `error_code` (`access_denied`, `login_required`, `not_found`) instead of invented content, so the agent can branch.
- Failed reads are not charged.
- Optional `response_format="markdown"` for clean page text.

## Setup

To access the Haunt tool you need an API key and the `langchain-haunt` integration package. Keys are free (no card) at [hauntapi.com](https://hauntapi.com/#signup).

### Credentials

```python Set API key icon="key"
import getpass
import os

if "HAUNT_API_KEY" not in os.environ:
    os.environ["HAUNT_API_KEY"] = getpass.getpass("Enter your Haunt API key: ")
```

### Installation

The Haunt tool lives in the `langchain-haunt` package:

<CodeGroup>
    ```python pip
    pip install -U langchain-haunt
    ```
    ```python uv
    uv add langchain-haunt
    ```
</CodeGroup>

## Instantiation

```python Initialize tool instance icon="robot"
from langchain_haunt import HauntExtract

tool = HauntExtract()
```

## Invocation

### Directly

The tool takes a `url` and a plain-language `prompt` describing the data to return:

```python Call tool icon="rocket"
tool.invoke({
    "url": "https://news.ycombinator.com",
    "prompt": "the top 5 story titles and their points",
})
# '{"stories": [{"title": "...", "points": 572}, ...]}'
```

An unreadable page returns an honest error instead of made-up data:

```python Honest failure icon="shield"
tool.invoke({
    "url": "https://example.com/admin",
    "prompt": "the dashboard numbers",
})
# '{"error_code": "login_required", "message": "This page needs a login. ..."}'
```

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
model_generated_tool_call = {
    "args": {
        "url": "https://example.com",
        "prompt": "the page title",
    },
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### Within an agent

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=[tool],
)

agent.invoke(
    {"messages": [{"role": "user", "content": "What is the current top story on Hacker News?"}]}
)
```
