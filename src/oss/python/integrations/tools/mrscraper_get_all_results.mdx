---
title: "MrScraperGetAllResults integration"
description: "List and filter MrScraper results in LangChain."
---

`MrScraperGetAllResults` lists scraping results with sorting, paging, and optional filters.

## Setup

```python
import os
from langchain_mrscraper import MrScraperGetAllResults

# Option 1: pass API key directly
tool = MrScraperGetAllResults(mrscraper_api_key="your-api-key")

# Option 2: auto-read from environment variable
os.environ["MRSCRAPER_API_KEY"] = "your-api-key"
tool = MrScraperGetAllResults()
```

## Invocation

```python
from langchain_mrscraper import MrScraperGetAllResults

tool = MrScraperGetAllResults(mrscraper_api_key="your-api-key")

result = tool.invoke(
    {
        "sort_field": "updatedAt",
        "sort_order": "DESC",
        "page_size": 10,
        "page": 1,
        "search": "product",
    }
)
print(result)
```

## Parameters

| Parameter | Type | Description |
| :-- | :-- | :-- |
| `sort_field` | `str` | Sort column |
| `sort_order` | `"ASC" \| "DESC"` | Sort direction |
| `page_size` | `int` | Page size |
| `page` | `int` | Page number |
| `search` | `str \| None` | Search keyword |
| `date_range_column` | `str \| None` | Date filter field |
| `start_at` | `str \| None` | Start date (ISO-8601) |
| `end_at` | `str \| None` | End date (ISO-8601) |
