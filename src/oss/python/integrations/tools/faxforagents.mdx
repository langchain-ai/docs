# Fax for Agents

[Fax for Agents](https://faxforagents.com) gives LangChain and LangGraph agents fax tools. They prepare a document, get a quote, request a human approval, send, check delivery, read the inbox and extract fields. Every account starts in a free sandbox.

## Installation and Setup

Install the package:

```bash
pip install langchain-faxforagents
```

## Toolkit

The `FaxForAgentsToolkit` provides the tools needed to interact with the Fax for Agents API.

```python
from langchain_faxforagents import FaxForAgentsToolkit

toolkit = FaxForAgentsToolkit()
tools = toolkit.get_tools()
```
