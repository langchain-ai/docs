[ProxyHat](https://proxyhat.com) provides a residential proxy network that lets you fetch web pages that may be geo-restricted or protected by anti-bot measures, making it useful for AI agents that need reliable access to live web content.

## Setup

The integration lives in the `langchain-proxyhat` package:

```python
pip install langchain-proxyhat
```

Set your ProxyHat API key as an environment variable (it auto-selects an active residential sub-user):

```python
import os

os.environ["PROXYHAT_API_KEY"] = "your-api-key"
```

Or pass it directly when initializing the tool:

```python
from langchain_proxyhat import ProxyHatFetchTool

tool = ProxyHatFetchTool(api_key="your-api-key")
```

## Instantiation

The tool accepts targeting parameters during instantiation (geo/session are fixed per instance, so an agent can't change the exit country mid-run):

- `api_key` (optional, str): Your ProxyHat API key (or set `PROXYHAT_API_KEY`). Alternatively pass `username` + `password`.
- `country` (optional, str): Two-letter country code for the residential exit IP (e.g. `"us"`, `"gb"`, `"de"`, `"jp"`).
- `region` / `city` (optional, str): Narrow the exit location further.
- `sticky` (optional, bool | str): Keep one pinned IP across calls (a TTL like `"30m"`), instead of a fresh IP per request.
- `filter` (optional, str): AI IP-quality tier.
- `protocol` (optional, str): `"http"` (default) or `"socks5"`.

```python
from langchain_proxyhat import ProxyHatFetchTool

tool = ProxyHatFetchTool(country="us")
```

## Invocation

### Basic usage

```python
result = tool.invoke("https://httpbin.org/ip")

print(result)
```

### With geo-targeting

```python
uk_tool = ProxyHatFetchTool(country="gb", sticky="30m")
result = uk_tool.invoke("https://example.com")
```
