[AgenticEmail](https://agenticemail.dev) is API-first email infrastructure for AI agents. Every inbox both sends and receives, so an agent can be reached at a real address, not just send outbound mail. The `langchain-agenticemail` package provides LangChain tools for creating inboxes and sending, reading, replying to, and searching real email, with optional end-to-end encryption.

## Overview

### Integration details

| Class | Package | Serializable | [JS support](https://js.langchain.com) | Version |
|:------|:--------| :---: | :---: | :---: |
| `AgenticEmailToolkit` | [`langchain-agenticemail`](https://pypi.org/project/langchain-agenticemail/) | ❌ | ❌ | ![PyPI - Version](https://img.shields.io/pypi/v/langchain-agenticemail?style=flat-square&label=%20) |

### Available tools

| Tool | Description |
|:-----|:------------|
| `create_inbox` | Create a new email inbox for the agent |
| `list_inboxes` | List the inboxes available to the agent |
| `send_email` | Send an email from an inbox to one or more recipients |
| `list_messages` | List the messages in an inbox |
| `get_message` | Fetch a single message with its parsed body |
| `reply_to_message` | Reply to a message inside the same thread |
| `search_messages` | Full-text search the messages in an inbox |

## Setup

Install the package:

```bash
pip install -qU langchain-agenticemail
```

### Credentials

You need an AgenticEmail API key. Create one at [app.agenticemail.dev](https://app.agenticemail.dev).

```python
import getpass
import os

if not os.environ.get("AGENTICEMAIL_API_KEY"):
    os.environ["AGENTICEMAIL_API_KEY"] = getpass.getpass("AgenticEmail API key:\n")
```

## Instantiation

Use the toolkit to get all tools at once:

```python
from langchain_agenticemail import AgenticEmailToolkit

toolkit = AgenticEmailToolkit.from_api_key()
tools = toolkit.get_tools()
```

## Invocation

### Invoke directly with args

```python
send_email = next(t for t in tools if t.name == "send_email")

result = send_email.invoke({
    "inbox_id": "inb_abc123",
    "to": ["alice@example.com"],
    "subject": "Hello from LangChain",
    "text": "This message was sent through langchain-agenticemail.",
})
print(result)
```

### Invoke with ToolCall

```python
model_generated_tool_call = {
    "args": {
        "inbox_id": "inb_abc123",
        "to": ["alice@example.com"],
        "subject": "Follow up",
        "text": "Just checking in.",
    },
    "id": "1",
    "name": "send_email",
    "type": "tool_call",
}
tool_msg = send_email.invoke(model_generated_tool_call)
print(tool_msg.content)
```

## Use within an agent

```python
from langchain.chat_models import init_chat_model
from langgraph.prebuilt import create_react_agent

from langchain_agenticemail import AgenticEmailToolkit

model = init_chat_model(model="claude-sonnet-4-5", model_provider="anthropic")

toolkit = AgenticEmailToolkit.from_api_key()
agent = create_react_agent(model, toolkit.get_tools())

response = agent.invoke({
    "messages": [(
        "user",
        "Create an inbox, then email a short welcome note to user@example.com.",
    )]
})
```
