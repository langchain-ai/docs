[Live Tennis API](https://livetennisapi.com) is a real-time tennis data API covering ATP, WTA, Challenger, ITF and junior Grand Slam draws. The `langchain-livetennis` package exposes it as LangChain tools, so an agent can read live scores, match detail, player profiles and upcoming fixtures.

This guide provides a quick overview for getting started with the Live Tennis API [tools](/oss/langchain/tools). For a detailed listing of all features, parameters and configurations, head to the [Live Tennis API reference](https://docs.livetennisapi.com).

## Overview

### Available tools

| Tool | Description |
| :--- | :--- |
| `live_tennis_matches` | List matches by status (`live`, `upcoming`, `completed`), optionally filtered to one tour, each with its latest score |
| `live_tennis_match` | Fetch one match in full: both players, tournament, surface, round, status and score |
| `live_tennis_match_score` | Fetch only the score of a match — sets, games, points, server and tiebreak flag |
| `live_tennis_player_search` | Find players by name and get their id, tour, country and ranking |
| `live_tennis_player` | Fetch one player's bio, ranking and cached statistics |
| `live_tennis_fixtures` | List upcoming scheduled fixtures, earliest first |

### Features

- Live scores updated in play, covering singles and doubles on every tour.
- `tour` filtering (`atp`, `wta`, `challenger`, `itf`, `juniors`) applied server-side, before pagination.
- Typed exceptions for the auth, plan, rate-limit and not-found cases, re-raised as LangChain's `ToolException` inside a tool call.
- Automatic retries on 429 and 5xx only, honouring `Retry-After`.

## Setup

To access the Live Tennis API tools you need a Live Tennis API key and the `langchain-livetennis` package.

### Credentials

Get a free key (1,000 requests/day) at [livetennisapi.com/subscribe/free](https://livetennisapi.com/subscribe/free). A request without a key is answered with HTTP 401 `{"error": "unauthorized"}`.

```python Set API key icon="key"
import getpass
import os

if "LIVETENNISAPI_KEY" not in os.environ:
    os.environ["LIVETENNISAPI_KEY"] = getpass.getpass("Enter your Live Tennis API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The Live Tennis API tools live in the `langchain-livetennis` package:

<CodeGroup>
    ```python pip
    pip install -U langchain-livetennis
    ```
    ```python uv
    uv add langchain-livetennis
    ```
</CodeGroup>

## Instantiation

Get every tool at once from the toolkit, which shares one HTTP connection pool across them:

```python Initialize the toolkit icon="robot"
from langchain_livetennis import LiveTennisToolkit

toolkit = LiveTennisToolkit()
tools = toolkit.get_tools()
```

Or instantiate a single tool on its own:

```python Initialize one tool icon="robot"
from langchain_livetennis import LiveTennisMatchesTool

tool = LiveTennisMatchesTool()
```

## Invocation

### Directly

`live_tennis_matches` takes `status` (`live`, `upcoming` or `completed`), an optional `tour`, and a `limit` between 1 and 200:

```python Call tool icon="rocket"
from langchain_livetennis import LiveTennisMatchesTool

tool = LiveTennisMatchesTool()
tool.invoke({"status": "live", "tour": "atp", "limit": 5})
```

Every tool returns the API's JSON payload as a string, so nothing is lost on the way to the model.

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"status": "live", "tour": "wta", "limit": 3},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### Within an agent

```python Agent with tools icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent
from langchain_livetennis import LiveTennisToolkit

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=LiveTennisToolkit().get_tools(),
)

agent.invoke(
    {"messages": [{"role": "user", "content": "Which ATP matches are live, and who is ahead?"}]}
)
```

## Filtering by tour

`tour` accepts `atp`, `wta`, `challenger`, `itf` or `juniors`. Each value covers that tour's singles and doubles draws, and `juniors` covers the boys' and girls' Grand Slam draws. Omit it for all tours. The filter is applied by the API before pagination, so the returned count reflects the filtered set. An unrecognised value is rejected rather than silently ignored.

```python Filter by tour icon="filter"
from langchain_livetennis import LiveTennisFixturesTool, LiveTennisMatchesTool

LiveTennisMatchesTool().invoke({"status": "upcoming", "tour": "challenger", "limit": 10})
LiveTennisFixturesTool().invoke({"limit": 10})
```

## Plans and errors

`status="live"`, `status="upcoming"` and every other tool here work on the free key. `status="completed"` is part of the paid History product and needs a BASIC plan or above; a free key gets HTTP 403.

API failures are raised as LangChain's `ToolException`, so an agent can be configured to recover from them rather than crash:

```python Handle tool errors icon="shield"
from langchain_livetennis import LiveTennisMatchesTool

tool = LiveTennisMatchesTool(handle_tool_error=True)
```

| Underlying exception | When |
| :--- | :--- |
| `LiveTennisAuthError` | 401 — key missing, unknown, or disabled |
| `LiveTennisUpgradeRequired` | 403 — valid key, plan too low |
| `LiveTennisNotFound` | 404 — no such match or player, or no data yet |
| `LiveTennisBadRequest` | 400 — a query parameter was rejected |
| `LiveTennisRateLimited` | 429 — carries `.retry_after` in seconds |
| `LiveTennisServerError` | 5xx, or the API was never reached |

Requests retry automatically on 429 and 5xx only. A 401 or 403 is never retried — a bad key or an unentitled plan cannot start working, and retrying only burns the rate limit.
