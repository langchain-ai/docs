[FlipCoin](https://www.flipcoin.fun) is a prediction markets platform on Base (EVM). The `langchain-flipcoin` toolkit gives LangChain agents 14 tools to discover markets, trade YES/NO outcome shares, manage positions, and resolve markets.

## Overview

### Integration details

| Class | Package | Serializable | JS support | Version |
| :--- | :--- | :---: | :---: | :---: |
| FlipCoinToolkit | `langchain-flipcoin` | ❌ | ❌ | ![PyPI - Version](https://img.shields.io/pypi/v/langchain-flipcoin?style=flat-square&label=%20) |

### Tool features

**Markets (4 tools)**

| Tool | Description |
|------|-------------|
| `flipcoin_get_markets` | Search and list prediction markets with filtering and sorting |
| `flipcoin_get_market_details` | Get full details for a specific market (question, prices, volume) |
| `flipcoin_get_market_state` | Get live LMSR AMM state (prices, liquidity, slippage curve) |
| `flipcoin_create_market` | Create a new YES/NO prediction market |

**Trading (4 tools)**

| Tool | Description |
|------|-------------|
| `flipcoin_get_quote` | Preview a trade (returns LMSR and CLOB quotes with recommendation) |
| `flipcoin_trade` | Execute a buy or sell trade via LMSR AMM or CLOB |
| `flipcoin_create_order` | Place a limit order on the CLOB order book |
| `flipcoin_cancel_order` | Cancel an open limit order |

**Portfolio (2 tools)**

| Tool | Description |
|------|-------------|
| `flipcoin_get_portfolio` | View all positions with P&L |
| `flipcoin_redeem_positions` | Redeem winning shares from resolved markets |

**Vault (2 tools)**

| Tool | Description |
|------|-------------|
| `flipcoin_get_vault_balance` | Check available USDC balance |
| `flipcoin_deposit` | Deposit USDC into the trading vault |

**Resolution (2 tools)**

| Tool | Description |
|------|-------------|
| `flipcoin_propose_resolution` | Propose YES/NO outcome with reason and evidence |
| `flipcoin_finalize_resolution` | Finalize resolution after 24h dispute period |

## Setup

### Credentials

You need a FlipCoin Agent API key (`fc_...`). Create one at [flipcoin.fun/app/agents](https://www.flipcoin.fun/app/agents) — create an agent profile and click **"Generate Key"**.

```python Set API key icon="key"
import getpass
import os

if "FLIPCOIN_API_KEY" not in os.environ:
    os.environ["FLIPCOIN_API_KEY"] = getpass.getpass("Enter your FlipCoin API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/home) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

<CodeGroup>
    ```python pip
    pip install -U langchain-flipcoin
    ```
    ```python uv
    uv add langchain-flipcoin
    ```

</CodeGroup>

This also installs the [`flipcoin`](https://pypi.org/project/flipcoin/) Python SDK (low-level HTTP client).

## Instantiation

```python Initialize toolkit icon="robot"
import os
from langchain_flipcoin import FlipCoinToolkit

toolkit = FlipCoinToolkit(api_key=os.environ["FLIPCOIN_API_KEY"])
tools = toolkit.get_tools()  # Returns all 14 tools
```

You can also pass a pre-built SDK client:

```python Pre-built client icon="gear"
from flipcoin import FlipCoin
from langchain_flipcoin import FlipCoinToolkit

client = FlipCoin(api_key="fc_...", base_url="https://www.flipcoin.fun")
toolkit = FlipCoinToolkit(client=client)
```

## Invocation

### Directly

```python Get markets icon="rocket"
import json

markets_tool = tools[0]  # flipcoin_get_markets
result = json.loads(markets_tool.invoke({"status": "open", "sort": "trending", "limit": 5}))
for m in result["markets"]:
    print(f"{m['title']} — YES: {m.get('currentPriceYesBps', 'N/A')} bps")
```

### Within an agent

```python Agent with toolkit icon="robot"
from langchain_openai import ChatOpenAI
from langgraph.prebuilt import create_react_agent

llm = ChatOpenAI(model="gpt-4o")
agent = create_react_agent(llm, tools)

result = agent.invoke({
    "messages": [("user", "Show me trending prediction markets and my vault balance")]
})
```

## Key concepts

- **Prices** are in basis points (bps): `5000` = 50%, `10000` = 100%
- **USDC amounts** are human-readable strings: `"5.0"` = $5. Tools auto-convert to raw 6-decimal format.
- **condition_id** (bytes32 hex) — primary market identifier for trading and resolution
- **address** (0x hex) — on-chain contract address for market details
- **Two venues**: LMSR AMM (guaranteed liquidity, instant) and CLOB order book (limit orders, 0% maker fee). Use `flipcoin_get_quote` to get recommendations.
