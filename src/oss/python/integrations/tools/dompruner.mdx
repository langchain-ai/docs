[dompruner](https://github.com/dong7812/dompruner-py) fetches a URL and returns the page content as compact Markdown after stripping DOM noise (nav, scripts, ads, footers). No summarization — the output is the original text with structural noise removed.

`DomPrunerFetchTool` wraps this as a LangChain `BaseTool` for use in agents. Its description tells agents to prefer it over built-in web fetch.

## Instantiation

```python
from dompruner.langchain import DomPrunerFetchTool

tool = DomPrunerFetchTool()
# name: "dompruner_fetch"
```

## Invocation

```python
# Basic fetch
result = tool.invoke({"url": "https://docs.python.org/3/library/asyncio-task.html"})

# With BM25 section filtering
result = tool.invoke({
    "url": "https://docs.python.org/3/library/asyncio-task.html",
    "query": "create_task",
})

print(result[:300])
```

## Use within an agent

```python
from dompruner.langchain import DomPrunerFetchTool
from langchain_anthropic import ChatAnthropic
from langgraph.prebuilt import create_react_agent

agent = create_react_agent(
    ChatAnthropic(model="claude-haiku-4-5"),
    tools=[DomPrunerFetchTool()],
)

result = agent.invoke({
    "messages": [{
        "role": "user",
        "content": "What does asyncio.create_task() return? "
                   "See: https://docs.python.org/3/library/asyncio-task.html",
    }]
})
print(result["messages"][-1].content)
```
