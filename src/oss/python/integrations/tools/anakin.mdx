## Setup

Install `langchain-community` and set your API key:

<CodeGroup>
```bash pip
pip install -U langchain-community
```

```bash uv
uv add langchain-community
```
</CodeGroup>

```bash
export ANAKIN_API_KEY="your-api-key"
```

Get your key from the [Anakin dashboard](https://anakin.io/dashboard).

## AnakinScrapeTool

Scrape a web page and return its content as clean markdown.

```python
from langchain_community.tools import AnakinScrapeTool

tool = AnakinScrapeTool()
```

Invoke the tool:

```python
result = tool.invoke({"url": "https://example.com"})
print(result[:200])
```

```text
# Example Domain

This domain is for use in illustrative examples in documents. ...
```

Use headless browser rendering for JavaScript-heavy pages:

```python
result = tool.invoke({"url": "https://example.com", "use_browser": True})
```

## AnakinSearchTool

Run an AI-powered web search and return results with titles, snippets, and source URLs.

```python
from langchain_community.tools import AnakinSearchTool

tool = AnakinSearchTool()
```

Invoke the tool:

```python
result = tool.invoke({"query": "latest AI news"})
print(result)
```

```text
[1] AI Advances in 2026
New breakthroughs in reasoning...
Source: https://example.com/ai-news

[2] ...
```

Set a custom result limit:

```python
result = tool.invoke({"query": "Python tutorials", "limit": 10})
```

## AnakinAgenticSearchTool

Perform deep, multi-stage autonomous research on a topic. Returns a comprehensive research report. Typically takes 1-5 minutes.

```python
from langchain_community.tools import AnakinAgenticSearchTool

tool = AnakinAgenticSearchTool()
```

Invoke the tool:

```python
result = tool.invoke({"query": "compare React vs Vue in 2026"})
print(result[:300])
```

```text
Based on analysis of multiple sources, React and Vue ...
```

## Use within an agent

Combine Anakin tools in a LangChain agent for autonomous web research workflows:

```python
# pip install -qU langchain-community "langchain[anthropic]"
from langchain_community.tools import (
    AnakinScrapeTool,
    AnakinSearchTool,
    AnakinAgenticSearchTool,
)
from langchain.agents import create_tool_calling_agent, AgentExecutor
from langchain_anthropic import ChatAnthropic
from langchain_core.prompts import ChatPromptTemplate

tools = [AnakinScrapeTool(), AnakinSearchTool(), AnakinAgenticSearchTool()]

llm = ChatAnthropic(model="claude-sonnet-4-5-20250929")
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful research assistant."),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}"),
])

agent = create_tool_calling_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools)

result = agent_executor.invoke(
    {"input": "Find and summarize the homepage of python.org"}
)
print(result["output"])
```
