This guide provides a quick overview for getting started with the [FlowSpeech](https://flowspeech.io/) text-to-speech [tool](/oss/langchain/tools). FlowSpeech generates human-like speech audio from text and supports voice selection and multi-speaker dialogue.

## Overview

### Details

| Class | Package | Serializable | JS support | Downloads | Version |
| :--- | :--- | :---: | :---: | :---: | :---: |
| `FlowSpeechTextToSpeechTool` | [`langchain-flowspeech`](https://pypi.org/project/langchain-flowspeech/) | ❌ | ❌ | ![PyPI - Downloads](https://img.shields.io/pypi/dm/langchain-flowspeech?style=flat-square&label=%20) | ![PyPI - Version](https://img.shields.io/pypi/v/langchain-flowspeech?style=flat-square&label=%20) |

### Features

- Generate speech audio from text
- Save generated audio to a local WAV file
- Configure a default voice
- Provide explicit speaker-to-voice assignments for dialogue

## Setup

To access the FlowSpeech tool, create a FlowSpeech account, get an API key, and install the `langchain-flowspeech` integration package.

### Credentials

```python Set API key icon="key"
import getpass
import os

if "FLOWSPEECH_API_KEY" not in os.environ:
    os.environ["FLOWSPEECH_API_KEY"] = getpass.getpass("Enter your FlowSpeech API key: ")
```

It's also helpful, but not required, to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The FlowSpeech tool lives in the `langchain-flowspeech` package:

<CodeGroup>
    ```python pip
    pip install -U langchain-flowspeech
    ```
    ```python uv
    uv add langchain-flowspeech
    ```
</CodeGroup>

## Instantiation

Instantiate the FlowSpeech tool:

```python Initialize tool instance icon="robot"
from langchain_flowspeech import FlowSpeechTextToSpeechTool

tool = FlowSpeechTextToSpeechTool()
```

You can also pass credentials directly:

```python Initialize with API key icon="key"
tool = FlowSpeechTextToSpeechTool(api_key="...")
```

## Invocation

### Directly

Call the tool with text, a voice name, and an output path:

```python Call tool icon="rocket"
result = tool.invoke(
    {
        "text": "Welcome to FlowSpeech. This audio is generated from a LangChain tool.",
        "voice_name": "Kore",
        "output_path": "flowspeech-demo.wav",
    }
)

print(result["output_path"])
print(result["mime_type"])
print(result["quota"])
```

### Multi-speaker speech

Use `FlowSpeechSpeaker` to map speaker labels in the input text to specific voices:

```python Multi-speaker speech icon="volume-2"
from langchain_flowspeech import FlowSpeechSpeaker, FlowSpeechTextToSpeechTool

tool = FlowSpeechTextToSpeechTool()

result = tool.invoke(
    {
        "text": "Speaker A: We can make this sound natural.\nSpeaker B: Great, let's use different voices.",
        "speakers": [
            FlowSpeechSpeaker(speaker="Speaker A", voice_name="Kore"),
            FlowSpeechSpeaker(speaker="Speaker B", voice_name="Puck"),
        ],
        "output_path": "conversation.wav",
    }
)
```

### As a ToolCall

You can also invoke the tool with a model-generated `ToolCall`, in which case a `ToolMessage` will be returned:

```python ToolCall icon="briefcase"
model_generated_tool_call = {
    "args": {
        "text": "Create a short narration file.",
        "voice_name": "Kore",
        "output_path": "narration.wav",
    },
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}

tool.invoke(model_generated_tool_call)
```
