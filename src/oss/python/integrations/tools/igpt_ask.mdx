This guide provides a quick overview for getting started with the **IGPTAsk** [tool](/oss/langchain/tools/igpt_ask). For a detailed listing of all IGPTAsk features, parameters, and configurations, head to the [IGPTAsk API reference](https://docs.igpt.ai/docs/api-reference/ask).

**IGPTAsk** is a LangChain tool that calls the **iGPT Recall Ask API** to generate answers **grounded in a user’s connected personal data sources** — emails, messages, file attachments, related metadata (timestamps, participants, subjects, etc.). IGPTAsk retrieves relevant evidence from the user’s indexed archive and produces a response based on that context.

### Features

- ✅ Grounded Q&A over connected personal data sources (emails, messages, files, metadata)
- ✅ Streaming responses (`stream=True`) (sync + async)
- ✅ Structured outputs via `output_format="json"` or JSON Schema wrapper
- ✅ Async support (`ainvoke`)
- ✅ Retries with exponential backoff

## Setup

To access the IGPTAsk tool, you’ll need iGPT credentials and to install the `langchain-igpt` integration package.

### Credentials

```bash
export IGPT_API_KEY="your-api-key"
export IGPT_API_USER="your-api-user"
```

```python
import getpass
import os

if "IGPT_API_KEY" not in os.environ:
    os.environ["IGPT_API_KEY"] = getpass.getpass("Enter your iGPT API key: ")

if "IGPT_API_USER" not in os.environ:
    os.environ["IGPT_API_USER"] = getpass.getpass("Enter your iGPT API user: ")
```

Alternatively, pass `api_key` / `user` directly to tool constructor.

### Installation

The IGPTAsk tool lives in the `langchain-igpt` package:

```python
pip install -U langchain-igpt
```

## Instantiation

Now we can instantiate an instance of the IGPTAsk tool with:

```python
from langchain_igpt import IGPTAsk

tool = IGPTAsk(user="user_123", api_key="ak:...", quality="cef-1-normal")
```

### Parameters

* `input` (string, required): The prompt/question to ask.
* `user` (string, optional if set in constructor): Unique user identifier.
* `stream` (boolean, optional, default: `false`): If `true`, returns iterable stream.
* `quality` (string, optional): Context engineering quality (e.g., `"cef-1-normal"`). [Read more](https://docs.igpt.ai/docs/concepts/cef).
* `output_format` (string | object, optional):

  * `"text"` (default)
  * `"json"`
  * `{ schema: <JSON Schema> }` to enforce a structured output

NOTE:
- `input` and `output_format` are intended to be provided **during invocation** (per request),
  not as fixed constructor defaults. This lets the agent change the prompt and the desired output shape on each call.
- If you set `user`, `stream`, or `quality` during invocation, that value will overwrite the value passed during instantiation.

## Invocation

IGPTAsk is used to **ask a question** and receive an answer **grounded** in the user’s connected context.

### Invoke directly

```python
res = tool.invoke({
    "input": "Summarize my last meeting in 5 bullet points."
})
print(res)
```

Example response:

```json
{
  "id": "...",
  "output": "...",
  "context": {
    "quality": "cef-1-normal",
    "indexed": 0.0001783,
    "datasources": [{...}]
  },
  "metadata": {
    "sources": [{...}]
  },
  "usage": {
    "input_tokens": 1272,
    "output_tokens": 281,
    "total_tokens": 1553
  }
}
```

### Invoke directly with JSON Schema

Use a schema to get consistent, machine-validated structure.

```python
output_format = {
    "strict": True,
    "schema": {
        "type": "object",
        "properties": {
        "action_items": {
            "type": "array",
            "description": "List of action items",
            "items": {
            "type": "object",
            "properties": {
                "title": { "type": "string", "description": "Short summary of the action item" },
                "owner": { "type": "string", "description": "Person responsible for the action item" },
                "due_date": { "type": "string", "format": "date", "description": "Expected completion date" }
            },
            "required": ["title", "owner", "due_date"],
            "additionalProperties": False
            }
        }
        },
        "required": ["action_items"],
        "additionalProperties": False
    }
}
res = tool.invoke({
    "input": "Open action items from yesterday’s board meeting",
    "output_format": output_format
})
print(res)
```

Example response (schema):

```json
{
  "action_items": [
    {
      "title": "Approve revised Q1 budget allocation",
      "owner": "Board of Directors",
      "due_date": "2026-01-15"
    },
    {
      "title": "Approve final FY2026 strategic priorities",
      "owner": "Board of Directors",
      "due_date": "2026-01-31"
    }
  ]
}
```

### Invoke asynchronously

```python
async def main():
    result = await tool.ainvoke({"input": "List all vendor escalations from last month"})
    print(result)
asyncio.run(main())
```

### Streaming IGPTAsk tool

For streaming responses, set `stream: True`. The tool returns an iterable that yields parsed JSON chunks.

```python
for chunk in tool.invoke({"input":"Stream the answer in chunks.", "stream":True, "quality":"cef-1-normal", "output_format": "text"}):
    print(chunk, end="", flush=True)
```

### Invoke with ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a `ToolMessage` will be returned:

```python
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"input": "Create a list of technical issues reported by Zach related to domain verification"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

## Use within an agent

We can use our tool in an agent. For this we will need a model with tool-calling capabilities.

This example shows how to plug the IGPTAsk tool into a LangChain agent,
so the LLM can decide when to call the tool to retrieve grounded context and then
compose an answer for the user.


```python
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI
from langchain_igpt import IGPTAsk

ask_tool = IGPTAsk()

agent = create_agent(
    model=ChatOpenAI(model="gpt-5", api_key="sk-..."),
    tools=[ask_tool],
    system_prompt=(
        "You are a helpful research assistant. Your primary job is to retrieve, "
        "summarize, and interpret user data via the igpt_ask tool."
    )
)

# Streaming agent responses step-by-step (using 'values' mode)
for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "Summarize key risks, decisions, and next steps from this week's meetings."}]},
    stream_mode="values",
):
    chunk["messages"][-1].pretty_print()
```
