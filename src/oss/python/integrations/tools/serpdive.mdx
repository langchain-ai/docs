[SERPdive](https://serpdive.com) is an AI search API that returns answer-ready web content: every result carries the actual text of the page, already extracted, cleaned, and sized for LLM consumption, so agents can quote and cite straight from the tool output. On a [public, replayable 1,000-question benchmark](https://github.com/edendalexis/serpdive-benchmark), SERPdive runs at the same speed as Tavily, feeds your LLM 20.2% fewer tokens, and wins 60.7% of decided quality duels.

<CodeGroup>
```bash pip
pip install -U langchain-serpdive
```

```bash uv
uv add langchain-serpdive
```

### Credentials

Get a free API key (no card required) at [serpdive.com/dashboard/keys](https://serpdive.com/dashboard/keys) and set it as the `SERPDIVE_API_KEY` environment variable:

```python
import getpass
import os

if not os.environ.get("SERPDIVE_API_KEY"):
    os.environ["SERPDIVE_API_KEY"] = getpass.getpass("SERPdive API key:\n")
```

## Instantiation

The tool accepts the following parameters during instantiation:

- `model` (optional, str): Retrieval depth. `"mako"` (default) returns the fact-carrying sentences of each page, fast. `"krill"` is the free tier — unlimited under fair use, the smallest useful payload, one request at a time, at low priority. `"moby"` returns the full readable text of each page, for deep research.
- `answer` (optional, bool): When `True`, the output also carries an `answer` field: a direct answer synthesized from the sources (concise on `mako`, cited on `moby`; not available on `krill`). Default is `False`.
- `max_results` (optional, int): Hard cap on delivered results (1-10). By default the engine picks its calibrated mix.
- `api_key` (optional, str): SERPdive API key. Defaults to the `SERPDIVE_API_KEY` environment variable.

There is no country or locale parameter to configure: the language of the query picks where the search runs, automatically.

```python
from langchain_serpdive import SerpdiveSearch

tool = SerpdiveSearch(
    # model="krill",     # free and unlimited (fair use)
    # model="moby",      # full page text, for deep research
    # answer=True,       # also return a synthesized answer
    # max_results=5,     # hard cap on delivered results, 1-10
)
```

## Invocation

### [Invoke directly with args](/oss/langchain/tools)

The tool accepts a single argument during invocation:

- `query` (required, str): A natural language search query, in any language.

```python
tool.invoke({"query": "latest developments in solid state batteries"})
```

The output is a lean dict the model can quote and cite directly:

```json
{
    "query": "latest developments in solid state batteries",
    "results": [
        {
            "url": "https://...",
            "title": "...",
            "date": "2026-07-11",
            "content": "The fact-carrying text of the page, extracted and cleaned..."
        }
    ]
}
```

### [Invoke with ToolCall](/oss/langchain/tools)

We can also invoke the tool with a model-generated `ToolCall`, in which case a `ToolMessage` will be returned:

```python
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "what changed in the EU AI Act this month"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool_msg = tool.invoke(model_generated_tool_call)

print(tool_msg.content[:400])
```

## Use within an agent

Pass the tool to any LangChain or LangGraph agent; the tool description tells the model when to call it.

```python
from langchain.agents import create_agent
from langchain_serpdive import SerpdiveSearch

agent = create_agent(
    model="claude-sonnet-5",
    tools=[SerpdiveSearch()],
)

agent.invoke(
    {"messages": [{"role": "user", "content": "What changed in the EU AI Act this month?"}]}
)
```
