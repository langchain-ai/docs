## Overview

The `PerplexitySearchResults` tool allows agents to search the web using Perplexity's Search API. It returns structured search results including titles, URLs, snippets, and publication dates.

## Setup

To use the tool, you'll need a Perplexity API key.

### Credentials

```python
import getpass
import os

if "PPLX_API_KEY" not in os.environ:
    os.environ["PPLX_API_KEY"] = getpass.getpass("Enter your Perplexity API key: ")
```

### Installation

```bash
pip install -qU langchain-perplexity
```

## Instantiation

```python
from langchain_perplexity import PerplexitySearchResults

tool = PerplexitySearchResults()
```

## Usage

The tool accepts a search query and optional parameters at invocation time:

```python
# Basic search
results = tool.invoke("What is LangChain?")

# Returns a list of dictionaries with search results
for res in results:
    print(f"Title: {res['title']}")
    print(f"URL: {res['url']}")
    print(f"Snippet: {res['snippet'][:100]}...")
    print("---")
```

### Advanced usage with parameters

When calling the tool directly (e.g., via `_run`), you can pass additional search parameters:

```python
# Search with advanced options
results = tool._run(
    query="Latest AI developments",
    max_results=5,
    country="US",
    search_recency_filter="week",
    search_domain_filter=["arxiv.org", "nature.com"],
)
```

Available parameters:
- `query`: Search query string (or list of strings for multi-query)
- `max_results`: Maximum number of results (default: 10)
- `country`: ISO country code for geographic filtering
- `search_domain_filter`: List of domains to limit results (max 20)
- `search_recency_filter`: Filter by recency (`"day"`, `"week"`, `"month"`, `"year"`)
- `search_after_date`: Only include content after this date (format: `MM/DD/YYYY`)
- `search_before_date`: Only include content before this date (format: `MM/DD/YYYY`)

## Use within an agent

When used with an agent, the tool receives the search query from the agent's reasoning:

```python
from langchain.agents import create_agent
from langchain_perplexity import PerplexitySearchResults

# Initialize the tool
search_tool = PerplexitySearchResults()

# Create the agent
agent = create_agent(
    model="gpt-4o",
    tools=[search_tool],
    system_prompt="You are a helpful assistant that can search the web.",
)

# Run the agent
result = agent.invoke(
    {"messages": [{"role": "user", "content": "What are the latest releases of LangChain?"}]}
)
print(result["messages"][-1].content)
```
