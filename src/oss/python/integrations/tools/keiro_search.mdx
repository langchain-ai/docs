## Setup

To access the Keiro search tool, you need a Keiro API key and the `langchain-keiro` package.

### Credentials

Get an API key at [keirolabs.cloud](https://keirolabs.cloud). The Explorer plan gives you 500 free credits, no credit card needed.

```python Set API key icon="key"
import getpass
import os

if "KEIRO_API_KEY" not in os.environ:
    os.environ["KEIRO_API_KEY"] = getpass.getpass("Enter your Keiro API key: ")
```

It is also helpful to set up [LangSmith](/langsmith/home) for best-in-class observability/tracing of your tool calls:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The Keiro search tool lives in the `langchain-keiro` package:

<CodeGroup>
    ```python pip
    pip install -U langchain-keiro
    ```
    ```python uv
    uv add langchain-keiro
    ```
</CodeGroup>

## Instantiation

```python Initialize tool icon="robot"
from langchain_keiro.tools import KeiroSearchTool

tool = KeiroSearchTool(keiro_api_key=os.environ["KEIRO_API_KEY"])
```

## Invocation

```python Call tool icon="rocket"
result = tool.invoke({"query": "What is quantum computing?", "max_results": 3})
print(result)
# Result 1:
# Title: What Is Quantum Computing? - IBM
# URL: https://www.ibm.com/think/topics/quantum-computing
# Content: Quantum computing is a rapidly-emerging technology...
# ---
# Result 2:
# ...
```

## Use within an agent

```python Agent with tool icon="robot"
from langchain_openai import ChatOpenAI
from langchain.agents import create_tool_calling_agent, AgentExecutor
from langchain_core.prompts import ChatPromptTemplate

llm = ChatOpenAI(model="gpt-5")
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a research assistant. Use the keiro_search tool to find information."),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}"),
])

agent = create_tool_calling_agent(llm, [tool], prompt)
agent_executor = AgentExecutor(agent=agent, tools=[tool])

response = agent_executor.invoke({"input": "What are the latest AI trends?"})
```
