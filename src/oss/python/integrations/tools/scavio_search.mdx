[Scavio's Search API](https://scavio.dev) is a multi-platform search engine built for AI agents (LLMs), delivering real-time, structured SERP data with knowledge graphs, related questions, and news results.

## Setup

The integration lives in the `langchain-scavio` package.

```python
pip install -qU langchain-scavio
```

### Credentials

Set your Scavio API key. Get one at [dashboard.scavio.dev](https://dashboard.scavio.dev/).

```python
import getpass
import os

if not os.environ.get("SCAVIO_API_KEY"):
    os.environ["SCAVIO_API_KEY"] = getpass.getpass("Scavio API key:\n")
```

## Instantiation

The tool accepts various parameters during instantiation:

- `max_results` (optional, int): Maximum number of search results to return. Default is 5.
- `light_request` (optional, bool): `None` for light mode (1 credit), `False` for full mode (2 credits). Default is `None`.
- `include_knowledge_graph` (optional, bool): Include knowledge graph data. Default is `True`.
- `include_questions` (optional, bool): Include "People Also Ask" questions. Default is `True`.
- `include_related` (optional, bool): Include related queries and searches. Default is `False`.
- `include_news_results` (optional, bool): Include news results. Default is `False`.
- `nfpr` (optional, bool): Disable autocorrection. Default is `False`.

For a comprehensive overview, refer to the [Scavio API documentation](https://scavio.dev/docs).

```python
from langchain_scavio import ScavioSearch

tool = ScavioSearch(
    max_results=5,
    include_knowledge_graph=True,
    include_questions=True,
    # include_related=False,
    # include_news_results=False,
    # light_request=None,
)
```

## Invocation

### [Invoke directly with args](/oss/langchain/tools)

The Scavio search tool accepts the following arguments during invocation:

- `query` (required): A natural language search query
- `search_type` (optional): `"classic"`, `"news"`, `"maps"`, `"images"`, or `"lens"`
- `country_code` (optional): ISO 3166-1 alpha-2 country code
- `language` (optional): ISO 639-1 language code
- `device` (optional): `"desktop"` or `"mobile"`
- `page` (optional): Result page number

These arguments are available for agents to dynamically set. If you set an argument during instantiation and then invoke the tool with a different value, the tool uses the invocation value.

```python
tool.invoke({"query": "What happened at the last wimbledon"})
```

### [Invoke with ToolCall](/oss/langchain/tools)

Invoke the tool with a model-generated ToolCall:

```python
model_generated_tool_call = {
    "args": {"query": "best python web frameworks 2026"},
    "id": "1",
    "name": "scavio_search",
    "type": "tool_call",
}
tool_msg = tool.invoke(model_generated_tool_call)
print(tool_msg.content[:400])
```

## Use within an agent

Bind the tool to an agent to give it web search capabilities. The agent can dynamically set search parameters per query.

```python
import getpass
import os

if not os.environ.get("OPENAI_API_KEY"):
    os.environ["OPENAI_API_KEY"] = getpass.getpass("OPENAI_API_KEY:\n")
```

```python
pip install -qU langgraph langchain-openai
```

```python
from langchain_scavio import ScavioSearch
from langgraph.prebuilt import create_react_agent
from langchain_openai import ChatOpenAI

tool = ScavioSearch(
    max_results=5,
    include_knowledge_graph=True,
)

agent = create_react_agent(
    ChatOpenAI(model="gpt-4o"),
    tools=[tool],
)

for step in agent.stream(
    {"messages": [{"role": "user", "content": "What are the latest AI regulations in the EU?"}]},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```
