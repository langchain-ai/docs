This guide provides an overview for getting started with the Sail SQL [toolkit](/oss/langchain/tools). For detailed documentation of all Sail SQL features and configurations, head to the [langchain-sail docs](https://github.com/lakehq/langchain-sail).

[Sail](https://github.com/lakehq/sail) is a drop-in replacement for Apache Spark, written in Rust. It uses the Spark Connect protocol, so existing PySpark code works out of the box—just point your `SparkSession` at a Sail server instead of a Spark cluster.

### Installation

The Sail SQL toolkit lives in the `langchain-sail` package:

<CodeGroup>
```bash pip
pip install -U langchain-sail pysail pyspark
```

```bash uv
uv add langchain-sail pysail pyspark
```
</CodeGroup>

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/home) API key:

```python Enable tracing icon="flask"
import getpass
import os

os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

```python
from pysail.spark import SparkConnectServer
from pyspark.sql import SparkSession

# Start a local Sail server
server = SparkConnectServer()
server.start()
_, port = server.listening_address

# Connect to Sail
spark = SparkSession.builder.remote(f"sc://localhost:{port}").getOrCreate()

# Create some test data
spark.sql("CREATE TABLE employees (name STRING, department STRING, salary INT)")
spark.sql(
    "INSERT INTO employees VALUES "
    "('Alice', 'Engineering', 120000), "
    "('Bob', 'Marketing', 95000), "
    "('Charlie', 'Engineering', 135000), "
    "('Diana', 'Marketing', 105000), "
    "('Eve', 'Engineering', 110000)"
)
```

```python
from langchain_sail import SailSQLToolkit, SailSQL
from langchain_anthropic import ChatAnthropic

# Note, you can also connect to a remote Sail server:
# sail_sql = SailSQL.from_uri("sc://your-sail-host:50051")
sail_sql = SailSQL(spark_session=spark)
llm = ChatAnthropic(model="claude-sonnet-4-6")
toolkit = SailSQLToolkit(db=sail_sql, llm=llm)
```

## Invocation

### Invoke directly with args

You can get the tools from the toolkit and invoke them directly:

```python
tools = toolkit.get_tools()
for tool in tools:
    print(tool.name)
```

```python
# List tables
list_tool = next(t for t in tools if "list" in t.name.lower())
list_tool.invoke("")
```

```text
'employees'
```

```python
# Get table schema
schema_tool = next(t for t in tools if "schema" in t.name.lower() or "info" in t.name.lower())
schema_tool.invoke("employees")
```

```text
'CREATE TABLE employees (name string, department string, salary int);\n\n/*\n3 rows from employees table:\nname\tdepartment\tsalary\nAlice\tEngineering\t120000\nBob\tMarketing\t95000\nCharlie\tEngineering\t135000\n*/'
```

### Use within an agent

You can use the toolkit with the `create_sail_sql_agent` helper to create an agent that can interact with Sail SQL:

```python
from langchain_sail import create_sail_sql_agent

agent = create_sail_sql_agent(llm=llm, toolkit=toolkit, verbose=True)
```

```python
agent.invoke({"input": "Describe the employees table"})
```
