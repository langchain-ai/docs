Give your AI agent the ability to capture website screenshots as PNG, JPEG, WebP, or PDF.

The `langchain-snaprender` package adds three ready-to-use [LangChain tools](/oss/integrations/tools/) backed by the [SnapRender](https://snap-render.com) screenshot API:

| Tool | Use it to |
|------|-----------|
| `take_screenshot` | Capture any website as PNG, JPEG, WebP, or PDF |
| `check_cache` | Check if a screenshot is cached (free, no quota cost) |
| `get_usage` | Get monthly screenshot usage statistics |

## Overview

### Tool features

| Tool | Returns artifact | Native async | Return type |
| :--- | :---: | :---: | :--- |
| `take_screenshot` | ✅ (saved file) | ❌ | `str` — file path + metadata |
| `check_cache` | ❌ | ❌ | `str` — cache status |
| `get_usage` | ❌ | ❌ | `str` — usage stats |

### Features

- Capture screenshots in 4 formats: PNG, JPEG, WebP, PDF
- Device emulation: iPhone 14, iPhone 15 Pro, Pixel 7, iPad Pro, MacBook Pro
- Dark mode CSS emulation
- Ad blocking and cookie banner removal (on by default)
- Full-page capture (entire scrollable page)
- Custom viewport dimensions (320-3840 x 200-10000)
- Built-in caching with free cache checks

## Setup

To access the SnapRender tools, you'll need to create a SnapRender account, get an API key, and install the `langchain-snaprender` integration package.

### Credentials

Create a free account at [SnapRender](https://app.snap-render.com/auth/signup) and get an API key:

```python
import getpass
import os

if "SNAPRENDER_API_KEY" not in os.environ:
    os.environ["SNAPRENDER_API_KEY"] = getpass.getpass("Enter your SnapRender API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](https://docs.langchain.com/langsmith/home) API key:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The SnapRender tools live in the `langchain-snaprender` package:

<CodeGroup>


</CodeGroup>

For JavaScript / TypeScript, see `npm install langchain-snaprender` ([npm](https://www.npmjs.com/package/langchain-snaprender)).

## Instantiation

Import the tools you need:

```python
from langchain_snaprender import take_screenshot, check_cache, get_usage
```

The tools are pre-configured `@tool` decorated functions. No class instantiation needed — just import and use.

## Invocation

### [Invoke directly with args](/oss/langchain/tools)

#### `take_screenshot`

Capture a screenshot and save it to a temporary file. Returns the file path and metadata.

| Argument | Type | Required | Description |
|----------|------|----------|-------------|
| `url` | `str` | Yes | Target page URL (must start with `http://` or `https://`) |
| `format` | `str` | No | `"png"` (default), `"jpeg"`, `"webp"`, or `"pdf"` |
| `full_page` | `bool` | No | Capture entire scrollable page (default: `False`) |
| `dark_mode` | `bool` | No | Enable dark mode CSS emulation (default: `False`) |
| `block_ads` | `bool` | No | Block advertisements (default: `True`) |
| `block_cookie_banners` | `bool` | No | Remove cookie consent banners (default: `True`) |
| `device` | `str` | No | `"iphone_14"`, `"iphone_15_pro"`, `"pixel_7"`, `"ipad_pro"`, `"macbook_pro"` |
| `width` | `int` | No | Viewport width in pixels (320–3840) |
| `height` | `int` | No | Viewport height in pixels (200–10000) |

```python
result = take_screenshot.invoke({"url": "https://example.com"})
print(result)
```

```text
Screenshot saved to /tmp/snaprender_abc123.png (44,908 bytes)
URL: https://example.com
Format: png
Cache: MISS
Response time: 2222ms
Remaining credits: 1750
```

With options:

```python
result = take_screenshot.invoke({
    "url": "https://github.com",
    "format": "jpeg",
    "full_page": True,
    "dark_mode": True,
    "device": "iphone_15_pro",
})
print(result)
```

#### `check_cache`

Check whether a screenshot exists in the cache without capturing a new one. This call is free and does not count against your quota.

| Argument | Type | Required | Description |
|----------|------|----------|-------------|
| `url` | `str` | Yes | URL to check |
| `format` | `str` | No | `"png"` (default), `"jpeg"`, `"webp"`, or `"pdf"` |

```python
result = check_cache.invoke({"url": "https://example.com"})
print(result)
```

```text
Cached: YES
URL: https://example.com
Cached at: 2026-02-21T18:44:04.794Z
Expires at: 2026-02-22T18:44:04.794Z
Content type: image/png
```

#### `get_usage`

Get your current month's screenshot usage, including plan name, screenshots used, limit, and remaining credits.

```python
result = get_usage.invoke({})
print(result)
```

```text
Plan: starter
Used: 42
Limit: 2000
Remaining: 1958
Period: {'start': '2026-02-01T00:00:00.000Z', 'end': '2026-02-28T23:59:59.000Z'}
```

### [Invoke with ToolCall](/oss/langchain/tools)

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"url": "https://example.com", "format": "png"},
    "id": "1",
    "name": take_screenshot.name,
    "type": "tool_call",
}
take_screenshot.invoke(model_generated_tool_call)
```

## Chaining

We can use our tool in a chain by first binding it to a [tool-calling model](/oss/langchain/tools/) and then calling it:

<ChatModelTabs customVarName="llm" />

```python
# | output: false
# | echo: false

# !pip install -qU langchain langchain-openai
from langchain.chat_models import init_chat_model

model = init_chat_model(model="gpt-4.1", model_provider="openai")
```

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableConfig, chain

prompt = ChatPromptTemplate(
    [
        ("system", "You are a helpful assistant that can capture website screenshots."),
        ("human", "{user_input}"),
        ("placeholder", "{messages}"),
    ]
)

# specifying tool_choice will force the model to call this tool.
model_with_tools = model.bind_tools([take_screenshot], tool_choice=take_screenshot.name)

model_chain = prompt | model_with_tools


@chain
def tool_chain(user_input: str, config: RunnableConfig):
    input_ = {"user_input": user_input}
    ai_msg = model_chain.invoke(input_, config=config)
    tool_msgs = take_screenshot.batch(ai_msg.tool_calls, config=config)
    return model_chain.invoke({**input_, "messages": [ai_msg, *tool_msgs]}, config=config)


tool_chain.invoke("Take a dark mode screenshot of https://news.ycombinator.com")
```

## Use within an agent

We can use our tools with an agent to take screenshots, check the cache, and report usage — all based on natural language instructions.

<ChatModelTabs customVarName="llm" />

```python
# | output: false
# | echo: false

# !pip install -qU langchain langchain-openai langgraph
from langchain.chat_models import init_chat_model

model = init_chat_model(model="gpt-4.1", model_provider="openai", temperature=0)
```

```python
from langchain_snaprender import take_screenshot, check_cache, get_usage
from langchain.agents import create_agent

tools = [take_screenshot, check_cache, get_usage]
agent = create_agent(model, tools)

for step in agent.stream(
    {"messages": "Take a screenshot of stripe.com in dark mode as a JPEG"},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```
