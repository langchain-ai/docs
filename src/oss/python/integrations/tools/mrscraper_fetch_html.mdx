---
title: "MrScraperFetchHTML integration"
description: "Fetch rendered HTML using MrScraper in LangChain."
---

`MrScraperFetchHTML` fetches rendered HTML from websites that require JavaScript execution or anti-bot bypassing.

## Setup

```bash
pip install -U langchain-mrscraper
```

```python
import os
from langchain_mrscraper import MrScraperFetchHTML

# Option 1: pass API key directly
tool = MrScraperFetchHTML(mrscraper_api_key="your-api-key")

# Option 2: auto-read from environment variable
os.environ["MRSCRAPER_API_KEY"] = "your-api-key"
tool = MrScraperFetchHTML()
```

## Invocation

```python
result = tool.invoke(
    {
        "url": "https://example.com",
        "geo_code": "US",
        "timeout": 120,
        "block_resources": False,
    }
)
print(result)
```

## Parameters

| Parameter | Type | Description |
| :-- | :-- | :-- |
| `url` | `str` | Target URL to fetch |
| `timeout` | `int` | Maximum render time in seconds |
| `geo_code` | `str` | Two-letter country code |
| `block_resources` | `bool` | Block images/fonts/CSS for speed |
