This guide provides a quick overview for getting started with the CrustAPI [tool](/oss/langchain/tools). CrustAPI returns Google and public LinkedIn data as clean, structured JSON: web search, Maps, News, Shopping, Images, Videos, Places, Scholar, and Patents, plus LinkedIn profiles, companies, posts, jobs, and people search. You only pay for successful results, and there's a free tier with no card.

## Setup

To access the CrustAPI tool, you'll need to create a CrustAPI account, get an API key, and install the `langchain-crustapi` integration package.

### Credentials

Head to [crustapi.com](https://crustapi.com) to sign up and generate an API key (3,000 credits per month, no card). Once you've done this, set the `CRUSTAPI_API_KEY` environment variable:

```python Set API key icon="key"
import getpass
import os

if "CRUSTAPI_API_KEY" not in os.environ:
    os.environ["CRUSTAPI_API_KEY"] = getpass.getpass("Enter your CrustAPI API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The CrustAPI tool lives in the `langchain-crustapi` package:

<CodeGroup>
    ```python pip
    pip install -U langchain-crustapi
    ```
    ```python uv
    uv add langchain-crustapi
    ```
</CodeGroup>

## Instantiation

Now we can instantiate an instance of the CrustAPI tool. Choose the Google surface with `search_type` (defaults to `web`):

```python Initialize tool instance icon="robot"
from langchain_crustapi import CrustAPISearch

tool = CrustAPISearch(
    search_type="web",  # web | news | maps | places | shopping | images | videos | scholar | patents
    max_results=5,
)
```

## Invocation

### Directly

The tool takes a single `query` string. It returns the parsed JSON for the chosen surface (for example, an `organic` list for web search, or a `places` list for maps).

```python Call tool icon="rocket"
tool.invoke({"query": "best crm software"})
```

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "coffee roasters brooklyn"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### Within an agent

We can use our tool in an agent. For this we will need a model with tool-calling capabilities.

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent

tools = [tool]
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=tools,
)

# Run the agent
agent.invoke(
    {"messages": [{"role": "user", "content": "What are the top-rated dentists in Miami?"}]}
)
```

## Local business and reviews

Because CrustAPI covers Maps and Reviews, the same tool doubles as a local-data source for lead generation and reputation monitoring:

```python Local search icon="map"
from langchain_crustapi import CrustAPISearch

maps = CrustAPISearch(search_type="maps", location="Austin, TX", max_results=10)
maps.invoke({"query": "dentists"})
```

## Public LinkedIn data

The same package ships `CrustAPILinkedIn` for public (logged-out) LinkedIn data. Choose the surface with `linkedin_type`: `profile` (default), `company`, `posts`, `jobs`, or `search` (people search). Pass a LinkedIn `url` for profile, company, and posts, or `keywords` for jobs and people search:

```python LinkedIn profile icon="user"
from langchain_crustapi import CrustAPILinkedIn

profile = CrustAPILinkedIn()
profile.invoke({"url": "https://www.linkedin.com/in/williamhgates"})
```

```python People search icon="users"
people = CrustAPILinkedIn(linkedin_type="search", enrich=True)  # enrich=True returns each person's full profile
people.invoke({"keywords": "head of growth fintech"})
```
