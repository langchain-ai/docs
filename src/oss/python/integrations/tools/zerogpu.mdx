[ZeroGPU](https://zerogpu.ai) is an ultra-fast, compute-efficient inference provider for apps and agents. ZeroGPU runs purpose-built small and nano language models across an edge-powered network for the high-volume, purpose-specific tasks your app or agent runs constantly. Plug in the OpenAI-compatible API and you are live: zero GPU infrastructure, serverless, auto-scaling by default.

The [`langchain-zerogpu`](https://pypi.org/project/langchain-zerogpu/) package exposes eleven [tools](/oss/langchain/tools) covering chat, summarization, classification, entity and JSON extraction, and PII redaction, so agents can offload repeatable work to fast, cheap models instead of spending frontier-model tokens.

This guide provides a quick overview for getting started with the ZeroGPU tools. For the full list of models and parameters, head to the [ZeroGPU documentation](https://docs.zerogpu.ai).

### Tool features

| [Returns artifact](/oss/langchain/tools) | Native async | Return data | Pricing |
| :---: | :---: | :---: | :---: |
| ❌ | ✅ | Text or parsed JSON, depending on the tool | Usage-based; see the [ZeroGPU dashboard](https://platform.zerogpu.ai/dashboard) |

Every tool routes a single text-in, structured-out task to a purpose-built ZeroGPU model:

| Tool class | ZeroGPU model | Purpose |
|------------|---------------|---------|
| `ZeroGPUChatTool` | `LFM2.5-1.2B-Instruct` | Short single-turn chat reply |
| `ZeroGPUChatThinkingTool` | `LFM2.5-1.2B-Thinking` | Chat with a visible reasoning trace |
| `ZeroGPUSummarizeTool` | `llama-3.1-8b-instruct-fast` | Condense a passage |
| `ZeroGPUClassifyIABTool` | `zlm-v1-iab-classify-edge` | IAB taxonomy classification |
| `ZeroGPUClassifyIABEnrichedTool` | `zlm-v1-iab-classify-edge-enriched` | IAB plus topics, keywords, and intent |
| `ZeroGPUClassifyZeroShotTool` | `deberta-v3-small` | Zero-shot classification against custom labels |
| `ZeroGPUClassifyStructuredTool` | `gliner2-base-v1` | Multi-axis schema classification |
| `ZeroGPUExtractEntitiesTool` | `gliner2-base-v1` | Custom-label named-entity recognition |
| `ZeroGPUExtractPIITool` | `gliner-multi-pii-v1` | Extract PII entities as JSON |
| `ZeroGPURedactPIITool` | `gliner-multi-pii-v1` | Mask PII inline with `[LABEL]` placeholders |
| `ZeroGPUExtractJSONTool` | `gliner2-base-v1` | Schema-driven JSON extraction |

## Setup

The integration lives in the `langchain-zerogpu` package:

<CodeGroup>
```bash pip
pip install -U langchain-zerogpu
```

```bash uv
uv add langchain-zerogpu
```
</CodeGroup>

<Note>
    The examples on this page require `langchain-zerogpu>=0.2.3`.
</Note>

### Credentials

Every request needs a ZeroGPU API key (starts with `zgpu-api-`) and a project ID. Create both in the [ZeroGPU dashboard](https://platform.zerogpu.ai/dashboard):

```python
import getpass
import os

if not os.environ.get("ZEROGPU_API_KEY"):
    os.environ["ZEROGPU_API_KEY"] = getpass.getpass("ZeroGPU API key:\n")
if not os.environ.get("ZEROGPU_PROJECT_ID"):
    os.environ["ZEROGPU_PROJECT_ID"] = getpass.getpass("ZeroGPU project ID:\n")
```

The API key is stored as a `pydantic.SecretStr` and is never logged.

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/observability) API key:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

Each tool reads `ZEROGPU_API_KEY` and `ZEROGPU_PROJECT_ID` from the environment when constructed with no arguments:

```python
from langchain_zerogpu import ZeroGPUSummarizeTool

tool = ZeroGPUSummarizeTool()
```

You can also pass credentials explicitly, plus an optional base URL override:

```python
tool = ZeroGPUSummarizeTool(
    api_key="zgpu-api-...",
    project_id="your-project-id",
    # base_url="https://...",  # optional API endpoint override
)
```

Authentication failures raise `ZeroGPUAuthError`; rate limits, server errors, and network failures raise `ZeroGPUError`.

## Invocation

### Invoke directly with args

Every tool takes a `text` argument. The schema-driven tools take additional arguments, listed per tool in the sections below:

```python
tool.invoke({"text": "LangChain is a framework for developing applications powered by large language models. It provides abstractions for chat models, tools, retrievers, and agents."})
```

```text
LangChain is a framework for building applications that utilize large language models, offering abstractions for various components such as chat models, tools, retrievers, and agents.
```

All tools support native async invocation:

```python
await tool.ainvoke({"text": "..."})
```

### Invoke with ToolCall

You can also invoke a tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"text": "LangChain is a framework for building LLM applications."},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool_msg = tool.invoke(model_generated_tool_call)
print(tool_msg.content)
```

```text
LangChain is a framework designed for developing and constructing applications that utilize large language models (LLMs).
```

## Chat tools

`ZeroGPUChatTool` generates a short single-turn reply with a fast nano model. `ZeroGPUChatThinkingTool` does the same but returns a visible reasoning trace followed by the answer.

Both accept:

- `text` (required, str): The user message to respond to.
- `system` (optional, str): A system prompt that steers the reply.

```python
from langchain_zerogpu import ZeroGPUChatTool

chat = ZeroGPUChatTool()
print(chat.invoke({
    "text": "Suggest a name for a coffee shop run by robots.",
    "system": "Reply in one short sentence.",
}))
```

```text
How about "RoboBrew Café"?
```

`ZeroGPUChatThinkingTool` works the same way but returns a visible reasoning trace before the answer:

```python
from langchain_zerogpu import ZeroGPUChatThinkingTool

thinking = ZeroGPUChatThinkingTool()
print(thinking.invoke({"text": "What is the capital of Japan"}))
```

## Summarization tool

`ZeroGPUSummarizeTool` condenses a passage into a short summary. Best for passages up to a few paragraphs.

It accepts:

- `text` (required, str): The input text to summarize.

```python
from langchain_zerogpu import ZeroGPUSummarizeTool

summarize = ZeroGPUSummarizeTool()
print(summarize.invoke({
    "text": (
        "LangChain is an open-source framework for developing applications "
        "powered by large language models. It provides a standard interface "
        "for chat models, embedding models, and vector stores, along with "
        "composable building blocks for retrieval, tool calling, and memory. "
        "By abstracting away provider-specific APIs, LangChain lets developers "
        "swap between hundreds of model providers and integrations without "
        "rewriting application logic. The framework is organized into modular "
        "packages: langchain-core defines the base abstractions and the "
        "LangChain Expression Language, which uses a declarative, pipe-based "
        "syntax to chain components together. Provider integrations live in "
        "standalone partner packages, while the main langchain package bundles "
        "higher-level constructs such as agents and retrieval chains. Companion "
        "libraries extend the ecosystem: LangGraph adds stateful, multi-actor "
        "orchestration for long-running agents, and LangSmith provides tracing, "
        "evaluation, and observability for production deployments. LangChain is "
        "widely used to build chatbots, retrieval-augmented generation "
        "pipelines, summarization services, and autonomous agents that plan and "
        "execute multi-step tasks."
    )
}))
```

The model condenses the multi-paragraph passage into a single sentence (output varies between runs):

```text
LangChain is an open-source framework that enables developers to build applications powered by large language models, providing a standard interface for various models and integrations, and abstracting away provider-specific APIs to allow for seamless swapping between hundreds of models without rewriting application logic.
```

## Classification tools

Four tools cover classification, from fixed taxonomies to caller-defined schemas:

- `ZeroGPUClassifyIABTool` classifies text into the IAB content taxonomy. Accepts `text` only.
- `ZeroGPUClassifyIABEnrichedTool` returns IAB categories together with topics, keywords, and intent signals. Accepts `text` only.
- `ZeroGPUClassifyZeroShotTool` scores text against a custom flat list of labels. Accepts `text` and `labels` (required, list of str).
- `ZeroGPUClassifyStructuredTool` classifies text along multiple labelled axes at once. Accepts `text`, `schema` (required, dict mapping each axis to its candidate labels), and `threshold` (optional, float 0-1).

```python
from langchain_zerogpu import (
    ZeroGPUClassifyIABTool,
    ZeroGPUClassifyStructuredTool,
    ZeroGPUClassifyZeroShotTool,
)

iab = ZeroGPUClassifyIABTool()
print(iab.invoke({"text": "The new GPU smashes every benchmark we threw at it."}))

zero_shot = ZeroGPUClassifyZeroShotTool()
print(zero_shot.invoke({
    "text": "The new GPU smashes every benchmark we threw at it.",
    "labels": ["tech", "politics", "sports"],
}))

structured = ZeroGPUClassifyStructuredTool()
print(structured.invoke({
    "text": "I was double-charged this month and support never replied.",
    "schema": {
        "sentiment": ["positive", "negative"],
        "topic": ["billing", "support", "shipping"],
    },
}))
```

Each classifier returns a parsed structure. The zero-shot tool returns per-label scores, and the structured tool returns one label per axis:

```text
{'audience': [{'name': 'Video Gaming', 'score': 0.827}, {'name': 'Educational Video Games', 'score': 0.632}, {'name': 'Consumer Electronics', 'score': 0.625}], 'content': {'iab_1_0': [{'name': 'Graphics Software', 'score': 0.690}, {'name': 'Video & Computer Games', 'score': 0.671}], 'iab_2_2': [{'name': 'Graphics Software', 'score': 0.690}, {'name': 'Video Gaming', 'score': 0.671}, {'name': 'Sports Video Games', 'score': 0.612}]}}
{'tech': 0.988, 'sports': 0.010, 'politics': 0.002}
{'classification': {'sentiment': 'negative', 'topic': 'support'}}
```

## Extraction and redaction tools

Four tools cover entity extraction, PII handling, and structured JSON extraction:

- `ZeroGPUExtractEntitiesTool` extracts named entities of custom types. Accepts `text`, `labels` (required, list of entity types), and `threshold` (optional, float 0-1).
- `ZeroGPUExtractPIITool` detects and extracts PII grouped by category. Accepts `text`, `categories` (optional, list of str to restrict the scan), and `threshold` (optional, float 0-1).
- `ZeroGPURedactPIITool` masks PII inline, replacing each match with a labelled placeholder such as `[PHONE]`. Accepts `text`, `categories` (optional), and `threshold` (optional).
- `ZeroGPUExtractJSONTool` extracts structured fields into JSON. Accepts `text`, `schema` (required, dict mapping a group name to a list of `"field::type::description"` specs), and `threshold` (optional).

```python
from langchain_zerogpu import (
    ZeroGPUExtractEntitiesTool,
    ZeroGPUExtractJSONTool,
    ZeroGPURedactPIITool,
)

entities = ZeroGPUExtractEntitiesTool()
print(entities.invoke({
    "text": "Sundar Pichai announced that Google will open a Tokyo office in March.",
    "labels": ["person", "company", "city", "date"],
}))

redact = ZeroGPURedactPIITool()
print(redact.invoke({"text": "Call Jane Smith at 555-0100 or email jane@example.com."}))

extract_json = ZeroGPUExtractJSONTool()
print(extract_json.invoke({
    "text": "Hi, I'm Maria Lopez, reachable at maria@acme.io, ordering 3 lattes.",
    "schema": {
        "order": [
            "customer::str::Full name of the customer",
            "email::str::Email address",
            "quantity::int::Number of items ordered",
        ]
    },
}))
```

The entity tool returns labelled spans, the redaction tool returns the masked text alongside the detected entities, and the JSON tool returns data shaped by the schema:

```text
{'entities': {'person': ['Sundar Pichai'], 'company': ['Google'], 'city': ['Tokyo'], 'date': ['March']}}
{"redacted_text": "Call [PERSON] at [PHONE_NUMBER] or email [EMAIL].", "entities": [{"text": "Jane Smith", "label": "person", "start": 5, "end": 15, "score": 0.9994}, {"text": "555-0100", "label": "phone number", "start": 19, "end": 27, "score": 0.9564}, {"text": "jane@example.com", "label": "email", "start": 37, "end": 53, "score": 0.9793}], "entities_by_label": {"person": ["Jane Smith"], "phone number": ["555-0100"], "email": ["jane@example.com"]}}
{'data': {'order': [{'customer': 'Maria Lopez', 'email': 'maria@acme.io', 'quantity': ['3']}]}}
```

## Use within an agent

`ZeroGPUToolkit` bundles all eleven tools behind one shared client, so you can bind them to an agent in one step:

```python
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent
from langchain_zerogpu import ZeroGPUToolkit

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=ZeroGPUToolkit().get_tools(),
)

agent.invoke(
    {"messages": [{"role": "user", "content": "Redact the PII in: 'Call Jane at 555-0100.'"}]}
)
```

The agent picks the right ZeroGPU tool per request, for example `zerogpu_redact_pii` for the prompt above, and the small-model call runs on ZeroGPU instead of the frontier model.
