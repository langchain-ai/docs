[Skim](https://skim402.com) is the x402-native clean reader API for AI agents. Give it a URL and it returns agent-ready Markdown—the article body with nav, ads, and boilerplate stripped—plus structured metadata (title, byline, published date, language, excerpt).

Skim has no accounts and no API keys. Each read costs $0.002 in USDC on [Base](https://base.org), paid automatically over the [x402](https://x402.org) protocol from a wallet you control. The wallet's private key never leaves your machine—it only signs payment authorizations locally.

This guide provides a quick overview for getting started with the Skim [tool](/oss/langchain/tools).

## Setup

Skim needs no account or API key. Reads are paid per call ($0.002 in USDC on Base) over the x402 protocol, so you need a Base wallet funded with a little USDC. A dollar covers roughly 500 reads.

<Note>
Use a dedicated wallet, not your personal one. Its private key signs payment authorizations locally—treat it like a hot wallet for paying small tolls, not a savings account. Step-by-step wallet setup (for non-crypto-native developers): [skim402.com/wallet](https://skim402.com/wallet).
</Note>

### Credentials

Instead of an API key, Skim reads the paying wallet's private key from the `SKIM_WALLET_PRIVATE_KEY` environment variable:

```python Set wallet key icon="key"
import getpass
import os

if "SKIM_WALLET_PRIVATE_KEY" not in os.environ:
    os.environ["SKIM_WALLET_PRIVATE_KEY"] = getpass.getpass("Enter your Base wallet private key: ")
```

It's also helpful (but not needed) to set up [LangSmith](/langsmith/observability) for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

Now we can instantiate an instance of the Skim tool:

```python Initialize tool instance icon="robot"
from langchain_skim import SkimReader

tool = SkimReader()  # reads SKIM_WALLET_PRIVATE_KEY from the environment
```

You can also pass the key directly and tune the per-call price cap:

```python Configure the tool
tool = SkimReader(
    private_key="0x...",    # or rely on the env var
    max_price_usd=0.005,    # refuse to sign for anything above this
    include_metadata=True,  # prepend a YAML frontmatter block of page metadata
)
```

## Invocation

### Directly

```python Call tool icon="rocket"
tool.invoke({"url": "https://en.wikipedia.org/wiki/HTTP_402"})
```

The tool signs an EIP-3009 USDC authorization for $0.002, Skim returns the cleaned article, and you get back Markdown (by default with a YAML frontmatter block of metadata).

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"url": "https://en.wikipedia.org/wiki/HTTP_402"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### Within an agent

We can use our tool in an agent. For this we will need a model with tool-calling capabilities.

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent

tools = [tool]
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=tools,
)

# Run the agent
agent.invoke(
    {"messages": [{"role": "user", "content": "Read https://en.wikipedia.org/wiki/HTTP_402 and summarize it."}]}
)
```

The agent decides when to call `skim_read`, the wallet pays per read, and the model receives clean Markdown instead of raw HTML.

## How payment works

Skim uses the x402 protocol. The first request returns `402 Payment Required` with a payment challenge; the x402 client signs an EIP-3009 USDC transfer authorization locally and retries with an `X-PAYMENT` header. Skim verifies and settles the payment on Base, then returns the content. The `max_price_usd` cap (default `$0.01`) bounds what the wallet will sign for, so a misconfigured price can never drain the wallet.
