[DexPaprika](https://dexpaprika.com) is a keyless DEX market-data API from CoinPaprika, covering on-chain DEX activity across every major blockchain (33M+ tokens, 36M+ pools). The `langchain-dexpaprika` package wraps it as LangChain tools for token search, market data, pool discovery, and OHLCV price history. No API key or signup is required.

This guide covers getting started with the DexPaprika [tools](/oss/langchain/tools). For a detailed listing of all endpoints, parameters, and responses, head to the [DexPaprika API reference](https://docs.dexpaprika.com/api-reference/introduction).

### Available tools

| Tool | Description |
| :--- | :--- |
| `DexPaprikaSearch` (`dexpaprika_search`) | Search tokens, pools, and DEXes by name, symbol, or address |
| `DexPaprikaTokenDetails` (`dexpaprika_token_details`) | Price, FDV, liquidity, and volume for one token on one network |
| `DexPaprikaTokenPools` (`dexpaprika_token_pools`) | The liquidity pools where a token trades, sortable |
| `DexPaprikaPoolOHLCV` (`dexpaprika_pool_ohlcv`) | Historical OHLCV price candles for one pool |
| `DexPaprikaNetworks` (`dexpaprika_networks`) | Every supported network with activity stats |

### Features

- Keyless: no API key, no signup, and no environment variable to set
- DEX market data across every network DexPaprika covers (33M+ tokens, 36M+ pools)
- Sync and async (`invoke` and `ainvoke`) on every tool
- Compact JSON output shaped for LLM context, with recoverable tool errors

## Setup

The DexPaprika tools live in the `langchain-dexpaprika` package:

<CodeGroup>
    ```python pip
    pip install -U langchain-dexpaprika
    ```
    ```python uv
    uv add langchain-dexpaprika
    ```
</CodeGroup>

### Credentials

No credentials are required. The DexPaprika API is public and keyless, so there is no API key to set and no account to create.

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
import getpass
import os

os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

Instantiate a single tool, or use the toolkit to get all five over one shared HTTP client:

```python Initialize tools icon="robot"
from langchain_dexpaprika import DexPaprikaSearch, DexPaprikaToolkit

# a single tool
search = DexPaprikaSearch()

# or all five tools at once
toolkit = DexPaprikaToolkit()
tools = toolkit.get_tools()
```

## Invocation

### Directly

`dexpaprika_search` resolves a name or ticker into the contract address and network id the other tools need. In each token result, the `id` field is the contract address (pass it as `token_address`) and `chain` is the network id (pass it as `network`):

```python Call tool icon="rocket"
search = DexPaprikaSearch()

search.invoke({"query": "WETH"})
```

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "WETH"},
    "id": "1",
    "name": search.name,
    "type": "tool_call",
}
search.invoke(model_generated_tool_call)
```

### Within an agent

We can use the tools in an agent. For this we will need a model with tool-calling capabilities:

```python Agent with tools icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent
from langchain_dexpaprika import DexPaprikaToolkit

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=DexPaprikaToolkit().get_tools(),
)

agent.invoke(
    {
        "messages": [
            {
                "role": "user",
                "content": "Find the most liquid WETH pool on ethereum and show its last 7 daily candles.",
            }
        ]
    }
)
```

## Price history with OHLCV

Once you have a pool address (from `dexpaprika_token_pools`), fetch candles for any window and interval. Set `inversed=True` to quote the pair from the other token's perspective:

```python OHLCV candles icon="chart-line"
from langchain_dexpaprika import DexPaprikaPoolOHLCV

ohlcv = DexPaprikaPoolOHLCV()

ohlcv.invoke(
    {
        "network": "ethereum",
        "pool_address": "0x88e6a0c2ddd26feeb64f039a2c41296fcb3f5640",
        "start": "2026-07-10",
        "interval": "1h",
        "limit": 24,
    }
)
```
