The [You.com API](https://docs.you.com) is a suite of endpoints that ground LLMs in recent, accurate, relevant information. The `langchain-youdotcom` package exposes four tools: `YouSearchTool` for web search, `YouContentsTool` for content extraction, `YouResearchTool` for cited research, and `YouFinanceResearchTool` for finance research.

## Setup

Install the `langchain-youdotcom` package:

```python
pip install -qU langchain-youdotcom
```

### Credentials

[Get a You.com API key](https://you.com/platform/api-keys) and set it as an environment variable:

```python
import getpass
import os

if not os.environ.get("YDC_API_KEY"):
    os.environ["YDC_API_KEY"] = getpass.getpass("You.com API key:\n")
```

Tools read `YDC_API_KEY` from the environment. To pass a key explicitly, set it on the `YouAPIWrapper` that backs each tool:

```python
from langchain_youdotcom import YouAPIWrapper, YouSearchTool

tool = YouSearchTool(api_wrapper=YouAPIWrapper(ydc_api_key="your-api-key"))
```

## YouSearchTool

Search the web with up-to-date results. Configure the tool through a `YouAPIWrapper`:

- `count` (`int`): Max results per section, 1-100.
- `country` (`str`): Two-letter country code to focus results geographically.
- `freshness` (`str`): Filter by recency: `day`, `week`, `month`, or `year`.
- `language` (`str`): BCP-47 language code for results.
- `livecrawl` (`str`): Fetch full page content: `web`, `news`, or `all`.
- `livecrawl_formats` (`str`): Format for live-crawled content: `html` or `markdown`.
- `offset` (`int`): Pagination offset, 0-9.
- `safesearch` (`str`): Content filter: `off`, `moderate`, or `strict`.
- `k` (`int`): Max documents to return.

The tool accepts a `query` string at invocation:

```python
from langchain_youdotcom import YouAPIWrapper, YouSearchTool

tool = YouSearchTool(
    api_wrapper=YouAPIWrapper(
        count=5,
        country="US",
        freshness="week",
        livecrawl="web",
        livecrawl_formats="markdown",
    ),
)

result = tool.invoke("latest AI news")
print(result)
```

## YouContentsTool

Extract clean, structured content from one or more web pages as markdown or HTML, plus metadata such as JSON-LD, OpenGraph, and Twitter Cards. All parameters are passed at invocation:

- `urls` (required, `list[str]`): URLs to extract content from.
- `formats` (`list[str]`): Output formats: `markdown`, `html`, and/or `metadata`. Defaults to `["markdown", "metadata"]`.
- `crawl_timeout` (`float`): Per-URL crawl timeout in seconds.

```python
from langchain_youdotcom import YouContentsTool

tool = YouContentsTool()
result = tool.invoke({"urls": ["https://example.com"]})
print(result)
```

## YouResearchTool

Synthesize a comprehensive, cited markdown answer to a complex question. Configure `research_effort` on the `YouAPIWrapper` to control depth and speed: `lite`, `standard` (default), `deep`, or `exhaustive`.

```python
from langchain_youdotcom import YouAPIWrapper, YouResearchTool

# Default effort
tool = YouResearchTool()
result = tool.invoke("what are the latest advances in quantum computing")
print(result)

# Deep research
tool = YouResearchTool(
    api_wrapper=YouAPIWrapper(research_effort="deep"),
)
result = tool.invoke("compare transformer architectures for long-context tasks")
print(result)
```

## YouFinanceResearchTool

Synthesize a citation-backed answer over a finance-optimized index covering SEC filings, earnings reports, equity prices, macro indicators, and financial news. Finance research accepts `research_effort` values `deep` (default) and `exhaustive`; other values raise `ValueError`.

```python
from langchain_youdotcom import YouAPIWrapper, YouFinanceResearchTool

tool = YouFinanceResearchTool()
result = tool.invoke("what were NVIDIA's key revenue drivers in FY2025")
print(result)

# Exhaustive research for complex due diligence
tool = YouFinanceResearchTool(
    api_wrapper=YouAPIWrapper(research_effort="exhaustive"),
)
result = tool.invoke(
    "compare gross margins of Apple, Microsoft, and Google over the past three fiscal years"
)
print(result)
```

## Use within an agent

Pass any of the tools to an agent. The model decides when to call them:

```python
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain_youdotcom import YouContentsTool, YouSearchTool

model = init_chat_model("claude-sonnet-4-6", model_provider="anthropic")

agent = create_agent(model, [YouSearchTool(), YouContentsTool()])

for step in agent.stream(
    {"messages": "What are the latest developments in AI? Cite your sources."},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```
