[Octen](https://octen.ai) is a web search engine built for AI agents, delivering real-time, accurate search results with sub-100ms latency. It supports domain filtering, time-range filtering, semantic search, and highlighted snippets.

## Setup

The integration lives in the `langchain-octen` package.

<CodeGroup>
```bash pip
pip install -qU langchain-octen
```
```bash uv
uv add langchain-octen
```
</CodeGroup>

### Credentials

Sign up at [octen.ai](https://octen.ai) to get an API key.

```python Set API key icon="key"
import getpass
import os

if "OCTEN_API_KEY" not in os.environ:
    os.environ["OCTEN_API_KEY"] = getpass.getpass("Enter your Octen API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/home) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

```python Initialize tool instance icon="robot"
from langchain_octen import OctenSearchResults

tool = OctenSearchResults(
    max_results=5,
    # search_type="auto",       # auto, keyword, or semantic
    # include_domains=None,      # restrict to specific domains
    # exclude_domains=None,      # exclude specific domains
    # safesearch="strict",       # off or strict
    # format="text",             # text or markdown
)
```

### Key parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `octen_api_key` | `SecretStr` | `$OCTEN_API_KEY` | Octen API key |
| `max_results` | `int` | `5` | Number of results (1-100) |
| `search_type` | `str` | `None` | `auto`, `keyword`, or `semantic` |
| `include_domains` | `list[str]` | `None` | Restrict to these domains |
| `exclude_domains` | `list[str]` | `None` | Exclude these domains |
| `time_basis` | `str` | `None` | `auto`, `published`, or `crawled` |
| `start_time` | `str` | `None` | Start time (ISO 8601) |
| `end_time` | `str` | `None` | End time (ISO 8601) |
| `format` | `str` | `None` | `text` or `markdown` |
| `safesearch` | `str` | `None` | `off` or `strict` |
| `highlight_enabled` | `bool` | `None` | Return highlighted snippets |
| `full_content_enabled` | `bool` | `None` | Return full page content |
| `timeout` | `float` | `None` | Request timeout in seconds |

## Invocation

### Invoke directly with args

The tool accepts the following arguments during invocation:

- `query` (required): A natural language search query
- `include_domains` (optional): List of domains to restrict results to
- `exclude_domains` (optional): List of domains to exclude from results

```python Call tool icon="rocket"
tool.invoke({"query": "What is LangChain?"})
```

```python Domain filtering icon="filter"
tool.invoke({
    "query": "machine learning research papers",
    "include_domains": ["arxiv.org"],
})
```

### Invoke with ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "latest AI news"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

## Use within an agent

We can use the Octen search tool directly with an agent. This gives the agent the ability to dynamically set the `include_domains` and `exclude_domains` arguments.

```python
pip install -qU langgraph
```

```python Agent with tool icon="robot"
from langchain.chat_models import init_chat_model
from langchain.agents import create_agent
from langchain_octen import OctenSearchResults

model = init_chat_model(model="claude-sonnet-4-6", model_provider="anthropic")

tool = OctenSearchResults(max_results=5)
agent = create_agent(model, [tool])

for step in agent.stream(
    {"messages": "What are the latest developments in quantum computing?"},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```
