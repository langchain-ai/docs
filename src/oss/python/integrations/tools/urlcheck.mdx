## Setup

The integration lives in the `langchain-urlcheck` package.

```python
pip install -qU langchain-urlcheck
```

### Credentials

URLCheck offers a free tier with up to 100 requests per day without an API key. For higher volumes, obtain an API key from [urlcheck.dev](https://urlcheck.dev).

```python
import getpass
import os

if not os.environ.get("URLCHECK_API_KEY"):
    os.environ["URLCHECK_API_KEY"] = getpass.getpass("URLCheck API key:\n")
```

It's also helpful (but not needed) to set up [LangSmith](https://smith.langchain.com/) for tracing:

```python
os.environ["LANGSMITH_TRACING"] = "true"
# os.environ["LANGSMITH_API_KEY"] = getpass.getpass()
```

## Instantiation

Here we show how to instantiate an instance of the URLCheck tool, with the available configuration parameters:

- `api_key` (optional, str): URLCheck API key. Not required for free tier. Default is `""`.
- `mcp_url` (optional, str): MCP server endpoint. Default is `"https://urlcheck.ai/mcp"`.
- `default_timeout_seconds` (optional, int): End-to-end scan timeout. Default is 120.
- `execution_mode` (optional, str): `"task"` (async with wait/poll) or `"direct"` (single blocking call). Default is `"task"`.
- `max_retries` (optional, int): Retry attempts for transient errors. Default is 2.

```python
from langchain_urlcheck import SafeUrlScanTool

# Free tier (no API key required)
tool = SafeUrlScanTool()

# Or with an API key for higher volumes
# tool = SafeUrlScanTool(api_key=os.environ["URLCHECK_API_KEY"])
```

## Invocation

### [Invoke directly with args](/oss/langchain/tools)

The URLCheck tool accepts the following arguments during invocation:

- `url` (required): The URL to scan for malicious content.
- `intent` (optional): User intent context (e.g., "login", "purchase") for targeted risk analysis. Max 248 characters.
- `timeout_seconds` (optional): Scan timeout override (30-720 seconds). Default is 120.

```python
tool.invoke({"url": "https://example.com"})
```

```json
{"risk_score": 0.15, "confidence": 0.92, "analysis_complete": true, "agent_access_directive": "ALLOW", "agent_access_reason": "clean"}
```

With intent context for more targeted risk analysis:

```python
tool.invoke({"url": "https://example.com/checkout", "intent": "purchase"})
```

### [Invoke with ToolCall](/oss/langchain/tools)

We can also invoke the tool with a model-generated ToolCall, in which case a ToolMessage will be returned:

```python
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"url": "https://example.com"},
    "id": "1",
    "name": "safe_url_scan",
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

## Use within an agent

We can use our tool with an agent. This gives the agent the ability to verify URL safety before recommending a user navigate to it.

```python
# !pip install -qU langchain-openai langgraph
```

```python
from langchain_openai import ChatOpenAI
from langgraph.prebuilt import create_react_agent

from langchain_urlcheck import SafeUrlScanTool

# Requires OPENAI_API_KEY environment variable to be set
model = ChatOpenAI(model="gpt-4o-mini", temperature=0)
tool = SafeUrlScanTool()

agent = create_react_agent(model, [tool])

user_input = "Is https://example.com safe to visit?"

for step in agent.stream(
    {"messages": [("human", user_input)]},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```

## Async usage

URLCheck natively supports async execution:

```python
import asyncio
from langchain_urlcheck import SafeUrlScanTool

tool = SafeUrlScanTool()

async def main():
    result = await tool.ainvoke({"url": "https://example.com"})
    print(result)

asyncio.run(main())
```

## Output format

Successful scans return a JSON string with these fields:

- `risk_score` (float): Risk level from 0.0 (safe) to 1.0 (dangerous).
- `confidence` (float): Confidence in the risk score (0.0-1.0).
- `analysis_complete` (bool): Whether the full analysis completed.
- `agent_access_directive` (str): One of `ALLOW`, `DENY`, `RETRY_LATER`, or `REQUIRE_CREDENTIALS`.
- `agent_access_reason` (str): Reason for the access directive.

Failed scans return:

```json
{"error": "Rate limit exceeded", "numeric_code": -32029, "retryable": true}
```

## MCP adapter compatibility

If you already use `langchain-mcp-adapters`, URLCheck provides a configuration helper:

```python
pip install -qU "langchain-urlcheck[mcp-adapters]"
```

```python
import asyncio

from langchain_mcp_adapters.client import MultiServerMCPClient
from langchain_urlcheck import get_mcp_server_config


async def main():
    client = MultiServerMCPClient({
        "urlcheck": get_mcp_server_config(api_key="your-api-key"),
    })
    tools = await client.get_tools()
    print(tools)

asyncio.run(main())
```

<Note>
The MCP adapter path uses direct MCP execution. For task-augmented execution with automatic wait/poll fallback, use `SafeUrlScanTool` directly.
</Note>
