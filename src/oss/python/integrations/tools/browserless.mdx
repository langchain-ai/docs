[Browserless](https://browserless.io) is a hosted browser automation MCP server. It exposes 10 tools—search, smart scraper, map, crawl, export, performance, function, download, and a multi-turn browser agent—over a single streamable-HTTP MCP endpoint, auto-imported via [`langchain-mcp-adapters`](https://github.com/langchain-ai/langchain-mcp-adapters) with no partner package required. Browser sessions are pinned by `Mcp-Session-Id`, so multi-turn ReAct loops preserve browser state across calls.

## Setup

The integration uses the generic [`langchain-mcp-adapters`](https://github.com/langchain-ai/langchain-mcp-adapters) package—no Browserless-specific package needed.

```bash
pip install -qU langchain-mcp-adapters langchain langgraph
```

### Credentials

Get a Browserless API token at [account.browserless.io](https://account.browserless.io) and export it as `BROWSERLESS_TOKEN`.

```python
import getpass
import os

if not os.environ.get("BROWSERLESS_TOKEN"):
    os.environ["BROWSERLESS_TOKEN"] = getpass.getpass("BROWSERLESS_TOKEN:\n")
```

## Instantiation

Connect to the hosted MCP server and load all 10 tools as LangChain `BaseTool` instances:

```python
from langchain_mcp_adapters.client import MultiServerMCPClient

client = MultiServerMCPClient(
    {
        "browserless": {
            "transport": "http",
            "url": "https://mcp.browserless.io/mcp",
            "headers": {"Authorization": f"Bearer {os.environ['BROWSERLESS_TOKEN']}"},
        }
    }
)

tools = await client.get_tools()
print([t.name for t in tools])
```

```text
['browserless_smartscraper', 'browserless_function', 'browserless_download', 'browserless_export', 'browserless_skill', 'browserless_agent', 'browserless_search', 'browserless_map', 'browserless_crawl', 'browserless_performance']
```

## Invocation

### Invoke a stateless tool directly

Eight of the tools are stateless single-shot calls (`browserless_smartscraper`, `browserless_search`, `browserless_map`, `browserless_crawl`, `browserless_export`, `browserless_performance`, `browserless_function`, `browserless_download`). You can call them without an LLM:

```python
smartscraper = next(t for t in tools if t.name == "browserless_smartscraper")
result = await smartscraper.ainvoke(
    {"url": "https://example.com", "formats": ["markdown"]}
)
print(result[0]["text"])
```

```text
Example Domain

Example Domain
==============

This domain is for use in documentation examples without needing permission. Avoid use in operations.

[Learn more](https://iana.org/domains/example)
```

### Multi-turn browser agent

The `browserless_agent` tool runs a multi-turn ReAct loop with browser state preserved across calls (navigate → snapshot → click → re-snapshot → extract).

<Note>
The Python `langchain-mcp-adapters` library opens a fresh MCP `ClientSession` for every `tool.ainvoke()` call by default. To share state across calls, wrap the multi-turn flow in a `client.session(...)` context manager and bind tools via `load_mcp_tools(session)`. Without this, each call gets a different `Mcp-Session-Id`, the load balancer routes to a different browser, and state is lost.
</Note>

```python
from langchain_mcp_adapters.tools import load_mcp_tools

async with client.session("browserless") as session:
    tools = await load_mcp_tools(session)
    agent_tool = next(t for t in tools if t.name == "browserless_agent")

    await agent_tool.ainvoke(
        {"method": "goto", "params": {"url": "https://example.com"}}
    )
    await agent_tool.ainvoke({"method": "snapshot"})
    result = await agent_tool.ainvoke(
        {"method": "text", "params": {"selector": "h1"}}
    )
    print(result[0]["text"])
```

```text
{
  "text": "Example Domain",
  "time": 4
}
```

## Use within an agent

Hand all 10 tools to a LangChain agent. The model decides when to use the multi-turn `browserless_agent` versus a stateless tool. The agent loop runs inside a `client.session(...)` block so every tool call shares one MCP session.

```python
if not os.environ.get("ANTHROPIC_API_KEY"):
    os.environ["ANTHROPIC_API_KEY"] = getpass.getpass("ANTHROPIC_API_KEY:\n")
```

```python
# | output: false
# | echo: false

from langchain.chat_models import init_chat_model

llm = init_chat_model(model="claude-sonnet-4-6", model_provider="anthropic")
```

```python
from langchain.agents import create_agent
from langchain_mcp_adapters.tools import load_mcp_tools

async with client.session("browserless") as session:
    tools = await load_mcp_tools(session)
    agent = create_agent(llm, tools)

    user_input = (
        "Use browserless_search to find recent articles on WebAssembly outside the "
        "browser, then use browserless_smartscraper to read the top result and "
        "summarize the takeaways in 5 bullet points."
    )

    async for step in agent.astream(
        {"messages": user_input}, stream_mode="values"
    ):
        step["messages"][-1].pretty_print()
```
