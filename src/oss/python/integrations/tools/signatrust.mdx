[Signatrust](https://signatrust.net) provides **AI Decision Receipts**—tamper-evident,
cryptographically signed records of decisions made by AI agents. Each receipt captures
the agent, the action taken, the decision, the model used, the policies and permissions
applied, and whether a human reviewed the action. Receipts are signed with Ed25519 on
the Signatrust service and can be independently verified afterwards, giving teams an
accountability and audit layer for regulated or high-stakes AI workflows.

The [`langchain-signatrust`](https://pypi.org/project/langchain-signatrust/) package
wraps the Signatrust REST API as LangChain tools, so an agent can generate, verify, and
retrieve Decision Receipts as part of its normal tool-calling flow.

### Tool features

- **Generate Decision Receipts**: Create a signed, tamper-evident record of an AI agent's action.
- **Verify receipts**: Confirm a receipt's cryptographic signature and integrity.
- **Retrieve receipts**: Fetch a previously generated receipt by its ID.
- **Privacy-first**: Only a SHA-256 hash of sensitive payloads is stored by default.
- **Self-hosting support**: Point the tools at a self-hosted Signatrust instance via `base_url`.

## Setup

The integration lives in the `langchain-signatrust` package.

```python pip
pip install -U langchain-signatrust
```

```python uv
uv add langchain-signatrust
```

### Credentials

You'll need a Signatrust API key. Sign up at [signatrust.net](https://signatrust.net) to
get your API key, then set it as an environment variable:

```python Set API key icon="key"
import getpass
import os

if not os.environ.get("SIGNATRUST_API_KEY"):
    os.environ["SIGNATRUST_API_KEY"] = getpass.getpass("Enter your Signatrust API key: ")
```

It's also helpful (but not needed) to set up [LangSmith](/langsmith/observability) for
best-in-class observability of your tool calls:

```python Enable tracing icon="flask"
# os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
# os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

Now we can instantiate the Signatrust tools. The API key is read from the
`SIGNATRUST_API_KEY` environment variable by default, or can be passed explicitly:

```python Initialize tools icon="robot"
from langchain_signatrust import (
    SignatrustGenerateReceiptTool,
    SignatrustVerifyReceiptTool,
    SignatrustGetReceiptTool,
)

generate_tool = SignatrustGenerateReceiptTool()  # reads SIGNATRUST_API_KEY
verify_tool = SignatrustVerifyReceiptTool()
get_tool = SignatrustGetReceiptTool()

# Or pass the key / a self-hosted endpoint explicitly:
# generate_tool = SignatrustGenerateReceiptTool(
#     api_key="sk_live_...",
#     base_url="https://signatrust.net/api/v1",
# )
```

## Invocation

### Directly

Generate a Decision Receipt by describing the agent, the action, and the decision:

```python Call tool icon="rocket"
receipt = generate_tool.invoke(
    {
        "agent_name": "loan-underwriting-agent",
        "action": "approve_loan_application",
        "decision": "approved",
        "model": "claude-sonnet-4-5",
        "policies": ["kyc_v3", "aml_screening"],
        "human_review": False,
    }
)
print(receipt)
```

Verify a receipt or retrieve it later by ID:

```python Verify and retrieve icon="shield-check"
receipt_id = receipt["id"]

verification = verify_tool.invoke({"receipt_id": receipt_id})
print(verification)  # -> includes signature validity

fetched = get_tool.invoke({"receipt_id": receipt_id})
print(fetched)
```

### Within an agent

We can use the tools in an agent that has tool-calling capabilities:

```python Agent with Signatrust tools icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent

from langchain_signatrust import (
    SignatrustGenerateReceiptTool,
    SignatrustVerifyReceiptTool,
)

tools = [SignatrustGenerateReceiptTool(), SignatrustVerifyReceiptTool()]

agent = create_agent(
    model="claude-sonnet-4-5",
    tools=tools,
)

agent.invoke(
    {
        "messages": [
            {
                "role": "user",
                "content": (
                    "You just approved refund #4821 for $250 under policy refund_v2. "
                    "Generate a signed Decision Receipt for this action."
                ),
            }
        ]
    }
)
```
