> [The Polaris Report](https://thepolarisreport.com) provides AI-verified news intelligence across 18 verticals including tech, markets, policy, science, crypto, and more. Every brief includes confidence scores, bias ratings, source attribution, counter-arguments, and entity enrichment. Polaris processes thousands of sources daily and publishes verified intelligence briefs that agents can search, retrieve, and fact-check programmatically.

- 9 specialized tools: search, feed, brief, extract, entities, trending, compare, research, verify

- Source attribution with counter-arguments

## Setup

To access Polaris tools, you'll need a free API key from [thepolarisreport.com](https://thepolarisreport.com) and the `langchain-polaris` package. A `demo` key is available for quick testing.

### Credentials

```python Set API key icon="key"
import getpass
import os

if "POLARIS_API_KEY" not in os.environ:
    os.environ["POLARIS_API_KEY"] = getpass.getpass("Enter your Polaris API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/home) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Invocation

### Search verified news

```python Search icon="rocket"
search = PolarisSearchTool(api_key="demo")
result = search.invoke({"query": "AI regulation Europe"})
print(result)
```

### Fact-check a claim

```python Verify icon="check"
verify = PolarisVerifyTool(api_key="demo")
result = verify.invoke({"claim": "The EU passed comprehensive AI regulation in 2024"})
print(result)
```

### Get trending entities

```python Trending icon="chart-line"
trending = PolarisTrendingTool(api_key="demo")
result = trending.invoke({"limit": 5})
print(result)
```

## Retriever

Polaris also provides a retriever for RAG pipelines that converts briefs into LangChain `Document` objects with rich metadata.

```python Retriever icon="database"
from langchain_polaris import PolarisRetriever

retriever = PolarisRetriever(
    api_key="demo",
    category="tech",
    min_confidence=0.6,
    limit=5,
)

docs = retriever.invoke("semiconductor supply chain")
for doc in docs:
    print(doc.metadata["brief_id"], doc.metadata["confidence"])
    print(doc.page_content[:200])
    print()
```

## Agent usage

Use Polaris tools with an agent for autonomous news research.

```python Agent with tools icon="robot"
from langchain_polaris import PolarisSearchTool, PolarisVerifyTool, PolarisCompareTool
from langchain_openai import ChatOpenAI
from langchain.agents import create_openai_tools_agent, AgentExecutor
from langchain_core.prompts import ChatPromptTemplate

tools = [
    PolarisSearchTool(api_key="your-key"),
    PolarisVerifyTool(api_key="your-key"),
    PolarisCompareTool(api_key="your-key"),
]

llm = ChatOpenAI(model="gpt-4o", temperature=0)

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a news research assistant with access to verified intelligence from The Polaris Report."),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}"),
])

agent = create_openai_tools_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

result = executor.invoke({"input": "What's happening with AI regulation this week? Verify any major claims."})
print(result["output"])
```
