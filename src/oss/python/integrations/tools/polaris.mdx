[Polaris](https://thepolarisreport.com) is a verified news intelligence API for AI agents. It provides confidence-scored, bias-analyzed news briefs across 18 verticals with counter-arguments and entity extraction.

## Overview

### Integration details

| Class | Package | Serializable | JS support | Version |
|:------|:--------|:---:|:---:|:---:|
| [PolarisSearchTool](https://github.com/JohnnyTarrr/polaris-sdks) | [langchain-polaris](https://pypi.org/project/langchain-polaris/) | ❌ | ❌ | ![PyPI - Version](https://img.shields.io/pypi/v/langchain-polaris?style=flat-square&label=%20) |

### Tool features

| [Returns artifact](/oss/langchain/tools) | Native async | Return data | Pricing |
|:---:|:---:|:---:|:---:|
| ❌ | ❌ | headline, summary, confidence, bias score, sources, entities, counter-arguments | Free demo key available |

## Setup

The integration lives in the `langchain-polaris` package.

```bash
pip install -qU langchain-polaris
```

### Credentials

Get an API key at [thepolarisreport.com/developers](https://thepolarisreport.com/developers), or use the free `demo` key to try it out.

```python
import getpass
import os

if not os.environ.get("POLARIS_API_KEY"):
    os.environ["POLARIS_API_KEY"] = getpass.getpass("Polaris API key:\n")
```

## Tools

`langchain-polaris` provides 7 tools:

| Tool | Description |
|------|-------------|
| `PolarisSearchTool` | Search verified news across 18 verticals with category filtering and speed tiers |
| `PolarisFeedTool` | Get latest briefs filtered by category or source domain |
| `PolarisEntityTool` | Look up entities (companies, people, technologies) in verified coverage |
| `PolarisBriefTool` | Get a specific brief by ID with full analysis, sources, and counter-arguments |
| `PolarisExtractTool` | Extract clean article content from URLs with metadata |
| `PolarisCompareTool` | Compare outlet coverage of the same story with framing and bias analysis |
| `PolarisResearchTool` | Deep research across intelligence briefs with sub-query expansion and synthesis |

## Instantiation

```python
from langchain_polaris import PolarisSearchTool, PolarisFeedTool, PolarisCompareTool

# Uses POLARIS_API_KEY env var automatically
search_tool = PolarisSearchTool()

# Or pass the key explicitly (use "demo" to try without signup)
search_tool = PolarisSearchTool(api_key="demo")
feed_tool = PolarisFeedTool(api_key="demo")
compare_tool = PolarisCompareTool(api_key="demo")
```

## Invocation

### [Invoke directly with args](/oss/langchain/tools)

```python
from langchain_polaris import PolarisSearchTool

tool = PolarisSearchTool(api_key="demo")
result = tool.invoke({"query": "AI regulation"})
print(result[:500])
```

### Search with category filter

```python
from langchain_polaris import PolarisSearchTool

tool = PolarisSearchTool(api_key="demo")
result = tool.invoke({"query": "semiconductor supply chain", "category": "technology"})
print(result[:500])
```

### Get latest briefs

```python
from langchain_polaris import PolarisFeedTool

tool = PolarisFeedTool(api_key="demo")
result = tool.invoke({"category": "technology", "limit": 5})
print(result[:500])
```

### Compare source coverage

```python
from langchain_polaris import PolarisCompareTool

tool = PolarisCompareTool(api_key="demo")
result = tool.invoke({"query": "AI regulation", "limit": 5})
print(result[:500])
```

### [Invoke with ToolCall](/oss/langchain/tools)

```python
model_generated_tool_call = {
    "args": {"query": "AI regulation"},
    "id": "1",
    "name": "polaris_search",
    "type": "tool_call",
}
tool_msg = search_tool.invoke(model_generated_tool_call)
print(tool_msg.content[:400])
```

## Use within an agent

```python
pip install -qU langgraph langchain-openai
```

```python
import getpass
import os

if not os.environ.get("OPENAI_API_KEY"):
    os.environ["OPENAI_API_KEY"] = getpass.getpass("OPENAI_API_KEY:\n")
```

```python
from langchain.chat_models import init_chat_model
from langchain.agents import create_agent
from langchain_polaris import (
    PolarisSearchTool,
    PolarisFeedTool,
    PolarisCompareTool,
)

model = init_chat_model(model="gpt-4.1", model_provider="openai", temperature=0)

tools = [
    PolarisSearchTool(api_key="demo"),
    PolarisFeedTool(api_key="demo"),
    PolarisCompareTool(api_key="demo"),
]

agent = create_agent(model, tools)

for step in agent.stream(
    {"messages": "What's happening with AI regulation? Compare how different sources cover it."},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```
