---
title: "MrScraperRerunManualScraper integration"
description: "Rerun manual MrScraper dashboard scrapers in LangChain."
---

`MrScraperRerunManualScraper` reruns a manually configured scraper from the MrScraper dashboard on one URL.

## Setup

```python
import os
from langchain_mrscraper import MrScraperRerunManualScraper

# Option 1: pass API key directly
tool = MrScraperRerunManualScraper(mrscraper_api_key="your-api-key")

# Option 2: auto-read from environment variable
os.environ["MRSCRAPER_API_KEY"] = "your-api-key"
tool = MrScraperRerunManualScraper()
```

## Invocation

```python
from langchain_mrscraper import MrScraperRerunManualScraper

tool = MrScraperRerunManualScraper(mrscraper_api_key="your-api-key")

result = tool.invoke(
    {
        "scraper_id": "scraper_uuid",
        "url": "https://example.com/product/new",
    }
)
print(result)
```

## Parameters

| Parameter | Type | Description |
| :-- | :-- | :-- |
| `scraper_id` | `str` | Manual scraper ID |
| `url` | `str` | Target URL |
