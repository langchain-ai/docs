This guide provides a quick overview for getting started with the [SearchApi.io](https://www.searchapi.io) [tool](/oss/langchain/tools). SearchApi provides a unified API for multiple search engines including Google, Google News, Google Shopping, Google Jobs, YouTube, Bing, and Baidu.

### Features

- Multi-engine search (Google, Google News, YouTube, Bing, Baidu, and more)
- Agents can dynamically select the search engine at invocation time
- Includes a retriever for RAG pipelines
- Full async support
- SecretStr API key management

## Setup

To access SearchApi, create an account at [searchapi.io](https://www.searchapi.io) and get an API key, then install the `langchain-searchapi` integration package.

### Credentials

```python Set API key icon="key"
import getpass
import os

if "SEARCHAPI_API_KEY" not in os.environ:
    os.environ["SEARCHAPI_API_KEY"] = getpass.getpass("Enter your SearchApi API key: ")
```

It is also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

Now you can instantiate an instance of the SearchApi search tool:

- `engine` (optional, str): Default search engine. Options: `google`, `google_news`, `google_shopping`, `google_jobs`, `google_scholar`, `youtube`, `bing`, `baidu`. Default is `google`.
- `num` (optional, int): Number of results to return.
- `gl` (optional, str): Country code for localized results (e.g., `us`, `gb`).
- `hl` (optional, str): Language code (e.g., `en`, `es`).
- `location` (optional, str): Location string for localized results.

```python Initialize tool instance icon="robot"
from langchain_searchapi import SearchApiSearch

tool = SearchApiSearch(
    engine="google",
    num=5,
    # gl="us",
    # hl="en",
    # location="New York",
)
```

## Invocation

### Directly

The tool accepts a `query` (required), and optionally `engine` and `num` to override defaults at call time:

```python Call tool icon="rocket"
tool.invoke({"query": "latest developments in AI agents"})
```

Override the engine dynamically:

```python Call with engine override icon="rocket"
tool.invoke({"query": "python tutorial", "engine": "youtube"})
```

### As a ToolCall

You can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "euro 2024 results", "engine": "google_news"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### Within an agent

You can use the SearchApi tool in an agent. For this you need a model with tool-calling capabilities.

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent
from langchain_searchapi import SearchApiSearch

tools = [SearchApiSearch()]
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=tools,
)

# Run the agent
agent.invoke(
    {"messages": [{"role": "user", "content": "What are the top AI news stories today?"}]}
)
```

## Retriever for RAG

The package also provides `SearchApiRetriever`, which returns search results as LangChain `Document` objects for use in RAG chains:

```python Retriever usage icon="database"
from langchain_searchapi import SearchApiRetriever

retriever = SearchApiRetriever(engine="google", num=5)
docs = retriever.invoke("machine learning frameworks comparison")

for doc in docs:
    print(f"{doc.metadata['title']}: {doc.page_content}")
```

Use the retriever in a chain:

```python RAG chain icon="link"
from langchain_searchapi import SearchApiRetriever
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
from langchain.chat_models import init_chat_model

retriever = SearchApiRetriever(num=5)
llm = init_chat_model(model="claude-sonnet-4-6", model_provider="anthropic")

prompt = ChatPromptTemplate.from_template(
    "Answer the question based on the context:\n\n{context}\n\nQuestion: {question}"
)

chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

chain.invoke("What are the best Python web frameworks?")
```

## Supported engines

| Engine | Value | Description |
|--------|-------|-------------|
| Google | `google` | Web search (default) |
| Google News | `google_news` | News articles |
| Google Shopping | `google_shopping` | Product listings |
| Google Jobs | `google_jobs` | Job postings |
| Google Scholar | `google_scholar` | Academic papers |
| YouTube | `youtube` | Video search |
| Bing | `bing` | Microsoft Bing |
| Baidu | `baidu` | Chinese search engine |
