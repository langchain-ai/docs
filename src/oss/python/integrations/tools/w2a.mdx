> The Web2Agent Protocol (W2A) is an open standard that makes any website agent-readable through a single file at `/.well-known/agents.json`. The `langchain-w2a` package turns those declared skills into typed LangChain tools.

## Overview

The W2A integration provides three LangChain components:

- **`W2ADiscoverTool`** — discover what a website declares it can do
- **`W2ASkillTool`** — call a specific skill on a W2A-enabled site
- **`W2AToolkit`** — auto-generate typed tools from a known W2A site

W2A solves the "agent discovery problem": instead of crawling 40-50 pages blind, an agent reads one JSON file that declares the site's skills, inputs, outputs, and auth requirements.

## Setup

No API key is needed for public W2A endpoints. The `langchain-w2a` package builds on the `w2a` Python SDK.

It's also helpful (but not needed) to set up LangSmith for best-in-class observability of your tool calls.

### Installation

```python pip
pip install -U langchain-w2a
```

```python uv
uv add langchain-w2a
```

## Instantiation

### Discover tool

Use `W2ADiscoverTool` when you need an agent to check whether a site has adopted W2A and explore its declared skills:

```python
from langchain_w2a import W2ADiscoverTool

discover_tool = W2ADiscoverTool()
```

### Skill tool

Use `W2ASkillTool` when you want an agent to invoke a specific skill on any W2A-enabled site at runtime:

```python
from langchain_w2a import W2ASkillTool

skill_tool = W2ASkillTool()
```

### Toolkit — typed tools for a known site

Use `W2AToolkit.from_url()` when your agent targets a specific site. The toolkit creates one typed tool per declared skill, with Pydantic input schemas built from the site's `agents.json`:

```python
from langchain_w2a import W2AToolkit

toolkit = await W2AToolkit.from_url("w2a-protocol.org")
tools = toolkit.get_tools()
```

## Invocation

### Discover a site

```python
result = discover_tool.invoke({"url": "w2a-protocol.org"})
print(result)
```

Returns a JSON summary of the site's declared capabilities:

```json
{
  "name": "W2A Protocol",
  "type": "api",
  "url": "https://w2a-protocol.org",
  "a2a_compatible": true,
  "skills": [
    {
      "id": "check_site",
      "intent": "check whether a website already serves a valid W2A manifest",
      "action": "GET /api/check",
      "auth": "none"
    }
  ]
}
```

### Call a skill

```python
result = skill_tool.invoke({
    "url": "w2a-protocol.org",
    "skill_id": "check_site",
    "params": {"url": "stripe.com"}
})
```

We can also invoke the tool with a model-generated ToolCall, in which case a `ToolMessage` will be returned:

```python
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"url": "stripe.com"},
    "id": "1",
    "name": discover_tool.name,
    "type": "tool_call",
}
discover_tool.invoke(model_generated_tool_call)
```

## Chaining — use in an agent

We can use these tools in an agent. For this we will need a model with tool-calling capabilities.

```python
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent
from langchain_w2a import W2ADiscoverTool, W2ASkillTool

tools = [W2ADiscoverTool(), W2ASkillTool()]

agent = create_agent(
    model="claude-sonnet-4-5-20250929",
    tools=tools,
)

result = agent.invoke({
    "messages": [
        ("user", "Check if w2a-protocol.org has W2A enabled, "
                 "then list its declared skills.")
    ]
})
```

## Toolkit usage

When your agent works with a specific site, the toolkit pattern gives each skill its own typed tool:

```python
from langchain_w2a import W2AToolkit

# Each W2A skill becomes a separate, typed LangChain tool
toolkit = await W2AToolkit.from_url("w2a-protocol.org")
tools = toolkit.get_tools()

for tool in tools:
    print(f"{tool.name}: {tool.description}")
# w2a_discover: Discover what a W2A-enabled website can do
# w2a_call_skill: Call a specific skill on a W2A-enabled website
# w2a_protocol_check_site: Check whether a website serves a valid W2A manifest
# w2a_protocol_validate_manifest: Validate an agents.json manifest against the W2A spec
# ... and so on, one tool per declared skill
```

The toolkit takes optional arguments:

```python
# Include skills that require authentication
toolkit = await W2AToolkit.from_url(
    "yoursite.com",
    include_auth_required=True
)

# Limit to specific skills
toolkit = await W2AToolkit.from_url(
    "yoursite.com",
    skill_ids=["search", "get_article"]
)
```

## Handling non-W2A sites gracefully

Not every site has adopted W2A yet. The tools handle this cleanly:

```python
from langchain_w2a import W2ADiscoverTool

tool = W2ADiscoverTool()
result = tool.invoke({"url": "stripe.com"})
# Returns: "stripe.com has not adopted the W2A protocol yet —
#  no /.well-known/agents.json found.
#  Generate one at https://w2a-protocol.org/tools"
```

This lets your agent fall back to other strategies (crawling, alternative APIs, etc.) when a site isn't W2A-enabled.
