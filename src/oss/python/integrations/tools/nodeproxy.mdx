[NodeProxy](https://github.com/pgalyen1987/NodeProxy) is an MCP + HTTP service that fetches any public URL, strips scripts, navigation, and ad noise, and returns token-efficient Markdown for LLM ingestion. Agents pay per parse via the [x402](https://www.x402.org/) protocol using USDC on Base mainnet.

## Overview

### Tool features

| [Returns artifact](/oss/langchain/tools) | Native async | Return data | Pricing |
| :---: | :---: | :--- | :--- |
| ❌ | ❌ | Clean Markdown from a public URL | ~$0.002 USDC per parse (x402 on Base) |

### Key features

- **Token-efficient output**: strips HTML chrome (~70% fewer tokens vs raw page HTML)
- **No API keys**: micropayments via x402 USDC instead of subscription keys
- **Agent-native**: tool name and schema match MCP registry / x402 Bazaar discovery strings
- **MCP compatible**: same tool exposed at `https://nodeproxy-production.up.railway.app/mcp`

## Setup

The integration lives in the `nodeproxy-tools` package.

<CodeGroup>
    ```python pip
    pip install -U "nodeproxy-tools[x402,langchain]"
    ```
    ```python uv
    uv add "nodeproxy-tools[x402,langchain]"
    ```
</CodeGroup>

### Credentials

NodeProxy uses x402 micropayments instead of an API key. Set an EVM private key for a wallet funded with USDC on Base mainnet:

```python Set up credentials icon="key"
import os

if not os.environ.get("EVM_PRIVATE_KEY"):
    raise RuntimeError("Set EVM_PRIVATE_KEY to a Base mainnet wallet with USDC")
```

Optional: override the default NodeProxy endpoint:

```python
os.environ["NODEPROXY_API_URL"] = "https://nodeproxy-production.up.railway.app/mcp/execute"
```

It's also helpful (but not needed) to set up [LangSmith](https://smith.langchain.com) for observability:

```python
import getpass

os.environ["LANGSMITH_TRACING"] = "true"
if not os.environ.get("LANGSMITH_API_KEY"):
    os.environ["LANGSMITH_API_KEY"] = getpass.getpass("LangSmith API key:\n")
```

## Instantiation

```python Initialize tool icon="robot"
from nodeproxy_tools.langchain import NodeProxyMarkdownTool

tool = NodeProxyMarkdownTool()
```

You can pass a custom API URL or client:

```python
from nodeproxy_tools.client import NodeProxyClient
from nodeproxy_tools.langchain import NodeProxyMarkdownTool

client = NodeProxyClient(api_url="https://nodeproxy-production.up.railway.app/mcp/execute")
tool = NodeProxyMarkdownTool(client=client)
```

## Invocation

### [Invoke directly with args](/oss/langchain/tools)

The tool accepts a single required argument:

- `url` (required, str): Public website URL to parse into LLM-ready Markdown.

```python
markdown = tool.invoke({"url": "https://docs.python.org/3/"})
print(markdown[:500])
```

### [Invoke with ToolCall](/oss/langchain/tools)

```python
model_generated_tool_call = {
    "args": {"url": "https://example.com"},
    "id": "1",
    "name": "surface_markdown_parser",
    "type": "tool_call",
}
tool_msg = tool.invoke(model_generated_tool_call)
print(tool_msg.content[:400])
```

## Use within an agent

<ChatModelTabs customVarName="llm" />

```python
from langchain.agents import create_agent
from nodeproxy_tools.langchain import NodeProxyMarkdownTool

tool = NodeProxyMarkdownTool()
agent = create_agent("gpt-4o-mini", tools=[tool])

result = agent.invoke(
    {"messages": [("user", "Summarize the Python 3 documentation homepage.")]}
)
print(result["messages"][-1].content)
```
