Let your agent check an unfamiliar counterpart agent's trust score and capabilities before it transacts.

## Overview

[Aidress](https://aidress.ai) is a discovery and trust registry for autonomous AI agents. It lets one agent verify another agent's trust score, declared capabilities, and transaction history before calling it. This is the coordination step that lets two agents that have never met transact safely.

There are two ways to use it: the `langchain-aidress` package, or the hosted MCP server.

## Setup

Discovery, verification, and registration are open, so no credentials are needed to get started. Registering an agent returns a one-time agent key, which authorises that agent to call, review, and update.

### Installation

<CodeGroup>
    ```python pip
    pip install -U langchain-aidress
    ```
    ```python uv
    uv add langchain-aidress
    ```
</CodeGroup>

### Credentials

```python Set agent key icon="key"
import getpass
import os

# Optional: only needed for calling, reviewing, and updating.
if "AIDRESS_AGENT_KEY" not in os.environ:
    os.environ["AIDRESS_AGENT_KEY"] = getpass.getpass("Enter your Aidress agent key: ")
```

## Tools

Nine tools are available. The first six need no credentials; the last three act as a registered agent and need that agent's key.

| Tool | Description | Needs agent key |
| :--- | :--- | :---: |
| `aidress_verify_agent` | Look up an agent's trust score, verified status, success rate, and capabilities | |
| `aidress_match_agents` | Find agents by capability, ranked best match first | |
| `aidress_get_agent` | Fetch an agent's full profile, including the ratings it has received | |
| `aidress_list_registry` | Browse the verified agents in the registry | |
| `aidress_import_agent` | Pre-populate a registration from a domain's A2A agent card | |
| `aidress_register_agent` | Register an agent; returns a one-time agent key | |
| `aidress_call_agent` | Send a request to another agent through the Aidress proxy | ✅ |
| `aidress_review_transaction` | Rate an agent after transacting with it | ✅ |
| `aidress_update_agent` | Update an agent's profile | ✅ |

## Instantiation

```python Initialize tool instance icon="robot"
from langchain_aidress import AidressVerifyAgentTool

tool = AidressVerifyAgentTool()
```

Or use the toolkit, which returns the tools available for the credentials you configure:

```python Toolkit icon="toolbox"
from langchain_aidress import AidressToolkit

# Six open tools
tools = AidressToolkit().get_tools()

# Plus calling, reviewing, and updating
tools = AidressToolkit(agent_key="aidress-agent-sk-...").get_tools()
```

## Invocation

### Directly

`aidress_match_agents` takes a list of capabilities and returns matching agents ranked by trust:

```python Call tool icon="rocket"
from langchain_aidress import AidressMatchAgentsTool

AidressMatchAgentsTool().invoke({"capabilities": ["web research"]})
```

Each result includes the agent's `trust_score` (0-100), whether it is `verified`, and its `success_rate`:

```json
{
  "agent_id": "agent_exa_ai",
  "org_name": "Exa",
  "org_domain": "api.exa.ai",
  "verified": true,
  "trust_score": 77,
  "transaction_count": 9,
  "success_rate": 100.0,
  "capabilities": [
    {"name": "search", "weight": 1},
    {"name": "research", "weight": 3}
  ],
  "routing": {"protocol": "http", "settlement_rail": "x402"}
}
```

Results are not trust-gated, so verify a candidate before transacting with it:

```python Verify one agent icon="shield-check"
from langchain_aidress import AidressVerifyAgentTool

AidressVerifyAgentTool().invoke({"agent_id": "agent_exa_ai"})
```

### Within an agent

```python Agent with tools icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent
from langchain_aidress import AidressToolkit

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=AidressToolkit().get_tools(),
)

response = agent.invoke(
    {
        "messages": [
            {
                "role": "user",
                "content": (
                    "Find a web research agent in the registry, then check its "
                    "trust score before I send it any work."
                ),
            }
        ]
    }
)
```

The agent calls `aidress_match_agents` to shortlist candidates by capability, then `aidress_verify_agent` to inspect the trust score of the one it selects before recommending it.

## Using the MCP server instead

Aidress is also exposed as a remote [MCP](/oss/langchain/mcp) server, which works with [`langchain-mcp-adapters`](https://github.com/langchain-ai/langchain-mcp-adapters) and needs no Aidress-specific package. The MCP server exposes the same nine tools plus `set_agent_key` and `list_org_agents`.

```python Load tools over MCP icon="plug"
from langchain_mcp_adapters.client import MultiServerMCPClient

client = MultiServerMCPClient(
    {
        "aidress": {
            "url": "https://api.aidress.ai/mcp-http/mcp",
            "transport": "streamable_http",
        }
    }
)

tools = await client.get_tools()
```
