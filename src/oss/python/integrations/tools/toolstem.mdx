[Toolstem](https://toolstem.com) provides agent-ready financial intelligence via MCP (Model Context Protocol) servers. It exposes 8 production tools across two domains: **Finance** (stock snapshots, company metrics, peer comparisons) and **SEC EDGAR** (filings, insider trades, institutional holdings, material events, disclosure signals).

This guide covers the `langchain-toolstem` package, which wraps Toolstem's MCP servers as native LangChain tools with built-in [x402](https://www.x402.org/) micropayment support.

### Tool summary

**Finance tools** (via `create_finance_tools`):

| Tool | Description |
| :--- | :--- |
| `get_stock_snapshot` | Real-time quote, valuation, DCF signal, and analyst rating for a single ticker |
| `get_company_metrics` | Deep fundamentals: profitability, health signal, cash flow, 3-year CAGR, per-share data |
| `compare_companies` | Side-by-side comparison of 2-5 companies with relative ranking |

**SEC EDGAR tools** (via `create_sec_tools`):

| Tool | Description |
| :--- | :--- |
| `get_company_filings_summary` | Recent SEC filings (10-K, 10-Q, 8-K, etc.) with summaries |
| `get_insider_signal` | Insider buying/selling activity and net signal |
| `get_institutional_signal` | 13F institutional ownership changes and concentration |
| `get_material_events_digest` | Material events from 8-K filings (earnings, M&A, leadership changes) |
| `compare_disclosure_signals` | Cross-company comparison of disclosure patterns |

## Setup

The Toolstem tools live in the `langchain-toolstem` package. Install it with the optional `x402` extra to enable paid tool calls:

<CodeGroup>
    ```python pip
    pip install -U 'langchain-toolstem[x402]'
    ```
    ```python uv
    uv add 'langchain-toolstem[x402]'
    ```
</CodeGroup>

### Credentials

Toolstem uses [x402](https://www.x402.org/) for per-call payments. Discovery (`initialize` and `tools/list`) is free; each tool invocation (`tools/call`) costs **$0.01 USDC** on Base mainnet. To make paid calls you need a wallet private key with a USDC balance on Base — no API key or account registration is required.

```python Set wallet key icon="key"
import getpass
import os

if "X402_PRIVATE_KEY" not in os.environ:
    os.environ["X402_PRIVATE_KEY"] = getpass.getpass("Enter your Base wallet private key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/home) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

Discovery is free and needs no wallet. To list the available tools:

```python Discover tools icon="robot"
from langchain_toolstem import create_finance_tools, create_sec_tools

finance_tools = await create_finance_tools()
sec_tools = await create_sec_tools()

for t in finance_tools + sec_tools:
    print(t.name)
```

To make paid tool calls, create an x402-paying HTTP client from your wallet key and pass it to the factory functions. The client automatically signs and pays the $0.01 USDC charge when the server responds with HTTP 402:

```python Paid tools icon="rocket"
from langchain_toolstem import create_finance_tools, create_x402_httpx_client

client = await create_x402_httpx_client(os.environ["X402_PRIVATE_KEY"])
tools = await create_finance_tools(http_client=client)
```

## Invocation

### Directly

Each tool is a LangChain `StructuredTool` and is invoked asynchronously. For example, `get_stock_snapshot` takes a `symbol`:

```python Call tool icon="rocket"
snapshot = next(t for t in tools if t.name == "get_stock_snapshot")
result = await snapshot.ainvoke({"symbol": "AAPL"})
print(result)
```

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"symbol": "AAPL"},
    "id": "1",
    "name": "get_stock_snapshot",
    "type": "tool_call",
}
await snapshot.ainvoke(model_generated_tool_call)
```

### Within an agent

We can use the Toolstem tools in any LangChain agent that supports tool calling. Here is an example using LangGraph:

```python Agent with tools icon="robot"
# pip install -qU "langchain[openai]" langgraph to call the model
import os

from langchain_openai import ChatOpenAI
from langgraph.prebuilt import create_react_agent

from langchain_toolstem import create_finance_tools, create_x402_httpx_client

client = await create_x402_httpx_client(os.environ["X402_PRIVATE_KEY"])
tools = await create_finance_tools(http_client=client)

agent = create_react_agent(ChatOpenAI(model="gpt-4o"), tools)
result = await agent.ainvoke(
    {"messages": [{"role": "user", "content": "Compare AAPL and MSFT fundamentals"}]}
)
```

## Pricing

| Aspect | Detail |
| :--- | :--- |
| Discovery (`initialize`, `tools/list`) | Free |
| Tool invocation (`tools/call`) | $0.01 USDC per call |
| Payment network | Base mainnet (`eip155:8453`) |
| USDC contract | `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913` |
| Payment protocol | [x402](https://www.x402.org/) |
| Supported wallets | Any EVM wallet (Coinbase Smart Wallet, MetaMask, etc.) |

You can also try the tools without a wallet at the [Toolstem playground](https://toolstem.com/playground) — real, cached responses, no payment required.
