This guide provides a quick overview for getting started with NewsCatcher CatchAll [tools](/oss/langchain/tools).

## Overview

[CatchAll](https://platform.newscatcherapi.com/catchall) is a web search API that finds real-world business events, such as acquisitions, regulatory approvals, and funding rounds across billions of web pages. The `langchain-catchall` package lets you use CatchAll as a tool within LangChain and LangGraph agents.

For detailed documentation of all CatchAll features and configurations, refer to the [CatchAll API reference](https://www.newscatcherapi.com/docs/web-search-api/api-reference).

### Features

- Two usage patterns: `CatchAllClient` for scripts and pipelines, `CatchAllTools` for LangGraph agents.
- Automatic job polling and result retrieval via `CatchAllClient.search()`.
- Two tools optimized for agent workflows: `catchall_search_data` (10-15 min, API credits) and `catchall_analyze_data` (instant, LLM costs only).
- Built-in monitor support for recurring scheduled searches.
- Async support via `AsyncCatchAllClient`.

## Setup

To access CatchAll tools, you need to create a NewsCatcher account, get an API key, and install the `langchain-catchall` integration package.

### Credentials

Sign up at [platform.newscatcherapi.com](https://platform.newscatcherapi.com) to get your API key.

```python Set API key icon="key"
import getpass
import os

if "CATCHALL_API_KEY" not in os.environ:
    os.environ["CATCHALL_API_KEY"] = getpass.getpass("Enter your CatchAll API key: ")
```

Optionally, enable LangSmith tracing to monitor tool calls:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

Install the `langchain-catchall` package:

<CodeGroup>
    ```bash pip
    pip install -U langchain-catchall
    ```
    ```bash uv
    uv add langchain-catchall
    ```
</CodeGroup>

## Instantiation

Initialize the CatchAll toolkit with your API key and a language model for result analysis:

```python
import os
from langchain_catchall import CatchAllTools
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o")

toolkit = CatchAllTools(
    api_key=os.environ["CATCHALL_API_KEY"],
    llm=llm,
    limit=100,              # Balance between context size and completeness
    verbose=True,           # Show progress during operations
    initialize_query=True,  # Call initialize_job() for suggested validators and enrichments
)

tools = toolkit.get_tools()
```

## Invocation

### Directly

You can invoke the search tool directly to submit a query:

```python
from langchain_catchall import CatchAllTools

toolkit = CatchAllTools(
    api_key=os.environ["CATCHALL_API_KEY"],
    llm=llm,
)

search_tool = toolkit.get_tools()[0]  # catchall_search_data

result = search_tool.invoke({
    "query": "Pharmaceutical company acquisitions in Europe"
})

# Returns raw structured records cached by the toolkit
print(result)
```

### As a ToolCall

You can invoke the tool with a model-generated `ToolCall`:

```python
# The tool call is generated by the model, but here we create it directly for demo purposes.
model_generated_tool_call = {
    "args": {
        "query": "Tech startup IPO filings in the US"
    },
    "id": "1",
    "name": search_tool.name,
    "type": "tool_call",
}

# Returns raw structured records cached by the toolkit
result = search_tool.invoke(model_generated_tool_call)
```

### Within an agent

Use both tools together in a LangGraph agent for the most powerful pattern — search once, then analyze the cached data multiple times:

```python
import os
from langchain_catchall import CatchAllTools, CATCHALL_AGENT_PROMPT
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain.messages import HumanMessage

llm = ChatOpenAI(model="gpt-4o")

toolkit = CatchAllTools(
    api_key=os.environ["CATCHALL_API_KEY"],
    llm=llm,
)

agent = create_agent(
    model=llm,
    tools=toolkit.get_tools(),
    system_prompt=CATCHALL_AGENT_PROMPT,
)

# Initial search (takes 10-15 minutes)
messages = [HumanMessage(content="Find corporate headquarters relocations in the US")]
response = agent.invoke({"messages": messages})

# Prints only the final agent response, omitting raw tool outputs
print(response["messages"][-1].content)
```

```txt
I found 40 records of corporate headquarters relocations in the US. Please let me know if you have any follow-up questions or need any specific analysis on this data!
```

### Follow-up analysis

Once data is cached, subsequent questions are answered instantly without additional API credits:

```python
# These queries use cached data — instant results, no additional API credits
messages = response["messages"]

messages.append(HumanMessage(content="Show only California locations"))
response = agent.invoke({"messages": messages})

print(response["messages"][-1].content)
```

```txt
Here are the relocations involving California locations:

1. **Public Storage** moved from Glendale, California to Frisco, Texas, citing benefits from North Texas's business climate and workforce.
2. **BitGo** relocated from California to Sioux Falls, South Dakota, due to a proposed wealth tax in California.
3. **Chevron** moved from California to Houston, Texas, though no specific reason was provided in the records.

If you need more details or further analysis, feel free to ask!
```

```python
messages = response["messages"]

messages.append(HumanMessage(content="What are the top 3 cities?"))
response = agent.invoke({"messages": messages})

```

```txt
2. **Miami, Florida** - Welcomed companies such as Palantir, GFL Environmental, and Trinity Investments.
3. **Plano, Texas** - Became the new headquarters location for AT&T with significant incentives.

These cities are notable for attracting multiple corporate relocations. Let me know if you need further information!
```
