[Tonic Textual](https://textual.tonic.ai) is a PII detection and transformation platform. The `langchain-textual` integration provides tools to find sensitive data — names, emails, addresses, and more — in text, JSON, HTML, and files, then synthesize it with realistic fake values or tokenize it with reversible placeholders.

### Tool features

- **`TonicTextualRedactText`**: Redact PII from plain text strings.
- **`TonicTextualRedactJson`**: Redact PII from JSON data.
- **`TonicTextualRedactHtml`**: Redact PII from HTML content.
- **`TonicTextualRedactFile`**: Redact PII from files (PDF, JPG, PNG, CSV, TSV).
- **`TonicTextualPiiTypes`**: List all supported PII entity types.

## Setup

To use the Tonic Textual tools, you'll need a [Tonic Textual](https://textual.tonic.ai) account and API key, and the `langchain-textual` package.

### Credentials

```python Set API key icon="key"
import getpass
import os

if "TONIC_TEXTUAL_API_KEY" not in os.environ:
    os.environ["TONIC_TEXTUAL_API_KEY"] = getpass.getpass("Enter your Tonic Textual API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability of your tool calls:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

```python Initialize tools icon="robot"
from langchain_textual import (
    TonicTextualRedactText,
    TonicTextualRedactJson,
    TonicTextualRedactHtml,
    TonicTextualRedactFile,
    TonicTextualPiiTypes,
)

text_tool = TonicTextualRedactText()
json_tool = TonicTextualRedactJson()
html_tool = TonicTextualRedactHtml()
file_tool = TonicTextualRedactFile()
pii_types_tool = TonicTextualPiiTypes()
```

## Invocation

### Redact plain text

```python Redact text icon="rocket"
text_tool.invoke("My name is John Smith and my email is john@example.com.")
# "My name is [NAME_GIVEN_xxxx] [NAME_FAMILY_xxxx] and my email is [EMAIL_ADDRESS_xxxx]."
```

### Redact JSON

```python Redact JSON icon="rocket"
json_tool.invoke('{"name": "John Smith", "email": "john@example.com"}')
# '{"name": "[NAME_GIVEN_xxxx] [NAME_FAMILY_xxxx]", "email": "[EMAIL_ADDRESS_xxxx]"}'
```

### Redact HTML

```python Redact HTML icon="rocket"
html_tool.invoke("<p>Contact John Smith at john@example.com</p>")
# "<p>Contact [NAME_GIVEN_xxxx] [NAME_FAMILY_xxxx] at [EMAIL_ADDRESS_xxxx]</p>"
```

### Redact files

```python Redact a file icon="rocket"
file_tool.invoke({"file_path": "/path/to/scan.pdf"})
# "/path/to/scan_redacted.pdf"
```

### As a ToolCall

You can also invoke a tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"text": "My SSN is 123-45-6789"},
    "id": "1",
    "name": text_tool.name,
    "type": "tool_call",
}
text_tool.invoke(model_generated_tool_call)
```

## Configuration

### Synthesis

Replace PII with realistic fake data that preserves the structure and meaning of the original:

```python Synthesis icon="wand"
tool = TonicTextualRedactText(generator_default="Synthesis")
tool.invoke("Contact Jane Doe at jane.doe@example.com.")
# "Contact Maria Chen at maria.chen@gmail.com."
```

### Tokenization

Replace PII with reversible placeholder tokens (the default behavior):

```python Tokenization icon="lock"
tool = TonicTextualRedactText(generator_default="Redaction")
tool.invoke("Contact Jane Doe at jane.doe@example.com.")
# "Contact [NAME_GIVEN_xxxx] [NAME_FAMILY_xxxx] at [EMAIL_ADDRESS_xxxx]."
```

### Per-entity control

Mix synthesis and tokenization per PII type with `generator_config`:

```python Per-entity config icon="sliders"
tool = TonicTextualRedactText(
    generator_default="Off",
    generator_config={
        "NAME_GIVEN": "Synthesis",
        "NAME_FAMILY": "Synthesis",
        "EMAIL_ADDRESS": "Redaction",
    },
)
tool.invoke("Contact Jane Doe at jane.doe@example.com.")
```

Use `TonicTextualPiiTypes` to discover all valid entity type names:

```python List PII types icon="list"
TonicTextualPiiTypes().invoke("")
# "NUMERIC_VALUE, LANGUAGE, MONEY, ..., EMAIL_ADDRESS, NAME_GIVEN, NAME_FAMILY, ..."
```

### Self-hosted deployment

```python Self-hosted icon="server"
tool = TonicTextualRedactText(tonic_textual_base_url="https://textual.your-company.com")
```

## Use within an agent

Every tool in this package is a standard LangChain tool, so they work anywhere tools do:

```python Agent with tools icon="robot"
from langchain_textual import (
    TonicTextualRedactText,
    TonicTextualRedactJson,
    TonicTextualRedactFile,
)
from langchain.chat_models import init_chat_model

llm = init_chat_model("claude-sonnet-4-6")

tools = [
    TonicTextualRedactText(),
    TonicTextualRedactJson(),
    TonicTextualRedactFile(),
]

from langgraph.prebuilt import create_react_agent

agent = create_react_agent(llm, tools)

events = agent.stream(
    {"messages": [("user", "Redact PII from: My name is Jane Doe, email jane@example.com")]},
    stream_mode="values",
)

for event in events:
    event["messages"][-1].pretty_print()
```
