This guide provides a quick overview for getting started with the [Opedd](https://opedd.com/for-ai-agents) [tools](/oss/langchain/tools). Opedd is a content-licensing platform between expert publishers and AI products: agents can check whether an article is licensable, browse verified publishers, verify license keys (with on-chain proof), and retrieve licensed article text.

### Features

- **No credentials needed** for discovery and verification (`OpeddLookupTool`, `OpeddDirectoryTool`, `OpeddVerifyLicenseTool`).
- **Licensing provenance**: every retrieved article carries a verifiable license key and content hash.
- **Compliance-grade evidence**: license verification includes on-chain registration proof; supports EU AI Act Article 53 attestation workflows.

## Setup

The tools live in the `langchain-opedd` package:

<CodeGroup>
    ```python pip
    pip install -U langchain-opedd
    ```
    ```python uv
    uv add langchain-opedd
    ```
</CodeGroup>

### Credentials

The discovery tools need no credentials. `OpeddContentTool` requires an Opedd buyer token (`opedd_buyer_live_*`) — self-serve signup at [opedd.com](https://opedd.com).

## Instantiation

```python
from langchain_opedd import (
    OpeddLookupTool,
    OpeddDirectoryTool,
    OpeddVerifyLicenseTool,
    OpeddContentTool,
)

lookup = OpeddLookupTool()
directory = OpeddDirectoryTool()
verify = OpeddVerifyLicenseTool()
content = OpeddContentTool(buyer_token="opedd_buyer_live_...")
```

---

## Invocation

### Look up licensing status of an article URL

```python
lookup.invoke({"url": "https://example-newsletter.com/p/some-article"})
```

### Browse verified publishers

```python
directory.invoke({"limit": 5})
```

### Verify a license key

```python
verify.invoke({"key": "OP-XXXX-XXXX"})
```

### Retrieve licensed article text

```python
content.invoke({"article_id": "9b2f4c1e-..."})
```

---

## Use within an agent

```python
from langchain.agents import create_agent

agent = create_agent(
    model="claude-sonnet-5",
    tools=[lookup, directory, verify, content],
)

agent.invoke({
    "messages": [{
        "role": "user",
        "content": "Find licensable articles about battery supply chains and quote the licensing cost.",
    }]
})
```

Autonomous license *purchasing* (a payment-confirmation flow) is deliberately not a LangChain tool — agents that buy licenses mid-task should use the [Opedd MCP server](https://github.com/Opedd/opedd-mcp) (`https://mcp.opedd.com/mcp` hosted, or `npx opedd-mcp` local), which includes `purchase_license` with Stripe support.
