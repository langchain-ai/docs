[MadeOnSol](https://madeonsol.com) provides real-time Solana memecoin intelligence for LangChain agents—a live trade feed from 1,000+ tracked KOL (key opinion leader) wallets, multi-KOL coordination signals, pump.fun deployer reputation, scout/consensus leaderboards, price alerts, and webhook/streaming management.

Two authentication modes: a MadeOnSol API key (free tier available), or **x402 USDC micropayments**, where agents with a Solana wallet pay per call with no signup.

### Features

- **`madeonsol_kol_feed`**—real-time buy/sell feed from 1,000+ tracked Solana KOL wallets (sub-3s from on-chain confirmation)
- **`madeonsol_kol_coordination`**—tokens that multiple KOLs are accumulating in the same window (convergence signal)
- **`madeonsol_kol_leaderboard`**—KOL rankings by PnL and win rate
- **`madeonsol_deployer_alerts`**—pump.fun launches enriched with deployer reputation tiers and rug history
- **`madeonsol_scout_leaderboard`** / **`madeonsol_kol_consensus`** / **`madeonsol_peak_history`**—first-mover and consensus analytics
- **`madeonsol_price_alert_*`** (create / list / events)—market-cap threshold alerts
- **`madeonsol_create_webhook`** / **`madeonsol_list_webhooks`** / **`madeonsol_stream_token`**—push-delivery management

## Setup

The tools live in the `madeonsol-x402` package, behind the `langchain` extra:

```bash
pip install "madeonsol-x402[langchain]"
```

### Credentials

Set **one** of:

```python Set API key icon="key"
import getpass
import os

# Option A—API key (free tier: 200 requests/day, no card)
if "MADEONSOL_API_KEY" not in os.environ:
    os.environ["MADEONSOL_API_KEY"] = getpass.getpass("Enter your MadeOnSol API key: ")

# Option B—x402 micropayments: pay per call in USDC from a Solana wallet
# os.environ["SVM_PRIVATE_KEY"] = "<base58 private key>"
```

Get a free API key at [madeonsol.com/pricing](https://madeonsol.com/pricing). With `SVM_PRIVATE_KEY` instead, each call settles a USDC micropayment ($0.005–$0.02) over the [x402 protocol](https://madeonsol.com/api-docs)—no account needed.

## Instantiation

```python
from madeonsol_x402.langchain_tools import (
    ALL_TOOLS,                 # all 13 tools
    MadeOnSolKolFeed,          # or import individual tools
    MadeOnSolKolCoordination,
)

kol_feed = MadeOnSolKolFeed()
```

## Invocation

```python
result = kol_feed.invoke({"limit": 5, "action": "buy"})
print(result)  # JSON: recent KOL buys with wallet, token, size, market cap at trade
```

## Use within an agent

```python
from langchain.agents import create_agent

agent = create_agent(
    model="claude-sonnet-4-5",
    tools=ALL_TOOLS,
)

agent.invoke({
    "messages": [{
        "role": "user",
        "content": "Which tokens are at least 4 Solana KOLs buying right now, and who are the top KOLs this week?",
    }]
})
```

The agent picks `madeonsol_kol_coordination` and `madeonsol_kol_leaderboard` and answers from live on-chain data.
