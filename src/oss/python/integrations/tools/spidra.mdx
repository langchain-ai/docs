This guide provides a quick overview for getting started with the Spidra [tools](/oss/langchain/tools). For a detailed listing of all Spidra features, parameters, and configurations, head to the [API reference](https://pypi.org/project/langchain-spidra/).

[Spidra](https://spidra.io) turns websites into structured, ready-to-use data using prompts, real browsers, proxies, CAPTCHA solving, and AI extraction — without requiring you to build or maintain scraping infrastructure.

### Details

| Class | Package | Downloads | Version |

### Features

- **SpidraScrape** — Scrape a single URL and return structured markdown content
- **SpidraCrawl** — Crawl an entire website from a seed URL, returning content from all discovered pages
- **SpidraBatchScrape** — Scrape up to 50 URLs in parallel in a single API call
- Real browser rendering with stealth mode, CAPTCHA solving, and rotating proxies built in
- Authenticated scraping support via session cookies

## Setup

To access Spidra tools, create a [Spidra account](https://app.spidra.io), get an API key, and install the `langchain-spidra` package.

### Credentials

```python Set API key icon="key"
import getpass
import os

if "SPIDRA_API_KEY" not in os.environ:
    os.environ["SPIDRA_API_KEY"] = getpass.getpass("Enter your Spidra API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The Spidra tools live in the `langchain-spidra` package:

<CodeGroup>
```bash pip
pip install -U langchain-spidra
```
```bash uv
uv add langchain-spidra
```
</CodeGroup>

## SpidraScrape

`SpidraScrape` scrapes a single URL and returns its content as structured markdown.

### Instantiation

```python Initialize tool icon="robot"
from langchain_spidra import SpidraScrape

tool = SpidraScrape()
```

### Invocation

#### Directly

```python Call tool icon="rocket"
result = tool.invoke({"url": "https://example.com"})
print(result)
```

#### As a ToolCall

```python ToolCall icon="briefcase"
model_generated_tool_call = {
    "args": {"url": "https://example.com"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

#### Within an agent

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent

tools = [SpidraScrape()]
agent = create_agent(
    model="claude-sonnet-4-5",
    tools=tools,
)

agent.invoke(
    {"messages": [{"role": "user", "content": "Scrape https://example.com and summarize what it's about."}]}
)
```

## SpidraCrawl

`SpidraCrawl` crawls an entire website from a seed URL, returning structured content from all discovered pages.

### Instantiation

```python Initialize tool icon="robot"
from langchain_spidra import SpidraCrawl

tool = SpidraCrawl()
```

### Invocation

```python Call tool icon="rocket"
result = tool.invoke({"url": "https://example.com"})
print(result)
```

## SpidraBatchScrape

`SpidraBatchScrape` scrapes up to 50 URLs in parallel in a single API call.

### Instantiation

```python Initialize tool icon="robot"
from langchain_spidra import SpidraBatchScrape

tool = SpidraBatchScrape()
```

### Invocation

```python Call tool icon="rocket"
result = tool.invoke({
    "urls": [
        "https://example.com",
        "https://example.org",
    ]
})
print(result)
```
