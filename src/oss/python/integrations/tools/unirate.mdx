>[UniRate](https://unirateapi.com) provides 593+ fiat, crypto, and commodity exchange rates with a permissive free tier. Latest rates and conversions are free; historical and time-series endpoints require a Pro plan.

The `langchain-unirate` package exposes a Pydantic API wrapper plus a structured `BaseTool`, so an agent can call FX conversions and rate lookups directly via tool-calling.

## Installation

```bash
pip install langchain-unirate
```

## Setup

Generate an API key from the [UniRate dashboard](https://unirateapi.com/dashboard) and put it in the `UNIRATE_API_KEY` environment variable.

```python
import getpass
import os

os.environ["UNIRATE_API_KEY"] = getpass.getpass()
```

## Direct usage

```python
from langchain_unirate import UniRateAPIWrapper

wrapper = UniRateAPIWrapper()

wrapper.convert("USD", "EUR", amount=100)
```

```text
92.5
```

```python
wrapper.get_rate("USD", "GBP")
```

```text
0.79
```

```python
wrapper.get_supported_currencies()[:5]
```

```text
['USD', 'EUR', 'GBP', 'JPY', 'CHF']
```

## As an agent tool

The `UniRateExchangeTool` is a `BaseTool` with a structured `args_schema` over `from_currency`, `to_currency`, and `amount`. Bind it to any tool-calling chat model.

```python
from langchain_unirate import UniRateAPIWrapper, UniRateExchangeTool

tool = UniRateExchangeTool(api_wrapper=UniRateAPIWrapper())

tool.invoke({"from_currency": "USD", "to_currency": "EUR", "amount": 100})
```

```text
'100 USD = 92.5 EUR (UniRate latest rate)'
```

```python
from langchain.chat_models import init_chat_model
from langgraph.prebuilt import create_react_agent

agent = create_react_agent(
    init_chat_model("openai:gpt-4o-mini"),
    tools=[tool],
)

agent.invoke({"messages": [("user", "How many euros is 250 dollars right now?")]})
```

## API

`UniRateAPIWrapper` exposes:

| Method | Returns | Description |
|---|---|---|
| `get_rate(from_currency="USD", to_currency=None)` | `float` or `dict[str, float]` | Latest rate; if `to_currency` is omitted, returns every supported target. |
| `convert(from_currency, to_currency, amount=1.0)` | `float` | Convert `amount` at the latest rate. |
| `get_supported_currencies()` | `list[str]` | All currency codes UniRate can convert between. |
| `run(from_currency, to_currency, amount=1.0)` | `str` | Agent-friendly formatter wrapping `convert`. |

HTTP errors map to `ValueError` for `401` / `403` / `404` / `429`; other non-2xx responses raise `requests.HTTPError`.
