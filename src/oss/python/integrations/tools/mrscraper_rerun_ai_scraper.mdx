---
title: "MrScraperRerunAIScraper integration"
description: "Rerun existing AI scrapers with MrScraper in LangChain."
---

`MrScraperRerunAIScraper` reruns a previously created AI scraper on another URL.

## Setup

```python
import os
from langchain_mrscraper import MrScraperRerunAIScraper

# Option 1: pass API key directly
tool = MrScraperRerunAIScraper(mrscraper_api_key="your-api-key")

# Option 2: auto-read from environment variable
os.environ["MRSCRAPER_API_KEY"] = "your-api-key"
tool = MrScraperRerunAIScraper()
```

## Invocation

```python
from langchain_mrscraper import MrScraperRerunAIScraper

tool = MrScraperRerunAIScraper(mrscraper_api_key="your-api-key")

result = tool.invoke(
    {
        "scraper_id": "scraper_uuid",
        "url": "https://example.com/page-2",
    }
)
print(result)
```

## Map-mode behavior

The scraper’s **agent type** (`general`, `listing`, or `map`) was set when it was first created. The parameters below adjust **map-style** crawling on this rerun: they matter when that scraper is a **map** scraper; for `general` or `listing` scrapers they are typically unused.

For when to use map vs other agents, see [MrScraperCreateScraper](./mrscraper_create_scraper#choosing-an-agent-type).

## Parameters

| Parameter | Type | Description |
| :-- | :-- | :-- |
| `scraper_id` | `str` | Existing AI scraper ID |
| `url` | `str` | URL to run the scraper against |
| `max_depth` | `int` | **Map only.** Crawl depth from the start URL (default: `2`) |
| `max_pages` | `int` | **Map only.** Max pages to process (default: `50`) |
| `limit` | `int` | **Map only.** Max records extracted across pages (default: `1000`) |
| `include_patterns` | `str` | **Map only.** URL regex patterns to crawl (default: `""`) |
| `exclude_patterns` | `str` | **Map only.** URL regex patterns to skip (default: `""`) |

### Map-mode crawling options

Same semantics as on create; see [Map-mode crawling options](./mrscraper_create_scraper#map-mode-crawling-options) on `MrScraperCreateScraper` for full detail. In short:

- **`max_depth`** — Depth from the starting URL (`0` = start only; each step follows links one level deeper). Prefer **1–2** for focused crawls; **3** is often enough for broad site coverage.
- **`max_pages`** — Total page cap regardless of depth (default **50**; lower for quick runs, higher for wide crawls).
- **`limit`** — Stops after this many extracted records (default **1000**).
- **`include_patterns`** / **`exclude_patterns`** — Regex filters; use **`||`** between patterns. An empty `include_patterns` string includes all URLs (subject to `exclude_patterns`); an empty `exclude_patterns` string excludes nothing by pattern.
