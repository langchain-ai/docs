[TalorData](https://talordata.com/) provides a unified SERP API that lets you query 33 search engines across Google, Bing, Yandex, and DuckDuckGo with geo-targeting, language controls, and engine-specific parameters. This integration is designed for agents that need live web search capabilities.

## Overview

### Integration details

| Class | Package | Serializable | JS support | Version |
| :-- | :-- | :-: | :-: | :-: |
| [`TalorDataSerpTool`](https://pypi.org/project/langchain-talordata/) | [`langchain-talordata`](https://pypi.org/project/langchain-talordata/) | ✅ | ✅ | ![PyPI - Version](https://img.shields.io/pypi/v/langchain-talordata?style=flat-square&label=%20) |

### Tool features

| Native async | Returns artifact | Return data | Pricing |
| :-: | :-: | :-- | :-: |
| ✅ | ❌ | Title, URL, snippet, position, knowledge graph, answer box, AI overview, and other search result data | Requires TalorData account |

## Setup

The integration lives in the `langchain-talordata` package.

```bash
pip install langchain-talordata
```

### Credentials

You'll need a TalorData API key to use this integration. Set it as an environment variable:

```python
import os
os.environ["TALOR_API_KEY"] = "your-api-key"
```

## Instantiation

`TalorDataSerpTool` is the main LangChain-facing entrypoint for this integration.

Use `TalorDataSerpTool.from_env()` in most cases:

```python
import os
from langchain_talordata import TalorDataSerpTool

os.environ["TALOR_API_KEY"] = "your-api-key"

tool = TalorDataSerpTool.from_env()
```

If you want to set default values such as the engine at construction time, you can also use:

```python
from langchain_talordata import TalorDataSerpTool

tool = TalorDataSerpTool.from_api_key(
    api_key="your-api-key",
    engine="google",
)
```

## Invocation

### Basic usage

```python
import os
from langchain_talordata import TalorDataSerpTool

# Set credentials
os.environ["TALOR_API_KEY"] = "your-api-key"

# Initialize the tool
tool = TalorDataSerpTool.from_env()

# Run a basic search
result = tool.invoke({"query": "LangChain tutorial"})
print(result)
```

### Advanced usage with parameters

```python
import os
from langchain_talordata import TalorDataSerpTool

# Set credentials
os.environ["TALOR_API_KEY"] = "your-api-key"

# Initialize the tool
tool = TalorDataSerpTool.from_env()

# Search with engine-specific parameters
result = tool.invoke({
    "query": "best electric vehicles",
    "engine": "google_shopping",
    "params": {
        "gl": "cn",
        "hl": "zh",
    },
})
print(result)
```

### Using different engines

```python
import os
from langchain_talordata import TalorDataSerpTool

os.environ["TALOR_API_KEY"] = "your-api-key"

tool = TalorDataSerpTool.from_env()

# Bing News
result = tool.invoke({"query": "AI news", "engine": "bing_news"})

# Google Scholar
result = tool.invoke({"query": "machine learning", "engine": "google_scholar"})

# Google Patents
result = tool.invoke({
    "engine": "google_patents_details",
    "params": {
        "parent_id": "patent/US11734097B1/en",
        "gl": "us",
        "hl": "en",
    },
})

# DuckDuckGo
result = tool.invoke({"query": "python programming", "engine": "duckduckgo"})

# Yandex
result = tool.invoke({"query": "test", "engine": "yandex"})
```

### Raw JSON results

If you specifically need the original API payload instead of formatted tool output, use `TalorDataSerpAPIWrapper`:

```python
import os
from langchain_talordata import TalorDataSerpAPIWrapper

os.environ["TALOR_API_KEY"] = "your-api-key"

wrapper = TalorDataSerpAPIWrapper()

# Get raw JSON response
result = wrapper.results("LangChain tutorial", engine="google")
print(result["ok"])      # True
print(result["engine"])  # "google"
print(result["data"])    # Full API response data
```

## Customization options

`TalorDataSerpTool.invoke()` accepts the following input shape:

| Parameter | Type | Description |
| :-- | :-- | :-- |
| `query` | str | The search query to perform (optional for some engines) |
| `engine` | str | Search engine key (default: `"google"`) |
| `params` | dict | Engine-specific parameters (country, language, filters, etc.) |

### Common parameters (all engines)

| Parameter | Type | Description |
| :-- | :-- | :-- |
| `gl` | str | Country code for geo-targeting (e.g., `"us"`, `"cn"`) |
| `hl` | str | Interface language (e.g., `"en"`, `"zh"`) |
| `device` | str | `"desktop"` or `"mobile"` |
| `no_cache` | bool | Force fresh results bypassing cache |
| `json` | str | Response format: `"1"` (JSON, default), `"2"` (JSON+HTML), `"3"` (HTML) |

### When to use which class

| Class | Use case |
| :-- | :-- |
| `TalorDataSerpTool` | Recommended for LangChain agents and normal tool invocation |
| `TalorDataSerpAPIWrapper` | Use when you specifically need raw JSON, async methods, history, or statistics |

## Tool features

This integration provides four LangChain tools:

| Tool | Description |
| :-- | :-- |
| `talor_serp_search` | Search the web using any of 33 engines |
| `talor_serp_list_engines` | List all supported engines and their parameters |
| `talor_serp_history` | Query SERP request history with filters |
| `talor_serp_statistics` | Query API usage statistics |

## Use within an agent

```python
import os
from langchain_talordata import TalorDataSerpTool
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain.agents import create_agent

os.environ["TALOR_API_KEY"] = "your-api-key"
os.environ["GOOGLE_API_KEY"] = "your-google-api-key"

# Initialize the LLM
llm = ChatGoogleGenerativeAI(model="gemini-2.5-flash")

# Initialize all TalorData tools
tools = TalorDataSerpTool.tools_from_env()

# Create the agent
agent = create_agent(llm, tools)

# Provide a user query
user_input = "Search for the latest AI research papers on Google Scholar"

# Stream the agent's output step-by-step
for step in agent.stream(
    {"messages": user_input},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```

## Async support

If you need native async methods or low-level JSON responses, use `TalorDataSerpAPIWrapper`:

```python
import asyncio
import os
from langchain_talordata import TalorDataSerpAPIWrapper

async def main():
    os.environ["TALOR_API_KEY"] = "your-api-key"
    wrapper = TalorDataSerpAPIWrapper()

    # Async search
    result = await wrapper.arun("LangChain tutorial")
    print(result)

    # Async raw results
    result = await wrapper.aresults("LangChain tutorial")
    print(result["data"])

asyncio.run(main())
```

## History and statistics

`TalorDataSerpAPIWrapper` also exposes low-level history and statistics endpoints:

```python
import os
from langchain_talordata import TalorDataSerpAPIWrapper

os.environ["TALOR_API_KEY"] = "your-api-key"
wrapper = TalorDataSerpAPIWrapper()

# Query search history
history = wrapper.history(
    page=1,
    page_size=20,
    search_engine="google",
    status="success",
)

# Query usage statistics
stats = wrapper.statistics(
    start_date="2024-01-01",
    end_date="2024-12-31",
    engines="google,bing",
)
```
