This guide provides a quick overview for getting started with the **IgptSearch** tool. For a detailed listing of all IgptSearch features, parameters, and configurations, head to the [IgptSearch API reference](https://docs.igpt.ai/docs/api-reference/search).

**IgptSearch** is a LangChain tool for the **iGPT Personal Data Retrieval (Recall) Search API**.
`IgptSearch` provides **retrieval-only** search over a user’s connected and indexed personal datasources - emails, messages, file attachments, related metadata.
It returns **raw results** (no summarization or generation), making it suitable for auditing, citations, building lists, and downstream pipelines.

### Features

- Retrieval-only search over connected datasources (returns raw results)
- Sync + async support (`invoke`, `ainvoke`)
- Retries with exponential backoff
- Stable, structured metadata in results (useful for citations and filtering)

## Setup

To access the IgptSearch tool, you’ll need iGPT credentials and to install the `langchain-igpt` integration package.

### Credentials

```bash
export IGPT_API_KEY="your-api-key"
export IGPT_API_USER="your-api-user"
```

```python
import getpass
import os

if "IGPT_API_KEY" not in os.environ:
    os.environ["IGPT_API_KEY"] = getpass.getpass("Enter your iGPT API key: ")

if "IGPT_API_USER" not in os.environ:
    os.environ["IGPT_API_USER"] = getpass.getpass("Enter your iGPT API user: ")
```

Alternatively, pass `api_key` and `user` directly to tool constructor.

### Installation

The IgptSearch tool lives in the `langchain-igpt` package:

```python
pip install -U langchain-igpt
```

## Instantiation

Now we can instantiate an instance of the IgptSearch tool with:

```python
from langchain_igpt import IgptSearch

tool = IgptSearch(user="user_123", api_key="ak:...", max_results=25)
```

### Parameters

* `query` (string, optional): Search query to execute.
* `user` (string, optional if set in constructor): Unique user identifier.
* `date_from` (string, optional): Start date filter (`YYYY-MM-DD`).
* `date_to` (string, optional): End date filter (`YYYY-MM-DD`).
* `max_results` (number, optional): Limit number of results (e.g., `50`).

NOTE:
- `query`, `date_from`, and `date_to` are intended to be provided **during invocation**
  (i.e., per-request), not as fixed constructor defaults. This lets the agent
  compute them dynamically (e.g., "last 30 days" -> concrete YYYY-MM-DD dates).
- If you set `user` or `max_results` during invocation, that value will overwrite the value passed during instantiation.

## Invocation

### Invoke directly

```python
res = tool.invoke({"query": "invoices", "date_from":"2025-01-02"})
print(res)
```

Example response:

```json
{
  "id": "...",
  "context": {
    "indexed": 1,
    "datasources": [{...}]
  },
  "results": [
    {
      "id": "...",
      "timestamp": "2025-05-13T11:48:34Z",
      "type": "message",
      "from": "...",
      "content": "..."
    }
  ],
  "durations": {
    "retrieve": 47,
    "resolve": 10
  }
}
```

### Invoke asynchronously

```python
async def main():
    res = await tool.ainvoke({"query": "meeting notes"})
    print(res)
asyncio.run(main())
```

### Invoke with ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in this case, a `ToolMessage` will be returned.

```python
# This is usually generated by a model, but we'll create a `ToolCall` directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "invoices", "date_from":"2025-01-02", "date_to":"2025-01-25"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

## Use within an agent

We can use our tool in an agent. For this we will need a model with tool-calling capabilities.

This example shows how to use the IgptSearch tool inside a LangChain agent.

What happens when you run it:
- The agent receives the user's request: "Find invoices/receipts from the last 30 days."
- The agent uses the LLM (ChatOpenAI) to translate the request into an `IgptSearch` tool call. Typically, the LLM will:
  - set `query` to something like `"invoice OR receipt"`
  - set `date_from` to **today minus 30 days** and `date_to` to **today**, formatted as `YYYY-MM-DD`
- `IgptSearch` queries the user’s connected datasources and returns raw results + metadata.

```python
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI
from langchain_igpt import IgptSearch

search_tool = IgptSearch()
agent = create_agent(
    model=ChatOpenAI(model="gpt-5", api_key="sk-..."),
    tools=[search_tool],
    system_prompt=(
        "You are a research assistant that retrieves user data using the igpt_search tool."
    )
)
response = agent.invoke({
    "messages": [
        {"role": "user", "content": "Find invoices/receipts from the last 30 days."}
    ]
})
print(response)
```
