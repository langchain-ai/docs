[AgentFetch](https://www.agentfetch.dev) is a token-budgeted web fetch service for AI agents. It auto-routes URLs to the cheapest effective fetcher (Trafilatura, Jina Reader, FireCrawl, or pypdf), caches responses for 6 hours, and lets agents estimate token counts *before* fetching so they don't blow their context window. The MCP server is open source (MIT) and the hosted REST API has a free tier (500 fetches/mo, no credit card).

## Overview

AgentFetch provides four LangChain tools:

- **`AgentFetchTool`** (`fetch_url`)—fetch any URL, return clean Markdown with token count + 6h cache. Pass `max_tokens` to cap response size.
- **`EstimateTokensTool`**—predict token count *before* fetching, so agents can skip URLs that won't fit their context window.
- **`FetchMultipleTool`**—fetch up to 20 URLs concurrently with per-result token caps.
- **`SearchAndFetchTool`**—web search + fetch top N results in one round-trip.

All four are bundled as `AgentFetchToolkit` for one-import setup.

### Features

- 🎯 **Token estimation before fetching**—`estimate_tokens` is ~10× cheaper than a full fetch and tells the agent if a URL fits the budget.
- 🗂️ **Server-side `max_tokens` truncation**—the response leaving the API always fits.
- 🔀 **Auto-routing**—picks Trafilatura (free, local) → Jina Reader → FireCrawl (JS) → pypdf (PDFs) based on URL pattern. The agent doesn't pick.
- 📦 **6-hour smart cache**—repeat fetches cost ~$0.0001.
- 📄 **PDF support out of the box**—no separate handling.
- 🌐 **JS-rendered pages**—Twitter/X, Notion, LinkedIn, Reddit work without you choosing a fetcher.

## Setup

To access the AgentFetch tools, you'll need to create an AgentFetch account, get an API key, and install the `langchain-agentfetch` integration package.

### Credentials

Sign up at [agentfetch.dev](https://www.agentfetch.dev)—500 free fetches per month, no credit card required.

```python Set API key icon="key"
import getpass
import os

if "AGENTFETCH_API_KEY" not in os.environ:
    os.environ["AGENTFETCH_API_KEY"] = getpass.getpass("Enter your AgentFetch API key: ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/home) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

You can instantiate any of the four tools individually, or grab all four at once via the toolkit.

### Single tool

```python Initialize tool instance icon="robot"
from langchain_agentfetch import AgentFetchTool

tool = AgentFetchTool()  # picks up AGENTFETCH_API_KEY from env
```

### All four tools (recommended for agents)

```python Initialize toolkit icon="toolbox"
from langchain_agentfetch import AgentFetchToolkit

toolkit = AgentFetchToolkit()
tools = toolkit.get_tools()
# [AgentFetchTool, EstimateTokensTool, FetchMultipleTool, SearchAndFetchTool]
```

## Invocation

### Directly

```python Call tool icon="rocket"
tool.invoke({
    "url": "https://news.ycombinator.com/item?id=39000000",
    "max_tokens": 2000,
})
```

The tool returns clean Markdown of the page, truncated to fit `max_tokens`. The agent gets a string it can reason over directly.

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"url": "https://example.com", "max_tokens": 1000},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### Within an agent

We can use our tool in an agent. For this we will need a model with tool-calling capabilities.

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent
from langchain_agentfetch import AgentFetchToolkit

tools = AgentFetchToolkit().get_tools()
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=tools,
    system_prompt=(
        "You are a research assistant. Use AgentFetch tools to read web pages. "
        "Always estimate tokens before fetching long URLs to stay within budget."
    ),
)

result = agent.invoke({"messages": [
    ("user", "What's the top thread on Hacker News right now? Summarize the discussion."),
]})
```

The agent will:

1. Call `agentfetch_search_and_fetch` or `agentfetch_fetch_url` to retrieve the page.
2. Get back clean, token-truncated Markdown.
3. Reason over it without blowing the context window.

## Why a token-aware fetch tool

LangChain's default tools (like `requests_get`) return raw HTML/JSON with no truncation, no awareness of your context budget, and no caching. That works at toy scale but fails the moment your agent fetches a 50KB news article into a 4K context window.

AgentFetch was built for exactly that case:

- **Pre-fetch token estimation** so the agent can skip a URL it can't afford
- **Server-side `max_tokens` truncation** before the response leaves the API
- **6-hour cache** for repeat fetches (~$0.0001 each)
- **Auto-routing** so the agent doesn't pick between Jina, FireCrawl, and pypdf manually
