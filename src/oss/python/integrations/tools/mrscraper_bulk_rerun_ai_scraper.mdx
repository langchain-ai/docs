---
title: "MrScraperBulkRerunAIScraper integration"
description: "Bulk rerun AI scrapers with MrScraper in LangChain."
---

`MrScraperBulkRerunAIScraper` reruns one AI scraper against multiple URLs in one request.

## Setup

```python
import os
from langchain_mrscraper import MrScraperBulkRerunAIScraper

# Option 1: pass API key directly
tool = MrScraperBulkRerunAIScraper(mrscraper_api_key="your-api-key")

# Option 2: auto-read from environment variable
os.environ["MRSCRAPER_API_KEY"] = "your-api-key"
tool = MrScraperBulkRerunAIScraper()
```

## Invocation

```python
from langchain_mrscraper import MrScraperBulkRerunAIScraper

tool = MrScraperBulkRerunAIScraper(mrscraper_api_key="your-api-key")

result = tool.invoke(
    {
        "scraper_id": "scraper_uuid",
        "urls": [
            "https://example.com/p1",
            "https://example.com/p2",
        ],
    }
)
print(result)
```

## Parameters

| Parameter | Type | Description |
| :-- | :-- | :-- |
| `scraper_id` | `str` | Existing AI scraper ID |
| `urls` | `list[str]` | Target URL list |
