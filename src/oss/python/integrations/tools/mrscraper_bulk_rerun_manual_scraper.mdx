---
title: "MrScraperBulkRerunManualScraper integration"
description: "Bulk rerun manual MrScraper dashboard scrapers in LangChain."
---

`MrScraperBulkRerunManualScraper` reruns one manual scraper against multiple URLs in a batch.

## Setup

```python
import os
from langchain_mrscraper import MrScraperBulkRerunManualScraper

# Option 1: pass API key directly
tool = MrScraperBulkRerunManualScraper(mrscraper_api_key="your-api-key")

# Option 2: auto-read from environment variable
os.environ["MRSCRAPER_API_KEY"] = "your-api-key"
tool = MrScraperBulkRerunManualScraper()
```

## Invocation

```python
from langchain_mrscraper import MrScraperBulkRerunManualScraper

tool = MrScraperBulkRerunManualScraper(mrscraper_api_key="your-api-key")

result = tool.invoke(
    {
        "scraper_id": "scraper_uuid",
        "urls": [
            "https://example.com/item1",
            "https://example.com/item2",
        ],
    }
)
print(result)
```

## Parameters

| Parameter | Type | Description |
| :-- | :-- | :-- |
| `scraper_id` | `str` | Manual scraper ID |
| `urls` | `list[str]` | Target URL list |
