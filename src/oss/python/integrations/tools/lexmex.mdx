This guide provides a quick overview for getting started with the LexMex tool. For a detailed listing of all LexMex features, parameters, and configurations, head to the LexMex API reference.

## Overview

[LEX-MEX](https://lex-mex.xyz) is a Spanish-language legal assistant covering all 316 Mexican federal laws, kept in sync with `diputados.gob.mx`. The tool answers legal questions in Spanish and cites the exact law/article behind each answer.

### Features

- Cites the exact law and article behind every answer (no hallucinated citations)
- Sync (`_run`) and async (`_arun`, requires the `async` extra) support
- Structured input validated with Pydantic (1–2000 character Spanish-language question)
- Clear error messages for invalid keys, insufficient balance, or rate limits

## Setup

To access the LexMex tool, create a human account at [lex-mex.xyz](https://lex-mex.xyz) (Google OAuth), generate an API key (VIP plan or pay-as-you-go credits), and install the `langchain-lexmex` package.

### Credentials

```python
import getpass
import os

if "LEXMEX_API_KEY" not in os.environ:
    os.environ["LEXMEX_API_KEY"] = getpass.getpass("Enter your LexMex API key: ")
```

### Installation

The LexMex tool lives in the `langchain-lexmex` package:

```python pip
pip install -U langchain-lexmex
```
```python uv
uv add langchain-lexmex
```

## Instantiation

```python
from langchain_lexmex import LexMexTool

tool = LexMexTool()
```

## Invocation

### Directly

```python
tool.invoke("¿Cuáles son las causales de despido justificado según la LFT?")
```

### As a ToolCall

```python
model_generated_tool_call = {
    "args": {"pregunta": "¿Qué dice el artículo 47 de la Ley Federal del Trabajo?"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### Within an agent

```python
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent

tools = [tool]
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=tools,
)

agent.invoke(
    {"messages": [{"role": "user", "content": "¿Qué dice el artículo 47 de la LFT?"}]}
)
```
