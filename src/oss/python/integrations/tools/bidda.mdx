[Bidda](https://bidda.com) is a registry of source-verified regulatory and compliance intelligence: 10,000+ obligations across 39 regulated pillars, each traced to a primary legal source with a content hash. The `BiddaComplianceTool` lets a LangChain agent look up what a regulation, law, or standard requires and cite the primary source, instead of relying on the model's own recall.

Bidda content is reference intelligence, not legal advice; the reader draws the legal conclusion.

## Setup

The integration lives in the `langchain-bidda` package.

```python
pip install -qU langchain-bidda
```

### Credentials

No credentials are required for the discovery-tier search this tool uses. To also pull full (gated) node payloads, pass a `skyfire_token` or `base_tx_hash` when constructing the tool.

## Instantiation

Here we show how to instantiate an instance of the tool:

```python
from langchain_bidda import BiddaComplianceTool

tool = BiddaComplianceTool(
    # pillar="ai-governance",  # optional: restrict to one pillar slug
    # max_results=4,           # optional: related node ids to surface
)
```

## Invocation

### Invoke directly with args

```python
print(tool.invoke({"query": "EU AI Act Article 10"}))
```

### Invoke with ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a `ToolMessage` will be returned:

```python
model_generated_tool_call = {
    "args": {"query": "GDPR breach notification deadline"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

## Use within an agent

```python
from langchain.chat_models import init_chat_model
from langchain_bidda import BiddaComplianceTool

llm = init_chat_model("gpt-4o-mini", model_provider="openai")
llm_with_tools = llm.bind_tools([BiddaComplianceTool()])

llm_with_tools.invoke(
    "What does the EU AI Act require for training-data governance? Cite the source."
)
```
