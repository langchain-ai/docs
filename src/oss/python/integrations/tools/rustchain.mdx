This guide shows how to load the [RustChain](https://rustchain.org) read-only tools for LangChain. The `langchain-rustchain-tools` package lets agents query public RustChain data, including network activity, payouts, miners, node health, epoch state, wallet balances, and open bounties.

## Setup

Install the package with the LangChain optional dependency:

```bash
pip install -U "langchain-rustchain-tools[langchain]"
```

No API key, wallet signing, or private credentials are required. The tools call public, read-only RustChain endpoints.

## Load tools

```python
from rustchain_langchain import get_rustchain_tools

tools = get_rustchain_tools()
```

The returned tools can be passed to a LangChain agent or invoked directly.

```python
tool_names = [tool.name for tool in tools]
print(tool_names)
```

## Use a custom RustChain node

Pass a base URL when you want to point the tools at another RustChain node:

```python
from rustchain_langchain import get_rustchain_tools

tools = get_rustchain_tools(base_url="https://rustchain.org")
```

For self-signed development nodes, disable TLS verification only when you control the endpoint:

```python
tools = get_rustchain_tools(base_url="https://50.28.86.131", verify=False)
```
