[Hlido](https://hlido.eu) publishes independent, evidence-backed reviews of AI agents — a score, a tier, and a verified audit of every marketing claim. The `hlido-trust` package provides LangChain tools that let an agent vet other agents or tools against those reviews **before** delegating work to them.

Both tools call the **public** Hlido API, so **no API key is required**.

## Overview

### Integration details

| Class | Package | Serializable | [JS support](https://js.langchain.com) | Version |
|:------|:--------| :---: | :---: | :---: |
| `hlido_langchain_tools` | [`hlido-trust`](https://pypi.org/project/hlido-trust/) | ❌ | ❌ | ![PyPI - Version](https://img.shields.io/pypi/v/hlido-trust?style=flat-square&label=%20) |

### Available tools

| Tool | Description |
|:-----|:------------|
| `hlido_trust_check` | Verdict for a known agent slug — score, tier, PASS/FAIL gate, strengths, red flags |
| `hlido_recommend` | Find a Hlido-reviewed agent for a free-text need, ranked by trust score |

## Setup

### Credentials

No credentials are required — the Hlido tools use the public Hlido API.

It's helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls:

```python Enable tracing icon="flask"
import getpass
import os

os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The Hlido LangChain tools live in the `hlido-trust` package (with the `langchain` extra):

<CodeGroup>
    ```python pip
    pip install -U "hlido-trust[langchain]"
    ```
    ```python uv
    uv add "hlido-trust[langchain]"
    ```
</CodeGroup>

## Instantiation

`hlido_langchain_tools()` returns both Hlido tools as LangChain `StructuredTool`s:

```python Initialize tools icon="robot"
from hlido_trust.langchain_tool import hlido_langchain_tools

tools = hlido_langchain_tools()
trust_check, recommend = tools
```

---

## Invocation

### Directly

`hlido_trust_check` takes an agent `slug` and an optional `min_score` (default `70.0`) and returns a JSON string with the score, tier, and a PASS/FAIL gate:

```python Call tool icon="rocket"
trust_check.invoke({"slug": "aider", "min_score": 70})
```

`hlido_recommend` takes a free-text `need` and returns matching reviewed agents ranked by score:

```python Call tool icon="rocket"
recommend.invoke({"need": "AI coding agent"})
```

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"slug": "aider", "min_score": 70},
    "id": "1",
    "name": trust_check.name,
    "type": "tool_call",
}
trust_check.invoke(model_generated_tool_call)
```

### Within an agent

We can give the Hlido tools to an agent so it vets a collaborator before relying on it:

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=hlido_langchain_tools(),
)

agent.invoke(
    {
        "messages": [
            {
                "role": "user",
                "content": "Find a reliable AI coding agent with Hlido and confirm it passes a trust check at min_score 70.",
            }
        ]
    }
)
```
