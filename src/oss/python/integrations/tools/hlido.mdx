This guide provides a quick overview for getting started with the [Hlido](https://hlido.eu) tools. [Hlido](https://hlido.eu) publishes independent, evidence-backed trust scores for AI agents, so a LangChain agent can vet another agent or tool *before delegating to it*. For a full listing of features and the API, head to the [Hlido API reference](https://hlido.eu/api/).

## Overview

### Details

| Class | Package | Serializable | JS support | Version |
| :--- | :--- | :---: | :---: | :---: |
| `hlido_trust_check`, `hlido_recommend` | [hlido-langchain](https://pypi.org/project/hlido-langchain/) | ❌ | ❌ | ![PyPI - Version](https://img.shields.io/pypi/v/hlido-langchain?style=flat-square&label=%20) |

### Features

- **`hlido_trust_check`** — vet an agent by its Hlido slug; returns a `PASS`/`FAIL` trust gate plus score, tier, what it fails at, red flags, and an evidence URL. Fails closed for unreviewed or red-flagged agents.
- **`hlido_recommend`** — given a free-text need, return Hlido-vetted agents ranked by an independent trust score, with evidence URLs.

Hlido is independent (it doesn't take money to rank anyone), evidence-backed, longitudinal (agents are re-tested over time), and machine-readable.

## Setup

The Hlido tools live in the `hlido-langchain` package.

### Credentials

No API key is required for trust checks. Optionally, set a Hlido API key (a `hlk_live_*` key from [hlido.eu/api](https://hlido.eu/api/)) to unlock top-k recommendations:

```python Set API key icon="key"
import getpass
import os

# Optional — only needed for top-k recommendations, not for trust checks.
if "HLIDO_API_KEY" not in os.environ:
    os.environ["HLIDO_API_KEY"] = getpass.getpass("Enter your Hlido API key (optional): ")
```

It's also helpful (but not needed) to set up LangSmith for best-in-class observability/<Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your tool calls. To enable automated tracing, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The Hlido tools live in the `hlido-langchain` package:

## Instantiation

`get_tools()` returns the Hlido LangChain tools:

```python Initialize tools icon="robot"
from hlido_langchain import get_tools

tools = get_tools()  # [hlido_trust_check, hlido_recommend]
trust_check = next(t for t in tools if t.name == "hlido_trust_check")
```

---

## Invocation

### Directly

`hlido_trust_check` takes an agent `slug` and an optional `min_score` (default `70`):

```python Call tool icon="rocket"
trust_check.invoke({"slug": "aider", "min_score": 70})
```

```output
[PASS @ min_score=70] Aider — VITAL (92/100), confidence high. Evidence: https://hlido.eu/reviews/aider/
```

### As a ToolCall

We can also invoke the tool with a model-generated `ToolCall`, in which case a @[`ToolMessage`] will be returned:

```python ToolCall icon="briefcase"
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"slug": "aider", "min_score": 70},
    "id": "1",
    "name": trust_check.name,
    "type": "tool_call",
}
trust_check.invoke(model_generated_tool_call)
```

### Within an agent

We can use the Hlido tools in an agent so it vets a candidate before delegating to it. For this we need a model with tool-calling capabilities.

```python Agent with tool icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=get_tools(),
    system_prompt="Never delegate to an AI agent unless its Hlido trust check PASSES (min_score 70).",
)

agent.invoke(
    {"messages": [{"role": "user", "content": "Find a reliable AI coding agent and confirm it passes the Hlido trust gate before we use it."}]}
)
```
