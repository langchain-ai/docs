This guide provides a quick overview for getting started with x402, the HTTP-native payment protocol that implements the `402 Payment Required` status code.

You can read more about `langchain-x402` on the project's [PyPI page](https://pypi.org/project/langchain-x402/) or [GitHub repository](https://github.com/kmatthewsio/langchain-x402). For protocol details, see [x402.org](https://x402.org).

## Overview

x402 enables software to pay software—per request, in USDC, with cryptographic proof. Instead of API keys and monthly subscriptions, agents pay only for what they use.

## Setup

Install the package with `pip`:

```bash
pip install --quiet -U langchain-x402
```

### Credentials

You'll need a wallet private key for signing USDC payment authorizations:

```python
import getpass
import os

if not os.environ.get("WALLET_PRIVATE_KEY"):
    os.environ["WALLET_PRIVATE_KEY"] = getpass.getpass("Wallet private key:\n")
```

You'll also need USDC balance on a supported network (Base, Ethereum, or testnets).

It's also helpful (but not needed) to set up [LangSmith](https://smith.langchain.com/) for best-in-class observability:

```python
os.environ["LANGSMITH_TRACING"] = "true"
# os.environ["LANGSMITH_API_KEY"] = getpass.getpass()
```

## Instantiation

Create a wallet with a spending budget and wrap it in the payment tool:

```python
from langchain_x402 import X402Wallet, X402PaymentTool

wallet = X402Wallet(
    private_key=os.environ["WALLET_PRIVATE_KEY"],
    network="base-mainnet",
    budget_usd=10.00  # Agent can't spend more than $10
)

tool = X402PaymentTool(wallet=wallet)
```

## Agent

Here's how to use the tool to create an agent that can access any x402-enabled API:

```python
from langchain_anthropic import ChatAnthropic
from langgraph.prebuilt import create_react_agent

model = ChatAnthropic(model="claude-sonnet-4-20250514")

agent = create_react_agent(model, tools=[tool])

result = agent.invoke({
    "messages": [
        {
            "role": "user",
            "content": "Get the sentiment analysis from https://api.example.com/analyze?text=hello"
        }
    ]
})

print(result["messages"][-1].content)
```

## How it works

1. Agent requests a resource using the tool
2. If the server returns `402 Payment Required`, the tool reads the payment requirements
3. Tool signs a USDC payment authorization (EIP-3009)
4. Tool retries the request with the signed payment
5. Server settles on-chain and returns the data

All of this happens automatically in a single tool invocation.

## Budget controls

Check remaining budget and spending history:

```python
# Check remaining budget
print(f"Remaining: ${wallet.remaining_usd}")

# Get spending summary
summary = wallet.get_payment_summary()
print(f"Total spent: ${summary['spent_usd']}")
print(f"Payments made: {summary['payment_count']}")
```

Set per-request price limits:

```python
result = tool.invoke({
    "url": "https://api.example.com/expensive",
    "max_price_usd": 0.05  # Won't pay more than $0.05
})
```
