This page demonstrates how to use `SulciCache` from the `sulci` package to implement
context-aware semantic caching for LLM responses in LangChain.

Unlike stateless semantic caches, Sulci Cache blends prior conversation turns into the
similarity lookup vector at query time — so ambiguous follow-ups like "What are the main
differences?" resolve correctly based on conversation history, not just the current prompt.

## Setup

Install Sulci Cache with the LangChain extra:

```python
pip install "sulci[sqlite,langchain]"
```

No external infrastructure required — the default SQLite backend runs entirely locally.
For production, swap to `chroma`, `qdrant`, `faiss`, `redis`, or `milvus`.

## Importing required libraries

```python
import time
from langchain.globals import set_llm_cache
from langchain_openai import OpenAI
from sulci.integrations.langchain import SulciCache
```

## Stateless semantic caching

Drop-in replacement for any LangChain cache. Semantically similar queries
("What is the capital of France?" and "What's France's capital city?") return
the same cached answer.

```python
# Initialize SulciCache — SQLite backend, zero infra
set_llm_cache(SulciCache(backend="sqlite", threshold=0.85))

llm = OpenAI(temperature=0)

def timed_completion(prompt):
    start = time.time()
    result = llm.invoke(prompt)
    return result, time.time() - start

# First call — not cached
prompt = "What is the capital of France?"
result1, time1 = timed_completion(prompt)
print(f"First call (not cached):\nResult: {result1}\nTime: {time1:.2f}s\n")

# Semantically similar query — cache hit
similar = "Can you tell me the capital city of France?"
result2, time2 = timed_completion(similar)
print(f"Similar query (cached):\nResult: {result2}\nTime: {time2:.2f}s\n")

print(f"Speed improvement: {time1 / time2:.2f}x faster")
```

```text
First call (not cached):
Result: The capital of France is Paris.
Time: 1.84s

Similar query (cached):
Result: The capital of France is Paris.
Time: 0.00074s

Speed improvement: 2486x faster
```

## Context-aware caching

Stateless caches fail on multi-turn conversations. A follow-up like
"What are the main differences?" is semantically ambiguous in isolation —
the cache has nothing to anchor it against.

Sulci Cache fixes this by blending prior turn embeddings into the lookup vector:

```
lookup_vec = α · embed(query) + (1−α) · Σ(decay^i · turn_i)
```

- `α = 0.70` — current query dominates
- `decay = 0.50` — each older turn gets half the weight
- Raw unblended vectors stored in cache; blending happens at lookup time only

```python
# Context-aware mode — remember last 4 turns per session
set_llm_cache(SulciCache(
    backend  = "sqlite",
    threshold      = 0.75,   # lower threshold — blended vector is richer
    context_window = 4,      # turns to remember
    query_weight   = 0.70,   # α
    context_decay  = 0.50,   # decay per older turn
))

llm = OpenAI(temperature=0)

# Turn 1 — establishes context
prompt1 = "Tell me about Python programming language."
result1, time1 = timed_completion(prompt1)
print(f"Turn 1:\nResult: {result1[:80]}...\nTime: {time1:.2f}s\n")

# Turn 2 — ambiguous follow-up, resolved via context
prompt2 = "What are the main differences?"
result2, time2 = timed_completion(prompt2)
print(f"Turn 2 (context-aware hit):\nResult: {result2[:80]}...\nTime: {time2:.4f}s\n")

print(f"Speed improvement: {time1 / time2:.2f}x faster")
```

```text
Turn 1:
Result: Python is a high-level, interpreted programming language known for its...
Time: 1.84s

Turn 2 (context-aware hit):
Result: Python differs from other languages in its use of indentation, dynamic...
Time: 0.00074s

Speed improvement: 2486x faster
```
