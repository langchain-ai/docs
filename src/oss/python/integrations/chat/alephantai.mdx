This guide helps you get started with Alephant AI [chat models](/oss/langchain/models). Alephant AI provides an OpenAI-compatible gateway for routing model requests, attaching session metadata, and attributing usage and cost analytics.

The `alephantai` Python package includes a LangChain helper that returns a standard `ChatOpenAI` instance configured to send requests through Alephant Gateway with Alephant session headers.

## Setup

To access models through Alephant Gateway, create an Alephant Virtual Key and install the `alephantai` package with LangChain support.

### Credentials

Set your Alephant Virtual Key as the `ALEPHANT_API_KEY` environment variable:

```python
import getpass
import os

if not os.getenv("ALEPHANT_API_KEY"):
    os.environ["ALEPHANT_API_KEY"] = getpass.getpass("Enter your Alephant API key: ")
```

To enable automated tracing of your model calls, set your [LangSmith](/langsmith/home) API key:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

Install the `alephantai` package with LangChain support:

<CodeGroup>
    ```bash pip
    pip install -U "alephantai[langchain]"
    ```
    ```bash uv
    uv add "alephantai[langchain]"
    ```
</CodeGroup>

## Instantiation

Instantiate a chat model with an Alephant gateway context:

```python
import os

from alephantai import AlephantGatewayContext
from alephantai.langchain import create_chat_openai

ctx = AlephantGatewayContext(session_name="langchain-chat")

llm = create_chat_openai(
    api_key=os.environ["ALEPHANT_API_KEY"],
    model="gpt-4o-mini",
    context=ctx,
    temperature=0,
    timeout=30,
)
```

`create_chat_openai` accepts additional keyword arguments supported by `langchain_openai.ChatOpenAI`, such as `temperature`, `timeout`, and `max_retries`.

## Invocation

```python
messages = [
    ("system", "You are a helpful assistant that writes concise product copy."),
    ("human", "Write a one-line product tagline for LLM observability."),
]
ai_msg = llm.invoke(messages)
ai_msg
```

```python
print(ai_msg.content)
```

## Session attribution

Alephant session metadata is attached through gateway request headers. The SDK generates an `Alephant-Session-Id` by default and can include an explicit session name for analytics grouping.

```python
from alephantai import AlephantGatewayContext

ctx = AlephantGatewayContext(session_name="customer-support-eval")
```

SDK v1 guarantees session-level request and cost attribution. It does not convert LangChain's internal run tree into Alephant journey steps.

## Custom gateway URL

The production Alephant Gateway base URL is `https://ai.alephant.io/v1`. Use `base_url` when testing against another gateway environment.

```python
llm = create_chat_openai(
    api_key=os.environ["ALEPHANT_API_KEY"],
    model="gpt-4o-mini",
    context=ctx,
    base_url="https://ai.alephant.io/v1",
)
```
