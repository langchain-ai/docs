`ChatDiffbot` wraps [Diffbot's LLM RAG endpoint](https://github.com/diffbot/diffbot-llm-inference), which answers questions by grounding responses in the Diffbot Knowledge Graph and the live web. It supports native token-level streaming.

See the [Diffbot provider page](/oss/integrations/providers/diffbot) for installation and authentication setup. For complete runnable examples, see the [`examples/`](https://github.com/diffbot/langchain-diffbot/tree/main/examples) folder in the langchain-diffbot repository.

## Setup

### Credentials

Get an API token at [app.diffbot.com/get-started](https://app.diffbot.com/get-started/), then set it as an environment variable:

```python
import os

os.environ["DIFFBOT_API_TOKEN"] = "your-api-token"
```

### Installation

```bash
pip install langchain-diffbot
```

## Instantiation

`ChatDiffbot` takes a pre-built `diffbot.Diffbot` client:

```python
import os

from diffbot import Diffbot
from langchain_diffbot import ChatDiffbot

llm = ChatDiffbot(client=Diffbot(token=os.environ["DIFFBOT_API_TOKEN"]))
```

## Invocation

```python
from langchain.messages import HumanMessage

response = llm.invoke([HumanMessage(content="What is the Diffbot Knowledge Graph?")])
print(response.content)
```

## Streaming

```python
for chunk in llm.stream([HumanMessage(content="What companies are working on AI in Boston?")]):
    print(chunk.content, end="", flush=True)
```

## Chaining

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages([
    ("system", "Answer concisely using grounded facts."),
    ("human", "{question}"),
])

chain = prompt | llm
response = chain.invoke({"question": "Who founded Diffbot, and when?"})
print(response.content)
```
