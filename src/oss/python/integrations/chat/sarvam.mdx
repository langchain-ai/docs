[Sarvam AI](https://www.sarvam.ai) is India's sovereign AI platform built for Indian languages. The `langchain-sarvamcloud` package provides LangChain integrations for Sarvam's full suite of AI services—chat completions, speech-to-text, text-to-speech, translation, transliteration, language detection, and document intelligence—all with native support for 22+ Indian languages.

Get your API key from [dashboard.sarvam.ai](https://dashboard.sarvam.ai).

<Tip>

    For detailed documentation of all features and configuration options, head to the @[`ChatSarvam`] API reference.
</Tip>

## Setup

### Installation

<CodeGroup>
    ```bash pip
    pip install -U langchain-sarvamcloud
    ```
    ```bash uv
    uv add langchain-sarvamcloud
    ```
</CodeGroup>

### Credentials

Head to [dashboard.sarvam.ai](https://dashboard.sarvam.ai) to sign up and generate an API key. Once you've done this, set the `SARVAM_API_KEY` environment variable:

```python
import getpass
import os

if "SARVAM_API_KEY" not in os.environ:
    os.environ["SARVAM_API_KEY"] = getpass.getpass("Enter your Sarvam API key: ")
```

To enable automated tracing of your model calls, set your [LangSmith](/langsmith/home) API key:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

```python
from langchain_sarvamcloud import ChatSarvam

model = ChatSarvam(
    model="sarvam-105b",       # See available models below
    temperature=0.2,            # Sarvam default is 0.2
    # top_p=1.0,
    # max_tokens=None,
    # reasoning_effort="medium",  # "low", "medium", "high" — sarvam-105b and sarvam-30b only
    # max_retries=2,
)
```

### Available models

All Sarvam models are **free to use** — no per-token cost.

| Model | Context window | Tool calling | Notes |
| :--- | :---: | :---: | :--- |
| `sarvam-105b` | 128,000 tokens | ✅ | Flagship model, default |
| `sarvam-105b-32k` | 32,000 tokens | ✅ | Short-context variant |
| `sarvam-30b` | 32,000 tokens | ✅ | Balanced speed and quality |
| `sarvam-30b-16k` | 16,000 tokens | ✅ | Short-context variant |
| `sarvam-m` | 8,192 tokens | ❌ | Legacy model |

## Tool calling

Tool calling is supported on `sarvam-105b` and `sarvam-30b`. Use `bind_tools` to attach tools to the model:

```python
from langchain.tools import tool
from langchain_sarvamcloud import ChatSarvam

@tool
def get_weather(city: str) -> str:
    """Get the current weather for a city."""
    return f"The weather in {city} is sunny and 28°C."

model = ChatSarvam(model="sarvam-105b")
model_with_tools = model.bind_tools([get_weather])

response = model_with_tools.invoke("What is the weather in Mumbai?")
print(response.tool_calls)
# [{'name': 'get_weather', 'args': {'city': 'Mumbai'}, 'id': '...'}]
```

## Structured output

Use `with_structured_output` with a Pydantic model to extract structured data:

```python
from pydantic import BaseModel
from langchain_sarvamcloud import ChatSarvam

class PersonInfo(BaseModel):
    name: str
    age: int
    city: str

model = ChatSarvam(model="sarvam-105b")
structured_model = model.with_structured_output(PersonInfo)

result = structured_model.invoke("Ravi is 28 years old and lives in Chennai.")
print(result.name)   # Ravi
print(result.age)    # 28
print(result.city)   # Chennai
```

## Reasoning effort

`sarvam-105b` and `sarvam-30b` support a `reasoning_effort` parameter that controls how deeply the model thinks before responding. Use `"high"` for complex tasks and `"low"` for fast, simple responses:

```python
from langchain_sarvamcloud import ChatSarvam

# Deep reasoning for complex tasks
model = ChatSarvam(model="sarvam-105b", reasoning_effort="high")
response = model.invoke("Explain the differences between transformers and RNNs in Tamil.")
print(response.content)

# Fast responses for simple queries
model = ChatSarvam(model="sarvam-105b", reasoning_effort="low")
response = model.invoke("What is the capital of India?")
print(response.content)
```

Accepted values: `"low"`, `"medium"`, `"high"`.

## Indian language support

All Sarvam models are optimized for Indian languages. Pass messages in any supported language and the model responds in kind:

```python
from langchain_sarvamcloud import ChatSarvam

model = ChatSarvam(model="sarvam-105b")

# Tamil
response = model.invoke("தமிழில் ஒரு கவிதை எழுதுங்கள்.")
print(response.content)

# Telugu
response = model.invoke("తెలుగులో నమస్కారం చెప్పండి.")
print(response.content)
```

## Other Sarvam components

The `langchain-sarvamcloud` package includes additional components beyond the chat model.

<AccordionGroup>
    <Accordion title="Speech-to-text — SarvamSTT">
        Transcribe audio files into text. Supports 23 languages, multiple transcription modes, and formats including WAV, MP3, OGG, FLAC, and MP4. Maximum 30 seconds per file — use `SarvamBatchSTT` for longer audio.

        **Transcription modes:** `transcribe` (default), `translate` (to English), `verbatim`, `translit` (romanize), `codemix`

        ```python
        from langchain_sarvamcloud import SarvamSTT

        stt = SarvamSTT(model="saaras:v3", mode="transcribe")

        with open("audio.wav", "rb") as f:
            result = stt.transcribe(f, language_code="hi-IN")

        print(result["transcript"])            # Transcribed text
        print(result["language_code"])         # Detected language
        print(result["language_probability"])  # Confidence score
        ```

        Translate speech directly to English:

        ```python
        stt = SarvamSTT(model="saaras:v3", mode="translate")

        with open("hindi_audio.wav", "rb") as f:
            result = stt.transcribe(f)  # Language auto-detected

        print(result["transcript"])  # English translation
        ```
    </Accordion>
    <Accordion title="Batch speech-to-text — SarvamBatchSTT">
        Process multiple long audio files asynchronously. Supports up to 1 hour per file, up to 20 files per job, and speaker diarization.

        ```python
        import httpx
        from langchain_sarvamcloud import SarvamBatchSTT

        batch = SarvamBatchSTT()

        # Create a job
        job_id = batch.create_job(
            model="saaras:v3",
            mode="transcribe",
            language_code="hi-IN",
            with_diarization=True,
            num_speakers=2,
        )

        # Get signed upload URLs and upload files
        filenames = ["part1.mp3", "part2.mp3"]
        upload_urls = batch.get_upload_urls(job_id, filenames)
        for filename, url_info in upload_urls.items():
            with open(filename, "rb") as f:
                httpx.put(url_info["url"], content=f.read())

        # Start and wait for completion
        batch.start_job(job_id)
        status = batch.wait_for_completion(job_id)

        if status["job_state"] == "Completed":
            for detail in status["job_details"]:
                print(f"{detail['file']}: {detail['output']}")
        ```
    </Accordion>
    <Accordion title="Text-to-speech — SarvamTTS">
        Convert text to natural-sounding speech in 11 Indian languages with 30+ voice options. Maximum 2500 characters per request.

        **Supported languages:** `hi-IN`, `en-IN`, `ta-IN`, `te-IN`, `kn-IN`, `ml-IN`, `mr-IN`, `gu-IN`, `pa-IN`, `bn-IN`, `od-IN`

        ```python
        from langchain_sarvamcloud import SarvamTTS

        tts = SarvamTTS(speaker="shubh", pace=1.0)

        audio_bytes = tts.synthesize_to_bytes(
            "नमस्ते! मैं सर्वम AI हूँ।",
            target_language_code="hi-IN",
        )

        with open("output.wav", "wb") as f:
            f.write(audio_bytes)
        ```

        Override speaker per call:

        ```python
        audio = tts.synthesize_to_bytes(
            "Hello, how are you?",
            target_language_code="en-IN",
            speaker="amelia",
            pace=1.2,
        )
        ```

        Available speakers include: `anushka`, `abhilash`, `manisha`, `karun`, `aditya`, `ritu`, `shubh`, `amelia`, and 20+ more.
    </Accordion>
    <Accordion title="Translation — SarvamTranslator">
        Translate text between 22 Indian languages with style controls including formal, colloquial, and code-mixed output.

        ```python
        from langchain_sarvamcloud import SarvamTranslator

        translator = SarvamTranslator(model="sarvam-translate:v1")

        result = translator.translate(
            "Hello, how are you?",
            source_language_code="en-IN",
            target_language_code="hi-IN",
            mode="formal",
        )
        print(result["translated_text"])  # नमस्ते, आप कैसे हैं?
        ```

        **Translation modes:** `formal` (default), `modern-colloquial`, `classic-colloquial`, `code-mixed`

        Code-mixed output (Hinglish):

        ```python
        result = translator.translate(
            "I am going to the market to buy vegetables.",
            source_language_code="en-IN",
            target_language_code="hi-IN",
            mode="code-mixed",
        )
        print(result["translated_text"])
        # Main market जा रहा हूँ vegetables buy करने के लिए।
        ```

        Auto-detect source language with `mayura:v1`:

        ```python
        translator = SarvamTranslator(model="mayura:v1")
        result = translator.translate(
            "நான் சென்னையில் வசிக்கிறேன்",
            source_language_code="auto",
            target_language_code="en-IN",
        )
        print(result["translated_text"])  # I live in Chennai
        ```
    </Accordion>
    <Accordion title="Transliteration — SarvamTransliterator">
        Convert text between scripts without changing language — for example, write Hindi in Roman letters, or write English words in Devanagari.

        <Note>
            This is not translation. Transliteration preserves pronunciation, not meaning. Indic-to-Indic transliteration (e.g. Hindi → Bengali script) is not supported — one language must be `en-IN`. Use `SarvamTranslator` for cross-language conversion.
        </Note>

        ```python
        from langchain_sarvamcloud import SarvamTransliterator

        tl = SarvamTransliterator()

        # Devanagari → Roman
        result = tl.transliterate(
            "नमस्ते, आप कैसे हैं?",
            source_language_code="hi-IN",
            target_language_code="en-IN",
        )
        print(result["transliterated_text"])  # namaste, aap kaise hain?

        # Roman → Telugu script
        result = tl.transliterate(
            "namaskaram",
            source_language_code="en-IN",
            target_language_code="te-IN",
        )
        print(result["transliterated_text"])  # నమస్కారం
        ```

        **Supported languages:** `bn-IN`, `en-IN`, `gu-IN`, `hi-IN`, `kn-IN`, `ml-IN`, `mr-IN`, `od-IN`, `pa-IN`, `ta-IN`, `te-IN`
    </Accordion>
    <Accordion title="Language detection — SarvamLanguageDetector">
        Identify the language and writing script of input text with a confidence score. Maximum 1000 characters per request.

        ```python
        from langchain_sarvamcloud import SarvamLanguageDetector

        detector = SarvamLanguageDetector()

        result = detector.detect("నమస్కారం, మీరు ఎలా ఉన్నారు?")

        print(result["language_code"])  # te-IN
        print(result["script_code"])    # Telu
        print(result["confidence"])     # e.g. 0.97
        ```

        **Supported languages:** `en-IN`, `hi-IN`, `bn-IN`, `gu-IN`, `kn-IN`, `ml-IN`, `mr-IN`, `od-IN`, `pa-IN`, `ta-IN`, `te-IN`
    </Accordion>
    <Accordion title="Document intelligence — SarvamDocumentIntelligence">
        Digitize PDF documents, images, and ZIP archives using Sarvam's vision model. Extracts text with layout preservation, table detection, and reading order. Returns LangChain `Document` objects.

        **Limits:** Max 500 pages, 200 MB per file. Input formats: PDF, PNG, JPEG, ZIP.

        **Output formats:** `md` (Markdown, best for LLM/RAG), `html` (layout-preserving), `json` (structured with bounding boxes)

        ```python
        from langchain_sarvamcloud import SarvamDocumentIntelligence

        loader = SarvamDocumentIntelligence(
            file_paths=["document.pdf"],
            language="hi-IN",
            output_format="md",
        )

        docs = loader.load()  # Returns list of LangChain Document objects

        for doc in docs:
            print(f"Source: {doc.metadata['source']}")
            print(doc.page_content[:500])
        ```

        Use with a RAG pipeline:

        ```python
        from langchain_sarvamcloud import SarvamDocumentIntelligence
        from langchain_text_splitters import RecursiveCharacterTextSplitter

        loader = SarvamDocumentIntelligence(
            file_paths=["hindi_report.pdf"],
            language="hi-IN",
            output_format="md",
        )
        docs = loader.load()

        splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=100)
        chunks = splitter.split_documents(docs)
        ```

        **Supported languages for OCR:** All 22+ Indian languages listed above.
    </Accordion>
