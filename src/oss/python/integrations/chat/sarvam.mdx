## Setup

To access Sarvam models you'll need to install the `langchain-sarvamcloud` integration package and acquire a Sarvam API key.

### Installation

<CodeGroup>
    ```bash pip
    pip install -U langchain-sarvamcloud
    ```
    ```bash uv
    uv add langchain-sarvamcloud
    ```
</CodeGroup>

### Credentials

Head to [dashboard.sarvam.ai](https://dashboard.sarvam.ai) to sign up and generate an API key. Once you've done this, set the `SARVAM_API_KEY` environment variable:

```python
import getpass
import os

if "SARVAM_API_KEY" not in os.environ:
    os.environ["SARVAM_API_KEY"] = getpass.getpass("Enter your Sarvam API key: ")
```

To enable automated tracing of your model calls, set your [LangSmith](/langsmith/home) API key:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

Now we can instantiate our model object and generate chat completions:

```python
from langchain_sarvamcloud import ChatSarvam

model = ChatSarvam(
    model="sarvam-105b",
    temperature=0.2,
    # max_tokens=None,
    # top_p=1.0,
    # reasoning_effort="medium",  # "low", "medium", or "high"
    # ...
)
```

See the @[`ChatSarvam`] API reference for details on all available instantiation parameters.

## Tool calling

`ChatSarvam` supports tool calling via `bind_tools` on `sarvam-105b` and `sarvam-30b` models:

```python
from langchain.tools import tool
from langchain_sarvamcloud import ChatSarvam

@tool
def get_weather(city: str) -> str:
    """Get the current weather for a city."""
    return f"The weather in {city} is sunny and 28°C."

model = ChatSarvam(model="sarvam-105b")
model_with_tools = model.bind_tools([get_weather])

response = model_with_tools.invoke([("human", "What is the weather in Mumbai?")])
print(response.tool_calls)
```

## Structured output

Use `with_structured_output` to extract structured data from model responses:

```python
from pydantic import BaseModel
from langchain_sarvamcloud import ChatSarvam

class PersonInfo(BaseModel):
    name: str
    age: int
    city: str

model = ChatSarvam(model="sarvam-105b")
structured_model = model.with_structured_output(PersonInfo)

result = structured_model.invoke("Ravi is 28 years old and lives in Chennai")
print(result.name)   # Ravi
print(result.age)    # 28
print(result.city)   # Chennai
```

## Reasoning effort

`sarvam-105b` and `sarvam-30b` support a `reasoning_effort` parameter that controls how much the model thinks before responding:

```python
from langchain_sarvamcloud import ChatSarvam

# For complex tasks
model = ChatSarvam(model="sarvam-105b", reasoning_effort="high")
response = model.invoke("Explain the differences between transformers and RNNs in Tamil.")

# For fast, simple responses
model = ChatSarvam(model="sarvam-105b", reasoning_effort="low")
response = model.invoke("What is the capital of India?")
```

## Indian language support

Sarvam models support 22+ Indian languages. Pass messages in any supported language and the model responds accordingly:

```python
from langchain_sarvamcloud import ChatSarvam

model = ChatSarvam(model="sarvam-105b")
response = model.invoke([("human", "தமிழில் ஒரு கவிதை எழுதுங்கள்.")])
print(response.content)
```
