## Setup

To access Sarvam models you'll need to install the `langchain-sarvamcloud` integration package and acquire a Sarvam API key.

### Installation

<CodeGroup>
    ```bash pip
    pip install -U langchain-sarvamcloud
    ```
    ```bash uv
    uv add langchain-sarvamcloud
    ```
</CodeGroup>

### Credentials

Head to the [Sarvam AI portal](https://portal.sarvam.ai) to sign up and generate an API key. Once you've done this, set the `SARVAM_API_KEY` environment variable:

```python
import getpass
import os

if "SARVAM_API_KEY" not in os.environ:
    os.environ["SARVAM_API_KEY"] = getpass.getpass("Enter your Sarvam API key: ")
```

To enable automated tracing of your model calls, set your [LangSmith](/langsmith/home) API key:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

Now we can instantiate our model object and generate chat completions:

```python
from langchain_sarvamcloud import ChatSarvam

model = ChatSarvam(
    model="sarvam-m",
    # temperature=0.7,
    # max_tokens=4096,
    # top_p=0.95,
    # stop=None,
    # ...
)
```

See the @[`ChatSarvam`] API reference for details on all available instantiation parameters.

## Tool calling

`ChatSarvam` supports tool calling via `bind_tools`:

```python
from langchain_core.tools import tool

@tool
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b

model_with_tools = model.bind_tools([add])
response = model_with_tools.invoke([("human", "What is 3 + 5?")])
print(response.tool_calls)
```

## Indian language support

Sarvam models are optimized for Indian languages. The `sarvam-m` model supports 22+ languages including:

| Language | Code |
| :--- | :--- |
| Hindi | `hi` |
| Bengali | `bn` |
| Gujarati | `gu` |
| Kannada | `kn` |
| Malayalam | `ml` |
| Marathi | `mr` |
| Punjabi | `pa` |
| Tamil | `ta` |
| Telugu | `te` |
| Urdu | `ur` |
| Odia | `or` |
| Assamese | `as` |

Pass messages in any supported language and the model will respond accordingly:

```python
from langchain_sarvamcloud import ChatSarvam

model = ChatSarvam(model="sarvam-m")
response = model.invoke([("human", "தமிழில் ஒரு கவிதை எழுதுங்கள்.")])
print(response.text)
```
