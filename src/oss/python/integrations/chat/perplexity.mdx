## Setup

To access Perplexity models you'll need to create a Perplexity account, get an API key, and install the `langchain-perplexity` integration package.

### Credentials

Head to [this page](https://www.perplexity.ai/) to sign up for Perplexity and generate an API key. Once you've done this set the `PPLX_API_KEY` environment variable:

```python
import getpass
import os

if "PPLX_API_KEY" not in os.environ:
    os.environ["PPLX_API_KEY"] = getpass.getpass("Enter your Perplexity API key: ")
```

To enable automated tracing of your model calls, set your [LangSmith](https://docs.langchain.com/langsmith/home) API key:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

```bash
pip install -qU langchain-perplexity
```

## Instantiation

You can verify the available models [here](https://docs.perplexity.ai/getting-started/models).

```python
from langchain_perplexity import ChatPerplexity

chat = ChatPerplexity(
    model="sonar",
    temperature=0.7,
    # verbose=True,
    # pplx_api_key="...",
)
```

## Invocation

```python
from langchain_core.prompts import ChatPromptTemplate

system = "You are a helpful assistant."
human = "{input}"
prompt = ChatPromptTemplate.from_messages([("system", system), ("human", human)])

chain = prompt | chat
response = chain.invoke({"input": "Why is the Higgs Boson important?"})
print(response.content)
```

```text

```

## Perplexity-specific features

`ChatPerplexity` supports many unique features of the Perplexity API, such as Pro Search, domain filtering, and returning images/videos.

### Pro search

Pro Search enables multi-step reasoning and deeper research. You can enable it using `web_search_options`.

```python
from langchain_perplexity import ChatPerplexity, WebSearchOptions

chat_pro = ChatPerplexity(
    model="sonar-pro",
    web_search_options=WebSearchOptions(search_type="pro")
)

response = chat_pro.invoke("How does the electoral college work in the US?")

# Access reasoning steps
if reasoning := response.additional_kwargs.get("reasoning_steps"):
    for step in reasoning:
        print(f"Thought: {step['thought']}")
```

### Search controls

You can control the search behavior with various parameters.

```python
chat = ChatPerplexity(
    model="sonar",
    # Filter by domain
    search_domain_filter=["wikipedia.org"],
    # Filter by recency
    search_recency_filter="month",
    # Return images and related questions
    return_images=True,
    return_related_questions=True
)

response = chat.invoke("Solar system planets")

# Access search results metadata
print("Citations:", len(response.additional_kwargs.get("citations", [])))
print("Images:", len(response.additional_kwargs.get("images", [])))
```

```text
Citations: 10
Images: 5
```

### Disabling search

For purely generative tasks using the model's internal knowledge:

```python
chat_offline = ChatPerplexity(model="sonar", disable_search=True)
response = chat_offline.invoke("Write a poem about a robot")
```

## Chaining

`ChatPerplexity` integrates seamlessly with LangChain's Runnable interface.

```python
prompt = ChatPromptTemplate.from_messages([("human", "Tell me a joke about {topic}")])
chain = prompt | chat
response = chain.invoke({"topic": "cats"})
print(response.content)
```

## Streaming

```python
for chunk in chat.stream("Give me a list of famous tourist attractions in Paris"):
    print(chunk.content, end="", flush=True)
```

```text
- **Eiffel Tower**[2][5].
...
```

## Structured output

`ChatPerplexity` supports structured outputs using `with_structured_output`.

```python
from pydantic import BaseModel, Field

class Person(BaseModel):
    name: str = Field(description="The name of the person")
    age: int = Field(description="The age of the person")
    occupation: str = Field(description="The person's job")

structured_llm = chat.with_structured_output(Person)
response = structured_llm.invoke("Elon Musk is 54 years old and is the CEO of Tesla")
print(response)
```

```text
name='Elon Musk' age=54 occupation='CEO of Tesla'
```

## Async usage

`ChatPerplexity` supports native async operations.

```python
import asyncio

async def main():
    chat = ChatPerplexity(model="sonar")
    response = await chat.ainvoke("What is the capital of France?")
    print(response.content)

# await main()
```
