The [Parallel Responses API](https://docs.parallel.ai/responses-api/responses-quickstart) answers questions using live web research and returns answers with citations.

<Warning>
    Parallel's Chat API is deprecated. Replace integrations using `ChatParallel` or `ChatParallelWeb` with the Responses API.
</Warning>

## Migrate to Responses

Use the OpenAI Python SDK to call `https://api.parallel.ai/v1/responses`. This replaces the deprecated chat endpoint; changing the model name in an existing chat client is not sufficient.

Install the SDK:

```bash
pip install -U openai
```

Set `PARALLEL_API_KEY` to your [Parallel API key](https://platform.parallel.ai/), then create a response:

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PARALLEL_API_KEY"],
    base_url="https://api.parallel.ai/v1",
    timeout=120.0,
)

response = client.responses.create(
    model="parallel",
    input="Who is the current CEO of the largest cloud provider by revenue?",
    reasoning={"effort": "low"},
)

print(response.output_text)
```

Use `model="parallel"` and select a research tier with `reasoning.effort`: `low`, `medium`, or `high`. The default effort is `medium`. Higher effort performs more research; `high` requests can take up to a minute.

The Responses API uses `input` for the request. Read the answer through the SDK's `response.output_text` accessor. Do not reuse Chat API model names or assume that its response metadata has the same shape.

## Use Parallel with LangChain

For agent tool calls, use the [Parallel search tool](/oss/integrations/tools/parallel_search) and [extract tool](/oss/integrations/tools/parallel_extract) with a tool-calling model. These integrations use the separate Search and Extract APIs.

For a research tool backed by Responses, see Parallel's [research subagent guide](https://docs.parallel.ai/responses-api/responses-quickstart#use-it-as-a-research-subagent).
