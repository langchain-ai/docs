sidebarTitle: Checkpointers
description: "Integrate with checkpointer backends for LangGraph persistence."
---

Checkpointers enable [persistence](/oss/langgraph/persistence) in LangGraph, allowing agents to save and resume state across interactions.

| Package | Backend | Description |
|---------|---------|-------------|
| `langgraph-checkpoint` | In-memory | Bundled with LangGraph. For experimentation only |
| `langgraph-checkpoint-sqlite` | SQLite | Local development and experimentation |
| `langgraph-checkpoint-postgres` | PostgreSQL | Production use. Also provides `PostgresStore` for long-term memory |
| `langgraph-checkpoint-mongodb` | MongoDB | Production use with MongoDB |
| `langgraph-checkpoint-redis` | Redis | Production use. Also provides `RedisStore` for long-term memory |
| `langgraph-checkpoint-cosmosdb` | Azure Cosmos DB | Production use on Azure |
| `langgraph-checkpoint-aws` | AWS (DynamoDB, Bedrock, Valkey) | Production use on AWS |
