This page will help you get started with the Perplexity [Retriever](/oss/langchain/retrievers).

## Overview

The `PerplexitySearchRetriever` allows you to retrieve relevant documents from the web using Perplexity's powerful search capabilities. It returns ranked search results with snippets, citations, and metadata.

## Setup

To use the retriever, you'll need a Perplexity API key.

### Credentials

```python
import getpass
import os

if "PPLX_API_KEY" not in os.environ:
    os.environ["PPLX_API_KEY"] = getpass.getpass("Enter your Perplexity API key: ")
```

### Installation

```bash
pip install -qU langchain-perplexity
```

## Instantiation

```python
from langchain_perplexity import PerplexitySearchRetriever

retriever = PerplexitySearchRetriever(
    k=3,
    # Optional filters
    # search_domain_filter=["wikipedia.org"],
    # search_recency_filter="month"
)
```

## Usage

```python
docs = retriever.invoke("What are the latest developments in nuclear fusion?")

for doc in docs:
    print(f"Title: {doc.metadata['title']}")
    print(f"URL: {doc.metadata['url']}")
    print(f"Snippet: {doc.page_content[:200]}...")
    print("---")
```

## Use within a chain

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_core.output_parsers import StrOutputParser
from langchain_perplexity import ChatPerplexity

llm = ChatPerplexity(model="sonar")

template = """Answer the question based only on the following context:
{context}

Question: {question}
"""
prompt = ChatPromptTemplate.from_template(template)

def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)

rag_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

rag_chain.invoke("What is the current status of ITER?")
```
