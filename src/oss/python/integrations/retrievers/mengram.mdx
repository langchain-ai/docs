> [Mengram](https://mengram.io) provides persistent AI memory with three types:
> semantic (facts and knowledge graphs), episodic (events and experiences), and
> procedural (workflows and learned routines).

# MengramRetriever

This will help you get started with the Mengram [retriever](/oss/langchain/retrieval).

### Integration details

| Retriever | Self-host | Cloud offering | Package |
| :--- | :--- | :---: | :---: |
| MengramRetriever | ✅ | ✅ | langchain-mengram |

## Setup

Sign up at [mengram.io](https://mengram.io) to get your API key, or self-host
from the [GitHub repo](https://github.com/alibaizhanov/mengram).

```python
import os

os.environ["MENGRAM_API_KEY"] = "om-..."
```

If you want to get automated tracing from individual queries, you can also set your [LangSmith](/langsmith/home) API key by uncommenting below:

```python
# os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
# os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

This retriever lives in the `langchain-mengram` package:

```bash
pip install -qU langchain-mengram
```

## Instantiation

```python
from langchain_mengram import MengramRetriever

retriever = MengramRetriever(
    api_key="om-...",
    user_id="user-123",
    top_k=5,
    memory_types=["semantic", "episodic", "procedural"],
)
```

**Parameters:**

- `api_key` (str) — Mengram API key starting with `om-`.
- `user_id` (str) — User whose memories to search. Default: `"default"`.
- `api_url` (str) — Mengram API base URL. Default: `"https://mengram.io"`.
- `top_k` (int) — Maximum results per memory type. Default: `5`.
- `memory_types` (list) — Which memory types to search. Default: all three.

## Usage

First, add some memories through the Mengram API:

```python
from mengram import Memory

m = Memory(api_key="om-...")
m.add("I deployed the app on Railway using gunicorn with 2 workers", user_id="user-123")
m.add("Our stack is Python, FastAPI, PostgreSQL, and Redis", user_id="user-123")
```

Then retrieve relevant context with the retriever:

```python
docs = retriever.invoke("deployment setup")

for doc in docs:
    print(f"[{doc.metadata['memory_type']}] {doc.page_content}")
```

```text
[semantic] user-123: Deployed app on Railway; Uses gunicorn with 2 workers
[procedural] Procedure: Deploy to Railway
  1. Push to main branch — Railway auto-deploys from main
  2. Configure gunicorn — Set 2 workers in Procfile
```

## Use within a chain

```python
from langchain_mengram import MengramRetriever
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_core.output_parsers import StrOutputParser

retriever = MengramRetriever(api_key="om-...", user_id="user-123")
llm = ChatOpenAI(model="gpt-4o-mini")


def format_docs(docs):
    return "\n\n".join(
        f"[{d.metadata['memory_type']}] {d.page_content}" for d in docs
    )


prompt = ChatPromptTemplate.from_messages([
    ("system", "Use the following memory context to answer:\n\n{context}"),
    ("human", "{question}"),
])

chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

chain.invoke("How do we deploy?")
```
