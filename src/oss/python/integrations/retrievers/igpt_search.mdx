[iGPT Search API](https://igpt.ai) provides retrieval over personal connected datasources, including emails, messages, files, attachments, and metadata.

This guide provides a quick overview for getting started with the **IgptSearchRetriever**. For a detailed listing of all iGPT Search features, parameters, and configurations, head to the [iGPT Search API reference](https://docs.igpt.ai/docs/api-reference/search).

## Setup

### Installation

The integration lives in the langchain-igpt package:

```python
pip install -U langchain-igpt
```

### Credentials

You also need to set your iGPT API key and user:

```bash
export IGPT_API_KEY="your-api-key"
export IGPT_API_USER="your-api-user"
```

```python
import getpass
import os

if "IGPT_API_KEY" not in os.environ:
    os.environ["IGPT_API_KEY"] = getpass.getpass("Enter your iGPT API key: ")

if "IGPT_API_USER" not in os.environ:
    os.environ["IGPT_API_USER"] = getpass.getpass("Enter your iGPT API user: ")
```

Alternatively, pass `api_key` and `user` directly to retriever constructor.

---

## Instantiation

Instantiate the retriever with optional filters like max results and date ranges:

```python
from langchain_igpt import IgptSearchRetriever

retriever = IgptSearchRetriever(max_results=50, date_from="2024-01-01", date_to="2025-01-01")
```

---

## Usage

Simple retrieval:

```python
docs = retriever.invoke("contract renewal date")
print(docs)
```

Async Usage:

```python
async def main():
    docs = await retriever.ainvoke("contract renewal date")
    print(docs)

asyncio.run(main())
```

Example output:

```text
[Document(metadata={'id': '<ID>', 'timestamp': '2026-01-22T14:40:12Z', 'type': 'message', 'from': '<FROM>', 'subject': 'Subscription renewal reminder Dec 17, 2025'}, page_content='...')]
```

## Use within a chain

You can combine this retriever in a chain for question answering:

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_openai import ChatOpenAI
from langchain_igpt import IgptSearchRetriever

retriever = IgptSearchRetriever()

prompt = ChatPromptTemplate.from_template("""
Answer the question using only the context below.

Context:
{context}

Question:
{question}
""")

llm = ChatOpenAI(model="gpt-5", api_key="sk-...")

def format_docs(docs):
    return "\n\n".join(d.page_content for d in docs)

chain = (
    {
        "context": retriever | format_docs,
        "question": RunnablePassthrough(),
    }
    | prompt
    | llm
    | StrOutputParser()
)

res = chain.invoke("Find Invoice/Receipt")
print(res)
```
