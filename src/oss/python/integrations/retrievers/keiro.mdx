Most search APIs give you a title and a 50-word snippet. Keiro gives you the whole page: content, summary, tags, entities, credibility score, and embedding vectors in a single request. No separate embedding model needed.

Every RAG pipeline has the same bottleneck: search returns a snippet, then you call a separate embedding model to vectorize it. That is two API calls, two round trips, two failure points. Keiro collapses that into one call. Every response includes a 768-dim query embedding plus per-chunk embeddings, so you skip the embedding step and go straight to vector similarity. Nobody else does this. Tavily and SerpAPI make you bring your own embedding model. Keiro ships embeddings in the response.

Deep mode also pulls structured metadata (tldr, tags, named entities, reading time, credibility) that other search APIs do not bother with. Useful for filtering, re-ranking, and deciding which results are actually worth using.

## Setup

To access the Keiro retriever, you need a Keiro API key and the `langchain-keiro` package.

### Credentials

Get an API key at [keirolabs.cloud](https://keirolabs.cloud). The Explorer plan gives you 500 free credits, no credit card needed.

```python Set API key icon="key"
import getpass
import os

if "KEIRO_API_KEY" not in os.environ:
    os.environ["KEIRO_API_KEY"] = getpass.getpass("Enter your Keiro API key: ")
```

It is also helpful to set up [LangSmith](/langsmith/home) for best-in-class observability/tracing of your retriever calls:

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

```python Initialize retriever icon="robot"
from langchain_keiro.retrievers import KeiroRetriever

retriever = KeiroRetriever(
    keiro_api_key=os.environ["KEIRO_API_KEY"],
    max_results=3,
    embedding_dimensions=768,  # 384, 512, 768, 1024
)
```

## Invocation

```python Retrieve documents icon="search"
docs = retriever.invoke("What is artificial intelligence?")

doc = docs[0]
doc.page_content[:200]  # full page text
# => "Artificial intelligence (AI) is the simulation of human intelligence processes by computer systems..."

doc.metadata["title"]         # => "What Is Artificial Intelligence (AI)? - IBM"
doc.metadata["source"]         # => "https://www.ibm.com/think/topics/artificial-intelligence"
doc.metadata["tldr"]           # AI-generated one-liner summary
doc.metadata["tags"]           # => ["ai", "machine learning", "cognitive computing"]
doc.metadata["entities"]      # => ["IBM", "Alan Turing", "neural networks"]
doc.metadata["query_embedding"]    # 768-dim vector for the search query
doc.metadata["chunk_embeddings"]   # per-chunk vectors with text and offset
```

This is the key difference from other search retrievers: you get embeddings for free. No need to call a separate embedding model after retrieval.

### Use in a RAG chain

```python RAG chain icon="link"
from langchain_openai import ChatOpenAI
from langchain.chains import create_retrieval_chain

llm = ChatOpenAI(model="gpt-5")
chain = create_retrieval_chain(retriever, llm)
response = chain.invoke({"input": "What is artificial intelligence?"})
```

### Async

```python
docs = await retriever.ainvoke("What is machine learning?")
```
