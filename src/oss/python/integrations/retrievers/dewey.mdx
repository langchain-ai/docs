>[Dewey](https://meetdewey.com) is a real-time document backend for AI applications. It provides hybrid semantic + BM25 search over document collections, with full citation metadata (document, section, relevance score) on every result.

This notebook shows how to use `DeweyRetriever` to query a Dewey collection and return results as LangChain [Documents](https://reference.langchain.com/python/langchain-core/documents/base/Document).

For detailed documentation of all `DeweyRetriever` features and configurations head to the [API reference](https://github.com/meetdewey/langchain-dewey).

## Setup

Sign up at [meetdewey.com](https://meetdewey.com) to get an API key and create a collection.

## Instantiation

`DeweyRetriever` parameters:

- `api_key`: your Dewey project API key
- `collection_id`: the ID of the collection to search
- optional `k`: number of chunks to return (default `10`, max `50`)
- optional `base_url`: override for local development

```python
from langchain_dewey import DeweyRetriever

retriever = DeweyRetriever(
    api_key=os.environ["DEWEY_API_KEY"],
    collection_id="3f7a1b2c-...",
    k=8,
)
```

## Usage

```python
docs = retriever.invoke("What are the main findings?")
docs[0]
```

Each returned `Document` includes citation metadata:

## Use within a chain

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template(
    """Answer the question based only on the context provided.

Context: {context}

Question: {question}"""
)

llm = ChatOpenAI(model="gpt-4o")


def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)


chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

chain.invoke("What are the key findings in the research?")
```
