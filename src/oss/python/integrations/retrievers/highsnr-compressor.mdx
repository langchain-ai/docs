>[HighSNR](https://www.high-snr.com) is a deterministic, privacy-first context optimizer API.
>Pass a document or pre-split chunks and a token budget — get back only the high signal chunks.
>No text is stored; compression is sub-second for most documents.

This notebook shows how to use [langchain-highsnr](https://github.com/HighSNRInc/langchain-highsnr) for document compression and retrieval.

## Setup

```bash
pip install -qU langchain-highsnr
```

Get a free API key at [console.high-snr.com](https://console.high-snr.com) (no card required).

```python
import os

os.environ["HIGHSNR_API_KEY"] = "snr-..."
```

## Compress retrieved chunks (post-retrieval)

`HighSNRDocumentCompressor` compresses retrieved chunks before they reach the LLM.
The user's query is automatically used as a selection hint.

By default, chunks are grouped by `metadata["source"]` and one API call is made per
source document — this is the [benchmark-validated](https://github.com/HighSNRInc/highsnr-benchmarks) pattern.

```python
from langchain_highsnr import HighSNRDocumentCompressor
from langchain.retrievers import ContextualCompressionRetriever

compressor = HighSNRDocumentCompressor(
    max_output_tokens=2000,  # token budget across all chunks
)

retriever = ContextualCompressionRetriever(
    base_compressor=compressor,
    base_retriever=vectorstore.as_retriever(search_kwargs={"k": 20}),
)

docs = retriever.invoke("what is the main finding?")
# docs are compressed to 2000 tokens, query-aware
```

| Parameter | Default | Description |
|---|---|---|
| `api_key` | `None` | Falls back to `HIGHSNR_API_KEY` env var |
| `max_output_tokens` | `2000` | Token budget across all chunks in one call |
| `include_boundaries` | `False` | Keep first and last chunk |
| `group_by_source` | `True` | Group chunks by `metadata["source"]` (one API call per source) |

## Compress documents before indexing (pre-indexing)

`HighSNRDocumentTransformer` compresses each document before embedding, producing a leaner vector index.

```python
from langchain_highsnr import HighSNRDocumentTransformer
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings

transformer = HighSNRDocumentTransformer(
    max_output_tokens=800,   # token budget per document
    context_hint="clinical trial methodology",  # optional topic hint
)

compressed = transformer.transform_documents(raw_docs)
vectorstore = FAISS.from_documents(compressed, OpenAIEmbeddings())
```

| Parameter | Default | Description |
|---|---|---|
| `api_key` | `None` | Falls back to `HIGHSNR_API_KEY` env var |
| `max_output_tokens` | `1000` | Token budget per document |
| `include_boundaries` | `True` | Keep first and last chunk |
| `context_hint` | `None` | Topic or query to bias chunk selection |

## Benchmarks

Evaluated on LongBench v1 with Claude Sonnet 4.5 (n=200 per dataset). At 50–60% token budget with hint:

- **HotpotQA** (multi-hop QA): F1 **69.10** at 60% budget — exceeds full-document baseline (66.26)
- **Qasper** (academic papers): F1 **48.98** at 50% budget — 97% of full-document baseline (50.69) at half the tokens

Full results and reproduction scripts: [github.com/HighSNRInc/highsnr-benchmarks](https://github.com/HighSNRInc/highsnr-benchmarks)
