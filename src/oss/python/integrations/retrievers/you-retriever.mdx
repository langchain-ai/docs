`YouRetriever` returns [You.com](https://you.com) search results as LangChain documents, grounding LLMs in recent, accurate, relevant information. It accepts the same search parameters as `YouSearchTool`.

## Setup

Install the `langchain-youdotcom` package:

```python
pip install -qU langchain-youdotcom
```

### Credentials

[Get a You.com API key](https://you.com/platform/api-keys) and set it as an environment variable:

```python
import getpass
import os

if not os.environ.get("YDC_API_KEY"):
    os.environ["YDC_API_KEY"] = getpass.getpass("You.com API key:\n")
```

To enable automated tracing of individual queries, set your [LangSmith](https://smith.langchain.com) API key:

```python
# os.environ["LANGSMITH_TRACING"] = "true"
# os.environ["LANGSMITH_API_KEY"] = getpass.getpass("LangSmith API key:\n")
```

## Instantiation

`YouRetriever` accepts the search parameters from `YouSearchTool`, including `count`, `k`, `livecrawl`, `livecrawl_formats`, `country`, `freshness`, and `safesearch`:

```python
from langchain_youdotcom import YouRetriever

retriever = YouRetriever(
    k=5,
    count=10,
    livecrawl="web",
    livecrawl_formats="markdown",
    country="US",
    freshness="week",
    safesearch="moderate",
)
```

## Usage

Call `invoke` with a query string to get back a list of documents:

```python
retriever = YouRetriever(count=5)
docs = retriever.invoke("latest AI news")

for doc in docs:
    print(doc.metadata["title"])
    print(doc.page_content[:200])
    print()
```

## Use within a chain

Use the retriever to supply context to a model in a retrieval-augmented generation chain:

```python
from langchain.chat_models import init_chat_model
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_youdotcom import YouRetriever

retriever = YouRetriever(count=5)
model = init_chat_model("claude-sonnet-4-6", model_provider="anthropic")

prompt = ChatPromptTemplate.from_template(
    """Answer the question based only on the context provided.

Context: {context}

Question: {question}"""
)

chain = (
    RunnablePassthrough.assign(context=(lambda x: x["question"]) | retriever)
    | prompt
    | model
    | StrOutputParser()
)

print(chain.invoke({"question": "What are the latest developments in AI?"}))
```
