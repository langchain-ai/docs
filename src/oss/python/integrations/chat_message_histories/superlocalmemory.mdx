`SuperLocalMemoryChatMessageHistory` stores chat conversation history in a local SQLite database with zero cloud dependencies.

The code lives in the integration package: [langchain-superlocalmemory](https://github.com/varun369/SuperLocalMemoryV2/).

## Overview

SuperLocalMemoryChatMessageHistory provides:

- **100% local storage**: All data stays on your machine in SQLite — no cloud, no API keys
- **Session isolation**: Each conversation has a unique session ID
- **Multi-session support**: Manage multiple conversation histories simultaneously
- **Universal AI tool access**: Works with 17+ AI tools via MCP protocol
- **Free and open-source**: MIT licensed, no subscriptions, no usage limits

## Setup

### Prerequisites

Install SuperLocalMemory V2:

```bash
npm install -g superlocalmemory
```

### Install

```bash
pip install -qU langchain-superlocalmemory
```

## Initialization

Create a chat history instance for a specific conversation:

```python
from langchain_superlocalmemory import SuperLocalMemoryChatMessageHistory

chat_history = SuperLocalMemoryChatMessageHistory(
    session_id="my-session",
)
```

<Tip>
All messages are stored locally at `~/.claude-memory/memory.db`. No cloud connection or API key is required.
</Tip>

## Usage

### Add messages

```python
from langchain.messages import HumanMessage, AIMessage

# Add messages to the conversation
chat_history.add_message(HumanMessage(content="Hello! What is SuperLocalMemory?"))
chat_history.add_message(AIMessage(content="SuperLocalMemory is a local-first memory system for AI assistants..."))
```

### Add multiple messages at once

```python
messages = [
    HumanMessage(content="How does it store data?"),
    AIMessage(content="It uses SQLite with FTS5 full-text search on your local machine..."),
    HumanMessage(content="Is it free?"),
    AIMessage(content="Yes, it is free forever with no API keys or subscriptions required."),
]

chat_history.add_messages(messages)
```

### Retrieve messages

Get all messages for the session:

```python
messages = chat_history.messages

for msg in messages:
    if isinstance(msg, HumanMessage):
        print(f"User: {msg.content}")
    elif isinstance(msg, AIMessage):
        print(f"AI: {msg.content}")
```

### Clear conversation history

Delete all messages for the session:

```python
chat_history.clear()
```

## Use with RunnableWithMessageHistory

Integrate with LangChain's `RunnableWithMessageHistory` for automatic history management:

```python
from langchain.runnables.history import RunnableWithMessageHistory

def get_session_history(session_id: str):
    return SuperLocalMemoryChatMessageHistory(session_id=session_id)

chain_with_history = RunnableWithMessageHistory(
    your_chain,
    get_session_history,
)

# Invoke with session tracking
result = chain_with_history.invoke(
    {"input": "What can you help me with?"},
    config={"configurable": {"session_id": "user-123"}},
)
```
