`SoulChatMessageHistory` stores chat conversation history in human-readable markdown files with hybrid RAG+RLM semantic retrieval.

The code lives in the integration package: [langchain-soul](https://github.com/menonpg/langchain-soul/).

## Overview

SoulChatMessageHistory provides:

- **Markdown-native storage**: Chat history in human-readable `.md` files you can edit
- **RAG + RLM hybrid retrieval**: Auto-routes queries to semantic search or exhaustive reasoning
- **Git-versionable**: Memory files under version control
- **Database schema intelligence**: Auto-document databases via LLM (via soul-schema)
- **Managed cloud option**: SoulMate API for zero-infrastructure deployments
- **Factory function**: Easy switching between local and cloud backends

## Setup

### Install

```bash
pip install -qU langchain-soul
```

This installs:
- `soul-agent` — Core RAG+RLM memory library
- `soul-schema` — Database semantic layer generator
- `httpx` — For SoulMate API client

## Initialization

### Local file-based storage

```python
from langchain_soul import SoulChatMessageHistory

# Create markdown-based chat history
chat_history = SoulChatMessageHistory(
    session_id="user-123",
    memory_dir="./memories"  # Optional: defaults to ~/.soul/memories
)
```

### Managed cloud (SoulMate)

```python
from langchain_soul import SoulMateChatMessageHistory

# Zero-infrastructure option
chat_history = SoulMateChatMessageHistory(
    session_id="user-123",
    api_key="your-soulmate-api-key"
)
```

### Factory function

```python
from langchain_soul import create_chat_history

# Switch backends easily
history = create_chat_history("local", session_id="user-123")
history = create_chat_history("soulmate", session_id="user-123", api_key="...")
```

## Usage

### Add messages

```python
from langchain_core.messages import HumanMessage, AIMessage

chat_history.add_message(HumanMessage(content="What's the weather like?"))
chat_history.add_message(AIMessage(content="I don't have access to weather data, but I can help you find that information."))
```

### Retrieve messages

```python
messages = chat_history.messages
for msg in messages:
    print(f"{msg.type}: {msg.content}")
```

### Semantic search (recall)

```python
# Search past conversations using RAG+RLM hybrid retrieval
results = chat_history.recall("What did we discuss about databases?")
for result in results:
    print(f"[{result['score']:.2f}] {result['content']}")
```

### Clear history

```python
chat_history.clear()
```

## With LangChain agents

```python
from langchain_openai import ChatOpenAI
from langchain.agents import AgentExecutor, create_tool_calling_agent
from langchain_core.prompts import ChatPromptTemplate
from langchain_soul import SoulChatMessageHistory

# Create chat history
chat_history = SoulChatMessageHistory(session_id="agent-session")

# Setup agent with memory
llm = ChatOpenAI(model="gpt-4")
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant."),
    ("placeholder", "{chat_history}"),
    ("human", "{input}"),
])

agent = create_tool_calling_agent(llm, tools=[], prompt=prompt)
agent_executor = AgentExecutor(agent=agent, tools=[])

# Run with history
response = agent_executor.invoke({
    "input": "Hello!",
    "chat_history": chat_history.messages
})

# Save response to history
chat_history.add_message(HumanMessage(content="Hello!"))
chat_history.add_message(AIMessage(content=response["output"]))
```

## Database schema intelligence

Generate semantic context for Text-to-SQL:

```python
from langchain_soul import SchemaMemory

# Connect to any SQLAlchemy-compatible database
schema = SchemaMemory("postgresql://user:pass@host/db")
schema.generate()  # Auto-documents tables via LLM

# Get context for queries
context = schema.context_for("Show me revenue by region")
print(context)
```
