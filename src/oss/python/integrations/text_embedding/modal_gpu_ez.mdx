This will help you get started with `ModalGpuEzEmbeddings` using LangChain.

## Overview

`ModalGpuEzEmbeddings` runs HuggingFace embedding models locally or on [Modal](https://modal.com) serverless GPUs. It wraps [modal-gpu-ez](https://pypi.org/project/modal-gpu-ez/), which handles model loading and device detection automatically.

Embedding models are lightweight, so the default runs locally (`gpu="Local"`) at no cost.

## Setup

### Installation

```bash
pip install langchain-modal-gpu-ez
```

### Credentials

For local-only usage (default), no credentials are needed.

For remote GPU usage, set your Modal credentials:

```python
import os

os.environ["MODAL_TOKEN_ID"] = "your_modal_token_id"
os.environ["MODAL_TOKEN_SECRET"] = "your_modal_token_secret"
```

## Instantiation

```python
from langchain_modal_gpu_ez import ModalGpuEzEmbeddings

embeddings = ModalGpuEzEmbeddings(
    model_id="BAAI/bge-small-en-v1.5",
    gpu="Local",
)
```

## Embed documents

```python
vectors = embeddings.embed_documents([
    "Modal provides serverless GPU infrastructure",
    "LangChain is a framework for LLM applications",
])

print(f"Documents: {len(vectors)}")
print(f"Dimensions: {len(vectors[0])}")
```

## Embed query

```python
query_vector = embeddings.embed_query("What is serverless computing?")
print(f"Dimensions: {len(query_vector)}")
```

## Use with vector stores

```python
from langchain_community.vectorstores import FAISS

documents = [
    "Modal provides serverless GPU infrastructure.",
    "LangChain is a framework for LLM applications.",
    "HuggingFace hosts open-source AI models.",
]

vectorstore = FAISS.from_texts(documents, embeddings)
results = vectorstore.similarity_search("GPU cloud", k=2)

for doc in results:
    print(doc.page_content)
```
