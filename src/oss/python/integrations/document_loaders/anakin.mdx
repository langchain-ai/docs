[Anakin](https://anakin.io) converts websites into clean, structured data at scale. It handles JavaScript rendering, anti-bot systems, and proxy rotation automatically. The `AnakinLoader` supports four modes: single URL scraping, batch scraping (up to 10 URLs), AI-powered web search, and multi-stage agentic research.

## Setup

Install `langchain-community` and set your API key:

<CodeGroup>
```bash pip
pip install -U langchain-community
```

```bash uv
uv add langchain-community
```
</CodeGroup>

```bash
export ANAKIN_API_KEY="your-api-key"
```

Get your key from the [Anakin dashboard](https://anakin.io/dashboard).

## Instantiation

### Scrape a single URL

```python
from langchain_community.document_loaders import AnakinLoader

loader = AnakinLoader(url="https://example.com", mode="scrape")
```

### Batch scrape multiple URLs

```python
loader = AnakinLoader(
    urls=["https://example.com", "https://python.org"],
    mode="batch_scrape",
)
```

### Search the web

```python
loader = AnakinLoader(query="latest AI news", mode="search")
```

### Agentic research

Run a deep, multi-stage autonomous research job. This typically takes 1-5 minutes.

```python
loader = AnakinLoader(query="compare React vs Vue", mode="agentic_search")
```

## Load

Use `.load()` to synchronously load all documents into memory:

```python
docs = loader.load()
docs[0]
```

```python
Document(page_content='# Example Domain\nThis domain is for use in ...', metadata={'source': 'https://example.com', 'title': 'Example Domain', 'status': 'completed', 'duration_ms': 1234})
```

```python
print(docs[0].metadata)
```

```python
{'source': 'https://example.com', 'title': 'Example Domain', 'status': 'completed', 'duration_ms': 1234}
```

## Lazy load

Use `lazy_load()` to iterate over documents one at a time, minimizing memory usage:

```python
docs = []

for doc in loader.lazy_load():
    docs.append(doc)

    if len(docs) >= 10:
        # do some paged operation, e.g.
        # index.upsert(doc)

        docs = []
```

## Async load

Use `alazy_load()` for async workflows:

```python
docs = []
async for doc in loader.alazy_load():
    docs.append(doc)

print(docs[0].page_content[:100])
```
