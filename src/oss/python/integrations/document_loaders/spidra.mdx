[Spidra](https://spidra.io) turns websites into structured, ready-to-use data using prompts, real browsers, proxies, CAPTCHA solving, and AI extraction — without requiring you to build or maintain scraping infrastructure.

This guide provides a quick overview for getting started with `SpidraLoader` as a [document loader](/oss/langchain/document-loaders). For more details, visit the [Spidra documentation](https://docs.spidra.io) or the [Spidra provider page](/oss/integrations/providers/spidra).

## Setup

To access the SpidraLoader you'll need to install the `langchain-spidra` integration package and create a Spidra account to get an API key.

### Credentials

Head to [app.spidra.io](https://app.spidra.io) to sign up and generate an API key. Once you've done this, set the `SPIDRA_API_KEY` environment variable:

```bash
export SPIDRA_API_KEY=<your-api-key>
```

### Installation

Install **langchain-spidra**:

<CodeGroup>
```bash pip
pip install -qU langchain-spidra
```
```bash uv
uv add langchain-spidra
```
</CodeGroup>

## Initialization

Instantiate the loader with a URL to scrape:

```python
from langchain_spidra import SpidraLoader

loader = SpidraLoader(
    url="https://example.com",
    api_key="YOUR_SPIDRA_API_KEY",  # or set SPIDRA_API_KEY env var
)
```

## Load

```python
docs = loader.load()
docs[0]
```

```text
Document(

```

```python
print(docs[0].metadata)
```

## Lazy load

```python
page = []
for doc in loader.lazy_load():
    page.append(doc)
    if len(page) >= 10:
        # do some paged operation, e.g.
        # index.upsert(page)
        page = []
```

## Advanced usage

### Crawl mode

To crawl an entire website (all reachable pages from the seed URL) instead of scraping a single page, use `SpidraCrawl` directly from the tools module or use the document loader in crawl mode if your use case requires returning multiple documents:

```python
from langchain_spidra import SpidraCrawl

tool = SpidraCrawl()
result = tool.invoke({"url": "https://docs.example.com"})
```

### Batch scraping

To scrape multiple URLs in parallel:

```python
from langchain_spidra import SpidraBatchScrape

tool = SpidraBatchScrape()
result = tool.invoke({
    "urls": [
        "https://example.com/page1",
        "https://example.com/page2",
        "https://example.com/page3",
    ]
})
```
