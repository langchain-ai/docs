---
title: "Opedd"
description: "Load a licensed Opedd content catalog as LangChain Documents."
---

`OpeddFeedLoader` loads an enterprise buyer's licensed [Opedd](https://opedd.com/for-ai-agents) catalog as LangChain `Document`s — one document per article, full article body as `page_content`, and licensing provenance (article id, publisher, source URL, content hash, `licensed: True`) on `metadata`. Useful when your RAG answers must stay attributable to licensed sources rather than scraped ones.

## Overview

| Class | Package |
|:------|:--------|
| `OpeddFeedLoader` | [`langchain-opedd`](https://pypi.org/project/langchain-opedd/) |

## Setup

Install the package:

```bash
pip install -qU langchain-opedd
```

You need an Opedd enterprise access key (`ent_*`), issued with an enterprise license at [opedd.com](https://opedd.com).

## Instantiation

```python
from langchain_opedd import OpeddFeedLoader

loader = OpeddFeedLoader(
    access_key="ent_...",
    since="2026-01-01T00:00:00Z",  # optional — only articles published after this instant
    max_documents=500,             # optional — hard cap on documents loaded
)
```

## Load

```python
docs = loader.load()
print(docs[0].page_content[:200])
print(docs[0].metadata)
```

Each `Document` carries the following metadata keys (when present):

- `id`, `title`, `source`, `publisher_id`, `published_at`
- `author`, `language`, `word_count`, `content_hash`
- `provider: "opedd"`, `licensed: True`

## Lazy load

The loader paginates the Opedd feed API; use `lazy_load()` to stream documents without holding the whole catalog in memory:

```python
for doc in loader.lazy_load():
    index(doc)  # e.g. add to a vectorstore batch
```

## Use in a RAG pipeline

```python
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS

vectorstore = FAISS.from_documents(docs, OpenAIEmbeddings())
```

Delta-feed polling: run the loader on a schedule with `since` set to the last run's timestamp to pick up only newly published articles.

## API reference

For the full API surface see the [langchain-opedd repository](https://github.com/Opedd/langchain-opedd) and the [Opedd API documentation](https://opedd.com/for-ai-agents).
