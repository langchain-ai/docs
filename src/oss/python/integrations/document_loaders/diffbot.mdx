[Diffbot](https://www.diffbot.com) is a structured web knowledge tool for developers. The `langchain-diffbot` package provides two document loaders: `DiffbotExtractLoader` fetches and structures content from a list of URLs into @[`Document`] objects, and `DiffbotCrawlLoader` drives a Diffbot crawl job and streams one `Document` per crawled URL.

See the [Diffbot provider page](/oss/integrations/providers/diffbot) for installation and authentication setup. For complete runnable examples, see the [`examples/`](https://github.com/diffbot/langchain-diffbot/tree/main/examples) folder in the langchain-diffbot repository.

### Integration details

| Class | Package | Serializable | JS support |

|:------:|:---------------------:|:--------------------:|

<Note>
    Async loading (`alazy_load()`) requires an async client: pass `async_client=DiffbotAsync(token=...)` instead of (or in addition to) `client=`.
</Note>

## Extract URLs into documents

`DiffbotExtractLoader` takes a list of URLs and returns one @[`Document`] per URL, with the structured page content as `page_content` and extraction metadata attached.

```python
import os

from diffbot import Diffbot
from langchain_diffbot import DiffbotExtractLoader

db = Diffbot(token=os.environ["DIFFBOT_API_TOKEN"])
loader = DiffbotExtractLoader(
    client=db,
    urls=["https://www.diffbot.com/products/extract/", "https://www.diffbot.com/products/knowledge-graph/"],
)

docs = loader.load()
for doc in docs:
    print(doc.metadata.get("pageUrl"), "—", doc.page_content[:80])
```

For large URL lists, use `lazy_load()` to stream documents one at a time rather than loading all into memory:

```python
for doc in loader.lazy_load():
    print(doc.metadata.get("pageUrl"))
```

## Crawl a site into documents

`DiffbotCrawlLoader` drives a Diffbot crawl from a seed URL (`site`) and yields one `Document` per crawled URL. The `page_content` of each document is the crawled URL itself — chain it with `DiffbotExtractLoader` to fetch and structure the page content.

```python
import os

from diffbot import Diffbot
from langchain_diffbot import DiffbotCrawlLoader, DiffbotExtractLoader

db = Diffbot(token=os.environ["DIFFBOT_API_TOKEN"])
crawl_loader = DiffbotCrawlLoader(client=db, site="https://www.diffbot.com")

urls = [doc.page_content for doc in crawl_loader.lazy_load()]

extract_loader = DiffbotExtractLoader(client=db, urls=urls)
docs = extract_loader.load()
```
