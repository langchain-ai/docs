>[HWP](https://en.wikipedia.org/wiki/Hangul_Word_Processor) and HWPX are widely used Korean document formats.

This page shows how to load `.hwp` and `.hwpx` files into LangChain `Document` objects.

In Korea, HWP/HWPX remains common in public-sector and enterprise workflows. Industry
estimates suggest Hancom Office accounts for roughly 30% of the office-suite market in
Korea ([source](https://biz.chosun.com/it-science/ict/2025/10/09/NHYQN77XSFAWXJFFGSKU47IPZQ/)).

## Installation

```bash
pip install -qU langchain-hwp-hwpx-loader
```

## Load a single file

```python
from langchain_hwp_hwpx import HwpHwpxLoader

loader = HwpHwpxLoader("/path/to/sample.hwp", mode="single")
docs = loader.load()

print(len(docs))
print(docs[0].metadata)
print(docs[0].page_content[:500])
```

## Load by element mode

```python
from langchain_hwp_hwpx import HwpHwpxLoader

loader = HwpHwpxLoader("/path/to/sample.hwpx", mode="elements")
docs = loader.load()

print(len(docs))
print(docs[0].metadata.get("element_type"))
```

## Load a directory

```python
from langchain_hwp_hwpx import HwpHwpxDirectoryLoader

loader = HwpHwpxDirectoryLoader("/path/to/folder")
docs = loader.load()

print(len(docs))
```

## Output metadata

Documents include metadata such as:

- `source`
- `file_name`
- `file_type`
- `loader`
- `parser`
- `extracted_at`
- `element_type`
