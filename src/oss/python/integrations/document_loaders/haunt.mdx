[Haunt](https://hauntapi.com?utm_source=langchain&utm_medium=integration&utm_campaign=sweep-2026-07) reads public web pages for AI applications. `HauntLoader` returns each page as a clean markdown `Document`, ready for splitting and embedding. A page that cannot be read raises with an honest reason (or is skipped with `on_failure="skip"`); the loader never yields invented content for a blocked or missing page.

## Setup

Get a free API key (no card) at [hauntapi.com](https://hauntapi.com/#signup), then install the package:

<CodeGroup>
    ```python pip
    pip install -U langchain-haunt
    ```
    ```python uv
    uv add langchain-haunt
    ```
</CodeGroup>

```python Set API key icon="key"
import getpass
import os

if "HAUNT_API_KEY" not in os.environ:
    os.environ["HAUNT_API_KEY"] = getpass.getpass("Enter your Haunt API key: ")
```

## Load documents

```python Load pages icon="rocket"
from langchain_haunt import HauntLoader

loader = HauntLoader([
    "https://example.com/docs/page-one",
    "https://example.com/docs/page-two",
])
docs = loader.load()
docs[0].page_content
# '# Page One\n\n...'
docs[0].metadata
# {'source': 'https://example.com/docs/page-one', ...}
```

Lazy loading is supported:

```python Lazy load icon="hourglass"
for doc in loader.lazy_load():
    print(doc.metadata["source"], len(doc.page_content))
```

## Unreadable pages are honest, never invented

By default an unreadable page raises with the plain reason:

```python Honest failure icon="shield"
HauntLoader("https://example.com/admin").load()
# ValueError: Haunt could not read https://example.com/admin: login_required: This page needs a login. ...
```

Pass `on_failure="skip"` to omit unreadable pages instead of raising.
