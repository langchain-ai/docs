[Firecrawl](https://www.firecrawl.dev) is an API that turns websites into clean, LLM-ready data. It can scrape a single page, crawl an entire site, map a site's URLs, extract structured data, and search the web — returning markdown and metadata ready for retrieval pipelines.

This guide provides a quick overview for getting started with the `FirecrawlLoader` [document loader](/oss/integrations/document_loaders). For more information about Firecrawl, visit the [Firecrawl website](https://www.firecrawl.dev) or the [Firecrawl docs](https://docs.firecrawl.dev).

## Setup

To access the Firecrawl document loader you'll need to install the `langchain-firecrawl` integration package and create a Firecrawl account to get an API key.

### Credentials

Head to [firecrawl.dev](https://www.firecrawl.dev) to sign up and generate an API key. Once you've done this, set the `FIRECRAWL_API_KEY` environment variable:

```python
import getpass
import os

if "FIRECRAWL_API_KEY" not in os.environ:
    os.environ["FIRECRAWL_API_KEY"] = getpass.getpass("Enter your Firecrawl API key: ")
```

### Installation

Install **langchain-firecrawl**.

```python
pip install -qU langchain-firecrawl
```

## Initialization

Now we can instantiate our loader and load documents. `FirecrawlLoader` supports several modes via the `mode` argument: `scrape` (a single URL), `crawl` (a URL and its accessible sub-pages), `map` (discover a site's URLs), `extract` (structured data), and `search` (web search).

```python
from langchain_firecrawl import FirecrawlLoader

loader = FirecrawlLoader(
    url="https://www.firecrawl.dev",
    mode="scrape",
)
```

## Load

```python
docs = loader.load()
docs[0]
```

```python
print(docs[0].metadata)
```

## Lazy load

```python
page = []
for doc in loader.lazy_load():
    page.append(doc)
    if len(page) >= 10:
        # do some paged operation, e.g.
        # index.upsert(page)

        page = []
```

## Modes

Use `mode="crawl"` to crawl a page and its sub-pages, returning one document per page:

```python
loader = FirecrawlLoader(url="https://www.firecrawl.dev", mode="crawl")
```

Additional options can be passed through the `params` argument. For the full set of supported parameters per mode, see the [Firecrawl docs](https://docs.firecrawl.dev).

```python
loader = FirecrawlLoader(
    url="https://www.firecrawl.dev",
    mode="crawl",
    params={"limit": 10, "scrape_options": {"only_main_content": True}},
)
```
