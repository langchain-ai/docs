[Plasmate SOM](https://docs.plasmate.app) (Set of Mark) provides structured UI element extraction from web pages. It identifies and labels interactive elements on a page, returning clean, structured data that is ideal for AI agent workflows and web automation.

## Overview

### Integration details

| Source | Document Lazy Loading | Native Async Support |
| :---: | :---: | :---: |

## Setup

### Installation

Install the **langchain-plasmate** package:

```python
pip install -qU langchain-plasmate
```

### Credentials

To use the Plasmate API, set your API key as an environment variable:

```python
import os

os.environ["PLASMATE_API_KEY"] = "YOUR_PLASMATE_API_KEY"
```

Alternatively, you can pass the API key directly to the loader. The loader also supports a local fallback mode when no API key is provided.

## Initialization

Create a loader instance with a URL to extract UI elements from:

```python
from langchain_plasmate import PlasmateSOMLLoader

loader = PlasmateSOMLLoader(
    url="https://example.com",
    # api_key="YOUR_PLASMATE_API_KEY",  # Optional if set in environment
)
```

## Load

Use `.load()` to extract UI elements and return them as Documents:

```python
docs = loader.load()
docs[0]
```

```python
Document(metadata={'url': 'https://example.com', 'element_count': 12}, page_content='[1] button "Sign In"\n[2] link "Home"\n[3] input "Search..."\n...')
```

```python
print(docs[0].metadata)
```

```python
{'url': 'https://example.com', 'element_count': 12}
```

## Lazy load

For processing pages incrementally:

```python
pages = []
for doc in loader.lazy_load():
    pages.append(doc)
    if len(pages) >= 10:
        # do some paged operation
        pages = []
```

## Configuration

The loader accepts several configuration options:

```python
loader = PlasmateSOMLLoader(
    url="https://example.com",
    api_key="YOUR_PLASMATE_API_KEY",  # API key for Plasmate service
    use_local_fallback=False,  # Use local extraction when API unavailable
    timeout=30,  # Request timeout in seconds
)
```
