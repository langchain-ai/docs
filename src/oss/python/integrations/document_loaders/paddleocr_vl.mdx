[PaddleOCR](https://www.paddleocr.com) is a powerful and lightweight OCR toolkit developed by Baidu that connects images and PDFs with LLMs. It supports over 100 languages and transforms document content into structured, AI-ready data.

This integration provides PaddleOCR's large-model document parsing capabilities via the `PaddleOCRVLLoader` document loader.

## Overview

### Integration details

| Class | Package | Local | Serializable | JS support|
| :--- | :--- | :---: | :---: |  :---: |
| `PaddleOCRVLLoader` | `langchain-paddleocr` | ✅ | ❌ | ❌ |

### Loader features

| Source | Document Lazy Loading | Native Async Support
| :---: | :---: | :---: |
| `PaddleOCRVLLoader` | ✅ | ❌ |

The `PaddleOCRVLLoader` enables you to:

- Extract text and layout information from PDF and image files using models from Baidu's PaddleOCR-VL series (e.g., PaddleOCR-VL, PaddleOCR-VL-1.5, PaddleOCR-VL-1.6)
- Process documents from local files or remote URLs

## Prerequisites

To use the PaddleOCR-VL loader, you need:

1. **API Access**: An access token for the PaddleOCR API (can be provided directly or via `PADDLEOCR_ACCESS_TOKEN` environment variable)

The access token is available on the [PaddleOCR official website](https://www.paddleocr.com). Simply click the **API** button and copy the token from the API invocation example provided there.

## Initialization

Basic initialization only requires a file path and access token. The `base_url` defaults to `https://paddleocr.aistudio-app.com` (the official service), so most users do not need to set it:

```python
from langchain_paddleocr import PaddleOCRVLLoader
from pydantic import SecretStr

loader = PaddleOCRVLLoader(
    file_path="path/to/document.pdf",
    access_token=SecretStr("your-access-token"),  # Optional if using environment variable
)
```

For authentication via environment variable:

```bash
export PADDLEOCR_ACCESS_TOKEN="your-access-token"
```

Then initialize without the access_token parameter:

```python
loader = PaddleOCRVLLoader(
    file_path="path/to/document.pdf",
)
```

### Select a model

Specify a model to use for document parsing:

```python
loader = PaddleOCRVLLoader(
    file_path="path/to/document.pdf",
    model="PaddleOCR-VL-1.6",
)
```

### Advanced configuration

The loader supports numerous configuration options for fine-tuning the document processing:

```python
loader = PaddleOCRVLLoader(
    file_path=["document1.pdf", "document2.jpg"],  # Multiple files
    model="PaddleOCR-VL-1.5",  # Optional: model selection

    use_doc_orientation_classify=False,  # Document orientation classification
    use_doc_unwarping=False,  # Document unwarping
    use_layout_detection=None,  # Layout detection (None = service default)
    use_chart_recognition=None,  # Chart recognition (None = service default)
    use_seal_recognition=None,  # Seal recognition (None = service default)
    use_ocr_for_image_block=None,  # OCR for image blocks (None = service default)

    layout_threshold=None,  # Detection threshold
    layout_nms=None,  # Non-maximum suppression
    layout_unclip_ratio=None,  # Layout unclip ratio
    layout_merge_bboxes_mode=None,  # Bounding box merge mode
    layout_shape_mode=None,  # Layout shape mode

    prompt_label=None,  # Prompt label for VLM
    format_block_content=None,  # Format block content to Markdown
    repetition_penalty=None,  # VLM repetition penalty
    temperature=None,  # VLM temperature
    top_p=None,  # VLM top-p sampling
    min_pixels=None,  # Minimum pixels for preprocessing
    max_pixels=None,  # Maximum pixels for preprocessing
    max_new_tokens=None,  # Maximum tokens generated by VLM
    vlm_extra_args=None,  # Additional VLM arguments

    merge_layout_blocks=None,  # Merge layout blocks across columns
    markdown_ignore_labels=None,  # Layout labels to ignore in Markdown
    prettify_markdown=None,  # Prettify Markdown output
    show_formula_number=None,  # Include formula numbers
    restructure_pages=None,  # Restructure results across pages
    merge_tables=None,  # Merge tables across pages
    relevel_titles=None,  # Relevel titles
    return_markdown_images=None,  # Return images referenced by Markdown
    output_formats=None,  # Additional export formats (e.g., ["docx"])
    visualize=None,  # Include visualization results
    extra_options=None,  # Additional service options as dict

    timeout=300,  # Poll timeout in seconds
)
```

## Basic usage

### Load documents

```python
loader = PaddleOCRVLLoader(
    file_path="https://arxiv.org/pdf/2408.09869",
)
docs = loader.load()

for doc in docs[:2]:
    print(f"Content: {doc.page_content[:200]}...")
    print(f"Source: {doc.metadata['source']}")
    print("---")
```

### Handle multiple file types

The loader supports both local files and remote URLs:

```python
files = [
    "document.pdf",      # Local PDF file
    "image.jpg",         # Local image file
    "https://example.com/report.pdf"  # Remote PDF
]

loader = PaddleOCRVLLoader(file_path=files)
```

Supported image formats: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tiff`, `.tif`, `.webp`
Supported document formats: `.pdf`

## Advanced features

### Access raw API responses

The loader includes the complete API response in document metadata:

```python
docs = loader.load()
first_doc = docs[0]

raw_response = first_doc.metadata["paddleocr_vl_raw_response"]
print(f"Job ID: {raw_response['job_id']}")
print(f"Pages: {len(raw_response['pages'])}")
```

### Error handling

The loader provides detailed error messages for troubleshooting:

```python
try:
    docs = loader.load()
except ValueError as e:
    print(f"Processing failed: {e}")
    # Common issues: authentication errors, file not found
```

## Troubleshooting

### Common issues

1. **Authentication errors**: Ensure `PADDLEOCR_ACCESS_TOKEN` is set or `access_token` is provided
2. **File not found**: Verify local file paths are correct and accessible
3. **Timeout**: Increase `timeout` parameter for large documents
