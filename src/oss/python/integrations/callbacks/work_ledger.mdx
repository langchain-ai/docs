> [Work Ledger](https://github.com/metawake/work-ledger) is an open-source tool for recording agent runs as structured artifacts, then diffing and replaying them. It provides a `BaseCallbackHandler` that captures LLM calls, tool invocations, retriever queries, and chain I/O with token metrics and causal links.

## Installation and setup

```bash
pip install work-ledger
```

No API keys or external services required. Runs are stored locally (JSONL, SQLite, or in-memory).

## Usage

### WorkLedgerCallbackHandler

`WorkLedgerCallbackHandler` inherits from `BaseCallbackHandler` and works with any LangChain runnable via the `callbacks` parameter or `RunnableConfig`.

```python
from work_ledger import WorkLedger, WorkLedgerCallbackHandler
from langchain_openai import ChatOpenAI

ledger = WorkLedger(store="./runs")
handler = WorkLedgerCallbackHandler(ledger, run_name="my-chain")

llm = ChatOpenAI(model="gpt-4o-mini")
result = llm.invoke(
    "What is LangChain?",
    config={"callbacks": [handler]},
)

run = handler.get_run()
print(f"Status: {run.status.value}")
print(f"Steps: {len(run.steps)}")
print(f"Tokens: {run.metrics.total_tokens}")
```

The handler captures:
- **LLM/chat model calls** with prompt/completion token counts
- **Tool invocations** with inputs and outputs
- **Retriever queries** with returned documents
- **Chain-level inputs/outputs** for the outermost chain
- **Causal links** between steps (which LLM call triggered which tool)

### Using with LCEL chains

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

prompt = ChatPromptTemplate.from_template("Translate to French: {text}")
chain = prompt | llm | StrOutputParser()

handler = WorkLedgerCallbackHandler(ledger, run_name="translate")
result = chain.invoke(
    {"text": "Hello world"},
    config={"callbacks": [handler]},
)

run = handler.get_run()
print(f"Input: {run.inputs}")   # {'text': 'Hello world'}
print(f"Output: {run.outputs}") # {'output': 'Bonjour le monde'}
```

### Comparing runs

After recording two runs, you can diff them to see what changed:

```python
from work_ledger.testing.diff import RunDiff

diff = RunDiff(run_v1, run_v2)
print(f"Similarity: {diff.similarity:.0%}")
print(f"Steps added: {diff.steps_added}, removed: {diff.steps_removed}")
print(f"Token delta: {diff.token_diff:+d}")
```

Or via CLI:

```bash
work-ledger diff <run-id-1> <run-id-2>
```

### Regression testing with pytest

```python
from work_ledger.testing.decorators import golden

@golden(store="./golden", name="qa-chain")
def test_qa_chain():
    return chain.invoke({"text": "Hello"})
```

For more details, see the [Work Ledger documentation](https://github.com/metawake/work-ledger).
