## Overview

Document transformers operate on a list of `Document` objects and return a transformed list. The canonical use cases are **reranking** (scoring retrieved documents against a query and keeping the most relevant), **content conversion** (HTML to plain text, document translation), and **metadata tagging**.

Reranking is the most impactful document transformer for RAG applications: retrieve a larger `k` from your vector store, then rerank down to the handful of documents you actually pass to the model. See [Choose an embedding model](/oss/langchain/choosing-embeddings) for the broader context, and the [reranking section of the RAG tutorial](/oss/langchain/rag#improve-retrieval-with-reranking) for a full example.
