[Upstash Box](https://upstash.com/docs/box) provides secure, isolated cloud sandboxes with a full Linux shell, filesystem, git, and language runtimes. See the [Upstash Box docs](https://upstash.com/docs/box) for signup, API keys, and platform details.

## Installation

<CodeGroup>
```bash pip
pip install langchain-upstash-box
```

```bash uv
uv add langchain-upstash-box
```
</CodeGroup>

## Authentication

Create an API key in the [Upstash Console](https://console.upstash.com) and set it in your environment:

```bash
export UPSTASH_BOX_API_KEY="box_xxxxxxxx"
```

## Create a sandbox backend

`UpstashBoxSandbox.create()` provisions a box, waits until it is ready, and returns a [deepagents backend](/oss/deepagents/backends).

```python
from langchain_upstash_box import UpstashBoxSandbox

backend = UpstashBoxSandbox.create(runtime="python")

result = backend.execute("echo hello")
print(result.output)
```

To wrap a box you have already created, pass its id instead:

```python
from langchain_upstash_box import UpstashBoxSandbox

backend = UpstashBoxSandbox(box_id="your-box-id")
```

## Use with Deep Agents

```python
from langchain_anthropic import ChatAnthropic

from deepagents import create_deep_agent
from langchain_upstash_box import UpstashBoxSandbox

backend = UpstashBoxSandbox.create(runtime="python")

agent = create_deep_agent(
    model=ChatAnthropic(model="claude-sonnet-4-20250514"),
    system_prompt="You are a coding assistant with sandbox access.",
    backend=backend,
)

result = agent.invoke(
    {
        "messages": [
            {"role": "user", "content": "Create a hello world Python script and run it"}
        ]
    }
)
```

## Cleanup

You manage the sandbox lifecycle. When you are done, delete the box:

```python
backend.delete()
```

See also: [Sandboxes](/oss/deepagents/sandboxes).
