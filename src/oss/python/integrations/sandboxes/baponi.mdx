[Baponi](https://baponi.ai) runs AI-generated code in sandboxes that you can host yourself, inside your own Kubernetes cluster or VPC, or use as a managed cloud service. Sandboxes are network-isolated by default, with egress opt-in. See the [Baponi Deep Agents guide](https://baponi.ai/docs/guides/deep-agents) for signup, authentication, and platform details.

## Installation

<CodeGroup>

```bash pip
pip install langchain-baponi
```

```bash uv
uv add langchain-baponi
```

</CodeGroup>

## Authentication

Set your Baponi API key:

```bash
export BAPONI_API_KEY="..."
```

Get an API key at [console.baponi.ai](https://console.baponi.ai). To run against a self-hosted Baponi deployment instead of the managed cloud, pass `base_url` when you create the sandbox (see [Use with Deep Agents Code](#use-with-deep-agents-code) for the `dcode` equivalent).

## Create a sandbox

In Python, `BaponiSandbox` is the [deepagents backend](/oss/deepagents/backends). Create it directly and use it as a context manager so its connections close when you are done.

```python
from langchain_baponi import BaponiSandbox

with BaponiSandbox() as sandbox:  # reads BAPONI_API_KEY
    result = sandbox.execute("echo hello")
    print(result.output)
```

## Use with Deep Agents

```python
from deepagents import create_deep_agent
from langchain_baponi import BaponiSandbox

with BaponiSandbox() as sandbox:  # reads BAPONI_API_KEY
    agent = create_deep_agent(
        "anthropic:claude-sonnet-4-6",
        system_prompt="You are a coding assistant. Your workspace is /home/baponi: create files there and run commands from it.",
        backend=sandbox,
    )
    result = agent.invoke(
        {"messages": [{"role": "user", "content": "Create a hello world Python script and run it"}]}
    )
    print(result["messages"][-1].content)
```

## Use with Deep Agents Code

`langchain-baponi` also publishes a Baponi sandbox provider for [Deep Agents Code](/oss/deepagents/code/remote-sandboxes), so `dcode` can run agent tool calls inside a Baponi sandbox. Install the package into the `dcode` environment, set your API key, then select the provider:

<Note>
    Using Baponi with Deep Agents Code requires `dcode` 0.1.19 or newer and `langchain-baponi` 0.1.0 or newer, which installs `baponi[deepagents]` 0.5.0 or newer and registers the `baponi` provider.
</Note>

```bash
dcode --install langchain-baponi --package
export BAPONI_API_KEY="..."
dcode --sandbox baponi
```

Baponi sandboxes use `/home/baponi` as the default working directory. Files there persist across calls, so you can reattach to an earlier sandbox by id with `dcode --sandbox baponi --sandbox-id <id>` and pick up where you left off.

To target a self-hosted Baponi deployment instead of the managed cloud, set `BAPONI_BASE_URL` to your cluster endpoint before running `dcode`:

```bash
export BAPONI_BASE_URL="https://baponi.your-company.internal"
dcode --sandbox baponi
```

Baponi's bring-your-own-bucket storage lets the agent read and write an S3 or GCS bucket as a normal directory at `/data`, with zero credential visibility inside the sandbox (the bucket is mounted by a sidecar that holds the credentials, so they never enter the sandbox). Configure the bucket on your Baponi workspace; the [Baponi Deep Agents guide](https://baponi.ai/docs/guides/deep-agents) covers workspace setup and self-hosting.

## Cleanup

The `with` block closes the sandbox connection when it exits. Baponi executors are stateless, so no sandbox keeps running or consuming resources after your agent finishes. Persistent storage under `/home/baponi` remains available if you reattach with the same sandbox id.

See also: [Sandboxes](/oss/deepagents/sandboxes).
