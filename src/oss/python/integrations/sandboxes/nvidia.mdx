[OpenShell](https://github.com/NVIDIA/OpenShell) gives LangChain agents a policy-governed Linux sandbox for code execution, file access, process permissions, and network egress. The [`langchain-nvidia-openshell`](https://github.com/langchain-ai/langchain-nvidia/tree/main/libs/openshell) package adapts OpenShell to the Deep Agents sandbox interface. For broader NVIDIA resources, see the [NVIDIA provider page](/oss/integrations/providers/nvidia#sandboxed-agents-with-openshell).

<Note>
    OpenShell and this integration are in alpha. APIs may change.
</Note>

## Installation

<CodeGroup>

```bash pip
pip install langchain-nvidia-openshell
```

```bash uv
uv add langchain-nvidia-openshell
```

</CodeGroup>

You also need the [OpenShell CLI and gateway](https://docs.nvidia.com/openshell/latest/get-started/quickstart/). Confirm the gateway is reachable before creating a sandbox:

```bash
openshell status
openshell sandbox list
```

## Create a sandbox

Create the sandbox with the OpenShell SDK, then wrap it with the [deepagents backend](/oss/deepagents/backends):

```python
import openshell
from langchain_nvidia_openshell import OpenShellSandbox

with openshell.Sandbox(delete_on_exit=True) as sandbox:
    backend = OpenShellSandbox(sandbox=sandbox)

    result = backend.execute("python3 --version")
    print(result.output)
```

## Use with Deep Agents

The agent can run on the host with `ChatNVIDIA`, while tool execution runs inside the OpenShell sandbox through the `OpenShellSandbox` backend:

```python
import openshell
from deepagents import create_deep_agent
from langchain_nvidia_ai_endpoints import ChatNVIDIA
from langchain_nvidia_openshell import OpenShellSandbox

with openshell.Sandbox() as sandbox:
    backend = OpenShellSandbox(sandbox=sandbox)
    agent = create_deep_agent(
        model=ChatNVIDIA(model="nvidia/nemotron-3-ultra-550b-a55b"),
        system_prompt="You are a careful coding agent.",
        backend=backend,
    )
```
