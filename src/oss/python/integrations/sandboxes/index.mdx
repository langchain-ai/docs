Sandboxes provide isolated execution environments for running agent-generated code safely. Learn more about [sandboxes](/oss/deepagents/sandboxes).

| Provider | Package | Description |
|----------|---------|-------------|
| [Daytona](/oss/integrations/providers/daytona) | `langchain-daytona` | TypeScript/Python development with fast cold starts |
| [Modal](/oss/integrations/providers/modal) | `langchain-modal` | ML/AI workloads with GPU access |
| [Runloop](/oss/integrations/providers/runloop) | `langchain-runloop` | Disposable devboxes for isolated code execution |
