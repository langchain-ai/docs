This guide provides a quick overview for getting started with the Pixeltable [vector store](/oss/integrations/vectorstores#overview).

[Pixeltable](https://pixeltable.com/) is an open-source Python library providing declarative, multimodal-native data infrastructure. Unlike standalone vector databases, Pixeltable stores text, images, video, audio, and documents alongside embeddings in persistent, versioned tables with incremental computation.

Key differentiators as a vector backend:

- **Metadata filtering via `.where()`**: Filter on metadata fields *before* ranking, not post-hoc
- **Computed column lineage**: Add derived columns that auto-backfill and auto-compute on new inserts
- **Multimodal native**: Image, video, audio, and document columns alongside text
- **Incremental**: Only new/changed rows get re-embedded
- **Persistent and versioned**: Data survives restarts; every change is tracked
- **No external services**: Embedded PostgreSQL, no Docker required
- **Any embedding model**: Works with OpenAI, Hugging Face, or any local model

## Setup

Pixeltable requires no API keys or external services for storage.

### Installation

<CodeGroup>
```python pip
pip install -U langchain-pixeltable
```
```python uv
uv add langchain-pixeltable
```
</CodeGroup>

If you want to get best in-class automated tracing of your model calls, set your [LangSmith](/langsmith/home) API key and enable tracing:

## Instantiation

Works with any LangChain `Embeddings` model -- cloud or local:

<CodeGroup>
```python OpenAI icon="cloud"
from langchain_pixeltable import PixeltableVectorStore
from langchain_openai import OpenAIEmbeddings

vector_store = PixeltableVectorStore(
    table_name="mydir.documents",
    embedding=OpenAIEmbeddings(model="text-embedding-3-small"),
)
```
```python Local (no API key) icon="laptop"
from langchain_pixeltable import PixeltableVectorStore
from langchain_huggingface import HuggingFaceEmbeddings

vector_store = PixeltableVectorStore(
    table_name="mydir.documents",
    embedding=HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2"),
)
```
</CodeGroup>

The store creates a Pixeltable directory and table on first use. The embedding dimension is inferred from the embedding model.

## Manage vector store

### Add items

```python Add documents icon="folder-plus"
from langchain_core.documents import Document

documents = [
    Document(page_content="Pixeltable handles multimodal data", metadata={"category": "infra", "priority": 1}),
    Document(page_content="LangChain builds LLM applications", metadata={"category": "framework", "priority": 2}),
    Document(page_content="Vector databases store embeddings", metadata={"category": "infra", "priority": 3}),
]

vector_store.add_documents(documents=documents, ids=["1", "2", "3"])
```

### Delete items

```python Delete documents by IDs icon="trash"
vector_store.delete(ids=["3"])
```

## Query vector store

### Similarity search

```python Basic similarity search icon="folders"
results = vector_store.similarity_search("multimodal data management", k=2)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

### Filtered similarity search

The `filter` parameter maps to Pixeltable's `.where()` clause -- predicates are evaluated **before** ranking, so only matching rows participate in the similarity sort:

```python Filter by metadata icon="filter"
results = vector_store.similarity_search(
    "data infrastructure",
    k=5,
    filter={"category": "infra"},
)
for doc in results:
    print(f"* {doc.page_content} [category={doc.metadata['category']}]")
```

### With scores

```python Similarity search with scores icon="star-half"
results = vector_store.similarity_search_with_score(
    "multimodal data", k=2, filter={"category": "infra"},
)
for doc, score in results:
    print(f"* [SIM={score:.3f}] {doc.page_content}")
```

### As retriever

```python Create retriever icon="robot"
retriever = vector_store.as_retriever(search_kwargs={"k": 3})
retriever.invoke("What is multimodal data infrastructure?")
```

## Access the underlying Pixeltable table

The `.table` property gives you the raw Pixeltable table for operations beyond the VectorStore interface -- computed columns, lineage, joins, version history, and arbitrary `.where()` predicates:

```python Computed columns with lineage icon="link"
import pixeltable as pxt

t = vector_store.table

# Inspect data
t.select(t.text, t.metadata, t.embedding).collect()

# Add computed columns -- auto-backfills existing rows
t.add_computed_column(word_count=my_word_counter(t.text))

# New inserts via the wrapper auto-compute lineage columns
vector_store.add_texts(["New document"], metadatas=[{"category": "infra"}])

# WHERE on computed columns + similarity
import numpy as np
sim = t.embedding.similarity(vector=np.array(query_vec, dtype=np.float32))
results = (
    t.where(t.word_count > 5)
    .order_by(sim, asc=False)
    .limit(3)
    .select(t.text, t.word_count, sim=sim)
    .collect()
)
```

## Connect to an existing Pixeltable table

If you already have a Pixeltable table -- including tables with multimodal columns like images or video -- connect directly:

```python
vs = PixeltableVectorStore.from_existing_table(
    table_name="mydir.existing_docs",
    embedding=OpenAIEmbeddings(),
    text_column="content",
    embedding_column="content_embedding",
)
results = vs.similarity_search("search query", filter={"source": "arxiv"})
```
