This guide provides a quick overview for getting started with the Pixeltable [vector store](/oss/integrations/vectorstores#overview).

[Pixeltable](https://pixeltable.com/) is an open-source Python library providing declarative, multimodal-native data infrastructure. Unlike standalone vector databases, Pixeltable stores text, images, video, audio, and documents alongside embeddings in persistent, versioned tables with incremental computation.

Key differentiators as a vector backend:

- **Multimodal native**: Image, video, audio, and document columns alongside text
- **Incremental**: Only new/changed rows get re-embedded
- **Persistent and versioned**: Data survives restarts; every change is tracked
- **No external services**: Embedded PostgreSQL, no Docker required
- **25+ AI providers**: Built-in functions for OpenAI, Anthropic, Gemini, and more

## Setup

Pixeltable requires no API keys or external services for storage.

### Installation

<CodeGroup>
```python pip
pip install -U langchain-pixeltable
```
```python uv
uv add langchain-pixeltable
```
</CodeGroup>

If you want to get best in-class automated tracing of your model calls, set your [LangSmith](/langsmith/home) API key and enable tracing:

## Instantiation

```python Initialize vector store icon="database"
from langchain_pixeltable import PixeltableVectorStore
from langchain_openai import OpenAIEmbeddings

vector_store = PixeltableVectorStore(
    table_name="mydir.documents",
    embedding=OpenAIEmbeddings(model="text-embedding-3-small"),
)
```

The store creates a Pixeltable directory and table on first use. The embedding dimension is inferred from the embedding model.

## Manage vector store

### Add items

```python Add documents icon="folder-plus"
from langchain_core.documents import Document

documents = [
    Document(page_content="Pixeltable handles multimodal data", metadata={"source": "docs"}),
    Document(page_content="LangChain builds LLM applications", metadata={"source": "docs"}),
    Document(page_content="Vector databases store embeddings", metadata={"source": "tutorial"}),
]

vector_store.add_documents(documents=documents, ids=["1", "2", "3"])
```

### Delete items

```python Delete documents by IDs icon="trash"
vector_store.delete(ids=["3"])
```

## Query vector store

### Directly

```python Similarity search icon="folders"
results = vector_store.similarity_search("multimodal data management", k=2)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

With scores:

```python Similarity search with scores icon="star-half"
results = vector_store.similarity_search_with_score("multimodal data", k=2)
for doc, score in results:
    print(f"* [SIM={score:.3f}] {doc.page_content} [{doc.metadata}]")
```

### By turning into retriever

```python Create retriever icon="robot"
retriever = vector_store.as_retriever(search_kwargs={"k": 3})
retriever.invoke("What is multimodal data infrastructure?")
```

## Connect to an existing Pixeltable table

If you already have a Pixeltable table with an embedding index, connect directly:

```python
vs = PixeltableVectorStore.from_existing_table(
    table_name="mydir.existing_docs",
    embedding=OpenAIEmbeddings(),
    text_column="content",
    embedding_column="content_embedding",
)
results = vs.similarity_search("search query")
```
