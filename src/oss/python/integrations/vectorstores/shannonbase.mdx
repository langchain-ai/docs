This guide provides a quick overview for getting started with the ShannonBase [vector store](/oss/integrations/vectorstores#overview). It stores embeddings in MySQL 9's native `VECTOR` type and works against [ShannonBase](https://github.com/Shannon-Data/ShannonBase), self-hosted MySQL 9, and MySQL HeatWave, which share the same `VECTOR` / `STRING_TO_VECTOR` / `DISTANCE` surface. For all `ShannonBaseVectorStore` features and parameters, see the [package README](https://github.com/apoorva-01/langchain-shannonbase).

## Setup

To use the ShannonBase vector store you need a MySQL-9-compatible database with the `VECTOR` type. For local development, [ShannonBase](https://github.com/Shannon-Data/ShannonBase) gives you those features without a HeatWave subscription.

### Credentials

The store connects to your database directly, so there's no API key to set. Pass the connection details when you create the store (see below). You will need credentials for whatever embedding model you use.

To enable automated <Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your model calls, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
import getpass
import os

os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation

The integration lives in the `langchain-shannonbase` package. The `[mysql]` extra pulls in the database driver:

<CodeGroup>
    ```python pip
    pip install -U "langchain-shannonbase[mysql]"
    ```
    ```python uv
    uv add "langchain-shannonbase[mysql]"
    ```
</CodeGroup>

## Instantiation

Point the store at your database and give it an embedding model:

```python Initialize vector store icon="database"
from langchain_openai import OpenAIEmbeddings
from langchain_shannonbase import ShannonBaseVectorStore

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

vector_store = ShannonBaseVectorStore(
    embedding=embeddings,
    table="documents",
    host="127.0.0.1",
    port=3306,
    user="root",
    password="",
    database="rag",
)
```

The table is created on first write, with an `embedding VECTOR(n)` column sized to your embedding model.

## Manage vector store

### Add items

```python Add documents icon="folder-plus"
from langchain_core.documents import Document

documents = [
    Document(page_content="Refunds are accepted within 30 days.", metadata={"topic": "refunds"}, id="1"),
    Document(page_content="Free shipping on orders over $50.", metadata={"topic": "shipping"}, id="2"),
]

vector_store.add_documents(documents=documents)
```

### Update items

Adding a document with an existing `id` upserts it, so updating is just another `add_documents` call:

```python Update a document icon="pen"
updated = Document(page_content="Refunds are accepted within 60 days.", metadata={"topic": "refunds"}, id="1")

vector_store.add_documents(documents=[updated])
```

### Delete items

```python Delete by id icon="trash"
vector_store.delete(ids=["2"])
```

## Query vector store

### Directly

```python Similarity search icon="magnifying-glass"
results = vector_store.similarity_search("what is the return policy?", k=2)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

To get cosine similarity scores back with each result:

```python Search with score icon="magnifying-glass-chart"
results = vector_store.similarity_search_with_score("return policy?", k=2)
for doc, score in results:
    print(f"* [{score:.3f}] {doc.page_content}")
```

You can restrict a search to matching metadata, or use maximal marginal relevance for more diverse results:

```python Filtering and MMR icon="filter"
# only return documents whose metadata matches
vector_store.similarity_search("policy?", k=2, filter={"topic": "refunds"})

# pick results that aren't near-duplicates of each other
vector_store.max_marginal_relevance_search("policy?", k=3, fetch_k=20, lambda_mult=0.5)
```

### By turning into retriever

```python As a retriever icon="filter"
retriever = vector_store.as_retriever(search_kwargs={"k": 2})
retriever.invoke("return policy?")
```
