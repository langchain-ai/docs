This guide provides a quick overview for getting started with the VAST Database [vector store](/oss/integrations/vectorstores#overview). For detailed documentation of all `VastDBVectorStore` features and configurations, head to the [API reference](https://github.com/vast-data/vast-vector-store).

## Overview

[VAST Database](https://vastdata.com/) is a high-performance, exabyte-scale data platform with native vector indexing. The `VastDBVectorStore` class implements the LangChain `VectorStore` interface, enabling similarity search, document storage, and RAG workflows backed by VAST Database.

| Feature | Support |
| :--- | :--- |
| Package | [`langchain-vastdb`](https://pypi.org/project/langchain-vastdb/) |
| Similarity search | L2 squared, cosine, inner product |
| Delete by ID | Yes |
| Metadata filtering | Yes |
| Search by vector | Yes |
| Search with score | Yes |
| Standard tests | Yes |

## Setup

To use the VAST Database vector store you need:

- A running VAST Database cluster with vector index support
- The `vastdb` SDK (installed automatically with `langchain-vastdb`)
- An embedding model (e.g., OpenAI, HuggingFace, or any LangChain-compatible embeddings)

### Credentials

VAST Database uses S3-style access key / secret key authentication. No cloud API key is needed — credentials are for your VAST cluster.

```python
import getpass
import os

if "VAST_ACCESS_KEY" not in os.environ:
    os.environ["VAST_ACCESS_KEY"] = getpass.getpass("Enter your VAST access key: ")
if "VAST_SECRET_KEY" not in os.environ:
    os.environ["VAST_SECRET_KEY"] = getpass.getpass("Enter your VAST secret key: ")
```

To enable automated <Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your model calls, set your [LangSmith](/langsmith/observability) API key:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Initialization

### From a pre-built session

```python
import vastdb
from langchain_vastdb import VastDBVectorStore

session = vastdb.connect(
    endpoint="http://vast-cluster:8070",
    access="YOUR_ACCESS_KEY",
    secret="YOUR_SECRET_KEY",
)

vector_store = VastDBVectorStore(
    embedding=embeddings,
    session=session,
    bucket="my-bucket",
    schema="my-schema",
    table_name="my-table",
)
```

### From connection parameters

Use the convenience factory to create a session internally:

```python
from langchain_vastdb import VastDBVectorStore

vector_store = VastDBVectorStore.from_connection_params(
    embedding=embeddings,
    endpoint="http://vast-cluster:8070",
    access_key="YOUR_ACCESS_KEY",
    secret_key="YOUR_SECRET_KEY",
    bucket="my-bucket",
    schema="my-schema",
    table_name="my-table",
)
```

## Manage vector store

### Add items

```python
from langchain_core.documents import Document

document_1 = Document(
    page_content="I had chocolate chip pancakes and scrambled eggs for breakfast this morning.",
    metadata={"source": "tweet"},
)
document_2 = Document(
    page_content="The weather forecast for tomorrow is cloudy and overcast, with a high of 62 degrees.",
    metadata={"source": "news"},
)
document_3 = Document(
    page_content="Building an exciting new project with LangChain - come check it out!",
    metadata={"source": "tweet"},
)

documents = [document_1, document_2, document_3]
ids = vector_store.add_documents(documents=documents, ids=["1", "2", "3"])
```

### Delete items

```python
vector_store.delete(ids=["3"])
```

## Query vector store

### Directly

Performing a simple similarity search:

```python
results = vector_store.similarity_search(
    "LangChain provides abstractions to make working with LLMs easy",
    k=2,
    filter={"source": "tweet"},
)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

### Similarity search with scores

```python
results = vector_store.similarity_search_with_score(
    "Will it be hot tomorrow?", k=1, filter={"source": "news"}
)
for doc, score in results:
    print(f"* [SIM={score:3f}] {doc.page_content} [{doc.metadata}]")
```

### Search by vector

```python
results = vector_store.similarity_search_by_vector(
    embedding=embeddings.embed_query("I love green eggs and ham!"), k=1
)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

### By turning into retriever

You can transform the vector store into a retriever for use in your chains:

```python
retriever = vector_store.as_retriever(search_kwargs={"k": 3})
retriever.invoke("What is the weather forecast?")
```

## Typed metadata columns

By default, document metadata is stored as a single JSON column. For performance-critical filtering, you can define typed metadata columns by subclassing `VastDBVectorStore`:

```python
from langchain_vastdb import TypedColumn, VastDBVectorStore


class TypedMetadataStore(VastDBVectorStore):
    _typed_metadata_columns = {
        "category": TypedColumn(),
        "priority": TypedColumn(),
    }
```

This extracts `category` and `priority` into dedicated typed columns for efficient database-level filtering, while keeping remaining metadata in the JSON column.
