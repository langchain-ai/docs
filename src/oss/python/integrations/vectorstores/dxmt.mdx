>[DXMT](https://github.com/dxmt/dxmt) is an open-source memory database for personal agents with a vector database underneath: one Rust binary with HNSW and HNSW-PQ vector search, BM25 full-text search (Chinese word segmentation included), hybrid fusion, metadata filters, a write-ahead log, and server-side embedding.

This guide shows how to use DXMT with LangChain for dense, hybrid and diversified (MMR) retrieval. `langchain-dxmt` runs LangChain's standard `VectorStoreIntegrationTests` against a live server in its own CI.

## Setup

DXMT runs as a server. Start one from a [release binary](https://github.com/dxmt/dxmt/releases) or with Docker:

```bash
docker run -d --name dxmt -p 127.0.0.1:9999:9999 -v dxmt:/data dxmtai/dxmt:latest
```

### Credentials

None are needed for a local server. If the server was started with `DXMT_API_KEY`, pass the same value as `api_key=` to the store.

To enable automated <Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip> of your model calls, set your [LangSmith](/langsmith/observability) API key:

```python Enable tracing icon="flask"
import getpass
import os

os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

<EmbeddingTabs/>

```python
from langchain_dxmt import DXMTVectorDB

vector_store = DXMTVectorDB(
    table_name="documents",
    embedding=embeddings,
    dimension=1536,          # the width of the embedding model's vectors
    host="localhost",
    port=9999,
    distance_metric="cosine",
)
```

A table that already exists is opened as it is, with its own dimension and metric:

```python
vector_store = DXMTVectorDB.from_existing_table("documents", embedding=embeddings)
```

### Letting the server embed

With `embedding=None`, the server computes the vectors: texts go in as text and queries are embedded with the table's model, so no embedding model runs in your process. `server_embedding` names the model when the store creates the table; `base_url` points it at any OpenAI-compatible `/embeddings` endpoint (ollama, text-embeddings-inference, vLLM, LM Studio), and `api_key_env` names an environment variable **of the server**, so no key is ever in a request body.

```python
vector_store = DXMTVectorDB(
    table_name="documents",
    embedding=None,
    server_embedding={"model": "text-embedding-3-small"},   # the server reads OPENAI_API_KEY
)
```

## Manage vector store

### Add items to vector store

```python
from uuid import uuid4

from langchain_core.documents import Document

document_1 = Document(page_content="I had chocolate chip pancakes and scrambled eggs for breakfast this morning.", metadata={"source": "tweet"})
document_2 = Document(page_content="The weather forecast for tomorrow is cloudy and overcast, with a high of 62 degrees.", metadata={"source": "news"})
document_3 = Document(page_content="Building an exciting new project with LangChain - come check it out!", metadata={"source": "tweet"})
document_4 = Document(page_content="Robbers broke into the city bank and stole $1 million in cash.", metadata={"source": "news"})

documents = [document_1, document_2, document_3, document_4]
uuids = [str(uuid4()) for _ in range(len(documents))]

vector_store.add_documents(documents=documents, ids=uuids)
```

Writing an id again replaces that record.

### Delete items from vector store

```python
vector_store.delete(ids=[uuids[-1]])
```

A delete that fails raises; it does not return `False`.

## Query vector store

### Query directly

```python
results = vector_store.similarity_search(
    "LangChain provides abstractions to make working with LLMs easy", k=2
)
for res in results:
    print(f"* {res.page_content} [{res.metadata}]")
```

With scores:

```python
results = vector_store.similarity_search_with_score("Will it be hot tomorrow?", k=1)
for res, score in results:
    print(f"* [SIM={score:3f}] {res.page_content} [{res.metadata}]")
```

### Metadata filtering

Filters are MongoDB-style dicts. Every operator either translates exactly to the server's filter or raises a `ValueError` naming the shape it cannot express; nothing is approximated.

```python
vector_store.similarity_search(
    "stealing from the bank is a crime",
    k=2,
    filter={"source": {"$eq": "news"}},
)
vector_store.similarity_search(
    "breakfast",
    k=2,
    filter={"$and": [{"source": "tweet"}, {"likes": {"$gte": 10}}]},
)
```

Supported: `$eq $ne $gt $gte $lt $lte $in $nin $contains $startswith $endswith $isempty $isnull` and `$and $or $nor $not`. A field holding an array matches when any element does.

### Hybrid search

A table created with `enable_full_text_search=True` has a BM25 index over the text beside the vectors, and `hybrid_search` fuses the two rankings on the server:

```python
vector_store = DXMTVectorDB(
    table_name="documents_fts",
    embedding=embeddings,
    dimension=1536,
    enable_full_text_search=True,
)
vector_store.add_documents(documents)

vector_store.hybrid_search("bank robbery", k=2)                      # the server's default fusion
vector_store.hybrid_search("bank robbery", k=2, vector_weight=0.3)   # mostly keywords
```

### Maximal marginal relevance

MMR is computed on the server over `fetch_k` candidates, so diversity is not limited to the page the client fetched:

```python
vector_store.max_marginal_relevance_search("LangChain", k=2, fetch_k=20, lambda_mult=0.5)
```

### Query by turning into retriever

```python
retriever = vector_store.as_retriever(search_type="mmr", search_kwargs={"k": 1})
retriever.invoke("Stealing from the bank is a crime")
```
