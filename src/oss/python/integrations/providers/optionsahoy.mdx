[OptionsAhoy](https://optionsahoy.com) provides keyless equity-compensation tax calculators (incentive stock option (ISO) and alternative minimum tax (AMT) exercise scheduling, non-qualified stock options (NSO), restricted stock units (RSU), qualified small business stock (QSBS), single-stock concentration, protective-put hedging, and funding a cash goal from equity) as a public REST API and Model Context Protocol (MCP) server.

## Installation and setup

```bash
pip install optionsahoy-langchain
```
