[ZeroGPU](https://zerogpu.ai) is an ultra-fast, compute-efficient inference provider built for apps and agents. ZeroGPU runs purpose-built small and nano language models across an edge-powered network, engineered for the high-volume, purpose-specific tasks that apps and agent loops run constantly.

ZeroGPU maintains a growing catalog of specialized models and use cases across Adtech, agentic tasks, security, classification, extraction, summarization, moderation, intent extraction, routing, and document parsing. Each model is tuned for its job, so you get frontier-level results on tasks that do not need a frontier model, at a fraction of the cost and latency. For agents firing hundreds of model calls per session, that is the difference between a workflow that pencils out and one that does not.

There are no GPUs to provision and no clusters to manage. ZeroGPU is serverless and auto-scaling by default: plug in the OpenAI-compatible API, point a workload at it, and you are live. Frontier models for reasoning, ZeroGPU for everything repeatable around it.

The [`langchain-zerogpu`](https://pypi.org/project/langchain-zerogpu/) package exposes these models as LangChain [tools](/oss/langchain/tools), so any LangChain agent can offload repeatable NLP tasks (classification, summarization, entity and JSON extraction, PII redaction, and short chat) to ZeroGPU instead of spending frontier-model tokens.

<Note>
    `langchain-zerogpu` is community-maintained by [ZeroGPU](https://github.com/zerogpu/langchain-zerogpu).
</Note>

## Installation and setup

Install the ZeroGPU integration package for LangChain Python:

<CodeGroup>
```bash pip
pip install langchain-zerogpu
```

```bash uv
uv add langchain-zerogpu
```
</CodeGroup>

Every request needs a ZeroGPU API key (starts with `zgpu-api-`) and a project ID. Create both in the [ZeroGPU dashboard](https://platform.zerogpu.ai/dashboard) and set them as environment variables:

```bash
export ZEROGPU_API_KEY="zgpu-api-..."
export ZEROGPU_PROJECT_ID="your-project-id"
```

You can also pass `api_key` and `project_id` directly to any tool or to the toolkit.

## Tools

Each tool routes a single text-in, structured-out task to a purpose-built ZeroGPU model:

| Tool class | ZeroGPU model | Purpose |
|------------|---------------|---------|
| `ZeroGPUChatTool` | `LFM2.5-1.2B-Instruct` | Short single-turn chat reply |
| `ZeroGPUChatThinkingTool` | `LFM2.5-1.2B-Thinking` | Chat with a visible reasoning trace |
| `ZeroGPUSummarizeTool` | `llama-3.1-8b-instruct-fast` | Condense a passage |
| `ZeroGPUClassifyIABTool` | `zlm-v1-iab-classify-edge` | IAB taxonomy classification |
| `ZeroGPUClassifyIABEnrichedTool` | `zlm-v1-iab-classify-edge-enriched` | IAB plus topics, keywords, and intent |
| `ZeroGPUClassifyZeroShotTool` | `deberta-v3-small` | Zero-shot classification against custom labels |
| `ZeroGPUClassifyStructuredTool` | `gliner2-base-v1` | Multi-axis schema classification |
| `ZeroGPUExtractEntitiesTool` | `gliner2-base-v1` | Custom-label named-entity recognition |
| `ZeroGPUExtractPIITool` | `gliner-multi-pii-v1` | Extract PII entities as JSON |
| `ZeroGPURedactPIITool` | `gliner-multi-pii-v1` | Mask PII inline with `[LABEL]` placeholders |
| `ZeroGPUExtractJSONTool` | `gliner2-base-v1` | Schema-driven JSON extraction |

See [usage examples](/oss/integrations/tools/zerogpu).

```python
from langchain_zerogpu import ZeroGPUSummarizeTool
```

## Toolkit

`ZeroGPUToolkit` registers all eleven tools at once, wired to a single shared client:

```python
from langchain_zerogpu import ZeroGPUToolkit

tools = ZeroGPUToolkit().get_tools()
```

See a [usage example](/oss/integrations/tools/zerogpu#use-within-an-agent).
