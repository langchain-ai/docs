>[Dewey](https://meetdewey.com) is a real-time document backend for AI applications. Upload a document collection and Dewey handles conversion, section extraction, chunking, and embedding — all immediately queryable via hybrid semantic + BM25 search.

## Installation and setup

Install the `langchain-dewey` package and set your API key.

<CodeGroup>
```bash pip
pip install langchain-dewey
```

```bash uv
uv add langchain-dewey
```
</CodeGroup>

Get an API key by signing up at [meetdewey.com](https://meetdewey.com).

```python
import os
os.environ["DEWEY_API_KEY"] = "dwy_live_..."
```
