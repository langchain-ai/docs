[AlphaAI](https://alphai.io) is a financial news API built for AI agents. Every
article on the feed carries per-ticker impact analysis, one of 14 categories,
and a 1-10 market-relevance score, and SEC Form 4 insider filings arrive as
structured events (who traded, side, shares, value, 10b5-1 flag).

The [`langchain-alphai`](https://github.com/makeev/langchain-alphai) package
exposes the feed as four tools and a retriever.

## Installation

```bash
pip install langchain-alphai
```

Create an API key at [alphai.io/developers](https://alphai.io/developers) (a
free tier is available) and set it as an environment variable:

```bash
export ALPHAI_API_KEY="ak_live_..."
```

## Tools

```python
from langchain_alphai import (
    AlphaAIInsiderNews,
    AlphaAIInsiderSummary,
    AlphaAINewsSearch,
    AlphaAITickerSentiment,
)

AlphaAINewsSearch().invoke({"symbol": "NVDA", "min_relevance": 7})
AlphaAIInsiderNews().invoke({"symbol": "NVDA"})
AlphaAITickerSentiment().invoke({"ticker": "NVDA"})
AlphaAIInsiderSummary().invoke({"ticker": "NVDA"})
```

## Retriever

The query is a ticker symbol; each `Document` is an article's title plus
summary, with the enrichment in `metadata`:

```python
from langchain_alphai import AlphaAINewsRetriever

retriever = AlphaAINewsRetriever(min_relevance=7, k=5)
docs = retriever.invoke("NVDA")
```
