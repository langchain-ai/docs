> [PaddleOCR](https://www.paddleocr.com) is a powerful and lightweight OCR toolkit developed by Baidu that connects images and PDFs with LLMs. It supports over 100 languages and transforms document content into structured, AI-ready data.
>
> This integration provides PaddleOCR's large-model document parsing capabilities via the `PaddleOCRVLLoader` document loader.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-paddleocr
```

```bash uv
uv add langchain-paddleocr
```
</CodeGroup>

You also need an API access token. Get one from the [PaddleOCR website](https://www.paddleocr.com) by clicking the **API** button and copying the URL and token from the invocation example.

Set the token as an environment variable:

```bash
export PADDLEOCR_ACCESS_TOKEN="your-access-token"
```

## Document loader

The `PaddleOCRVLLoader` extracts text and layout information from PDFs and images using Baidu's PaddleOCR-VL model series (including PaddleOCR-VL and PaddleOCR-VL-1.5). It supports both local files and remote URLs.

```python
from langchain_paddleocr import PaddleOCRVLLoader

loader = PaddleOCRVLLoader(
    file_path="path/to/document.pdf",
    api_url="your-api-endpoint"
)

docs = loader.load()
```

For end-to-end usage check out
[the PaddleOCR-VL document loader guide](/oss/integrations/document_loaders/paddleocr_vl).
