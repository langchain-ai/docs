> **Rust-powered PDF parsing for RAG** — fast, local, no system dependencies.

> [oxidize-pdf](https://github.com/bzsanti/oxidize-python) is a PDF engine written in
> Rust with first-class RAG primitives. It produces element-disjoint semantic chunks
> with heading-aware context, so PDFs become retrieval-ready without any post-processing.
>
> **Why oxidize-pdf:**
> - **Fast & low-memory** — native Rust parser, efficient on large PDFs.
> - **RAG-native** — element-disjoint semantic chunking; no chunk's text is a substring
>   of another's, and each source element appears in exactly one chunk (enforced by
>   regression tests).
> - **No system dependencies** — ships as a wheel for Linux, macOS, and Windows.

## Installation

```bash
pip install -U langchain-oxidize-pdf
```

The package depends on `langchain-core` and `oxidize-pdf>=0.4.3`.

## Document loaders

The integration exposes `OxidizePdfLoader`, a `BaseLoader` with three modes (`rag`,
`pages`, `markdown`).

See the [oxidize-pdf document loader guide](/oss/integrations/document_loaders/oxidize_pdf)
for full usage.

```python
from langchain_oxidize_pdf import OxidizePdfLoader

loader = OxidizePdfLoader("paper.pdf")  # mode="rag" by default
documents = loader.load()
```
