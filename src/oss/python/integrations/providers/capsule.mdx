> [Capsule](https://github.com/mavdol/capsule) runs untrusted code in isolated WebAssembly sandboxes.
> The sandbox binaries are bundled inside the package with no cloud dependencies.

## Installation and setup

You have to install a Python package:

<CodeGroup>
```bash pip
pip install langchain-capsule
```

```bash uv
uv add langchain-capsule
```
</CodeGroup>

## Tools

See a [usage example](/oss/integrations/tools/capsule).

```python
from langchain_capsule import (
    CapsulePythonTool,
    CapsuleJSTool,
    CapsulePythonREPLTool,
    CapsuleJSREPLTool,
)
```
