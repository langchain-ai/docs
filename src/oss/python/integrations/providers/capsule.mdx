> [Capsule](https://github.com/mavdol/capsule) runs untrusted code in isolated WebAssembly sandboxes.
> The sandbox binaries are bundled inside the package — no server, API key, or network request required.

## Installation and setup

Install the Python package:

<CodeGroup>
```bash pip
pip install langchain-capsule
```

```bash uv
uv add langchain-capsule
```
</CodeGroup>

## Tools

See usage examples:

- [Stateless tools](/oss/integrations/tools/capsule#stateless-execution) — `CapsulePythonTool`, `CapsuleJSTool`
- [Session-based REPL tools](/oss/integrations/tools/capsule#session-based-execution) — `CapsulePythonREPLTool`, `CapsuleJSREPLTool`

```python
from langchain_capsule import (
    CapsulePythonREPLTool,
    CapsulePythonTool,
    CapsuleJSREPLTool,
    CapsuleJSTool,
)
```
