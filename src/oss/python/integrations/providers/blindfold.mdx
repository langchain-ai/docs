[Blindfold](https://blindfold.dev) provides PII detection and protection for AI applications. It detects personally identifiable information in text and applies protection methods like tokenization, redaction, masking, hashing, synthesis, and encryption.

## Installation and setup

Install the integration package:

```python
pip install -U langchain-blindfold
```

Get a Blindfold API key from [blindfold.dev](https://blindfold.dev) and set it as an environment variable (`BLINDFOLD_API_KEY`).

## Tools

Blindfold provides LangChain Runnables for protecting PII in chains and a DocumentTransformer for RAG pipelines:

```python
from langchain_blindfold import blindfold_protect, BlindfoldPIITransformer
```

For detailed documentation and examples, see the [tools guide](/oss/integrations/tools/blindfold).
