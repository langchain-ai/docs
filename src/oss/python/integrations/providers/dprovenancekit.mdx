> **What is DProvenanceKit?** [DProvenanceKit](https://github.com/Therealdk8890/DProvenanceKitPython) is an open source (Apache-2.0) library for reasoning observability and regression testing of LLM agents. It records each run as a queryable, diffable trace, then diffs a candidate run against a golden baseline and fails CI when a reasoning step is dropped, a tool loops, or the execution path drifts — even when the final answer still looks right. The core depends only on the Python standard library; LangChain support is an optional extra.

## Tracing LangChain

DProvenanceKit integrates with LangChain through a callback handler—the standard mechanism for hooking into the execution of LangChain and LangGraph components. `DProvenanceTracer.trace(...)` yields a `langchain-core` `BaseCallbackHandler` that you pass via `config={"callbacks": [cb]}`. Every LLM, tool, chain, and retriever event in the run is recorded as a typed, ordered trace you can query, diff, and fingerprint.

Install the LangChain extra:

```bash
pip install "dprovenancekit[langchain]"
```

```python
from dprovenancekit import SQLiteTraceStore
from dprovenancekit.integrations.langchain import DProvenanceTracer, LangChainTraceEvent
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

# A store persists recorded runs so you can query and diff them later
store = SQLiteTraceStore(LangChainTraceEvent, "traces.sqlite")
tracer = DProvenanceTracer(store)

# Build any LangChain chain
llm = ChatOpenAI(model="gpt-5.5")
prompt = ChatPromptTemplate.from_template("Tell me a joke about {topic}")
chain = prompt | llm

# `trace()` yields a callback handler; pass it to the chain to record the run
with tracer.trace(context_id="customer-42") as cb:
    response = chain.invoke({"topic": "cats"}, config={"callbacks": [cb]})

print(response.content)

# Afterwards: query the recorded run, diff it against a golden baseline, or
# compare run fingerprints to detect when the agent took a different path.
```

## Tracing LangGraph

The same handler works with LangGraph, which propagates callbacks through the graph. Pass the handler in `config={"callbacks": [cb]}` on `graph.invoke(...)` or `graph.stream(...)`:

```python
with tracer.trace(context_id="customer-42") as cb:
    result = graph.invoke(
        {"messages": [{"role": "user", "content": "What is DProvenanceKit?"}]},
        config={"callbacks": [cb]},
    )
```

## Regression-gating in CI

Because each run is recorded structurally, DProvenanceKit can diff a candidate run against a known-good ("golden") run and fail CI when a step is dropped, added, or reordered, or when a tool loops. For the end-to-end workflow, see the [DProvenanceKit LangChain guide](https://dprovenance.dev/langchain/) and the [Python package](https://github.com/Therealdk8890/DProvenanceKitPython) (PyPI: [`dprovenancekit`](https://pypi.org/project/dprovenancekit/)).
