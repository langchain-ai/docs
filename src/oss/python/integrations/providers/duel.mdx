>[Duel Agents](https://duelagents.com) runs each prompt against multiple models
> concurrently and bills the cheapest answer that still wins. The proxy is wire
> compatible with the OpenAI chat completions API, so existing LangChain code
> works by pointing at the Duel endpoint.

## Installation and setup

Install the `langchain-duel` package and set your Duel API key (create one at
[duelagents.com](https://duelagents.com)):

<CodeGroup>
```bash pip
pip install -U langchain-duel
```

```bash uv
uv add langchain-duel
```

</CodeGroup>

```bash
export DUEL_API_KEY="duel_<prefix>_<secret>"
```
