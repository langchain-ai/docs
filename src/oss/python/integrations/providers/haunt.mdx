[Haunt](https://hauntapi.com?utm_source=langchain&utm_medium=integration&utm_campaign=sweep-2026-07) is a web extraction API built for AI agents. It reads public web pages and returns structured JSON or clean markdown. When a page cannot be read, Haunt returns a plain error code (for example `access_denied`, `login_required`, `not_found`) instead of invented content, so an agent can branch on the failure. Failed reads are not charged.

## Installation and setup

Install the integration package:

<CodeGroup>
```bash pip
pip install langchain-haunt
```

```bash uv
uv add langchain-haunt
```
</CodeGroup>

## API Key

Get a free API key (no card) at [hauntapi.com](https://hauntapi.com/#signup) and add it to your environment variables:

```
export HAUNT_API_KEY="your-api-key-here"
```

## Tools

`HauntExtract` extracts structured data or clean text from a public web page from a URL and a plain-language prompt.

```python
from langchain_haunt import HauntExtract
```

See our [tool documentation and usage example](/oss/integrations/tools/haunt).

## Document loader

`HauntLoader` loads web pages as clean markdown Documents, ready for splitting and embedding.

```python
from langchain_haunt import HauntLoader
```

See our [document loader documentation and usage example](/oss/integrations/document_loaders/haunt).
