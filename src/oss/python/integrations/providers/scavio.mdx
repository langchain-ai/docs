[Scavio](https://scavio.dev) is a multi-platform search API designed for AI agents.
Scavio provides real-time web search with structured SERP data including knowledge graphs,
"People Also Ask", and related searches across Google, Amazon, YouTube, and Walmart.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-scavio
```

```bash uv
uv add langchain-scavio
```
</CodeGroup>
