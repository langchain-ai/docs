[Keenable](https://keenable.ai) is a web-search and page-fetch API built for AI agents.
It returns ranked web results and renders any page to clean markdown, with a keyless free
tier so agents work out of the box and an optional API key that lifts rate limits.

**Key capabilities:**

- **Search built for agents**: ranked results with title, URL, description, and
  publication / index dates.
- **Per-query filters**: restrict by `site` and by publication/index date ranges, and pick
  `pro` (default) or `realtime` mode — all per call.
- **Page fetch**: turn any URL into markdown for grounded reading after a search.
- **Keyless by default**: the public endpoints work with no signup; set `KEENABLE_API_KEY`
  to raise limits and enable `realtime`.

For more information, visit [keenable.ai](https://keenable.ai) or the
[Keenable API reference](https://docs.keenable.ai).

## Installation and setup

The Keenable integration lives in its own partner package:

<CodeGroup>
```bash pip
pip install -U langchain-keenable
```
```bash uv
uv add langchain-keenable
```
</CodeGroup>

Both tools work with no key via their keyless public endpoints. To use the authenticated
endpoints (higher limits and `realtime` mode), set `KEENABLE_API_KEY` to a key created in
the [Keenable console](https://keenable.ai/console).
