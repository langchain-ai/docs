[ProxyHat](https://proxyhat.com) provides residential proxy infrastructure for reliable web access, letting AI agents and RAG pipelines fetch pages that may be geo-restricted or protected by anti-bot measures.

The `langchain-proxyhat` package exposes ProxyHat as a LangChain tool and document loader, so agents can retrieve live web content and pipelines can ingest URLs through ProxyHat's residential proxy network (rotating IPs, sticky sessions, and country/city geo-targeting).

## Installation and setup

Install the ProxyHat integration package:

<CodeGroup>
```bash pip
pip install langchain-proxyhat
```

```bash uv
uv add langchain-proxyhat
```

</CodeGroup>

Sign up at [proxyhat.com](https://proxyhat.com), grab an API key, and set it as an environment variable named `PROXYHAT_API_KEY` (it auto-selects an active residential sub-user):

```python
import os

os.environ["PROXYHAT_API_KEY"] = "your-api-key"
```

You can also pass explicit gateway credentials (`username` / `password`) instead of an API key.

## Tools

### ProxyHatFetchTool

A tool that fetches the text of a URL through ProxyHat residential proxies, giving an agent honest access to the open web from a residential IP.

See a [usage example](/oss/python/integrations/tools/proxyhat).

```python
from langchain_proxyhat import ProxyHatFetchTool
```

## Document loaders

### ProxyHatLoader

A document loader that retrieves one or more URLs through ProxyHat residential proxies and returns them as LangChain `Document` objects for indexing in RAG pipelines.

```python
from langchain_proxyhat import ProxyHatLoader
```

## Components reference

| Class | Abstraction | Import path | Description |
|-------|-------------|-------------|-------------|
| `ProxyHatFetchTool` | Tool | `from langchain_proxyhat import ProxyHatFetchTool` | Fetches a URL's text through ProxyHat residential proxies. |
| `ProxyHatLoader` | Document loader | `from langchain_proxyhat import ProxyHatLoader` | Loads web pages through ProxyHat proxies as `Document` objects. |
