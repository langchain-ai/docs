[Yutori](https://yutori.com) provides browser-control LLMs and a hosted web-automation API: Navigator (a pixels-to-actions chat model), Browsing (one-shot tasks on a remote browser), Research (deep research over the web), and Scouts (recurring web monitors).

`langchain-yutori` provides:
- `ChatYutoriNavigator` — Navigator chat model (defaults to n1.5) for browser-control agents.
- `YutoriBrowsingTool` — execute one-shot browsing tasks on a remote browser.
- `YutoriResearchTool` — run deep research with 100+ tools.
- `YutoriScoutingTool` — create and manage recurring web monitors with Scouts.

## Quickstart

### Installation

<CodeGroup>
```bash pip
pip install langchain-yutori
```

```bash uv
uv add langchain-yutori
```
</CodeGroup>

### Authentication

Get an API key at [platform.yutori.com](https://platform.yutori.com), then either:

```bash
yutori auth login   # opens your browser, saves the key locally
```

or set the env var:

```bash
export YUTORI_API_KEY="yt_..."
```

### Chat model — `ChatYutoriNavigator`

Navigator accepts screenshots and returns browser actions (click, type, scroll, etc.). With Playwright:

```python
from langchain_yutori import ChatYutoriNavigator
from langchain.messages import HumanMessage
from yutori.navigator import aplaywright_screenshot_to_data_url

llm = ChatYutoriNavigator()  # defaults to n1.5-latest, uses YUTORI_API_KEY env var

image_url = await aplaywright_screenshot_to_data_url(page)
message = HumanMessage(content=[
    {"type": "text", "text": "What's the next action to complete: 'Add item to cart'?"},
    {"type": "image_url", "image_url": {"url": image_url}},
])
response = llm.invoke([message])
# response.tool_calls -> browser actions you execute, then feed the new screenshot back as a ToolMessage
```

### Tool — `YutoriBrowsingTool`

```python
from langchain_yutori import YutoriBrowsingTool

tool = YutoriBrowsingTool()
result = tool.invoke({
    "task": "What is the page title?",
    "start_url": "https://yutori.com",
})
```

`YutoriResearchTool` and `YutoriScoutingTool` follow the same `BaseTool` shape.
