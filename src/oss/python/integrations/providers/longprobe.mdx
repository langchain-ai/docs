# LongProbe

This page covers how to use the [LongProbe](https://github.com/ENDEVSOLS/LongProbe) ecosystem within LangChain. 
LongProbe is a sub-second RAG retrieval regression harness designed to track chunk-level stability.

## Installation and Setup

To use the LangChain integration, install the official partner package:

```bash
pip install langchain-longprobe
```

## Retrieval Probe

LongProbe provides a `RetrievalProbe` that wraps any LangChain retriever. It allows you to run sub-second regression checks against a "golden" set of questions to ensure your retrieval logic hasn't degraded after code changes.

```python
from langchain_longprobe import RetrievalProbe

# Wrap your existing LangChain retriever
probe = RetrievalProbe.from_retriever(
    retriever=your_retriever,
    goldens_path="goldens.yaml"
)

# Run a regression check
report = probe.run()

if report.regression_detected:
    print(f"Regressions found! Overall Recall: {report.overall_recall}")
```

## Callbacks and LCEL

LongProbe also supports passive monitoring via a Callback Handler and can be used directly in LCEL chains.

```python
from langchain_longprobe import LongProbeCallbackHandler, RetrievalRegressionRunnable

# As a Callback
handler = LongProbeCallbackHandler(goldens_path="goldens.yaml")
docs = retriever.invoke("query", config={"callbacks": [handler]})

# As an LCEL step
regression_check = RetrievalRegressionRunnable(retriever=retriever, goldens_path="goldens.yaml")
chain = retriever | regression_check | llm
```
