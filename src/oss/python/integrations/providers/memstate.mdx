Memstate AI is a structured, versioned long-term memory store for AI agents. Unlike vector databases, Memstate organizes facts in a **keypath hierarchy** (e.g., `users.alice.preferences.language`) so agents can store, retrieve, and browse structured knowledge with full version history and time-travel retrieval built in.

Every fact stored in Memstate is automatically versioned. You can retrieve the current value, browse the full history of changes, or time-travel to see what an agent knew at any point in the past.

Get started at [memstate.ai](https://memstate.ai).

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-memstate
```
```bash uv
uv add langchain-memstate
```
</CodeGroup>

Set your API key:

```python
import os
os.environ["MEMSTATE_API_KEY"] = "your-api-key-here"
```
