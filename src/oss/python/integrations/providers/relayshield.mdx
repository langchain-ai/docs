[RelayShield](https://relayshield.net) provides identity and agentic-attack-surface threat intelligence: breach/infostealer/SIM-swap monitoring, MCP registry risk, and AI-agent-sourced credential exposure detection.

Give agents tools to:

- Check an MCP server or package for registry risk before connecting to or installing it
- Check whether an email shows signs of exposure via a compromised or hijacked AI agent

### How it works

`langchain-relayshield` calls RelayShield's metered API per-tool-invocation, with the API key passed as a call argument rather than read from the environment, so a shared agent process can safely act on behalf of multiple callers.

It also ships an optional mandatory gate — `RelayShieldMCPGateMiddleware` — that blocks a protected connect/install action outright on a risk finding, rather than relying on the model to choose to call an advisory tool first.
