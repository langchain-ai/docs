>[iLoveVideoEditor](https://ilovevideoeditor.com) is a cloud video rendering platform. It renders MP4 videos from declarative [VideoJSON](https://ilovevideoeditor.com/docs/api-guide) specifications via a REST API.
>

## Installation and setup

The `iLoveVideoEditor` integration exists in its own [partner package](https://pypi.org/project/langchain-ilovevideoeditor/). You can install it with:

```python
pip install -qU langchain-ilovevideoeditor
```

In order to use the package, you will also need to set the `ILOVEVIDEOEDITOR_API_KEY` environment variable to your iLoveVideoEditor API key. You can get an API key from the [dashboard](https://ilovevideoeditor.com/dashboard).

## Tool

### ILoveVideoEditorTool

A tool that renders an MP4 video from a VideoJSON specification. Input is a VideoJSON object (`{"name": str, "layers": [...]}` where each layer has a `type` — `"text"`, `"image"`, `"video"`, `"audio"`, `"captions"`, or `"shape"` — and `settings`). The tool queues the render, polls until it finishes, and returns a JSON string with the job ID, status, and download URL.

```python
from langchain_ilovevideoeditor import ILoveVideoEditorTool
```

See a usage example below.

## Usage

```python
from langchain_ilovevideoeditor import ILoveVideoEditorTool

tool = ILoveVideoEditorTool()

result = tool.invoke({
    "video_json": {
        "name": "hello",
        "layers": [
            {
                "type": "text",
                "settings": {
                    "startTime": 0,
                    "duration": 3,
                    "text": "Hello from LangChain",
                    "fontSize": 64,
                    "color": "#ffffff",
                },
            }
        ],
    }
})
# '{"jobId": "425ba18a-...", "status": "completed", "downloadUrl": "https://..."}'
```

To queue a render without waiting for it to finish, pass `wait_for_completion=False`:

```python
result = tool.invoke({
    "video_json": video_json,
    "wait_for_completion": False,
})
# '{"jobId": "425ba18a-...", "status": "queued"}'
```

## Use within an agent

```python
from langchain_ilovevideoeditor import ILoveVideoEditorTool

tools = [ILoveVideoEditorTool()]
# pass `tools` to your agent or `model.bind_tools(...)`
```

## Configuration options

- `api_key`: API key. Defaults to the `ILOVEVIDEOEDITOR_API_KEY` environment variable.
- `base_url`: API base URL. Defaults to the `ILOVEVIDEOEDITOR_API_BASE` environment variable or `https://api.ilovevideoeditor.com`.
- `max_wait_seconds`: Maximum time to poll for render completion (default `300`).
- `poll_interval_seconds`: Interval between status polls (default `2`).

## API reference

For the full VideoJSON schema and REST API reference, see the [iLoveVideoEditor API docs](https://ilovevideoeditor.com/docs/api/).
