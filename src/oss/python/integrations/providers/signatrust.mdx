[Signatrust](https://signatrust.net) provides **AI Decision Receipts**—tamper-evident,
cryptographically signed (Ed25519) records of decisions made by AI agents. Each receipt
captures the agent, the action, the decision, the model, the policies and permissions
applied, and whether a human reviewed the action, providing an accountability and audit
layer for regulated or high-stakes AI workflows.

The `langchain-signatrust` package wraps the Signatrust REST API as LangChain tools.

## Installation and setup

```bash pip
pip install langchain-signatrust
```

```bash uv
uv add langchain-signatrust
```

Get your API key from [signatrust.net](https://signatrust.net) and set it as an
environment variable:

```bash
export SIGNATRUST_API_KEY="your-api-key"
```

## Tools

See the [Signatrust tool](/oss/integrations/tools/signatrust) guide for details on the
available tools, including generating, verifying, and retrieving AI Decision Receipts.
