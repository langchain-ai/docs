>[UniRate](https://unirateapi.com) is a currency exchange API providing 593+ fiat, crypto, and commodity rates. Latest rates and conversions are free; historical and time-series endpoints require a Pro plan.

This page covers how to use the UniRate API within LangChain.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-unirate
```

```bash uv
uv add langchain-unirate
```
</CodeGroup>

- Sign up at [UniRate](https://unirateapi.com) and obtain an API key.
- Set the key as an environment variable `UNIRATE_API_KEY`.

## Wrappers

### Utility

The `UniRateAPIWrapper` utility wraps the UniRate API. Import it with:

```python
from langchain_unirate import UniRateAPIWrapper
```

For a more detailed walkthrough see [the UniRate tool guide](/oss/integrations/tools/unirate).

### Tool

The `UniRateExchangeTool` is a `BaseTool` with a structured `args_schema` over `from_currency`, `to_currency`, and `amount`, ready to bind to any tool-calling chat model:

```python
from langchain_unirate import UniRateAPIWrapper, UniRateExchangeTool

tool = UniRateExchangeTool(api_wrapper=UniRateAPIWrapper())
```

For more information on tools, see [Tools](/oss/integrations/tools).
