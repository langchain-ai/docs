description: "LangGraph checkpointers for DynamoDB, Cosmos DB and Firestore with bounded message history and a long-term memory hook, plus stores with native semantic search."
---

>[agentstate](https://skamalj.github.io/agentstate-reducer/) is a family of open-source (MIT) LangGraph persistence packages for managed cloud databases: checkpointers for Amazon DynamoDB, Azure Cosmos DB and Google Firestore, and `BaseStore` backends for the same three plus PostgreSQL.

The checkpointers add two things to the save path that a plain checkpointer does not have, without any change to the graph:

- **Bounded message history.** An optional `MessageReducer` prunes the message list before every checkpoint is written, by message count or token budget, whole messages only, with tool-call pairs kept intact.
- **A route to long-term memory.** The messages that leave the window are handed to the reducer's `on_prune` hook, once each, together with a `memory_namespace` taken from the run config. The hook runs off the request path through a bounded worker pool, and a hook that raises never fails the checkpoint.

The stores implement LangGraph's `BaseStore` with `IndexConfig` semantic search on each backend's own vector engine: DynamoDB `SearchVectors`, pgvector, Cosmos DB `VectorDistance` and Firestore `find_nearest`.

## Installation

```bash
pip install "langgraph-dynamodb-checkpoint[reducer]"   # or langgraph-checkpoint-cosmosdb, langgraph-checkpoint-firestore
pip install langgraph-store-dynamodb                    # or langgraph-store-postgres, langgraph-store-cosmosdb, langgraph-store-firestore
```

## Checkpointer

```python
from agentstate_reducer import MessageReducer, ReducerConfig
from langgraph_dynamodb_checkpoint import DynamoDBSaver

reducer = MessageReducer(config=ReducerConfig(max_messages=20))
checkpointer = DynamoDBSaver("checkpoints", reducer=reducer)
graph = builder.compile(checkpointer=checkpointer)

graph.invoke(
    {"messages": [("user", "hello")]},
    config={"configurable": {"thread_id": "thread-1"}},
)
```

`CosmosDBSaver(database_name, container_name, reducer=...)` and `FirestoreSaver(project_id, collection, reducer=...)` take the same `reducer` argument. Without a reducer each saver is a conventional checkpointer.

All three pass the base suite of [`langgraph-checkpoint-conformance`](https://pypi.org/project/langgraph-checkpoint-conformance/); the conformance test ships in each repository.

## Long-term memory from pruned turns

```python
from agentstate_reducer import Background, MessageReducer, ReducerConfig
from langgraph_store_dynamodb import DynamoDBStore

store = DynamoDBStore("memories", index={"dims": 1024, "embed": embeddings, "fields": ["text"]})

def remember(pruned, namespace):
    for message in pruned:
        store.put(namespace, key=message.id, value={"role": message.type, "text": message.content})

reducer = MessageReducer(config=ReducerConfig(max_messages=20, on_prune=[Background(remember)]))
checkpointer = DynamoDBSaver("checkpoints", reducer=reducer)
graph = builder.compile(checkpointer=checkpointer, store=store)

graph.invoke(
    {"messages": [("user", "hello")]},
    config={"configurable": {"thread_id": "thread-1", "memory_namespace": ("memories", "user-42")}},
)
```

The hook receives the pruned messages and the namespace from the run config. Any `BaseStore` works, as does an extraction engine: [`langgraph-memory`](https://pypi.org/project/langgraph-memory/) exposes `engine.on_prune`, which extracts facts, consolidates them against existing memories and stores them for recall ranked by similarity, recency and importance.

## Store

```python
from langgraph_store_postgres import PostgresStore

store = PostgresStore(url, index={"dims": 1024, "embed": embeddings, "fields": ["text"]})
store.put(("memories", "user-42"), "k1", {"text": "prefers window seats"})
store.search(("memories", "user-42"), query="seating preference", limit=5)
```
