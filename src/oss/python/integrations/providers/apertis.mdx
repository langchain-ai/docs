[Apertis](https://apertis.ai) provides an OpenAI-compatible API. You can use
the `langchain-openai` package to call a model enabled for your Apertis account.

## Installation and setup

<CodeGroup>

```bash pip
pip install langchain-openai
```

```bash uv
uv add langchain-openai
```

</CodeGroup>

Create an [Apertis API key](https://apertis.ai/settings/apiKeys) and set it as
the `APERTIS_API_KEY` environment variable. Use a model ID available to your
account; the authenticated `/v1/models` endpoint lists the current catalog.

## Chat

```python
import os

from langchain.messages import HumanMessage
from langchain_openai import ChatOpenAI

chat = ChatOpenAI(
    model="YOUR_APERTIS_MODEL_ID",
    api_key=os.environ["APERTIS_API_KEY"],
    base_url="https://api.apertis.ai/v1",
)

response = chat.invoke([HumanMessage(content="Hello!")])
print(response.content)
```
