[Jev](https://docs.typesafe.ai/models) is a [System One model](https://docs.typesafe.ai/concepts/system-one): it reads natural language like an LLM, but returns typed answers and calibrated probabilities rather than generated text. It does not write replies, produce code, or explain its reasoning — it answers questions you define up front, and your code branches on the result.

That makes it a fit for the small decisions an agent makes constantly: which model to use, which skills apply, whether a tool call is safe to run.

## Setup

```bash
pip install langchain-typesafe
```

Create an API key in the [TypeSafe console](https://console.typesafe.ai/settings/keys) and export it:

```bash
export TYPESAFE_API_KEY=...
```

## Quickstart

`TypeSafeClassifier` is a `Runnable` that asks a fixed set of named questions about whatever you pass it. Questions are answered independently and in parallel, so asking several at once costs little more than asking one:

```python
from langchain_typesafe import Choice, Noul, Score, TypeSafeClassifier

classifier = TypeSafeClassifier(
    questions={
        "urgent": Noul(instructions="Does this need attention right now?"),
        "team": Choice(
            instructions="Which team should pick this up?",
            criteria={
                "infra": "Deploys, availability, and on-call incidents.",
                "billing": "Payments, invoices, and subscriptions.",
            },
        ),
        "severity": Score(
            instructions="How severe is the impact?",
            criteria=["Cosmetic.", "Degraded for some users.", "Full outage."],
        ),
    }
)

response = classifier.invoke(
    "The deploy failed twice and customers are seeing 500s. Can someone look now?"
)

print(response.nouls["urgent"].noul)
print(response.choices["team"].choice, response.choices["team"].confidence)
print(response.scores["severity"].score)
```

Answers are keyed by the question IDs you supplied, and grouped by type on `nouls`, `choices`, and `scores`. The response also carries the `model` that answered, token `usage`, and the TypeSafe `request_id`.

State can be a string, a JSON object or array, or LangChain messages — a `BaseMessage` or a sequence of them is converted to role/content JSON, including when nested inside a larger object.

## Decision types

Each question is one of three [primitives](https://docs.typesafe.ai/primitives):

| Primitive | Asks | Returns | Reach for it when |
|---|---|---|---|
| [`Noul`](https://docs.typesafe.ai/primitives/noul) | Is this true? | `noul`, the probability of yes | Your code branches on an `if` |
| [`Choice`](https://docs.typesafe.ai/primitives/choice) | Which of these options? | `choice`, plus `probabilities` and `confidence` | Options map to distinct code paths |
| [`Score`](https://docs.typesafe.ai/primitives/score) | Which level? | `score`, plus `legend`, `probabilities`, and `confidence` | The answer is a spectrum you compare to a threshold |

`Noul` is the only one without a `confidence`, since the probability is the answer. Use `Score` rather than a `Noul` for a spectrum: a `Noul` of `0.5` means an even split between yes and no, not "medium".

## Agent middleware

Three [middleware](/oss/langchain/middleware/overview) put the classifier on an agent's decision points. Import them from `langchain_typesafe.experimental.middleware`.

<Note>
The middleware are still in review and are not part of `langchain-typesafe` `0.0.1a1`. Follow [#40543](https://github.com/langchain-ai/langchain/pull/40543) (model routing), [#40544](https://github.com/langchain-ai/langchain/pull/40544) (skills), and [#40545](https://github.com/langchain-ai/langchain/pull/40545) (tool-risk gating). Their APIs may change before release.
</Note>

| Middleware | Hook | Decision |
|---|---|---|
| [`ModelRouterMiddleware`](#model-routing) | `before_agent`, `wrap_model_call` | Which model handles the run |
| [`SkillsMiddleware`](#skill-selection) | `before_agent`, `wrap_model_call` | Which skills apply to the request |
| [`AutoModeMiddleware`](#tool-risk-gating) | `wrap_tool_call` | Whether a tool call is too risky to run |

### Model routing

Classifies the latest human message across your named models and uses the selected one for every model call in the run. Each `ModelChoice` pairs a model — an instance, or a string for `init_chat_model` — with the criterion for picking it:

```python
from langchain.agents import create_agent
from langchain_typesafe.experimental.middleware import ModelChoice, ModelRouterMiddleware

router = ModelRouterMiddleware(
    choices={
        "fast": ModelChoice(
            model="openai:gpt-5-nano",
            criteria="Direct lookups, extraction, and localized changes with explicit targets.",
        ),
        "powerful": ModelChoice(
            model="openai:gpt-5",
            criteria="Architecture, novel root-cause reasoning, and high-stakes decisions.",
        ),
    },
    instructions="Choose the least costly model that can complete the task safely.",
)

agent = create_agent("openai:gpt-5-nano", middleware=[router])
```

The full `ChoiceAnswer` is stored in agent state under `model_route`, so downstream middleware can read `confidence` and the per-model `probabilities`, not just the selected route.

### Skill selection

Scores each skill independently against the request and prepends only the selected skills' instructions to the model request, so the roster never enters the prompt. Skills come from Agent Skills-compatible `SKILL.md` files, `Skill` objects, or `SKILL.md` strings:

```python
from pathlib import Path

from langchain_typesafe.experimental.middleware import SkillsMiddleware

skills = SkillsMiddleware(
    skills=[Path("skills/code-review/SKILL.md")],
    relevance_threshold=0.3,
)

agent = create_agent("openai:gpt-5", middleware=[skills])
```

Because each skill is its own `Noul`, two skills that both apply are both selected, and adding a skill cannot shift another skill's score.

<Warning>
Skill instructions become a system message and can direct agent behavior, so skill sources are trusted configuration. Do not load a `SKILL.md` that a user can write.
</Warning>

### Tool-risk gating

Asks for the probability that a tool call is risky or insufficiently authorized, and returns an error `ToolMessage` instead of running the tool when it is at or above `threshold`. Only the tools you list are classified — pass names or tool objects:

```python
from langchain_typesafe.experimental.middleware import AutoModeMiddleware

agent = create_agent(
    "openai:gpt-5",
    tools=[read_file, delete_all_backups],
    middleware=[AutoModeMiddleware(tools=[delete_all_backups], threshold=0.2)],
)
```

The classifier sees user messages, the tool-call name, and its arguments with credential-like keys redacted. Tool output and assistant messages are excluded, so content the agent fetched cannot authorize its own execution. Override `instructions`, or pass `criteria=NoulCriteria(true=..., false=...)`, to describe risk for your own tools.

<Warning>
Tool arguments are sent to TypeSafe, and redaction matches credential-like argument *keys* — a secret inside an unrelated free-form value is not caught.

This middleware refuses; it does not ask. Pair it with [human-in-the-loop middleware](/oss/langchain/middleware/built-in) if you want approval.
</Warning>

## Reference

Classification runs are traced like model calls: the run carries `ls_provider`, `ls_model_name`, and TypeSafe's token usage as `usage_metadata`, so classifier spend shows up alongside the rest of the agent in [LangSmith](https://docs.langchain.com/langsmith/home).

Errors are both TypeSafe types and LangChain `ModelError` subclasses, so either import catches them:

```python
from langchain_core.exceptions import ModelRateLimitError
from langchain_typesafe.client import TypeSafeRateLimitError

try:
    response = classifier.invoke("...")
except TypeSafeRateLimitError as error:
    print(error.request_id, error.retry_after_ms)
except ModelRateLimitError:
    back_off()
```

`ClassificationResponse` is importable from `langchain_typesafe.types`, and the classifier is beta, so constructing it emits a `LangChainBetaWarning`.

See the [TypeSafe docs](https://docs.typesafe.ai/) for question and model semantics, and [Confidence](https://docs.typesafe.ai/confidence) for choosing thresholds.
