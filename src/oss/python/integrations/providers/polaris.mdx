[The Polaris Report](https://thepolarisreport.com) provides AI-verified news intelligence
across 18 verticals. Every brief includes confidence scores, bias ratings, source attribution,
counter-arguments, and entity enrichment. Polaris publishes verified intelligence briefs
that agents can search, retrieve, and fact-check programmatically.

## Installation and setup

Install the `langchain-polaris` package.

<CodeGroup>
```bash pip
pip install langchain-polaris
```

```bash uv
uv add langchain-polaris
```
</CodeGroup>

Get an API key at [thepolarisreport.com](https://thepolarisreport.com) or use `demo` for quick testing.

## Tools

See a [usage example](/oss/integrations/tools/polaris).

9 specialized tools for search, feed, brief, extract, entities, trending, compare, research, and claim verification.

```python
from langchain_polaris import PolarisSearchTool, PolarisVerifyTool
```

## Retriever

See a [usage example](/oss/integrations/tools/polaris#retriever).

Converts verified intelligence briefs into LangChain `Document` objects with confidence and bias metadata.

```python
from langchain_polaris import PolarisRetriever
```
