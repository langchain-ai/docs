[SERPdive](https://serpdive.com) is an AI search API built for agents: your agent asks a question, the API returns answer-ready web content that is extracted, cleaned, and sized for LLM consumption, so facts can be quoted and cited straight from the response. On a [public, replayable 1,000-question benchmark](https://github.com/edendalexis/serpdive-benchmark), SERPdive runs at the same speed as Tavily, feeds your LLM 20.2% fewer tokens, and wins 60.7% of decided quality duels.

The `langchain-serpdive` package exposes SERPdive's Search API as a LangChain tool.

## Installation and setup

Install the SERPdive integration package for LangChain Python:

<CodeGroup>
```bash pip
pip install langchain-serpdive
```

```bash uv
uv add langchain-serpdive
```
</CodeGroup>

Get a free API key (no card required) at [serpdive.com/dashboard/keys](https://serpdive.com/dashboard/keys) and set it as an environment variable named `SERPDIVE_API_KEY`:

```bash
export SERPDIVE_API_KEY="sd_live_..."
```

## Tools

### SerpdiveSearch

A search tool that returns extracted, answer-ready page content: each result carries the URL, title, date, and the actual text of the page. Localization is automatic; the language of the query picks where the search runs.

See a [usage example](/oss/integrations/tools/serpdive).

```python
from langchain_serpdive import SerpdiveSearch
```
