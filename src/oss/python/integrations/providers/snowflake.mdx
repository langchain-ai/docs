> [Snowflake](https://www.snowflake.com/) provides a cloud data and AI platform with built-in LLM inference
> through [Cortex REST API](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api). All inference runs within Snowflake's security perimeter.

Snowflake embraces the LangChain ecosystem in various ways:

1. 🚀 **Chat Models (Cortex REST API)** — Access frontier LLMs from Anthropic (Claude), OpenAI (GPT), Meta (Llama), Mistral, DeepSeek, and Snowflake via two industry-standard endpoints. Use `ChatOpenAI` or `ChatAnthropic` with a custom `base_url` — no additional packages needed. LangChain provides a [Cortex REST API chat integration](/oss/integrations/chat/cortex_rest_api) with streaming, tool calling, and structured output.
2. 💬 **Chat Models (Cortex Complete)** — Access LLMs via [ChatSnowflake](/oss/integrations/chat/snowflake) using Snowflake's [Cortex Complete](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-llm-functions) function with built-in tool calling, structured output, and streaming.
3. 🔍 **Cortex Search** — [Cortex Search](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-search/cortex-search-overview) is a fully managed semantic search service. Use `SnowflakeCortexSearchRetriever` to connect LangChain to your Cortex Search services for RAG applications.
4. 📊 **Cortex Analyst** — [Cortex Analyst](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst) converts natural language questions to SQL via semantic models. Use `SnowflakeCortexAnalyst` as a tool in LangChain agents to query structured data.
5. 🤖 **Cortex Agents** — [Cortex Agents](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents) provides managed agent orchestration with thread management. Use `SnowflakeCortexAgent` for production-ready agentic workflows.
6. 🔧 **Cortex AI Tools** — Pre-built tools powered by [Cortex AI functions](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-llm-functions) for sentiment analysis, summarization, translation, and SQL query execution.
7. 🔌 **MCP Integration** — [Model Context Protocol](https://modelcontextprotocol.io/) support for connecting external tools to Snowflake agents.
8. 📃 **Embeddings** — Open-weight [Arctic](https://huggingface.co/Snowflake/snowflake-arctic-embed-m-v1.5) embedding models via Hugging Face, plus [Cortex Embed REST API](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api/embed-api) for server-side embedding generation.
9. 📥 **Document Loader** — Load data directly from Snowflake tables using [`SnowflakeLoader`](/oss/integrations/document_loaders/snowflake).

## Installation

<CodeGroup>
```bash pip
pip install langchain-snowflake
```

```bash uv
uv add langchain-snowflake
```
</CodeGroup>

For Cortex REST API (chat models via OpenAI/Anthropic-compatible endpoints), no additional packages are needed beyond `langchain-openai` or `langchain-anthropic`.

## Chat Models (Cortex REST API)

[Cortex REST API](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api) is fully compatible with both the OpenAI and Anthropic APIs:

| Compatibility | Endpoint | LangChain Class |
|---|---|---|
| OpenAI Chat Completions | `/api/v2/cortex/v1/chat/completions` | `ChatOpenAI` |
| Anthropic Messages | `/api/v2/cortex/v1/messages` | `ChatAnthropic` |

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    base_url="https://<account_identifier>.snowflakecomputing.com/api/v2/cortex/v1",
    api_key="<your-snowflake-pat>",
    model="claude-sonnet-4-5",
)
```

```python
from langchain_anthropic import ChatAnthropic

llm = ChatAnthropic(
    base_url="https://<account_identifier>.snowflakecomputing.com/api/v2/cortex",
    api_key="<your-snowflake-pat>",
    model="claude-sonnet-4-5",
)
```

See the [Cortex REST API chat integration](/oss/integrations/chat/cortex_rest_api) for streaming, tool calling, structured output, and more.

## Chat Models (Cortex Complete)

`ChatSnowflake` provides access to Cortex Complete with built-in tool calling, structured output, and streaming support.

```python
from langchain_snowflake import ChatSnowflake

llm = ChatSnowflake(
    model="claude-sonnet-4-5",
    snowflake_pat="<your-pat>",
    snowflake_account="<orgname>-<account_name>",
)
```

See the [ChatSnowflake integration](/oss/integrations/chat/snowflake) for more details.

## Cortex Search (Retriever)

[Cortex Search](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-search/cortex-search-overview) provides fully managed semantic search with relevance scoring. Use it as a retriever in RAG pipelines.

```python
from langchain_snowflake import SnowflakeCortexSearchRetriever

retriever = SnowflakeCortexSearchRetriever(
    search_service="my_search_service",
    search_column="content",
    snowflake_account="<orgname>-<account_name>",
    snowflake_pat="<your-pat>",
)

docs = retriever.invoke("What is Snowflake Cortex?")
```

## Cortex Analyst (Tool)

[Cortex Analyst](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst) converts natural language to SQL using semantic models. Use it as a tool in LangChain agents to query structured data.

```python
from langchain_snowflake import SnowflakeCortexAnalyst

analyst = SnowflakeCortexAnalyst(
    semantic_model="my_semantic_model",
    snowflake_account="<orgname>-<account_name>",
    snowflake_pat="<your-pat>",
)
```

## Cortex Agents

[Cortex Agents](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents) provides managed agent orchestration with thread management.

```python
from langchain_snowflake import SnowflakeCortexAgent

agent = SnowflakeCortexAgent(
    agent_name="my_agent",
    snowflake_account="<orgname>-<account_name>",
    snowflake_pat="<your-pat>",
)
```

## Cortex AI Tools

Pre-built tools for common AI tasks:

```python
from langchain_snowflake import (
    CortexSentimentTool,
    CortexSummarizerTool,
    CortexTranslatorTool,
    SnowflakeQueryTool,
)
```

| Tool | Description |
|---|---|
| `CortexSentimentTool` | Sentiment analysis |
| `CortexSummarizerTool` | Text summarization |
| `CortexTranslatorTool` | Translation |
| `CortexCompleteTool` | LLM completion as a tool |
| `SnowflakeQueryTool` | Execute SQL queries |

## MCP Integration

[Model Context Protocol](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents) support for connecting external tools to Snowflake agents.

```python
from langchain_snowflake import MCPToolWrapper, bind_mcp_tools
```

## Embedding Models

Snowflake offers their open-weight `arctic` line of embedding models for free
on [Hugging Face](https://huggingface.co/Snowflake/snowflake-arctic-embed-m-v1.5). The most recent model, snowflake-arctic-embed-m-v1.5 features [matryoshka embedding](https://arxiv.org/abs/2205.13147) which allows for effective vector truncation.

<CodeGroup>
```bash pip
pip install sentence-transformers
```

```bash uv
uv add sentence-transformers
```
</CodeGroup>

```python
from langchain_huggingface import HuggingFaceEmbeddings

model = HuggingFaceEmbeddings(model_name="snowflake/arctic-embed-m-v1.5")
```

Snowflake also provides a [Cortex Embed REST API](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api/embed-api) for server-side embedding generation.
