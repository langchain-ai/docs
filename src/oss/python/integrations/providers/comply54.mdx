[comply54](https://comply54.io) is a runtime compliance engine for AI agents operating under African regulatory frameworks. It evaluates agent tool calls against Rego policies—covering NDPA 2023, CBN transaction limits, Ghana DPA, Kenya DPA, and 15+ other regulations—and returns structured `deny / escalate / audit / allow` decisions without an OPA binary or external service.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-comply54
```

```bash uv
uv add langchain-comply54
```
</CodeGroup>

`langchain-comply54` depends on `comply54[langgraph]>=0.3.0`, which is installed automatically.

## LangGraph guard node

`Comply54Guard` is a LangGraph node that intercepts tool calls **before execution**, evaluates them against a comply54 sector pack, and either blocks the call (injecting a structured `ToolMessage` error) or lets it through.

```python
from langchain_comply54 import Comply54Guard, comply54_route
from comply54.sectors import NigeriaFintechCompliance
from langgraph.graph import StateGraph, MessagesState, END
from langgraph.prebuilt import ToolNode

guard = Comply54Guard(
    NigeriaFintechCompliance(),
    context={"kyc_tier": 3, "customer_verified": True},
)

graph = StateGraph(MessagesState)
graph.add_node("agent", agent_node)
graph.add_node("comply54_guard", guard)
graph.add_node("tools", ToolNode(tools))

graph.set_entry_point("agent")
graph.add_conditional_edges("agent", should_continue,
    {"comply54_guard": "comply54_guard", END: END})
graph.add_conditional_edges("comply54_guard", comply54_route,
    {"tools": "tools", "agent": "agent"})
graph.add_edge("tools", "agent")

app = graph.compile()
```

When a tool call is blocked, the agent receives a structured denial it can explain to the user:

```json
{
  "blocked": true,
  "decision": "deny",
  "reason": "CBN NIP Framework: single transfer of ₦15,000,000 exceeds the ₦10,000,000 per-transaction cap",
  "regulation": "CBN Transaction Limits & Controls",
  "audit_id": "a3f2c1d4-...",
  "jurisdictions": ["NG"]
}
```

## LangChain StructuredTool

For agents that should self-check compliance before acting:

```python
from langchain_comply54 import comply54_tool
from comply54.sectors import NigeriaFintechCompliance

compliance_check = comply54_tool(NigeriaFintechCompliance())
tools = [transfer_funds_tool, compliance_check]
```

## Available sector packs

| Import | Jurisdictions | Key regulations |
|---|---|---|
| `NigeriaFintechCompliance` | NG | NDPA 2023, CBN NIP (₦10M cap), NFIU AML/CFT, BVN/NIN |
| `NigeriaHealthCompliance` | NG | NDPA 2023, NHA, NHIA |
| `NigeriaInsuranceCompliance` | NG | NDPA 2023, NIIRA 2025 |
| `KenyaFintechCompliance` | KE | Kenya Data Protection Act 2019, CBK guidelines |
| `PanAfricanCompliance` | NG, KE, GH, RW, EG, MU, ZA, TZ, UG | 9-jurisdiction pack |

```python
from comply54.sectors import (
    NigeriaFintechCompliance,
    NigeriaHealthCompliance,
    NigeriaInsuranceCompliance,
    KenyaFintechCompliance,
    PanAfricanCompliance,
)
```
