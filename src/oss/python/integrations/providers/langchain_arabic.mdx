> [langchain-arabic](https://pypi.org/project/langchain-arabic/) is a LangChain output parser
> that post-processes Arabic LLM output for text-to-speech pipelines — restoring diacritics (tashkeel),
> converting numbers to words, and applying dialect-specific phrasing.

LLMs produce Arabic text without diacritics 60–70% of the time. This causes mispronunciation
in TTS engines and reduces readability. `langchain-arabic` fixes this as a drop-in replacement
for `StrOutputParser`.

## Installation and setup

<CodeGroup>
```bash pip
pip install -U langchain-arabic
```

```bash pip (with neural backend)
pip install -U "langchain-arabic[catt]"
```
</CodeGroup>

No API keys or environment variables required.

## Output parsers

### ArabicTextOutputParser

`ArabicTextOutputParser` extends `BaseTransformOutputParser` and supports `invoke()`, `stream()`, and `batch()`.

```python
from langchain_arabic import ArabicTextOutputParser
```

#### Dictionary-based diacritics

Provide a mapping of plain Arabic words to their diacritized forms. The parser applies longest-first replacement to prevent partial matches.

```python
parser = ArabicTextOutputParser(
    diacritics_map={
        "تقنية": "تِقْنِيَة",
        "شركة": "شَرِكَة",
        "علم الحاسوب": "عِلْمُ الحَاسُوبِ",
    },
    convert_numbers=False,
)

result = parser.parse("شركة تقنية في علم الحاسوب")
# "شَرِكَة تِقْنِيَة في عِلْمُ الحَاسُوبِ"
```

#### Number-to-word conversion

Numbers are detected and converted based on context (percentage, currency, phone, plain):

```python
parser = ArabicTextOutputParser(convert_numbers=True, language="ar")

parser.parse("النسبة 95%")
# "النسبة خمسة و تسعون بالمائة"

parser.parse("اتصل على 920001234")
# "اتصل على تسعة اثنان صفر صفر صفر واحد اثنان ثلاثة أربعة"
```

#### Chain integration

Slots into any LCEL chain as a drop-in replacement for `StrOutputParser`:

```python
from langchain_arabic import ArabicTextOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template(
    "اشرح {topic} باللغة العربية في جملتين."
)
llm = ChatOpenAI(model="gpt-4o-mini")
parser = ArabicTextOutputParser(
    diacritics_map={"تقنية": "تِقْنِيَة"},
    convert_numbers=True,
)

chain = prompt | llm | parser
result = chain.invoke({"topic": "الذكاء الاصطناعي"})
```

<Note>
The parser buffers streaming chunks and processes the complete text once the LLM finishes, because diacritics and number conversion require complete words.
</Note>

#### Dialect support

Use the `dialect` parameter for dialect-specific number phrasing and diacritics maps:

```python
# Gulf dialect — numbers use Gulf phrasing
parser = ArabicTextOutputParser(dialect="gulf", convert_numbers=True)
parser.parse("النسبة 100%")
# "النسبة مية بالمية" (not "مائة بالمائة")
```

Supported dialects: `"msa"` (Modern Standard Arabic, default), `"gulf"` (Khaleeji).

#### CATT neural backend

For full auto-diacritization without a manual dictionary (requires `pip install langchain-arabic[catt]`):

```python
parser = ArabicTextOutputParser(backend="catt", catt_model="encoder_only")
result = parser.parse("نص عربي بدون تشكيل")
```
