> [HippoDid](https://hippodid.com) provides persistent, structured character memory
> for AI agents. Each customer or user gets their own **character** — a scoped identity
> with categorized, searchable memory that persists across sessions, machines, and
> frameworks.

Unlike session-only memory, HippoDid memories survive restarts, work across tools
(Claude Desktop, Cursor, your app), and support semantic search, salience scoring,
and time-based decay.

## Installation

<CodeGroup>
```bash pip
pip install langchain-hippodid
```

```bash uv
uv add langchain-hippodid
```
</CodeGroup>

This installs `langchain-hippodid` and its dependency `hippodid` (the core Python SDK).

Get your API key at [hippodid.com](https://hippodid.com).

## Chat message history

`HippoDidChatMessageHistory` implements LangChain's `BaseChatMessageHistory`,
storing and retrieving messages via the HippoDid cloud memory API.

See a [usage example](/oss/integrations/chat_message_histories/hippodid).

```python
from langchain_hippodid import HippoDidChatMessageHistory
```

## Memory wrapper

`HippoDidMemory` provides a `get_history()` factory function compatible with
`RunnableWithMessageHistory`, making it straightforward to add persistent memory to
LCEL chains.

```python
from langchain_hippodid import HippoDidMemory
```

## Key capabilities

| Capability | Description |
|---|---|
| Persistent storage | Memories survive restarts and work across machines |
| Character-scoped isolation | Each user gets their own memory via `character_id` or `external_id` |
| Semantic search | Hybrid BM25 + vector search across memories |
| Three memory modes | `VERBATIM` (zero AI cost), `EXTRACTED` (AI-structured), `HYBRID` |
| Context assembly | `get_context()` builds formatted prompts with profile + memories |
| MCP support | Also accessible via 38 Model Context Protocol tools |
