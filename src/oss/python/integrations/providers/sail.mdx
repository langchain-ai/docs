>[Sail](https://github.com/lakehq/sail) is a drop-in replacement for Apache Spark,
> written in Rust. It uses the Spark Connect protocol, so existing PySpark code works
> out of the box—just point your `SparkSession` at a Sail server instead of a Spark
> cluster. Sail offers up to 4x speed-up with 94% less hardware cost and zero changes
> to your PySpark code.

## Installation and setup

Install the integration package, Sail, and the lightweight Spark Connect client with

<CodeGroup>
```bash pip
pip install langchain-sail pysail pyspark-client
```

```bash uv
uv add langchain-sail pysail pyspark-client
```
</CodeGroup>

`pyspark-client` is the lightweight option for connecting to a Sail server over
Spark Connect. If you need the full PySpark distribution or the `pyspark` shell,
install `pyspark[connect]` instead.

For more setup options, see the [Sail getting started guide](https://docs.lakesail.com/sail/latest/introduction/getting-started/).

To run a local Sail server for development/testing, `pysail` is sufficient:

```bash
pip install pysail
```

## Tools/Toolkits

### Sail SQL toolkit

Toolkit for interacting with `Sail SQL`.

See a [usage example](/oss/integrations/tools/sail_sql).

```python
from langchain_sail import SailSQLToolkit, create_sail_sql_agent, SailSQL
```

#### Sail SQL individual tools

You can use individual tools from the Sail SQL Toolkit:
- `InfoSailSQLTool`: tool for getting metadata about a Sail SQL database
- `ListSailSQLTool`: tool for getting table names
- `SailQueryCheckerTool`: tool that uses an LLM to check if a query is correct
- `QuerySailSQLTool`: tool for querying Sail SQL

```python
from langchain_sail import InfoSailSQLTool
from langchain_sail import ListSailSQLTool
from langchain_sail import SailQueryCheckerTool
from langchain_sail import QuerySailSQLTool
```
