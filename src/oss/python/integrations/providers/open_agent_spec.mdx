This page covers all LangChain integrations with Oracle [Open Agent Spec](https://oracle.github.io/agent-spec).

Open Agent Spec is a framework-agnostic declarative language by Oracle for defining agentic systems. It allows to define agents and workflows in a portable JSON/YAML format that can be executed across different runtimes.

The [LangGraph Adapter](https://oracle.github.io/agent-spec/adapters/langgraph.html) enables conversion of Open Agent Spec configurations into LangGraph workflows and vice versa. 

## Installation and setup

You can refer to the [installation guide](https://oracle.github.io/agent-spec/installation.html) to install `pyagentspec`.

You can subsequently install the LangGraph Adapter following [this guide](https://oracle.github.io/agent-spec/adapters/langgraph.html#get-started).
