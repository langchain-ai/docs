[Kyvvu](https://kyvvu.com) provides runtime governance and policy enforcement for AI agents — evaluating every agent action against your policies *before* it runs, so unsafe or non-compliant behavior is blocked, not merely logged. It produces a tamper-evident audit trail for EU AI Act, OWASP, and GDPR requirements.

## Installation

The Kyvvu integration ships in the [`kyvvu`](https://pypi.org/project/kyvvu/) package:

```bash
pip install kyvvu
```

## Integrations

- [Kyvvu callback handler](/oss/integrations/callbacks/kyvvu) — Runtime policy enforcement and tamper-evident audit logging for LangChain and LangGraph agents.
