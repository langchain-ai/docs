[Voxell](https://voxell.ai/) builds [Forge](https://voxell.ai/forge), a hosted text-embedding API. Forge runs the Qwen3-Embedding family across three tiers so you can trade quality against size and cost: `turbo` (1024 dimensions), `pro` (2560 dimensions), and `ultra` (4096 dimensions). The `ultra` tier is the Qwen3-Embedding-8B model, which scores roughly 75+ on the MTEB average task score and is currently #4 on MTEB (English), the top usable model. Every tier supports Matryoshka truncation, so you can request fewer (re-normalized) dimensions for cheaper vectors.

Voxell offers first-class support for LangChain's embedding interface through the [`langchain-voxell`](https://pypi.org/project/langchain-voxell/) integration package.

## Setup

Create a free account at [dash.voxell.ai](https://dash.voxell.ai). New accounts start with 10M tokens and no credit card. Create an API key from the dashboard.

Install the [`langchain-voxell`](https://pypi.org/project/langchain-voxell/) package:

<CodeGroup>
```bash pip
pip install langchain-voxell
```

```bash uv
uv add langchain-voxell
```
</CodeGroup>

Then set your `FORGE_API_KEY` environment variable to your Forge API key:

<CodeGroup>
```bash bash
export FORGE_API_KEY="your_api_key_here"
```
```powershell powershell
$env:FORGE_API_KEY="your_api_key_here"
```
</CodeGroup>

## Embeddings

The snippet below ranks a search query against a document by cosine similarity. A fuller walkthrough is in the [Forge embeddings guide](/oss/integrations/embeddings/voxell).

```python
import numpy as np  # You may need to `pip install numpy`.

from langchain_voxell import ForgeEmbeddings

client = ForgeEmbeddings(model="ultra")

document_embedding = client.embed_documents(
    texts=["GitHub charges for additional storage beyond the included quota."]
)[0]

query_embedding = client.embed_query(text="What are GitHub's billing policies?")

similarity = np.dot(query_embedding, document_embedding)
print(f"Similarity: {similarity * 100:.2f}")
```
