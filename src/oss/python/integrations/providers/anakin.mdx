> [Anakin](https://anakin.io) is a web scraping, search, and AI research API.
> It provides URL scraping with optional headless browser rendering, batch scraping of up to 10 URLs,
> AI-powered web search, and multi-stage autonomous agentic research.

## Installation and setup

Install the `langchain-community` package:

<CodeGroup>
```bash pip
pip install -U langchain-community
```

```bash uv
uv add langchain-community
```
</CodeGroup>

Set your Anakin API key as an environment variable. Get your key from the [Anakin dashboard](https://anakin.io/dashboard).

```bash
export ANAKIN_API_KEY="your-api-key"
```

## Document loader

See a [usage example](/oss/integrations/document_loaders/anakin).

```python
from langchain_community.document_loaders import AnakinLoader
```

## Tools

See a [usage example](/oss/integrations/tools/anakin).

from langchain_community.tools import AnakinScrapeTool
from langchain_community.tools import AnakinSearchTool
