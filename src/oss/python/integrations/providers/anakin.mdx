> [Anakin](https://anakin.io) converts websites into clean, structured data at scale.
> Extract data from any website with a single API call — Anakin handles JavaScript rendering,
> anti-bot systems, and proxy rotation automatically. It also provides AI-powered web search
> and multi-stage autonomous agentic research.

## Installation and setup

Install the `langchain-community` package:

<CodeGroup>
```bash pip
pip install -U langchain-community
```

```bash uv
uv add langchain-community
```
</CodeGroup>

Set your Anakin API key as an environment variable. Get your key from the [Anakin dashboard](https://anakin.io/dashboard).

```bash
export ANAKIN_API_KEY="your-api-key"
```

## Document loader

See a [usage example](/oss/integrations/document_loaders/anakin).

```python
from langchain_community.document_loaders import AnakinLoader
```

## Tools

See a [usage example](/oss/integrations/tools/anakin).
