[DexPaprika](https://dexpaprika.com) is a keyless DEX market-data API from CoinPaprika, covering on-chain DEX activity across every major blockchain (33M+ tokens, 36M+ pools). The `langchain-dexpaprika` package wraps it as LangChain tools for token search, market data, pool discovery, and OHLCV price history.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-dexpaprika
```

```bash uv
uv add langchain-dexpaprika
```
</CodeGroup>

No API key or account is required. The DexPaprika API is public and keyless.

## Tools

See the [DexPaprika](/oss/integrations/tools/dexpaprika) guide for details on the available tools, including token search, token market data, pool discovery, and OHLCV price history.
