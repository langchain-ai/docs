>[Opedd](https://opedd.com/for-ai-agents) is a content-licensing platform between expert publishers and AI products. Every article comes with a verifiable license key, on-chain proof, and EU AI Act Article 53 attestation support — a licensed alternative to scraping for RAG, agents, and AI search.

The integration lives in the `langchain-opedd` package.

```bash
pip install -qU langchain-opedd
```

## Document loader

`OpeddFeedLoader` loads an enterprise buyer's licensed catalog as LangChain `Document`s, with licensing provenance on every document's metadata. See the [Opedd document loader page](/oss/python/integrations/document_loaders/opedd).

```python
from langchain_opedd import OpeddFeedLoader

loader = OpeddFeedLoader(access_key="ent_...")  # Opedd enterprise access key
docs = loader.load()
```

## Tools

Discovery and verification tools need no credentials; content retrieval needs a buyer token. See the [Opedd tools page](/oss/python/integrations/tools/opedd).

```python
from langchain_opedd import (
    OpeddLookupTool,          # licensing status + price for any article URL (no auth)
    OpeddDirectoryTool,       # browse verified publishers (no auth)
    OpeddVerifyLicenseTool,   # verify a license key + on-chain proof (no auth)
    OpeddContentTool,         # retrieve licensed article text (buyer token)
)
```

## MCP server

Agents that purchase licenses autonomously (a payment-confirmation flow, deliberately not shipped as a LangChain tool) can use the [Opedd MCP server](https://github.com/Opedd/opedd-mcp) — hosted at `https://mcp.opedd.com/mcp` or local via `npx opedd-mcp`.
