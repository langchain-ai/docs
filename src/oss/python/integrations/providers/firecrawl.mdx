[Firecrawl](https://www.firecrawl.dev) is an API that turns websites into clean, LLM-ready data. It can scrape a single page, crawl an entire site, map a site's URLs, extract structured data, and search the web — returning markdown and metadata ready for retrieval and agents.

The `langchain-firecrawl` package exposes Firecrawl both as a **document loader** and as a set of **agent tools**.

## Installation and setup

Install the Firecrawl integration package for LangChain Python:

<CodeGroup>
```bash pip
pip install langchain-firecrawl
```

```bash uv
uv add langchain-firecrawl
```

</CodeGroup>

[Set up a Firecrawl API key](https://www.firecrawl.dev) and set it as an environment variable named `FIRECRAWL_API_KEY`:

```bash
export FIRECRAWL_API_KEY="your-api-key"
```

## Document loader

`FirecrawlLoader` loads web content as LangChain `Document`s. Choose a `mode`: `scrape`, `crawl`, `map`, `extract`, or `search`.

See a [usage example](/oss/integrations/document_loaders/firecrawl).

```python
from langchain_firecrawl import FirecrawlLoader
```

## Tools

Each Firecrawl capability is also available as a `BaseTool` you can bind to an agent.

See a [usage example](/oss/integrations/tools/firecrawl).

### FirecrawlScrape

Scrape a single URL and return clean markdown + metadata.

```python
from langchain_firecrawl import FirecrawlScrape
```

### FirecrawlCrawl

Crawl a site starting from a URL and return each page as markdown.

```python
from langchain_firecrawl import FirecrawlCrawl
```

### FirecrawlMap

Map a site and return the list of discovered, related URLs.

```python
from langchain_firecrawl import FirecrawlMap
```

### FirecrawlExtract

Extract structured data from one or more URLs using a prompt or JSON schema.

```python
from langchain_firecrawl import FirecrawlExtract
```

### FirecrawlSearch

Search the web and return LLM-ready results.

```python
from langchain_firecrawl import FirecrawlSearch
```
