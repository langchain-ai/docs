[DaoXE](https://daoxe.com) is a multi-model, multi-protocol API gateway. It exposes OpenAI-compatible Chat Completions and Responses endpoints, Anthropic Messages (Claude protocol) paths, and image-compatible endpoints where available, so applications can route multiple providers through one account.

For LangChain and LangGraph, use DaoXE's OpenAI-compatible Chat Completions surface through @[`ChatOpenAI`] with base URL `https://daoxe.com/v1`.

<Note>
  DaoXE is not available in mainland China. Model IDs, availability, and pricing are account-scoped. Prefer IDs from authenticated `GET /v1/models` or the [pricing page](https://daoxe.com/pricing) over any static public list.
</Note>

## Prerequisites

1. **DaoXE account**: Create an account at [daoxe.com](https://daoxe.com).
2. **API key**: Create an API key in the DaoXE dashboard and set `DAOXE_API_KEY` in the environment. Do not commit keys to source control.
3. **Model ID**: Choose an exact model ID that is currently available on the account.

## Quickstart

Connect to DaoXE through the @[`ChatOpenAI`] interface:

- Set `base_url` to `https://daoxe.com/v1`
- Set `api_key` to the DaoXE API key
- Pass an account-visible model ID as `model`

### Installation

<CodeGroup>
```bash pip
pip install langchain-openai
```

```bash uv
uv add langchain-openai
```
</CodeGroup>

### Basic setup

```python
import os

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    api_key=os.environ["DAOXE_API_KEY"],
    base_url="https://daoxe.com/v1",
    model=os.environ["DAOXE_MODEL"],  # Exact ID from the account catalog
)

llm.invoke("Summarize multi-protocol API gateways in one sentence.")
```

The request is routed through DaoXE to the selected model. Swap models by changing `DAOXE_MODEL` (or the `model` argument) without changing the rest of the LangChain application code.

### Environment variables

```bash
export DAOXE_API_KEY="your_api_key"
export DAOXE_MODEL="your_exact_model_id"
```

You can also pass the key and model directly to @[`ChatOpenAI`]. Prefer environment variables in shared or automated environments.

### Streaming

```python
import os

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    api_key=os.environ["DAOXE_API_KEY"],
    base_url="https://daoxe.com/v1",
    model=os.environ["DAOXE_MODEL"],
)

for chunk in llm.stream("Write one practical tip for evaluating LLM APIs."):
    print(chunk.content, end="", flush=True)
```

### LangGraph integration

```python
import os

from langchain.messages import HumanMessage
from langchain_openai import ChatOpenAI
from langgraph.graph import MessagesState, StateGraph


def call_model(state: MessagesState):
    model = ChatOpenAI(
        api_key=os.environ["DAOXE_API_KEY"],
        base_url="https://daoxe.com/v1",
        model=os.environ["DAOXE_MODEL"],
    )
    response = model.invoke(state["messages"])
    return {"messages": [response]}


workflow = StateGraph(MessagesState)
workflow.add_node("agent", call_model)
workflow.set_entry_point("agent")
workflow.set_finish_point("agent")

app = workflow.compile()

result = app.invoke({"messages": [HumanMessage(content="Hello!")]})
```

## Protocols and clients

DaoXE is multi-protocol. LangChain's @[`ChatOpenAI`] path uses the OpenAI-compatible Chat Completions surface at `https://daoxe.com/v1`. The same account can also use other published DaoXE endpoints (for example Anthropic Messages / Claude protocol clients) outside of this integration page when those clients are a better fit.

For OpenAI SDK-style examples in Python, Node.js, and curl, see [seven7763/DaoXE-AI](https://github.com/seven7763/DaoXE-AI).
