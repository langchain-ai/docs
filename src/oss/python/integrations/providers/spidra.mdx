> [Spidra](https://spidra.io) turns websites into structured, ready-to-use data using prompts, real browsers, proxies, CAPTCHA solving, and AI extraction — without forcing you to build or maintain scraping infrastructure.
>
> Key features:
>
> - **Scrape** — Describe what you want in plain text. Spidra opens a real browser, runs your prompt, and returns clean, structured data.
> - **Crawl** — Discover pages, visit each one, and extract structured data across an entire site automatically.
> - **Batch scrape** — Submit up to 50 URLs in one request; they all run in parallel.
> - **Stealth mode** — Residential proxies to 50+ countries, CAPTCHA solving, and browser fingerprint evasion built in.
> - **Authenticated scraping** — Pass session cookies to scrape pages behind login walls.

For more information, visit the [Spidra website](https://spidra.io) or the [Spidra documentation](https://docs.spidra.io).

## Installation and setup

Install the `langchain-spidra` package:

<CodeGroup>
```bash pip
pip install langchain-spidra
```

```bash uv
uv add langchain-spidra
```
</CodeGroup>

Set your API key as an environment variable. Get your key from [app.spidra.io](https://app.spidra.io):

```bash
export SPIDRA_API_KEY=<your-api-key>
```

## Available tools

Spidra provides three LangChain tools for web scraping and crawling:

### SpidraScrape

Scrape a single URL and return its content as structured markdown.

```python
from langchain_spidra import SpidraScrape

tool = SpidraScrape()
result = tool.invoke({"url": "https://example.com"})
print(result)
```

See the [Spidra tools guide](/oss/integrations/tools/spidra) for full usage details.

### SpidraCrawl

Crawl an entire website starting from a seed URL and return content from all discovered pages.

```python
from langchain_spidra import SpidraCrawl

tool = SpidraCrawl()
result = tool.invoke({"url": "https://example.com"})
print(result)
```

### SpidraBatchScrape

Scrape up to 50 URLs in parallel in a single request.

```python
from langchain_spidra import SpidraBatchScrape

tool = SpidraBatchScrape()
result = tool.invoke({"urls": ["https://example.com", "https://example.org"]})
print(result)
```

See the [Spidra tools guide](/oss/integrations/tools/spidra) for full usage details, including use within an agent.

## Document loader

`SpidraLoader` loads scraped web pages as LangChain `Document` objects. It supports both single-URL scraping and full-site crawling.

```python
from langchain_spidra import SpidraLoader

loader = SpidraLoader(url="https://example.com")
docs = loader.load()
print(docs[0])
```

See the [SpidraLoader document loader guide](/oss/integrations/document_loaders/spidra) for full usage details.
