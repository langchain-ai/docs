This page covers all LangChain integrations with Baidu products, such as PaddleOCR.

## PaddleOCR

The `langchain-paddleocr` package implements integrations of PaddleOCR's capabilities. [PaddleOCR](https://www.paddleocr.com) is a powerful and lightweight OCR toolkit developed by Baidu that connects images and PDFs with LLMs. It supports over 100 languages and transforms document content into structured, AI-ready data.

### Installation and setup

<CodeGroup>
```bash pip
pip install langchain-paddleocr
```

```bash uv
uv add langchain-paddleocr
```
</CodeGroup>
