[AproxPay](https://aproxpay.com) is a residential proxy designed for autonomous AI agents, with native [x402](https://www.x402.org/) payments in USDC on Base. No signup and no API key — a buyer wallet pays per request or session pass.

[`langchain-aproxpay`](https://pypi.org/project/langchain-aproxpay/) provides LangChain tools for:

- Per-request residential fetches (`aproxpay_proxy_get`)
- Sticky sessions and optional exit-country pinning
- Session passes with ephemeral CONNECT credentials for Playwright / browser agents

JavaScript/TypeScript support is available via the same package name on [npm](https://www.npmjs.com/package/langchain-aproxpay).

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-aproxpay
```

```bash uv
uv add langchain-aproxpay
```
</CodeGroup>

Set `APROXPROXY_PRIVATE_KEY` to a dedicated buyer wallet private key funded with USDC on Base. See the [tool documentation](/oss/integrations/tools/aproxpay) for full setup, invocation, and session-pass examples.
