[GoodSender](https://goodsender.com) is a free email API (100,000 emails/month free) built around permission-first sending. It offers transactional templates that deliver to any address without prior consent, and consent-gated custom/marketing email enforced at the API through the Permission Loop. The `langchain-goodsender` package wraps the GoodSender API as LangChain tools for sending transactional templates, sending custom email, and managing recipient consent.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-goodsender
```

```bash uv
uv add langchain-goodsender
```
</CodeGroup>

Get your API key from [goodsender.com](https://goodsender.com) and set it as an environment variable:

```bash
export GOODSENDER_API_KEY="your-api-key"
```

## Tools

See the [GoodSender Toolkit](/oss/integrations/tools/goodsender) guide for details on the available tools, including sending transactional templates, sending consent-gated custom email, and requesting recipient consent via the Permission Loop.
