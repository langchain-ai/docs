[modal-gpu-ez](https://pypi.org/project/modal-gpu-ez/) provides one-liner inference using [Modal](https://modal.com) serverless GPUs and HuggingFace models. It supports automatic GPU selection, cost tracking, budget management, and local/remote switching.

`langchain-modal-gpu-ez` wraps `modal-gpu-ez` as a LangChain integration, providing LLM and Embeddings interfaces.

## Installation

```bash
pip install langchain-modal-gpu-ez
```

## Setup

Set your Modal API credentials:

```python
import os

os.environ["MODAL_TOKEN_ID"] = "your_modal_token_id"
os.environ["MODAL_TOKEN_SECRET"] = "your_modal_token_secret"

# Optional: for gated models (e.g., Llama)
os.environ["HF_TOKEN"] = "your_hf_token"
```
