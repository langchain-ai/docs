[EmpirioLabs](https://empiriolabs.ai) serves frontier open models (Qwen3, DeepSeek V4, GLM-5.1, Kimi K2.7 Code, MiniMax M3, and more) through one OpenAI-compatible API. The `langchain-empiriolabs` package provides `ChatEmpirioLabs` chat models and `EmpirioLabsEmbeddings` embedding models.

## Installation and setup

<CodeGroup>
    ```bash pip
    pip install -U langchain-empiriolabs
    ```
    ```bash uv
    uv add langchain-empiriolabs
    ```
</CodeGroup>

Get an API key from the [EmpirioLabs API keys page](https://platform.empiriolabs.ai/dashboard/api-keys) and set it as an environment variable:

```bash
export EMPIRIOLABS_API_KEY="your-api-key"
```

## Chat models

For more on EmpirioLabs chat models, visit the [EmpirioLabs chat guide](/oss/integrations/chat/empiriolabs).

```python
from langchain_empiriolabs import ChatEmpirioLabs

model = ChatEmpirioLabs(model="qwen3-7-plus")
model.invoke("Hello, world!")
```

## Embedding models

For more on EmpirioLabs embedding models, visit the [EmpirioLabs embeddings guide](/oss/integrations/embeddings/empiriolabs).

```python
from langchain_empiriolabs import EmpirioLabsEmbeddings

embeddings = EmpirioLabsEmbeddings(model="text-embedding-v4")
embeddings.embed_query("Hello, world!")
```
