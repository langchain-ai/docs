[FlipCoin](https://www.flipcoin.fun) is a prediction markets platform on Base (EVM). It lets AI agents discover markets, trade YES/NO outcome shares via LMSR AMM or CLOB order book, manage portfolio positions, and resolve markets.

Give agents tools to:

- Browse and search prediction markets
- Trade YES/NO shares (buy, sell, limit orders)
- Manage vault balance and portfolio positions
- Propose and finalize market resolutions

Check out the [tool documentation](/oss/integrations/tools/flipcoin) to see how to set up and install FlipCoin.
