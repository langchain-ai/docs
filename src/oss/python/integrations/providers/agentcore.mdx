[Amazon Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/) Code Interpreter provides secure code execution in isolated MicroVM environments. Each session runs in a dedicated MicroVM with its own filesystem, Python runtime, and shell access.

## Installation

<CodeGroup>
```bash pip
pip install langchain-agentcore-codeinterpreter
```
```bash uv
uv add langchain-agentcore-codeinterpreter
```
</CodeGroup>

## Credentials

AgentCore uses AWS credentials. Configure via environment variables, `~/.aws/credentials`, or an IAM role:
```bash
export AWS_ACCESS_KEY_ID="..."
export AWS_SECRET_ACCESS_KEY="..."
export AWS_SESSION_TOKEN="..."
export AWS_REGION="us-west-2"
```

## Usage

### Standalone
```python
from bedrock_agentcore.tools.code_interpreter_client import CodeInterpreter
from langchain_agentcore_codeinterpreter import AgentCoreSandbox

interpreter = CodeInterpreter(region="us-west-2")
interpreter.start()

backend = AgentCoreSandbox(interpreter=interpreter)

result = backend.execute("echo hello && python3 --version")
print(result.output)

interpreter.stop()
```

### With Deep Agents
```python
from bedrock_agentcore.tools.code_interpreter_client import CodeInterpreter
from langchain_aws import ChatBedrockConverse
from deepagents import create_deep_agent

from langchain_agentcore_codeinterpreter import AgentCoreSandbox

interpreter = CodeInterpreter(region="us-west-2")
interpreter.start()

model = ChatBedrockConverse(
    model="us.anthropic.claude-sonnet-4-6",
    region_name="us-west-2",
)
backend = AgentCoreSandbox(interpreter=interpreter)

agent = create_deep_agent(
    model=model,
    backend=backend,
    system_prompt="You are a coding assistant with sandbox access.",
)

try:
    result = agent.invoke(
        {
            "messages": [
                {"role": "user", "content": "Create and run a hello world script"}
            ]
        }
    )
    print(result["messages"][-1].content)
finally:
    interpreter.stop()
```

### With the CLI
```bash
uv tool upgrade deepagents-cli --with langchain-agentcore-codeinterpreter
deepagents --sandbox agentcore
```

## File operations

### Upload files
```python
backend.upload_files([
    ("hello.py", b"print('hello world')"),
    ("data.csv", b"name,value\na,1\nb,2"),
])
```

### Download files
```python
files = backend.download_files(["hello.py"])
for f in files:
    if f.content:
        print(f"{f.path}: {f.content.decode()}")
```

## Session behavior

- Each session runs in an isolated MicroVM with dedicated resources
- Files persist for the session lifetime (default 15 minutes, configurable up to 8 hours)
- Sessions cannot be reconnected after stopping — `--sandbox-id` is not supported
- Binary files are supported via base64 encoding
