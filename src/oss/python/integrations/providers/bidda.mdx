[Bidda](https://bidda.com) is a registry of source-verified regulatory and compliance intelligence: 10,000+ obligations across 39 regulated pillars, each traced to a primary legal source with a content hash. The `langchain-bidda` package exposes the Bidda registry as a LangChain tool, so an agent can look up what a regulation requires and cite a primary source instead of relying on the model's own recall.

Bidda content is reference intelligence, not legal advice; the reader draws the legal conclusion.

## Installation and setup

Install the Bidda integration package for LangChain Python:

<CodeGroup>
```bash pip
pip install langchain-bidda
```

```bash uv
uv add langchain-bidda
```
</CodeGroup>

No API key is required for the discovery-tier search used by the tool.

## Tools

See a [usage example](/oss/python/integrations/tools/bidda).

```python
from langchain_bidda import BiddaComplianceTool
```
