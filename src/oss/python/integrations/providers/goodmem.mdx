[GoodMem](https://goodmem.ai) is a long-term memory layer for AI agents. GoodMem handles embedding, vector search, reranking, and optional LLM-powered answering server-side, so agents can store and recall information across sessions without a bespoke retrieval pipeline.

Two packages bring GoodMem to the LangChain stack, both exposing the same GoodMem operations as tools:

- `langchain-goodmem` for LangChain agents and chains
- `langgraph-goodmem` for LangGraph agents and graphs

## Installation and setup

Install the package for LangChain:

<CodeGroup>
```bash pip
pip install langchain-goodmem
```

```bash uv
uv add langchain-goodmem
```
</CodeGroup>

For LangGraph, install `langgraph-goodmem` instead:

<CodeGroup>
```bash pip
pip install langgraph-goodmem
```

```bash uv
uv add langgraph-goodmem
```
</CodeGroup>

The tools accept the GoodMem server URL and API key directly. The examples read them from the following environment variables:

| Variable | Description |
| :--- | :--- |
| `GOODMEM_BASE_URL` | Base URL of the GoodMem API server |
| `GOODMEM_API_KEY` | API key for authentication |
| `GOODMEM_VERIFY_SSL` | Set to `false` to skip TLS verification for self-signed development certificates (default: `true`) |

## Tools

GoodMem exposes its memory operations as LangChain tools: create and retrieve memories, manage spaces, and list embedder models. For the full tool reference and runnable quickstarts for both LangChain and LangGraph, see the [GoodMem tools page](/oss/integrations/tools/goodmem).
