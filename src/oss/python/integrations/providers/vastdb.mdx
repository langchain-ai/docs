>[VAST Database](https://vastdata.com/) is a high-performance, exabyte-scale data platform with native vector indexing, enabling similarity search directly alongside structured and unstructured data.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-vastdb
```

```bash uv
uv add langchain-vastdb
```
</CodeGroup>

You will need access to a running VAST Database cluster with vector index support.

## VectorStore

The `VastDBVectorStore` class implements the LangChain `VectorStore` interface, enabling similarity search, document storage, and retrieval-augmented generation (RAG) workflows backed by VAST Database.

```python
from langchain_vastdb import VastDBVectorStore
```

For a more detailed walkthrough, see the [VAST Database vector store guide](/oss/integrations/vectorstores/vastdb).
