[MrScraper](https://mrscraper.com) provides web scraping APIs for rendered HTML retrieval, AI-based extraction, scraper reruns, and result management.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-mrscraper
```

```bash uv
uv add langchain-mrscraper
```
</CodeGroup>

Set your API token:

```python
import os
os.environ["MRSCRAPER_API_KEY"] = "your-api-token"
```

## Toolkit

```python
from langchain_mrscraper import MrScraperToolkit

tools = MrScraperToolkit().get_tools()
```

## Tool integrations

The MrScraper integration provides several tools:

- [MrScraper Unblocker](/oss/python/integrations/tools/mrscraper_fetch_html) - Fetch rendered HTML through the unblocker (stealth browser and IP rotation) when pages are geo-restricted or bot-protected
- [MrScraper create AI scraper](/oss/python/integrations/tools/mrscraper_create_scraper) - Create an AI scraper run from natural-language instructions with general, listing, or map agents and optional proxy country
- [MrScraper rerun AI scraper](/oss/python/integrations/tools/mrscraper_rerun_ai_scraper) - Rerun an existing AI scraper configuration on a new URL (including map-agent crawl options when applicable)
- [MrScraper bulk rerun AI scraper](/oss/python/integrations/tools/mrscraper_bulk_rerun_ai_scraper) - Run one AI scraper configuration across many URLs in a single bulk job
- [MrScraper rerun manual scraper](/oss/python/integrations/tools/mrscraper_rerun_manual_scraper) - Execute a dashboard-built manual workflow scraper on a URL, with optional workflow overrides
- [MrScraper bulk rerun manual scraper](/oss/python/integrations/tools/mrscraper_bulk_rerun_manual_scraper) - Run one manual scraper configuration across many URLs in a single bulk job
- [MrScraper get all results](/oss/python/integrations/tools/mrscraper_get_all_results) - List scrape results with pagination, sorting, search, and optional date-range filters
- [MrScraper get result by ID](/oss/python/integrations/tools/mrscraper_get_result_by_id) - Retrieve the full detail for a single scrape result by its result ID
