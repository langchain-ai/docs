# Kalibr

[Kalibr](https://kalibr.systems) is outcome-aware execution routing for AI agents.
It learns which model+tool+parameter path works best for each goal and routes
traffic accordingly — automatically, before failures reach users.

Kalibr is not observability. It does not show you dashboards after failures occur.
It prevents failures by routing proactively based on whether agent steps actually
achieved their goal.

## When to Use Kalibr

Add Kalibr when:

- Your LangChain agent or chain runs in production with real users
- You want automatic fallback that triggers on *outcome degradation*, not just exceptions
- You have multiple models or tool configurations you could use for a task
- You want cost/quality routing to optimize automatically over time

Kalibr is distinct from LangChain's built-in error handling: Kalibr routes proactively 
based on learned outcomes, before hard failures occur.

## Installation

```bash
pip install kalibr langchain-openai
```

## Setup

Get your Kalibr API key from [kalibr.systems/dashboard](https://kalibr.systems/dashboard):

```bash
export KALIBR_API_KEY="your-api-key"

```

## Usage with LangChain

```python
from kalibr.integrations.langchain import KalibrChatModel
from langchain_core.messages import HumanMessage

llm = KalibrChatModel(
    goal="summarize_document",
    paths=["gpt-4o", "claude-sonnet-4-20250514"],
)

response = llm.invoke([HumanMessage(content="Summarize this: ...")])
print(response.content)
```

```python
# With LangChain Expression Language (LCEL)
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

prompt = ChatPromptTemplate.from_template("Summarize: {text}")
chain = prompt | llm | StrOutputParser()
result = chain.invoke({"text": "Your document here"})
```

## Reporting Outcomes

Outcome reporting is what makes Kalibr learn and improve routing over time:

```python
from kalibr import Router

router = Router(
    goal="classify_intent",
    paths=["gpt-4o-mini", "gpt-4o"],
)

response = router.completion(
    messages=[{"role": "user", "content": "Is this a complaint? Yes/No: ..."}]
)

# Report whether the result was correct
router.report_outcome(
    request_id=response.request_id,
    success=True,
    quality_score=0.95,
)
```
