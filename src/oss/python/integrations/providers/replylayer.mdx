[ReplyLayer](https://replylayer.ai) is an email platform for AI agents with governance built in — sends pass recipient-allowlist, quota, human-approval, and content-scanning gates before anything leaves, and inbound mail is security-scanned before an agent reads it. The `langchain-replylayer` package wraps the ReplyLayer SDK as six LangChain tools whose results are governed outcomes an agent can branch on — a refused send comes back as a structured tool result, not a raised exception — plus a live inbox retriever and a document loader that only ever emit scanned, settled messages.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-replylayer
```

```bash uv
uv add langchain-replylayer
```
</CodeGroup>

ReplyLayer is currently in private beta — get access and an API key at [replylayer.ai](https://replylayer.ai), then set it as an environment variable. Use a **mailbox-scoped agent key**, not an admin key, so the credential you hand the agent is limited to its own mailbox:

```bash
export REPLYLAYER_API_KEY="your-api-key"
```

## Tools

See the [ReplyLayer Toolkit](/oss/integrations/tools/replylayer) guide for the six tools — sending, replying inside a thread, listing, reading with the message's safety context, long-polling for inbound mail, and preflighting the send quota — and the `status` contract each returns.

## Document loader and retriever

`ReplyLayerRetriever` is a live, search-backed retriever over a mailbox: every query re-runs the server's state gating, scoping, and redaction and is audit-logged, instead of snapshotting an inbox into a vector store. `ReplyLayerLoader` exports scanned, settled messages as `Document`s for indexing, with quarantined and unscanned mail excluded. Both stamp a provenance header into `page_content` so retrieved email reads as untrusted data rather than instructions, and both surface server-side body truncation to the model.

```python
from langchain_replylayer import ReplyLayerLoader, ReplyLayerRetriever

retriever = ReplyLayerRetriever(mailbox_id="your-mailbox-id", k=5)
docs = retriever.invoke("refund request")

loader = ReplyLayerLoader(mailbox_id="your-mailbox-id", direction="inbound")
for doc in loader.lazy_load():
    ...
```
