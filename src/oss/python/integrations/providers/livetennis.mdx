[Live Tennis API](https://livetennisapi.com) is a real-time tennis data API covering ATP, WTA, Challenger, ITF and junior Grand Slam draws. See the [Live Tennis API docs](https://docs.livetennisapi.com) for signup, authentication and endpoint details.

## Installation and setup

Install `langchain-livetennis`:

<CodeGroup>
```bash pip
pip install -qU langchain-livetennis
```

```bash uv
uv add langchain-livetennis
```
</CodeGroup>

Get a free API key (1,000 requests/day) at [livetennisapi.com/subscribe/free](https://livetennisapi.com/subscribe/free), then set it in your environment:

```bash
export LIVETENNISAPI_KEY="your-key"
```
