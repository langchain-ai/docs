[1Claw](https://1claw.xyz) keeps secrets and signing keys out of your agent's reach. LangChain agents can:

- Fetch external API keys from an HSM-backed vault at call time, so they never enter the LLM context
- Route every LLM call through [Shroud](https://docs.1claw.xyz/docs/guides/shroud), a TEE proxy that redacts secrets/PII, scores prompt injection, and enforces output and budget policy
- Sign on-chain transactions via the Intents API without the agent ever holding a private key

### How it works

1Claw works with stock LangChain — no special SDK required:

1. Store your provider key (OpenAI/Anthropic) and any tool API keys in a 1Claw vault.
2. Point `ChatOpenAI` or `ChatAnthropic` at the Shroud proxy using `base_url` and `default_headers`.
3. Each request and response passes through Shroud's filters before reaching the model provider; tool keys are fetched from the vault inside the tool's call boundary and discarded after use.

## Installation and setup

See the [1claw-langchain-demo](https://github.com/1clawAI/1claw-langchain-demo) for a complete LangGraph ReAct agent wired to Shroud + vault, and the [1Claw docs](https://docs.1claw.xyz) for vault and Shroud setup.
