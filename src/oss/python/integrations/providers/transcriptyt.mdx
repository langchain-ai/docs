# TranscriptYT

This page covers how to use [TranscriptYT](https://transcript-yt.com) within LangChain. TranscriptYT is a YouTube transcript API: it returns the transcript of any public YouTube video in 150+ languages, with machine translation and AI transcription for videos without captions. Requests run through rotating proxies, so they work from cloud servers where YouTube blocks datacenter IPs.

## Installation and Setup

Install the standalone integration package:

```bash
pip install -U langchain-transcriptyt
```

Get a free API key at [transcript-yt.com/dashboard/keys](https://transcript-yt.com/dashboard/keys) and set it as an environment variable:

```python
import os

os.environ["TRANSCRIPTYT_API_KEY"] = "YOUR_API_KEY"
```

## Document Loader

`TranscriptYTLoader` loads one document per video, or splits each transcript into timestamped paragraphs.

```python
from langchain_transcriptyt import TranscriptYTLoader

loader = TranscriptYTLoader(["https://www.youtube.com/watch?v=dQw4w9WgXcQ", "jNQXAC9IVRw"])
docs = loader.load()

print(docs[0].page_content[:200])
print(docs[0].metadata)
```

It can also load a whole playlist or channel:

```python
loader = TranscriptYTLoader(
    playlist="https://www.youtube.com/@3blue1brown",
    limit=20,
    chunk="paragraph",
    chunk_size=1000,
)
docs = loader.load()

# Paragraph chunks link to the exact moment in the video
print(docs[0].metadata["source"])
```

Options include `language`, `translate_to`, `chunk` (`"video"` or `"paragraph"`), `chunk_size`, `mode` (`"auto"`, `"captions"` or `"ai"`) and `continue_on_failure`.

## Tools

`TranscriptYTSearchTool` searches YouTube, and `TranscriptYTTranscriptTool` returns a video's transcript with timestamps.

```python
from langchain.agents import create_agent
from langchain_transcriptyt import TranscriptYTSearchTool, TranscriptYTTranscriptTool

agent = create_agent(
    "openai:gpt-5",
    tools=[TranscriptYTSearchTool(), TranscriptYTTranscriptTool()],
)
agent.invoke(
    {"messages": [{"role": "user", "content": "Find a recent video on RAG evaluation and summarize it."}]}
)
```
