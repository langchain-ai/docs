[eucompliance.tools](https://eucompliance.tools) marks model output under **Article 50 of the EU AI Act**, which has applied since 2 August 2026.

Article 50 places the transparency obligation on the *deployer* — whoever puts a model into a product — not on the model provider. The callback produces the disclosure text you have to show your users, plus a signed provenance record for your own files.

The content of your runs is not transmitted: the SHA-256 is computed locally and only that hash is sent.

## Installation and setup

```bash
pip install eucompliance-ai-act
```

No account and no API key are required. The free tier allows 500 disclosures per day per address.

## Callbacks

```python
from eucompliance_ai_act.integrations import langchain_callback

disclosure = langchain_callback(deployer="Your Company GmbH")

response = chain.invoke(
    {"question": "What is the capital of Austria?"},
    config={"callbacks": [disclosure]},
)

print(disclosure.last.disclosure_text)
# "This content was generated using artificial intelligence."

print(disclosure.last.record)
# signed provenance record: content hash, model, deployer, timestamp
```

Pass it once at construction time to cover every call:

```python
llm = ChatOpenAI(model="gpt-4o", callbacks=[disclosure])
```

### Options

| Argument | Default | What it does |
| --- | --- | --- |
| `deployer` | `None` | Your organisation — appears in the record |
| `kind` | `"text"` | `text`, `bearbeitet` (edited), `deepfake`, `interaktion` |
| `language` | `"de"` | Language of the disclosure text (`"de"` or `"en"`) |
| `file` | `None` | Append every record to this JSONL file |
| `sink` | `None` | Callable that receives each record |
| `blocking` | `False` | Wait for the disclosure instead of backgrounding it |

```python
disclosure.summary()
# {"disclosed": 128, "unsigned": 0, "kept": 128}
```

## Verifying a record

Records are signed with EIP-191 and can be verified by anyone, free and without an account:

```python
from eucompliance_ai_act import verify

verify(disclosure.last.record, content=the_text)
# {"valid": True, "content_matches": True, ...}
```

Or open [eucompliance.tools/verify](https://eucompliance.tools/verify) in a browser.

## Notes

The handler runs on a background thread, so your chain never waits for it, and it swallows its own exceptions — if the service is unreachable you still get valid disclosure text, flagged `offline=True`, and your application is unaffected.

It attests **origin**, not detection: a record proves that this exact content was declared AI-generated at that time and is unchanged since. It does not prove that content *without* a record is human-made. This is a technical attestation, not legal advice — classifying your own system remains your responsibility.
