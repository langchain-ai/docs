>[Daytona](https://www.daytona.io/) is dedicated to accelerating AI innovation by providing a secure, lightning-fast runtime that eliminates execution barriers and empowers both developers and AI systems to focus on what truly matters — transforming intelligent code into real-world solutions.
><br/>
>Daytona is open source. Check out the [GitHub repository](https://github.com/daytonaio/daytona) to learn more, contribute, or star the project.

## Installation and Setup

Install the `langchain-daytona-data-analysis` package. For detailed installation instructions, see the [tool usage guide](/oss/integrations/tools/daytona_data_analysis).

## Prerequisites

- Python 3.9+
- Daytona API Key ([Get it from Daytona Dashboard](https://app.daytona.io/dashboard/keys))
- Set `DAYTONA_API_KEY` environment variable

## Tool

The `DaytonaDataAnalysisTool` enables LangChain agents to perform secure Python data analysis in an isolated, sandboxed environment powered by Daytona's infrastructure.

```python
from langchain_daytona_data_analysis import DaytonaDataAnalysisTool
```

For more details about the tool and its usage, see the [Daytona tool guide](https://www.daytona.io/docs/en/langchain-data-analysis).
