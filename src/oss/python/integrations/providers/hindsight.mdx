[Hindsight](https://github.com/vectorize-io/hindsight) is an open-source (MIT) long-term memory engine for AI agents. It gives your agents the ability to store, recall, and synthesize memories across conversations, automatically extracting facts, building entity graphs, and retrieving relevant context using four parallel strategies (semantic, BM25, graph traversal, temporal).

Hindsight can run locally via Docker, as a pip-installable server, or embedded in your Python process.

This page covers how to use [Hindsight](https://github.com/vectorize-io/hindsight) within LangChain and LangGraph.

## Installation and setup

### Run Hindsight locally

The fastest way to get started is with Docker:

```bash
docker run --rm -it --pull always -p 8888:8888 -p 9999:9999 \
  -e HINDSIGHT_API_LLM_API_KEY=$OPENAI_API_KEY \
  -v $HOME/.hindsight-docker:/home/hindsight/.pg0 \
  ghcr.io/vectorize-io/hindsight:latest
```

This starts the Hindsight API on `http://localhost:8888` and a control plane UI on `http://localhost:9999`.

Or install as a Python package:

```bash
pip install hindsight-api
HINDSIGHT_API_LLM_API_KEY=$OPENAI_API_KEY hindsight-api
```

### Install the LangChain integration

<CodeGroup>
```bash pip
pip install -U hindsight-langgraph
```

```bash uv
uv add hindsight-langgraph
```
</CodeGroup>

### Connect to your Hindsight instance

```python
from hindsight_client import Hindsight

# Point to your self-hosted instance
client = Hindsight(base_url="http://localhost:8888")
```

You can pass this `client` directly to any of the integration functions below. Alternatively, use `configure()` to set global defaults:

```python
from hindsight_langgraph import configure

configure(hindsight_api_url="http://localhost:8888")
```

## Tools

Hindsight provides three tools for agent-driven memory: **retain** (store), **recall** (retrieve), and **reflect** (synthesize). See the [Hindsight tools integration](/oss/integrations/tools/hindsight) for usage details.

```python
from hindsight_langgraph import create_hindsight_tools
```

## Store

`HindsightStore` is a drop-in `BaseStore` implementation for LangGraph's native `store=` parameter, replacing `InMemoryStore` with persistent long-term memory. See the [Hindsight store integration](/oss/integrations/stores/hindsight) for usage details.

```python
from hindsight_langgraph import HindsightStore
```

## Nodes

Pre-built graph nodes for automatic memory injection and storage in LangGraph workflows:

```python
from hindsight_langgraph import create_recall_node, create_retain_node
```

These require the `langgraph` extra:

```bash
pip install -U "hindsight-langgraph[langgraph]"
```
