[Gandr](https://gandr.ai) is a text to speech API built for voice agents that read numbers, order IDs and addresses out loud. One engine speaks 23 languages with six voices, and every render is watermarked. The `gandr-langchain` package exposes Gandr as a LangChain tool. The underlying API is OpenAI compatible: `POST https://tts.gandr.ai/v1/audio/speech` with a Bearer key returns `mp3`, `wav` or `pcm` audio (default `mp3`).

## Installation and setup

Install the Gandr integration package for LangChain Python:

<CodeGroup>
```bash pip
pip install gandr-langchain
```

```bash uv
uv add gandr-langchain
```
</CodeGroup>

Get an API key at [gandr.ai](https://gandr.ai) and set it as an environment variable named `GANDR_API_KEY`. The free tier is 50,000 tokens.

```bash
export GANDR_API_KEY="your-api-key"
```

## Tools

### GandrText2SpeechTool

A tool that renders text to speech and returns the path of the generated WAV file.

```python
from gandr_langchain import GandrText2SpeechTool

tts = GandrText2SpeechTool()
audio_path = tts.invoke("Your order 4815 has shipped to 12 Main Street.")
```

The constructor accepts a `voice` (default `"gandr-jenny"`), an optional `language`, and an optional `api_key` that overrides the environment variable.
