[Thrindex](https://thrindex.com) is the memory OS for AI agents. It provides persistent, semantically-searchable memory so agents can store and recall facts across sessions without managing embeddings or vector infrastructure.

## Installation and setup

```python
pip install -U langchain-thrindex
```

To use Thrindex, [create an account](https://app.thrindex.com) and generate an API key from the dashboard.

```python
import os

os.environ["THRINDEX_API_KEY"] = "<your-api-key>"
```

## Stores

`ThrindexStore` implements the LangGraph `BaseStore` interface, giving agents persistent long-term memory that survives process restarts and works across distributed deployments.

```python
from langchain_thrindex import ThrindexStore

store = ThrindexStore(
    api_key=os.environ["THRINDEX_API_KEY"],
    agent_id="my-agent",
)
```

Pass it directly to `graph.compile()` or `create_react_agent()`:

```python
from langgraph.prebuilt import create_react_agent

agent = create_react_agent(
    model="openai:gpt-4o",
    tools=[...],
    store=store,
)
```

See the [ThrindexStore integration page](/oss/integrations/stores/thrindex) for full usage including semantic search, namespaces, and async support.

## Retrievers

`ThrindexRetriever` implements `BaseRetriever` and can be used in any LCEL chain or RAG pipeline:

```python
from langchain_thrindex import ThrindexRetriever

retriever = ThrindexRetriever(
    api_key=os.environ["THRINDEX_API_KEY"],
    agent_id="my-agent",
    user_id="user-42",
    k=5,
)
```
