[You.com](https://you.com) provides real-time web search, content extraction, and research APIs built for grounding LLMs in current, accurate information.

The `langchain-youdotcom` package exposes You.com's Search, Contents, Research, and Finance Research APIs as LangChain tools, along with a retriever and a lower-level API wrapper.

## Installation and setup

Install the You.com integration package for LangChain Python:

<CodeGroup>
```bash pip
pip install langchain-youdotcom
```

```bash uv
uv add langchain-youdotcom
```
</CodeGroup>

[Get a You.com API key](https://you.com/platform/api-keys) and set it as an environment variable named `YDC_API_KEY`:

```bash
export YDC_API_KEY="your-api-key"
```

You can also pass the key directly when instantiating any component:

```python
from langchain_youdotcom import YouAPIWrapper, YouSearchTool

tool = YouSearchTool(api_wrapper=YouAPIWrapper(ydc_api_key="your-api-key"))
```

## Tools

### YouSearchTool

A search tool that returns real-time web and news results, with geographic filtering, freshness controls, and optional live-crawling for full page content.

See a [usage example](/oss/integrations/tools/you).

```python
from langchain_youdotcom import YouSearchTool
```

### YouContentsTool

A tool that extracts clean, structured content from one or more URLs as markdown or HTML, plus metadata.

See a [usage example](/oss/integrations/tools/you).

```python
from langchain_youdotcom import YouContentsTool
```

### YouResearchTool

A tool that synthesizes a cited, markdown answer to a complex question, with configurable research effort.

See a [usage example](/oss/integrations/tools/you).

```python
from langchain_youdotcom import YouResearchTool
```

### YouFinanceResearchTool

A research tool that searches a finance-optimized index covering SEC filings, earnings reports, equity prices, and financial news.

See a [usage example](/oss/integrations/tools/you).

```python
from langchain_youdotcom import YouFinanceResearchTool
```

## Retriever

`YouRetriever` returns You.com search results as LangChain documents and accepts the same search parameters as `YouSearchTool`.

See a [usage example](/oss/integrations/retrievers/you-retriever).

```python
from langchain_youdotcom import YouRetriever
```

## API wrapper

`YouAPIWrapper` is the lower-level client that powers the tools and retriever. Use it directly when you need full control over API calls and response formats. It exposes `results`, `raw_results`, `contents`, `research_text`, `raw_research`, `finance_text`, and `raw_finance`, each with an async variant.

```python
from langchain_youdotcom import YouAPIWrapper
```
