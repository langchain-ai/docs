[1Claw](https://1claw.xyz) provides HSM-backed secret management for AI agents. Secrets are fetched just-in-time from a vault (scoped, audited, and revocable) and are never exposed to the model or persisted in the context window, so a compromised agent has no raw credentials to leak.

## Installation

```bash
pip install langchain-1claw
```

## Tools

The `langchain-1claw` package exposes tools across several categories:

- **Secrets** — `OneclawGetSecretTool`, `OneclawPutSecretTool`, `OneclawListSecretsTool`, `OneclawRotateSecretTool`: read, write, list, and rotate HSM-encrypted vault secrets.
- **Memory** — `OneclawMemoryPutTool`, `OneclawMemoryGetTool`, `OneclawMemorySearchTool`: encrypted persistent memory with semantic search.
- **Signing** — `OneclawSignMessageTool`, `OneclawSubmitTransactionTool`, `OneclawGetBalanceTool`: EIP-191 message signing and multi-chain transaction submission.
- **Automations** — `OneclawTriggerAutomationTool`: trigger pre-configured workflow automations.

The package also provides `OneclawChatMessageHistory` (a `BaseChatMessageHistory`) and `OneclawMemoryRetriever` (a `BaseRetriever`) backed by encrypted vault memory.

## Setup

Authenticate with your agent's API key and load the tools:

```python
from langchain_1claw import OneclawClient, get_all_tools

client = OneclawClient(api_key="ocv_your_agent_key")
tools = get_all_tools(client)
```

You can then pass `tools` to any LangChain tool-calling agent.
