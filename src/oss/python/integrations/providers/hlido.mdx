> [Hlido](https://hlido.eu) publishes independent, evidence-backed trust scores for AI agents — independent (it doesn't take money to rank anyone), evidence-backed, longitudinal (agents are re-tested over time), and machine-readable. The LangChain tools let an agent vet another agent or tool *before delegating to it*.

## Installation and setup

### Using pip
You can install the package directly from PyPI:

<CodeGroup>
```bash pip
pip install hlido-langchain
```

```bash uv
uv add hlido-langchain
```
</CodeGroup>

## Prerequisites

- Python 3.9+
- No API key is required for trust checks. Optionally, a Hlido API key ([obtain one](https://hlido.eu/api/)) unlocks top-k recommendations.

## Environment variables

Trust checks need no configuration. To use top-k recommendations, set:

```bash
export HLIDO_API_KEY='your-hlido-api-key'  # optional
```

## Tools

See the [Hlido tools page](/oss/integrations/tools/hlido) for a full walkthrough. `get_tools()` returns:

### hlido_trust_check
Vet an AI agent by its Hlido slug before delegating to it — returns a PASS/FAIL trust gate plus score, tier, red flags, and an evidence URL. Fails closed for unreviewed or red-flagged agents.

```python
from hlido_langchain import get_tools

tools = get_tools()
trust_check = next(t for t in tools if t.name == "hlido_trust_check")
```

### hlido_recommend
Given a free-text need, return Hlido-vetted agents ranked by an independent trust score, with evidence URLs.

```python
from hlido_langchain import get_tools

recommend = next(t for t in get_tools() if t.name == "hlido_recommend")
```
