[Octen](https://octen.ai) is a web search engine built for AI agents, delivering real-time, accurate, and factual search results with sub-100ms latency. It supports semantic search, domain filtering, time-range filtering, and highlighted snippets, making it ideal for production agents that require fast and reliable web retrieval.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-octen
```

```bash uv
uv add langchain-octen
```
</CodeGroup>

Get your API key at [octen.ai](https://octen.ai) and set it as an environment variable:

```python
import os
os.environ["OCTEN_API_KEY"] = "your-api-key"
```
