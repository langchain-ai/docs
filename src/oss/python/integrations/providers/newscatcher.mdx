NewsCatcher's [CatchAll](https://www.newscatcherapi.com/docs/web-search-api/get-started/introduction) is a web search API that finds real-world business events — acquisitions, regulatory approvals, funding rounds, and more — and returns structured records ready for analysis.
## Installation and setup

<CodeGroup>
    ```bash pip
    pip install -qU langchain-catchall
    ```
    ```bash uv
    uv add langchain-catchall
    ```
</CodeGroup>

Sign up at [platform.newscatcherapi.com](https://platform.newscatcherapi.com) to get your API key:

```python
import os

os.environ["CATCHALL_API_KEY"] = "your-api-key"
```

## CatchAllClient

For scripts and data pipelines:

```python
import os
from langchain_catchall import CatchAllClient

client = CatchAllClient(api_key=os.environ["CATCHALL_API_KEY"])
result = client.search("FDA drug approvals for rare disease treatments")

print(f"Found {result.valid_records} records")
for record in result.all_records[:3]:
    print(f"- {record.record_title}")
```

For granular control, monitors, async support, and cost optimization patterns, see the [LangChain CatchAll integration guide](https://www.newscatcherapi.com/docs/web-search-api/integrations/langchain).

## CatchAllTools

For LangGraph agents. The toolkit provides two tools:

| Tool | Duration | Cost | Description |
| :--- | :--- | :--- | :--- |
| `catchall_search_data` | 10-15 min | API credits | Initialize new search |
| `catchall_analyze_data` | Instant | LLM costs only | Query cached results |

```python
import os
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain.messages import HumanMessage
from langchain_catchall import CatchAllTools, CATCHALL_AGENT_PROMPT

llm = ChatOpenAI(model="gpt-4o", api_key=os.environ["OPENAI_API_KEY"])
toolkit = CatchAllTools(api_key=os.environ["CATCHALL_API_KEY"], llm=llm)
agent = create_agent(model=llm, tools=toolkit.get_tools(), system_prompt=CATCHALL_AGENT_PROMPT)

# Initial search (10-15 min, uses API credits)
messages = [HumanMessage(content="Find corporate headquarters relocations in the US")]
response = agent.invoke({"messages": messages})
messages = response["messages"]

# Follow-ups use cached data — instant, no additional API credits
messages.append(HumanMessage(content="Show only California locations"))
response = agent.invoke({"messages": messages})
messages = response["messages"]

messages.append(HumanMessage(content="What are the top 3 cities?"))
response = agent.invoke({"messages": messages})

# Prints only the final agent response, omitting raw tool outputs
print(response["messages"][-1].content)
```
