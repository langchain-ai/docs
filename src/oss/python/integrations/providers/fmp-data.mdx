  title: FMP Data (Financial Modeling Prep)                                               
  ---                                                                                     
                                                                                          
  > [langchain-fmp-data](https://pypi.org/project/langchain-fmp-data/) is a LangChain     
  integration                                                                             
  > for [Financial Modeling Prep (FMP) API](https://financialmodelingprep.com/), providing
   easy access                                                                            
  > to financial data through LangChain tools and agents.                                 
                                                                                          
  ## Installation and Setup                                                               
                                                                                          
  Get an FMP API key by visiting [this                                                    
  page](https://site.financialmodelingprep.com/pricing-plans?couponCode=mehdi)            
  and set it as an environment variable:                                                  
                                                                                          
  ```bash                                                                                 
  export FMP_API_KEY="your-fmp-api-key"                                                   
  export OPENAI_API_KEY="your-openai-api-key"                                             
                                                                                          
  Install the package:                                                                    
                                                                                          
  pip install -U langchain-fmp-data                                                       
                                                                                          
  Tools                                                                                   
                                                                                          
  FMPDataTool                                                                             
                                                                                          
  An AI-powered agent tool for natural language financial data queries:                   
                                                                                          
  from langchain_fmp_data import FMPDataTool                                              
                                                                                          
  tool = FMPDataTool()                                                                    
                                                                                          
  # Natural language query                                                                
  response = tool.invoke({"query": "What is Apple's current stock price?"})               
  print(response)                                                                         
                                                                                          
  # Get structured data                                                                   
  response = tool.invoke({                                                                
      "query": "Show me Tesla's revenue for the last 4 quarters",                         
      "response_format": "data_structure"                                                 
  })                                                                                      
                                                                                          
  FMPDataToolkit                                                                          
                                                                                          
  A toolkit for retrieving specific financial data tools based on your query:             
                                                                                          
  from langchain_fmp_data import FMPDataToolkit                                           
                                                                                          
  # Get tools for specific financial data needs                                           
  toolkit = FMPDataToolkit(                                                               
      query="Stock prices and fundamental data",                                          
      num_results=10                                                                      
  )                                                                                       
                                                                                          
  tools = toolkit.get_tools()                                                             
  for tool in tools:                                                                      
      print(f"- {tool.name}: {tool.description}")                                         
                                                                                          
  Response Formats                                                                        
                                                                                          
  The FMPDataTool supports three response formats:                                        
                                                                                          
  from langchain_fmp_data import FMPDataTool, ResponseFormat                              
                                                                                          
  tool = FMPDataTool()                                                                    
                                                                                          
  # Natural language (default)                                                            
  tool.invoke({"query": "...", "response_format": ResponseFormat.NATURAL_LANGUAGE})       
                                                                                          
  # Structured JSON data                                                                  
  tool.invoke({"query": "...", "response_format": ResponseFormat.DATA_STRUCTURE})         
                                                                                          
  # Both formats                                                                          
  tool.invoke({"query": "...", "response_format": ResponseFormat.BOTH})                   
                                                                                          
  Features                                                                                
                                                                                          
  - Comprehensive Financial Data: Stock prices, financial statements, economic indicators,
   and more                                                                               
  - LangGraph Integration: Built on LangGraph for reliable agent workflows                
  - Vector Search: Intelligent tool selection using embeddings and similarity search      
  - Python 3.10 - 3.14 support
