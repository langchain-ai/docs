>[DXMT](https://github.com/dxmt/dxmt) is an open-source memory database for personal agents
> with a vector database underneath: one Rust binary with HNSW and HNSW-PQ vector search,
> BM25 full-text search, hybrid fusion, metadata filters, a write-ahead log and server-side
> embedding.

## Installation and setup

Install the Python package:

<CodeGroup>
```bash pip
pip install langchain-dxmt
```

```bash uv
uv add langchain-dxmt
```
</CodeGroup>

A DXMT server has to be running: a [release binary](https://github.com/dxmt/dxmt/releases)
(`vectordb serve`) or Docker (`docker run -p 127.0.0.1:9999:9999 -v dxmt:/data dxmtai/dxmt`).

## Vector store

`DXMTVectorDB` wraps a DXMT table as a LangChain vector store: dense search with scores and
metadata filters, hybrid (vector + BM25) search, server-side MMR, async methods, and
optional server-side embedding so the store can run with `embedding=None`.

```python
from langchain_dxmt import DXMTVectorDB
```

See the [DXMT vector store guide](/oss/integrations/vectorstores/dxmt).
