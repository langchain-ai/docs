[The Context Company](https://www.thecontextcompany.com) provides observability and customer analytics for production AI agents. The integration captures LangChain and LangGraph runs, model calls, tool executions, errors, token usage, latency, sessions, and metadata. The platform analyzes production conversations and traces to surface recurring patterns and account-level insights that help teams improve their agents.

For complete configuration and usage options, see [The Context Company LangChain and LangGraph documentation](https://docs.thecontextcompany.com/frameworks/langchain-langgraph).

## Install the integration

```bash
pip install "contextcompany[langchain]" langchain langchain-openai langgraph
```

Set your API key:

```bash
export TCC_API_KEY="your-api-key"
```

## Trace LangChain and LangGraph

Initialize the instrumentation before importing LangChain or LangGraph:

```python
from contextcompany.langchain import instrument_langchain

instrument_langchain()

from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-5.5")
response = model.invoke("What patterns are users encountering?")
print(response.content)
```

The instrumentation also captures compiled LangGraph applications without requiring a separate callback:

```python
result = graph.invoke(
    {"messages": [{"role": "user", "content": "Help me investigate this account."}]},
    {
        "metadata": {
            "tcc.sessionId": "session-123",
            "tcc.userId": "user-123",
            "environment": "production",
        }
    },
)
```

Use a UUID in `tcc.runId` when you need a stable run identifier for feedback or deep links. See the [integration guide](https://docs.thecontextcompany.com/frameworks/langchain-langgraph) for sessions, organizations, agents, feedback, and additional metadata options.
