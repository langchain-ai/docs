---
title: "Signet"
description: "Cryptographic receipts for every agent tool call."
---

[Signet](https://github.com/Prismer-AI/signet) produces Ed25519-signed receipts for LangChain tool lifecycle events, writing each one to a local hash-chained audit log. Receipts verify offline.

## Integrations

- [Signet Callback Handler](/oss/integrations/callbacks/signet) - Signs every LangChain tool lifecycle event and appends to a local audit log.
