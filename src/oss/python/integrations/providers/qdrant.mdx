>[Qdrant](https://qdrant.tech/documentation/) (read: quadrant) is a vector similarity search engine.
> It provides a production-ready service with a convenient API to store, search, and manage
> points - vectors with an additional payload. `Qdrant` is tailored to extended filtering support.


## Installation and setup

Install the Python partner package:

<CodeGroup>
```bash pip
pip install langchain-qdrant
```

```bash uv
uv add langchain-qdrant
```
</CodeGroup>

## Embedding models

### FastEmbedSparse

```python
from langchain_qdrant import FastEmbedSparse
```

### SparseEmbeddings

```python
from langchain_qdrant import SparseEmbeddings
```

## Vector store

There exists a wrapper around `Qdrant` indexes, allowing you to use it as a vectorstore,
whether for semantic search or example selection.

To import this vectorstore:
```python
from langchain_qdrant import QdrantVectorStore
```

For a more detailed walkthrough of the Qdrant wrapper, see [this notebook](/oss/integrations/vectorstores/qdrant)

## Long-term memory store

`QdrantStore` is a LangGraph store that persists [long-term memory](/oss/langgraph/stores) in Qdrant, so agents can save data in one conversation and recall it in later ones. Use it anywhere LangGraph accepts a store, such as `graph.compile(store=store)`, in place of `InMemoryStore` or `PostgresStore`.

Install the store package:

<CodeGroup>
```bash pip
pip install -U langgraph-store-qdrant
```

```bash uv
uv add langgraph-store-qdrant
```
</CodeGroup>

Create the store and call `setup()` once before first use:

```python
from langgraph.store.qdrant import QdrantStore
from qdrant_client import QdrantClient

store = QdrantStore(QdrantClient(url="http://localhost:6333"))
store.setup()

store.put(("users", "alice"), "prefs", {"theme": "dark", "lang": "en"})
item = store.get(("users", "alice"), "prefs")
```

For semantic search, item expiry, async usage and other configuration options, refer to the [package documentation](https://pypi.org/project/langgraph-store-qdrant/).
