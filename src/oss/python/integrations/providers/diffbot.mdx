[Diffbot](https://www.diffbot.com) is a structured web knowledge tool for developers. Diffbot reads the public web and maintains the [Diffbot Knowledge Graph](https://www.diffbot.com/products/knowledge-graph/), a continuously refreshed database of linked entities (organizations, people, articles, products, and more) that you query directly instead of crawling and parsing pages yourself. Alongside the Knowledge Graph, Diffbot provides APIs that turn any part of the web into structured, machine-readable data: extract a URL into typed JSON, search the web, tag named entities in free text, crawl entire sites, and answer questions with grounded responses.

For LLM applications, these structured knowledge tools ground agents and chains in precise, citable facts rather than raw HTML or unranked search snippets. Typical uses include company and people research agents, RAG over live web data, and entity enrichment pipelines.

`langchain-diffbot` is a thin integration over the official [`diffbot-python`](https://github.com/diffbot/diffbot-python) SDK. Every Diffbot API gets the closest LangChain primitive:

| Diffbot API | LangChain class(es) |
| --- | --- |
| Knowledge Graph (DQL) | `DiffbotKnowledgeGraphRetriever`, `DiffbotKnowledgeGraphTool` |
| Web Search | `DiffbotWebSearchRetriever`, `DiffbotWebSearchTool` |
| Extract (Analyze) | `DiffbotExtractTool`, `DiffbotExtractLoader` |
| NLP entities | `DiffbotEntitiesTool` |
| Crawl | `DiffbotCrawlLoader` |
| LLM RAG (`ask`) | `ChatDiffbot` (with native streaming), `DiffbotAskTool` |

<Info>
    For complete runnable examples, including a company research agent, see the [`examples/`](https://github.com/diffbot/langchain-diffbot/tree/main/examples) folder in the langchain-diffbot repository.

## Authentication

Get an API token at [app.diffbot.com/get-started](https://app.diffbot.com/get-started/).

Every component takes a pre-built SDK client. Build a `diffbot.Diffbot` (sync) and/or `diffbot.DiffbotAsync` (async) and pass it via `client=` / `async_client=`. Configure the client once and share it across all components — they reuse its connection pool and never close it.

```python
import os

from diffbot import Diffbot

db = Diffbot(token=os.environ["DIFFBOT_API_TOKEN"])
```
