A thin LangChain integration over the official [`diffbot-python`](https://github.com/diffbot/diffbot-python) SDK. Every Diffbot API gets the closest LangChain primitive:

| Diffbot API | LangChain class(es) |
| --- | --- |
| Knowledge Graph (DQL) | `DiffbotKnowledgeGraphRetriever`, `DiffbotKnowledgeGraphTool` |
| Web Search | `DiffbotWebSearchRetriever`, `DiffbotWebSearchTool` |
| Extract (Analyze) | `DiffbotExtractTool`, `DiffbotExtractLoader` |
| NLP entities | `DiffbotEntitiesTool` |
| Crawl | `DiffbotCrawlLoader` |
| LLM RAG (`ask`) | `ChatDiffbot` (with native streaming), `DiffbotAskTool` |

## Installation

<CodeGroup>
```bash pip
pip install langchain-diffbot
```

```bash uv
uv add langchain-diffbot
```
</CodeGroup>

## Authentication

Get an API token at [app.diffbot.com/get-started](https://app.diffbot.com/get-started/).

Every component takes a pre-built SDK client. Build a `diffbot.Diffbot` (sync) and/or `diffbot.DiffbotAsync` (async) and pass it via `client=` / `async_client=`. Configure the client once and share it across all components — they reuse its connection pool and never close it.

```python
import os

from diffbot import Diffbot

db = Diffbot(token=os.environ["DIFFBOT_API_TOKEN"])
```

## Chat model

`ChatDiffbot` wraps Diffbot's LLM RAG endpoint with native streaming support.

```python
import os

from diffbot import Diffbot
from langchain.messages import HumanMessage
from langchain_diffbot import ChatDiffbot

llm = ChatDiffbot(client=Diffbot(token=os.environ["DIFFBOT_API_TOKEN"]))
for chunk in llm.stream([HumanMessage(content="What is the Diffbot Knowledge Graph?")]):
    print(chunk.content, end="", flush=True)
```

## Document loaders

`DiffbotExtractLoader` fetches and structures content from a list of URLs. `DiffbotCrawlLoader` drives a Diffbot crawl job and yields one `Document` per crawled URL (the `page_content` is the URL itself — chain it with `DiffbotExtractLoader` to fetch page content).

```python
from langchain_diffbot import DiffbotCrawlLoader, DiffbotExtractLoader
```
