[Mengram](https://mengram.io) is an AI memory API that gives LLMs and AI agents
persistent memory across conversations. It supports three memory types:

- **Semantic memory** — facts, entities, and knowledge graph relationships
- **Episodic memory** — events, experiences, and their outcomes
- **Procedural memory** — workflows, step-by-step procedures, and learned routines

Mengram automatically extracts and organizes memories from conversations, then
retrieves the most relevant context when your agent needs it. It also generates
a Cognitive Profile — a system prompt built from everything the agent knows about
a user.

## Installation and setup

<CodeGroup>
```bash pip
pip install langchain-mengram
```

```bash uv
uv add langchain-mengram
```
</CodeGroup>

Get your API key at [mengram.io](https://mengram.io).
