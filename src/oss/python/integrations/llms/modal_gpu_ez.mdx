This will help you get started with `ModalGpuEzLLM` using LangChain.

## Overview

`ModalGpuEzLLM` runs any HuggingFace text-generation model on [Modal](https://modal.com) serverless GPUs. It wraps [modal-gpu-ez](https://pypi.org/project/modal-gpu-ez/), which handles GPU selection, model caching, and cost tracking automatically.

### Supported GPUs

| GPU | VRAM | Price/hr |
|-----|------|----------|
| `"T4"` | 16GB | $0.27 |
| `"L4"` | 24GB | $0.59 |
| `"A10G"` | 24GB | $0.54 |
| `"A100"` | 40GB | $1.64 |
| `"H100"` | 80GB | $3.89 |
| `"auto"` | — | auto-select cheapest |
| `"Local"` | — | free (CUDA/MPS/CPU) |

## Setup

### Installation

```bash
pip install langchain-modal-gpu-ez
```

### Credentials

```python
import os

os.environ["MODAL_TOKEN_ID"] = "your_modal_token_id"
os.environ["MODAL_TOKEN_SECRET"] = "your_modal_token_secret"
```

For local-only usage (`gpu="Local"`), no credentials are needed.

## Instantiation

```python
from langchain_modal_gpu_ez import ModalGpuEzLLM

llm = ModalGpuEzLLM(
    model_id="distilgpt2",
    gpu="T4",
    max_new_tokens=100,
)
```

## Invocation

```python
result = llm.invoke("Explain serverless computing in one sentence:")
print(result)
```

## Chaining

```python
from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate.from_template("Explain {topic} for a beginner:")
chain = prompt | llm

result = chain.invoke({"topic": "machine learning"})
print(result)
```

## Local execution

Run on your local GPU (Apple MPS, CUDA, or CPU) at no cost:

```python
llm_local = ModalGpuEzLLM(
    model_id="distilgpt2",
    gpu="Local",
    max_new_tokens=50,
)

result = llm_local.invoke("Python is great because")
```
