DeepKeep middleware applies DeepKeep AI Firewall checks around LangChain agent model calls. Use it to run pre-moderation on user input and post-moderation on model output without changing your agent loop.

## Install

```bash
pip install langchain-deepkeep
```

## Configure credentials

Set the DeepKeep API key and base URL as environment variables, or pass them directly to `DeepKeepMiddleware`:

```bash
export DEEPKEEP_API_KEY="..."
export DEEPKEEP_BASE_URL="..."
```

## Use DeepKeep middleware

Pass `DeepKeepMiddleware` to `create_agent` with at least one DeepKeep firewall ID:

```python
import os

from langchain.agents import create_agent
from langchain_deepkeep import DeepKeepMiddleware

agent = create_agent(
    model="gpt-5.5",
    tools=[],
    middleware=[
        DeepKeepMiddleware(
            api_key=os.environ["DEEPKEEP_API_KEY"],
            base_url=os.environ["DEEPKEEP_BASE_URL"],
            pre_model="input-firewall-id",
            post_model="output-firewall-id",
        )
    ],
)
```

`pre_model` and `post_model` are DeepKeep firewall IDs. Each value is sent to the matching moderation endpoint as the `model` field.

<Accordion title="Configuration options">

<ParamField body="api_key" type="str | None">
    DeepKeep API key. If omitted, the middleware reads `DEEPKEEP_API_KEY`.
</ParamField>

<ParamField body="base_url" type="str | None">
    DeepKeep base URL. If omitted, the middleware reads `DEEPKEEP_BASE_URL`.
</ParamField>

<ParamField body="pre_model" type="str | None">
    DeepKeep firewall ID for pre-moderation of user input before the model call.
</ParamField>

<ParamField body="post_model" type="str | None">
    DeepKeep firewall ID for post-moderation of model output after the model call.
</ParamField>

<ParamField body="title" type="str" default="">
    Optional title value sent to DeepKeep moderation endpoints.
</ParamField>

<ParamField body="chat" type="str" default="">
    Optional chat value sent to DeepKeep moderation endpoints.
</ParamField>

<ParamField body="timeout" type="float" default="30.0">
    Request timeout, in seconds, for DeepKeep API calls.
</ParamField>

</Accordion>
