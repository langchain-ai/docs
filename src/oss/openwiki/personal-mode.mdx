Personal mode builds a local personal brain wiki in `~/.openwiki/wiki` from configured sources such as local repositories, Gmail, Notion, web search, Hacker News, and X/Twitter.

```bash
openwiki personal
openwiki personal --init
openwiki personal --update
openwiki personal --update "Refresh the wiki from configured connectors"
```

## First-run onboarding

On first interactive personal setup, OpenWiki can:

- Configure an inference provider, API key, and model
- Optionally set a LangSmith API key
- Offer connector setup for supported sources
- Let you choose a wiki template, customize its scope, and save per-source ingestion notes and schedules

Global personal wiki instructions are saved in `~/.openwiki/INSTRUCTIONS.md`. Onboarding and schedule metadata are stored in `~/.openwiki/onboarding.json`. On macOS, source schedules can be installed as user LaunchAgents under `~/Library/LaunchAgents/` with logs under `~/.openwiki/logs/`.

## Connectors

During an ingestion run, connector tools write raw data and manifests under `~/.openwiki/connectors/<connector>/raw/`, then source-specific agent runs synthesize the local wiki under `~/.openwiki/wiki/` from those local files.

You can configure the same connector more than once. For example, add one web search source for AI research and another for NBA news. OpenWiki stores them as separate source instances such as `web-search-1` and `web-search-2`.

```bash
openwiki ingest all
openwiki ingest web-search
openwiki ingest web-search-2
```

For connector details, auth flows, and credential notes, see [Connectors](/oss/openwiki/connectors).

## Manage schedules

On macOS, manage connector schedules with:

```bash
openwiki cron list
openwiki cron pause <source|all>
openwiki cron resume <source|all>
openwiki cron delete <source|all>
```

`cron delete` removes schedule metadata. It does not remove auth, connector config, raw data, or wiki content.
