# Neuralwatt

>[Neuralwatt](https://neuralwatt.com) is an energy-aware AI inference platform that provides
>OpenAI-compatible access to large language models while measuring and attributing the real
>GPU energy consumed by every request. Each response includes per-call energy and carbon
>metrics, making it easy to track the environmental footprint of AI workloads.

## Installation

```bash
pip install langchain-neuralwatt
```

Get your API key at [neuralwatt.com](https://neuralwatt.com).

## Configuration

```python
import os
os.environ["NEURALWATT_API_KEY"] = "your-api-key"
```

## Chat model

See the [ChatNeuralwatt integration page](/oss/python/integrations/chat/neuralwatt) for full details.

```python
from langchain_neuralwatt import ChatNeuralwatt

llm = ChatNeuralwatt(model="glm-5-fast")
response = llm.invoke("What is the carbon footprint of a typical LLM inference request?")

# Access per-call energy metadata
energy = response.response_metadata.get("energy", {})
print(f"{energy.get('energy_kwh', 0):.6f} kWh")
print(f"{energy.get('carbon_g_co2eq', 0):.4f} g CO₂eq")
```
