# Fodda

>[Fodda](https://fodda.ai) is an authoritative context layer providing verified knowledge graphs, corporate earnings intelligence, and working Human Agents for autonomous AI models.

## Installation

```bash
pip install langchain-fodda
```

## Configuration

Configure your environment variable with your Fodda API key:

```python
import os

os.environ["FODDA_API_KEY"] = "sk_live_..."
```

Or pass the key directly when instantiating:

```python
from langchain_fodda import FoddaContextRetriever

fodda_tool = FoddaContextRetriever(api_key="sk_live_...")
```

## Tools

### FoddaContextRetriever

`FoddaContextRetriever` provides agents with direct access to curated domain knowledge graphs and analyst intelligence. It automatically handles HTTP 402 payment challenges and falls back to verified markdown schema summaries when credentials are unconfigured, preventing reasoning loops from crashing.

```python
from langchain_fodda import FoddaContextRetriever

# Initialize tool
fodda_tool = FoddaContextRetriever()

# Query a knowledge graph by slug
result = fodda_tool.run("psfk-retail")
print(result)
```

### In a LangChain Agent

```python
from langchain_fodda import FoddaContextRetriever
from langchain.agents import create_agent

tools = [FoddaContextRetriever()]
# Pass tools to your agent executor
```

## Capabilities and Settlement

- **Autonomous 402 Paywall Handling**: Catches HTTP 402 challenges. Unauthenticated requests receive verified schema summaries (`free_readme`) so the model continues reasoning without halting.
- **Base USDC Micro-Settlement**: Supports autonomous on-chain 5¢ Base USDC payments via `X-402-Payment`.
- **Enterprise Delegated Billing**: Supports zero-friction enterprise billing and delegated account budgets.
