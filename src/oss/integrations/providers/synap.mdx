>[Synap](https://maximem.ai) is a managed long-term memory layer for AI agents.
>It automatically extracts and structures knowledge from conversations — facts,
>preferences, episodes, emotions, and temporal events — and retrieves only what
>is relevant to the current query. Agents remember users across sessions
>without manual bookkeeping.

## Installation

```bash
pip install maximem-synap-langchain
```

Get your API key at [synap.maximem.ai](https://synap.maximem.ai).

## Configuration

```python
import os
os.environ["SYNAP_API_KEY"] = "your-api-key"
```

Or pass the SDK directly:

```python
from maximem_synap import MaximemSynapSDK

sdk = MaximemSynapSDK(api_key="your-api-key")
```

## Integration surfaces

`maximem-synap-langchain` provides five surfaces — pick the one that matches your chain:

| Surface | Class / Function | Use when |
|---------|------------------|----------|
| Chat history | `SynapChatMessageHistory` | Drop-in `BaseChatMessageHistory` for `RunnableWithMessageHistory` |
| Retriever | `SynapRetriever` | RAG pipelines that need typed long-term memory items |
| Agent tools | `SynapSearchTool`, `SynapStoreTool` | Let the LLM explicitly search or write to memory |
| Callbacks | `SynapCallbackHandler` | Zero-config auto-recording of user / AI turns |
| LangGraph node | `create_synap_node` | Inject Synap context into graph state |

### Chat message history

```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.runnables.history import RunnableWithMessageHistory
from langchain_openai import ChatOpenAI
from maximem_synap import MaximemSynapSDK
from synap_langchain import SynapChatMessageHistory

sdk = MaximemSynapSDK(api_key="your-api-key")

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant with long-term memory."),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{input}"),
])
chain = prompt | ChatOpenAI()

chain_with_memory = RunnableWithMessageHistory(
    chain,
    lambda session_id: SynapChatMessageHistory(
        sdk=sdk,
        session_id=session_id,
        user_id="alice",
        customer_id="acme_corp",
    ),
    input_messages_key="input",
    history_messages_key="history",
)
```

### Retriever

```python
from synap_langchain import SynapRetriever

retriever = SynapRetriever(
    sdk=sdk,
    user_id="alice",
    customer_id="acme_corp",
)
docs = retriever.invoke("What does the user prefer for breakfast?")
```

### Agent tools

```python
from langchain.agents import AgentExecutor, create_tool_calling_agent
from synap_langchain import SynapSearchTool, SynapStoreTool

tools = [
    SynapSearchTool(sdk=sdk, user_id="alice", customer_id="acme_corp"),
    SynapStoreTool(sdk=sdk, user_id="alice", customer_id="acme_corp"),
]
agent = create_tool_calling_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools)
```

### Callbacks — zero-config recording

```python
from synap_langchain import SynapCallbackHandler

handler = SynapCallbackHandler(
    sdk=sdk,
    user_id="alice",
    customer_id="acme_corp",
)
chain.invoke({"input": "Hi"}, config={"callbacks": [handler]})
```

### LangGraph node

```python
from langgraph.graph import StateGraph
from synap_langchain import create_synap_node

graph = StateGraph(MyState)
graph.add_node(
    "memory",
    create_synap_node(sdk, user_id="alice", customer_id="acme_corp"),
)
```

## Scoping

Memory is scoped to `user_id` and `customer_id`, ensuring strict isolation in
multi-tenant applications — one customer's memories never leak into another's.
