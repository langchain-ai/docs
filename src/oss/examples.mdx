LangChain and LangGraph are powerful open-source libraries for building LLM applications. LangChain provides the foundational components and abstractions, while LangGraph enables you to build stateful, multi-actor applications with complex workflows. These examples demonstrate real-world patterns and use cases for building production-ready applications.

## All Examples

| Example | Description | Experience Level | Repository |
|---------|-------------|------------------|------------|
| LangSmith PII Removal | Demonstrates the various ways that users can mask PII using the LangSmith SDK. | Beginner | [GitHub](https://github.com/langchain-ai/langsmith-pii-removal/tree/main) |
| Multi-Supervisor Commerce Agent | A simple multi-agent ecommerce system built with LangChain and LangGraph. A top-level supervisor routes customer queries to specialized business unit (BU) supervisors that focus on billing & payments, order management, and promotions & loyalty tasks. | Intermediate | [GitHub](https://github.com/j-broekhuizen/ecommerce) |
| LS Multi-Project Tracing | A LangGraph agent that routes LangSmith traces to different workspaces based on configuration. Perfect for multi-tenant applications or testing across different environments. | Intermediate | [GitHub](https://github.com/victorm-lc/ls-deployments-multi-project-tracing) |
| Distributed Tracing [Remote Graph] | Demonstrates proper implementation of distributed tracing between a supervisor (parent) graph and a subagent (child/remote) graph using LangGraph. | Intermediate | [GitHub](https://github.com/victorm-lc/remote-graph-distributed-tracing) |
| LangGraph Fault Tolerance | Demonstrates LangGraph's fault tolerance mechanism using pending writes to handle partial failures in parallel execution workflows. | Intermediate | [GitHub](https://github.com/j-broekhuizen/langgraph-fault-tolerance) |
| LangSmith CI/CD Example | Shows how to setup CI/CD for a LangSmith Deployment with unit, integration, e2e tests, offline evaluations, and preview and prod agent deployments using the control plane API. | Advanced | [GitHub](https://github.com/langchain-ai/cicd-pipeline-example) |
| LangSmith On-Demand Agent Auth | Demonstrates the new Agent OAuth Authentication capabilities in LangSmith, showcasing how to build intelligent agents that can securely authenticate with external services like GitHub and access user data on-demand. | Advanced | [GitHub](https://github.com/PeriniM/agent-auth-example/tree/main) |
| LangSmith MCP Auth | End-to-end example of user authentication for LangGraph agents that interact with MCP servers using individual user credentials. | Advanced | [GitHub](https://github.com/victorm-lc/mcp-auth-demo) |

<Tip>
  These examples link to repositories with complete implementations and best practices to help you build production-ready applications with LangChain and LangGraph.
